# 🚀 CodeRush - Бесплатная образовательная платформа

---

## 🇷🇺 О проекте

**CodeRush** - это полностью бесплатная платформа для изучения программирования с нуля до уровня, достаточного для первой работы. Без платных подписок, дедлайнов и сложной регистрации. Учитесь в своём темпе!

Проект написан на чистом **HTML, CSS и JavaScript** без использования сборщиков и тяжелых фреймворков. Все данные (курсы, словарь, тренажёры) хранятся в JSON-файлах. Прогресс обучения сохраняется локально в браузере (`localStorage`), поэтому регистрация не требуется.

**Что внутри:**
*   📚 **Курсы:** C#, Python, JavaScript, Кибербезопасность, Вёрстка сайтов, SQL, Нейросети и не только.
*   🪜 **Три уровня:** В каждом курсе есть начальный, средний и продвинутый уровни.
*   🎮 **Тренажёры:** Интерактивные инструменты для слепой печати и изучения горячих клавиш IDE.
*   📖 **Словарь:** База знаний с понятными объяснениями сложных IT-терминов.

**Ссылка на сайт:** [ghostfromcastle.github.io/CodeRush/](https://ghostfromcastle.github.io/CodeRush/)

> **Важное примечание:** Проект развивается силами энтузиастов. Мы не гарантируем бесперебойную работу сайта и постоянный выход обновлений. Некоторые курсы, уроки или элементы интерфейса могут временно не работать. Просим отнестись с пониманием!

# 🚀 CodeRush - Free educational platform

## 🇬🇧 About the project

**CodeRush** is a completely free platform for learning programming from scratch to a job-ready level. No paid subscriptions, no deadlines, and no complex registration. Learn at your own pace!

The project is built with pure **HTML, CSS, and JavaScript** without any build tools or heavy frameworks. All data (courses, dictionary, trainers) is stored in JSON files. Learning progress is saved locally in the browser (`localStorage`), so no registration is required.

**Features:**
*   📚 **Courses:** C#, Python, JavaScript, Cybersecurity, HTML/CSS, SQL, AI and not only.
*   🪜 **Three levels:** Each course has beginner, intermediate, and advanced levels.
*   🎮 **Trainers:** Interactive tools for touch typing and learning IDE hotkeys.
*   📖 **Dictionary:** A knowledge base with clear explanations of complex IT terms.

**Live Demo:** [ghostfromcastle.github.io/CodeRush/](https://ghostfromcastle.github.io/CodeRush/)

> **Important note:** This project is developed by enthusiasts. We do not guarantee uninterrupted operation or regular updates. Some courses, lessons, or UI elements may be temporarily unavailable. We appreciate your understanding!
