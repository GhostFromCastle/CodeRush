# Политика безопасности / Security Policy

---

## 🇷🇺 Русская версия

### Поддерживаемые версии

Проект CodeRush находится в активной разработке. Мы поддерживаем безопасность только в актуальной версии кода, которая находится в ветке `main` и развернута на GitHub Pages.

| Версия | Поддерживается |
| ------ | -------------- |
| main   | Да             |
| < main | Нет            |

### Как сообщить об уязвимости

Если вы обнаружили уязвимость в коде проекта (например, XSS в тренажёрах, проблему с обработкой данных или случайно оставленные секреты), пожалуйста, сообщите об этом ответственно.

**Как связаться:**
1. Используйте функцию **Private vulnerability reporting** прямо на GitHub (вкладка Security -> Advisories).
2. Либо напишите напрямую в Telegram: [@GhostFromCastle](https://t.me/GhostFromCastle).

Пожалуйста, не создавайте публичные Issues с описанием уязвимости.

**Чего ожидать:**
- Мы постараемся подтвердить получение вашего сообщения в течение 24-48 часов.
- Если уязвимость подтвердится, мы выпустим исправление в ветку `main` в ближайшее время.
- После исправления мы будем рады указать ваше имя в списке благодарностей (если вы этого хотите).

Спасибо, что помогаете делать проект безопаснее!

## 🇬🇧 English version

### Supported Versions

CodeRush is under active development. We only support the security of the current codebase located in the `main` branch and deployed on GitHub Pages.

| Version | Supported |
| ------- | --------- |
| main    | Yes       |
| < main  | No        |

### Reporting a Vulnerability

If you discover a vulnerability in the project code (e.g., XSS in trainers, data handling issues, or accidentally exposed secrets), please report it responsibly.

**How to report:**
1. Use the **Private vulnerability reporting** feature directly on GitHub (Security tab -> Advisories).
2. Or contact us directly on Telegram: [@GhostFromCastle](https://t.me/GhostFromCastle).

Please do not create public Issues describing the vulnerability.

**What to expect:**
- We will try to acknowledge your report within 24-48 hours.
- If the vulnerability is confirmed, we will release a fix to the `main` branch as soon as possible.
- After the fix, we will gladly credit you in our acknowledgments (if you wish).

Thank you for helping make the project safer!
