SQL и базы данных

Данные, а не догадки

Excel заканчивается там, где начинаются связи между таблицами, сотни тысяч строк и несколько пользователей одновременно. SQL - язык, на котором говорят все серьёзные базы данных: от SQLite в телефоне до PostgreSQL и Oracle в банках.
