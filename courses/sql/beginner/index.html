Начальный уровень

С нуля

Для всех, кто ни разу не писал запросов. Начнём с вопроса «зачем нужна база, если есть Excel», поставим настоящую СУБД и дойдём до группировки, подсчётов и изменения данных. Каждый запрос можно выполнить сразу - всё показываем на конкретных таблицах.

6 уроков ~4 часа Для новичков
01

Зачем нужны базы данных и что такое SQL

Таблицы, строки, столбцы, СУБД и чем база отличается от Excel.
02

Установка и первый запрос

SQLite, DB Browser и первая таблица. Команда SELECT и её результат.
03

SELECT: столбцы, псевдонимы, сортировка

Выбор полей, AS, DISTINCT, ORDER BY и LIMIT.
04

WHERE: фильтруем строки

Сравнения, AND/OR, BETWEEN, IN, LIKE и работа с NULL.
05

Агрегаты, GROUP BY и HAVING

COUNT, SUM, AVG, MIN, MAX и группировка с фильтром по группам.
06

INSERT, UPDATE, DELETE

Добавление, изменение и удаление записей. Опасность DELETE без WHERE.
