Функции: строки, даты, NULL и CASE

~30 минут Средний уровень Теория и Практика

Данные редко лежат в идеальном виде. Имена приходят в разном регистре, даты - строками, пустые значения мешают расчётам. Функции SQL приводят всё это в порядок прямо в запросе.

В этом уроке мы:

  • Разберём строковые функции.
  • Научимся работать с датами.
  • Поймём COALESCE и CASE.
  • Освоим приведение типов через CAST.
Аналогия

Кухонный комбайн: одни и те же продукты можно нарезать, взбить или перемолоть. Функции делают то же с данными.

Строки

SELECT    UPPER(name)              AS upper_name,    LOWER(email)             AS lower_email,    LENGTH(name)             AS name_length,    TRIM('  Анна  ')         AS trimmed,    SUBSTR(email, 1, 5)      AS email_start,    REPLACE(phone, '-', '')  AS phone_digitsFROM users;
  • UPPER / LOWER - регистр.
  • LENGTH - длина в символах (в MySQL - CHAR_LENGTH).
  • TRIM - убирает пробелы по краям.
  • SUBSTR - подстрока с позиции (нумерация с 1!).
  • REPLACE - замена всех вхождений.

Склейка:

-- SQLite, PostgreSQL, OracleSELECT name || ' <' || email || '>' AS contact FROM users;-- MySQLSELECT CONCAT(name, ' <', email, '>') AS contact FROM users;

Числа и округление

SELECT    ROUND(price * 1.2, 2) AS with_vat,    ABS(balance)          AS absolute,    CAST(price AS REAL)   AS as_realFROM products;

Важно: ROUND в разных СУБД округляет по-разному в спорных случаях (0.5 вверх или к чётному). Для денег надёжнее хранить копейки целым числом, а делить только при выводе.

Даты

Функции дат сильнее всего отличаются между СУБД. Покажем три варианта:

-- SQLiteSELECT DATE('now')                       AS today;SELECT STRFTIME('%Y-%m', created_at)     AS month;SELECT DATE('now', '+7 days')            AS in_week;-- PostgreSQLSELECT CURRENT_DATE                      AS today;SELECT DATE_TRUNC('month', created_at)   AS month;SELECT CURRENT_DATE + INTERVAL '7 days'  AS in_week;-- MySQLSELECT CURDATE()                         AS today;SELECT DATE_FORMAT(created_at, '%Y-%m')  AS month;SELECT DATE_ADD(CURDATE(), INTERVAL 7 DAY) AS in_week;

Разница дат:

-- SQLite: разница в дняхSELECT JULIANDAY('2026-12-31') - JULIANDAY('2026-01-01');-- PostgreSQLSELECT DATE '2026-12-31' - DATE '2026-01-01';
Даты и группировка

Если хранить дату со временем, GROUP BY created_at даст группу на каждую секунду. Сначала обрежьте до дня или месяца: GROUP BY DATE(created_at) в SQLite или DATE_TRUNC('day', created_at) в PostgreSQL.

NULL: COALESCE

COALESCE возвращает первое непустое значение:

SELECT    name,    COALESCE(phone, 'не указан') AS phoneFROM users;

Так же считают суммы с пустыми значениями:

SELECT COALESCE(SUM(price), 0) AS totalFROM ordersWHERE customer_id = 999; -- заказов нет

Без COALESCE результат был бы NULL, а не 0. В MySQL есть IFNULL, в SQL Server - ISNULL, но COALESCE работает везде.

CASE

Аналог if/else внутри запроса:

SELECT    title,    price,    CASE        WHEN price < 1000  THEN 'дешёвый'        WHEN price < 30000 THEN 'средний'        ELSE 'дорогой'    END AS price_categoryFROM products;

Частый приём - условная агрегация:

SELECT    COUNT(*) AS total_orders,    SUM(CASE WHEN status = 'paid' THEN 1 ELSE 0 END) AS paid_ordersFROM orders;

Так одним запросом считают несколько показателей без отдельных подзапросов.

CAST

SELECT CAST('42' AS INTEGER) + 8 AS result;  -- 50SELECT CAST(price AS TEXT) AS price_text FROM products;

Приведение нужно, когда число пришло строкой (например, из CSV) или когда нужно склеить число с текстом в строгой СУБД.

Шпаргалка

  • UPPER / LOWER регистр
  • SUBSTR подстрока
  • COALESCE первое непустое
  • CASE WHEN условие в запросе
  • CAST приведение типа
  • DATE / DATE_TRUNC обрезать дату

Если что-то не работает

  • «no such function». Функция называется иначе в вашей СУБД. Сверьтесь с документацией.
  • SUBSTR вернул не то. Позиции начинаются с 1, а не с 0.
  • Сумма равна NULL. Все значения пустые. Оберните в COALESCE.
  • Дата сравнивается как строка. Формат YYYY-MM-DD сортируется правильно, а DD.MM.YYYY - нет.
  • CASE вернул NULL. Ни одно условие не совпало, а ELSE не указан.
  • «В отчёте пустые ячейки». Это не пустая строка, а NULL: конкатенация с ним даёт NULL. Оборачивайте в COALESCE.

Практика

Задача 1. Красивый контакт

Выведите строку вида «Анна <anna@example.com>» для всех пользователей. Если почта не указана - подставьте «нет почты».

Подсказка

Склейка через || и COALESCE(email, 'нет почты').

Решение учителя 
SELECT name || ' <' || COALESCE(email, 'нет почты') || '>' AS contactFROM users;
Задача 2. Категории цен

Разметьте товары: до 1000 - «бюджет», от 1000 до 30000 - «стандарт», дороже - «премиум». Посчитайте количество товаров в каждой категории.

Подсказка

Сначала CASE в подзапросе, затем GROUP BY по получившейся категории.

Решение учителя 
SELECT category, COUNT(*) AS products_countFROM (    SELECT CASE        WHEN price < 1000  THEN 'бюджет'        WHEN price < 30000 THEN 'стандарт'        ELSE 'премиум'    END AS category    FROM products) AS tGROUP BY category;
Задача 3. Продажи по месяцам

Посчитайте количество заказов и сумму по месяцам. Даты хранятся в created_at в формате ISO.

Подсказка

В SQLite: STRFTIME('%Y-%m', created_at). В PostgreSQL: TO_CHAR(created_at, 'YYYY-MM').

Решение учителя 
SELECT    STRFTIME('%Y-%m', created_at) AS month,    COUNT(*)                      AS orders_count,    SUM(price)                    AS revenueFROM ordersGROUP BY monthORDER BY month;
Задача 4. Подпись пользователя

Выведите строку «Анна (25 лет)». Если возраст неизвестен - «Анна (возраст не указан)».

Подсказка

Склейте имя и COALESCE(age || ' лет', 'возраст не указан').

Решение учителя 
SELECT    name || ' (' || COALESCE(age || ' лет', 'возраст не указан') || ')' AS labelFROM users;
