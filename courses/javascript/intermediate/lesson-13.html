Современный синтаксис ES6+

~25 минут Средний уровень Теория и Практика

JavaScript развивается, и с 2015 года язык получил много синтаксического сахара. Он не добавляет новых возможностей, но делает код короче и понятнее. В этом уроке - приёмы, которые встречаются в каждом современном проекте.

В этом уроке мы:

  • Разберём деструктуризацию объектов и массивов.
  • Поймём разницу между spread и rest.
  • Научимся безопасно обращаться к вложенным данным через ?. и ??.
  • Познакомимся с Map и Set.
Аналогия

Швейцарский нож: те же инструменты, что и раньше, но компактнее и всегда под рукой.

Деструктуризация объектов

Мы уже видели базовую форму. Добавим детали:

const user = {    name: "Алексей",    age: 25,    address: { city: "Москва" }};const { name, age } = user;const { address: { city } } = user;   // вложеннаяconst { name: userName } = user;      // переименованиеconst { email = "нет" } = user;       // значение по умолчанию

Значение по умолчанию срабатывает, только если свойства нет или оно undefined. Если там null или пустая строка, останется как есть.

Деструктуризация массивов

Работает по позиции, а не по имени:

const colors = ["red", "green", "blue"];const [first, second] = colors;console.log(first, second); // red greenconst [, , third] = colors;  // пропускаем первые дваconsole.log(third);          // blueconst [head, ...tail] = colors;console.log(head); // redconsole.log(tail); // ["green", "blue"]

Этот приём часто используется для обмена значений:

let a = 1;let b = 2;[a, b] = [b, a];console.log(a, b); // 2 1

Spread: разворачиваем

Три точки перед коллекцией «раскрывают» её содержимое:

const first = [1, 2, 3];const second = [4, 5];const all = [...first, ...second];console.log(all); // [1, 2, 3, 4, 5]const user = { name: "Алексей", age: 25 };const updated = { ...user, age: 26, city: "Москва" };console.log(updated); // { name: "Алексей", age: 26, city: "Москва" }

В объектах свойства применяются по порядку: если ключ встречается дважды, побеждает последний. Именно поэтому { ...user, age: 26 } обновляет возраст, не меняя остальное.

Копия неглубокая

{ ...user } копирует только верхний уровень. Вложенный user.address останется той же ссылкой: изменение адреса в копии изменит и оригинал. Для глубокого копирования используют structuredClone(obj).

Rest: собираем

Те же три точки, но в другом месте - в параметрах функции - собирают аргументы в массив:

function sum(...numbers) {    return numbers.reduce((total, n) => total + n, 0);}console.log(sum(1, 2, 3, 4)); // 10

Rest всегда идёт последним. Такой приём удобен для функций с произвольным числом аргументов:

function logMessage(level, ...messages) {    console.log(`[${level}]`, ...messages);}logMessage("INFO", "сервер", "запущен");

Опциональная цепочка ?.

Классическая проблема: данные приходят с сервера неполными. Попытка прочитать user.address.city, когда адреса нет, обрушит программу. Оператор ?. решает это элегантно:

const user = { name: "Алексей" };console.log(user.address?.city);      // undefined, без ошибкиconsole.log(user.address?.city?.name); // undefined

Он же работает с вызовами функций и индексами массива:

user.greet?.();        // вызов, только если метод существуетitems?.[0];            // безопасный доступ по индексу

Важно: ?. защищает только тот шаг, где стоит. Если нужна защита всей цепочки, ставьте его на каждом потенциально пустом звене.

Оператор ??

Для значений по умолчанию часто используют ||, но у него есть недостаток: 0, "" и false считаются ложными и тоже заменяются. Оператор ?? подставляет значение только при null и undefined:

const count = 0;console.log(count || 10);  // 10 - неправильно, ноль потерянconsole.log(count ?? 10);  // 0  - правильно

Правило простое: если ноль и пустая строка - валидные значения, используйте ??.

Сокращённые свойства и вычисляемые ключи

const name = "Алексей";const age = 25;const user = { name, age }; // вместо { name: name, age: age }const field = "email";const data = {    [field]: "alex@example.com" // ключ из переменной};console.log(data.email); // "alex@example.com"

Map

Map - коллекция «ключ: значение», где ключом может быть что угодно, не только строка. В отличие от обычного объекта, она сохраняет порядок вставки и знает свой размер:

const visits = new Map();visits.set("Аня", 3);visits.set("Борис", 7);console.log(visits.get("Аня"));  // 3console.log(visits.has("Вера")); // falseconsole.log(visits.size);        // 2visits.delete("Борис");for (const [name, count] of visits) {    console.log(`${name}: ${count}`);}

Когда использовать Map вместо объекта? Когда ключи динамические, часто добавляются и удаляются, или когда нужен именно размер коллекции.

Set

Set - коллекция уникальных значений. Идеально для удаления дубликатов:

const numbers = [1, 2, 2, 3, 3, 3];const unique = [...new Set(numbers)];console.log(unique); // [1, 2, 3]const tags = new Set(["js", "css"]);tags.add("html");tags.add("js"); // уже есть - ничего не изменитсяconsole.log(tags.size);        // 3console.log(tags.has("css"));  // true

Шпаргалка

  • const { a, b } = obj деструктуризация объекта
  • const [a, b] = arr деструктуризация массива
  • ...arr развернуть или собрать
  • obj?.prop безопасный доступ
  • value ?? default значение по умолчанию для null
  • new Map() коллекция ключ-значение
  • new Set() коллекция уникальных значений

Если что-то не работает

  • || подставил значение вместо нуля. Используйте ??.
  • Изменился оригинал после spread. Копия поверхностная: вложенные объекты общие. Нужен structuredClone.
  • «Rest parameter must be last». ...rest может стоять только последним в списке параметров.
  • ?. не спасает. Он защищает только свой шаг цепочки. Ставьте его на каждом звене, которое может быть пустым.
  • Set не удалил дубликаты объектов. Он сравнивает по ссылке: два одинаковых по содержанию объекта - разные значения.
  • Ноль превратился в 16. Для значения по умолчанию использовали ||, а он считает 0 и пустую строку ложными. Если ноль - валидное значение, нужен ??.

Практика

Задача 1. Настройки

Есть объект настроек { theme: "dark", fontSize: 0 }. Напишите функцию getSettings(userSettings), которая возвращает настройки с дефолтами { theme: "light", fontSize: 16 }. Ноль должен сохраняться.

Подсказка

Соберите результат через spread и ??: { theme: userSettings.theme ?? "light", ... }. Не используйте ||, иначе ноль превратится в 16.

Решение учителя 
function getSettings(userSettings = {}) {    return {        theme: userSettings.theme ?? "light",        fontSize: userSettings.fontSize ?? 16    };}console.log(getSettings({ theme: "dark", fontSize: 0 }));// { theme: "dark", fontSize: 0 }
Задача 2. Сумма аргументов

Напишите функцию sumAll, которая принимает любое количество чисел и возвращает их сумму. Проверьте на sumAll(1, 2, 3, 4, 5).

Подсказка

Используйте rest-параметр ...numbers и метод reduce с начальным значением 0.

Решение учителя 
function sumAll(...numbers) {    return numbers.reduce((total, n) => total + n, 0);}console.log(sumAll(1, 2, 3, 4, 5)); // 15
Задача 3. Уникальные теги

Дан массив тегов с повторами: ["js", "css", "js", "html", "css"]. Получите массив уникальных значений, отсортированный по алфавиту.

Подсказка

new Set(tags) уберёт повторы, spread превратит обратно в массив, sort() отсортирует строки по алфавиту.

Решение учителя 
const tags = ["js", "css", "js", "html", "css"];const unique = [...new Set(tags)].sort();console.log(unique); // ["css", "html", "js"]
Задача 4. Настройки с приоритетом

Объедините настройки по умолчанию { theme: "light", size: 16 } и пользовательские { theme: "dark" } так, чтобы пользовательское значение победило.

Подсказка

Spread применяет свойства по порядку: побеждает последнее.

Решение учителя 
const defaults = { theme: "light", size: 16 };const user = { theme: "dark" };const settings = { ...defaults, ...user };console.log(settings); // { theme: "dark", size: 16 }
