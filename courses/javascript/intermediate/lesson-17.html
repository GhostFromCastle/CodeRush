Регулярные выражения

~30 минут Средний уровень Теория и Практика

Регулярные выражения - это язык описания шаблонов текста. Одна короткая строка вроде /\d{3}-\d{2}/ заменяет десяток условий с includes и slice. Выглядят они пугающе, но на деле это просто набор правил: «цифра, цифра, дефис, цифра...».

В этом уроке мы:

  • Научимся читать и составлять простые регулярки.
  • Разберём методы test, match, replace.
  • Поймём флаги и группы.
  • Соберём готовые шаблоны для телефона, даты и slug.
Аналогия

Трафарет: одна форма подходит ко множеству надписей. Регулярное выражение - трафарет для текста.

Зачем это нужно

Сравните две проверки телефона:

const phone = "+79991234567";// без регуляркиconst digits = phone.slice(2);const ok = phone.startsWith("+7") && digits.length === 10 && !isNaN(Number(digits));// с регуляркойconst okRegex = /^\+7\d{10}$/.test(phone);

Второй вариант короче и точнее: он проверяет всю строку целиком, а не только длину.

Создание и метод test

Регулярное выражение записывают между слешами. Метод test возвращает true или false:

const hasDigits = /\d/;console.log(hasDigits.test("abc123")); // trueconsole.log(hasDigits.test("abc"));    // false

Второй способ - конструктор new RegExp. Он нужен, когда шаблон собирается из переменной:

const word = "кот";const regex = new RegExp(word, "i");console.log(regex.test("У нас живёт КОТ")); // true

Флаги

/\d/      // первое совпадение/\d/g     // все совпадения (global)/кот/i    // без учёта регистра (insensitive)/^кот/m   // ^ и $ работают в каждой строке (multiline)

Флаг g критичен для match и replace: без него вы получите только первое совпадение.

Классы символов

\d      цифра 0-9\D      не цифра\w      буква, цифра или _\s      пробел, таб, перевод строки.       любой символ, кроме перевода строки[abc]   любой из символов a, b, c[^abc]  любой, кроме a, b, c[а-я]   диапазон: любая русская строчная буква

Пример: проверим, что в строке есть хотя бы одна заглавная латинская буква:

console.log(/[A-Z]/.test("приветМир")); // trueconsole.log(/[A-Z]/.test("привет мир")); // false

Квантификаторы: сколько раз

\d?      ноль или один раз\d*      ноль или больше\d+      один или больше\d{3}    ровно три\d{2,5}  от двух до пяти\d{2,}   два или больше

Квантификатор применяется к предыдущему символу или группе:

console.log(/^\d{3}-\d{2}-\d{2}$/.test("123-45-67")); // trueconsole.log(/^\d{3}-\d{2}-\d{2}$/.test("123-456-7")); // false

Якоря

^    начало строки$    конец строки\b   граница слова

Без якорей проверка «найдено где-то внутри» может пропустить мусор: /\d+/.test("abc123def") вернёт true. Если нужна строгая проверка формата - оборачивайте шаблон в ^...$.

Группы и альтернация

// альтернация: илиconsole.log(/^(да|нет)$/.test("да")); // true// группа захватаconst date = "2026-10-30";const match = date.match(/^(\d{4})-(\d{2})-(\d{2})$/);console.log(match[1]); // "2026"console.log(match[2]); // "10"console.log(match[3]); // "30"

Именованные группы читаются лучше:

const result = date.match(/^(?<year>\d{4})-(?<month>\d{2})-(?<day>\d{2})$/);console.log(result.groups.year);  // "2026"console.log(result.groups.month); // "10"

Методы строк с регулярками

const text = "Цены: 100, 250 и 399 рублей";console.log(text.match(/\d+/g));      // ["100", "250", "399"]console.log(text.search(/\d+/));      // индекс первого числаconsole.log("2026-10-30".replace(/(\d{4})-(\d{2})-(\d{2})/, "$3.$2.$1"));// "30.10.2026"console.log("a1b2c3".split(/\d/));    // ["a", "b", "c", ""]

matchAll возвращает все совпадения вместе с группами - удобно для разбора текста:

const pairs = "яблоко: 3, груша: 5";const regex = /(?<fruit>\w+):\s*(?<count>\d+)/g;for (const match of pairs.matchAll(regex)) {    console.log(`${match.groups.fruit} - ${match.groups.count}`);}

Готовые шаблоны

Простейшая проверка почты (не идеальная, но рабочая для форм):

const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]{2,}$/;console.log(emailRegex.test("alex@example.com")); // trueconsole.log(emailRegex.test("alex@example"));     // false

Российский телефон:

const phoneRegex = /^\+7\d{10}$/;

Slug для адреса страницы:

function slugify(title) {    return title        .toLowerCase()        .trim()        .replace(/\s+/g, "-")        .replace(/[^a-zа-я0-9-]/g, "");}console.log(slugify("Как выучить JavaScript за месяц"));// "как-выучить-javascript-за-месяц"
Три классические ловушки

1. Флаг g у регулярки хранит состояние: повторный test с тем же объектом может вернуть false. Создавайте регулярку заново или не используйте g с test. 2. Точка не совпадает с переводом строки - для этого есть флаг s. 3. Сложные вложенные квантификаторы вроде (a+)+$ могут «подвесить» страницу на неудачной строке - это называется катастрофическим бэктрекингом.

Шпаргалка

  • \d цифра
  • \w буква, цифра, _
  • \s пробельный символ
  • + * ? {n,m} количество повторений
  • ^ $ начало и конец строки
  • test есть ли совпадение
  • match найти совпадения

Если что-то не работает

  • Регулярка «не находит» очевидное. Проверьте флаг i и регистр, а также якоря: возможно, шаблон требует совпадения всей строки.
  • test то true, то false. У регулярки с флагом g сохраняется позиция поиска. Уберите g или создавайте выражение заново.
  • / внутри шаблона ломает код. Экранируйте: \/, либо используйте new RegExp("/").
  • Обратный слеш «съедается». В строковом литерале нужен двойной: "\\d+", а в литерале регулярки - одинарный: /\d+/.
  • match вернул null. Совпадений нет - проверяйте результат до обращения к [0].
  • Регулярка работает в консоли, но «ломается» на форме. Если у выражения флаг g, оно запоминает позицию поиска между вызовами. Для проверки одного значения флаг не нужен.

Практика

Задача 1. Телефон

Напишите функцию isPhone(value), которая принимает номер в формате +79991234567 и возвращает true только для корректного номера.

Подсказка

Шаблон: ^\+7\d{10}$. Не забудьте экранировать плюс - в регулярках он означает квантификатор.

Решение учителя 
function isPhone(value) {    return /^\+7\d{10}$/.test(value.trim());}console.log(isPhone("+79991234567"));  // trueconsole.log(isPhone("89991234567"));   // falseconsole.log(isPhone("+7999123456"));   // false
Задача 2. Все числа из текста

Из строки «Заказ 12, доставка 350 рублей, скидка 15%» получите массив чисел и посчитайте их сумму.

Подсказка

match(/\d+/g) вернёт массив строк. Преобразуйте каждую через Number и сложите через reduce.

Решение учителя 
const text = "Заказ 12, доставка 350 рублей, скидка 15%";const numbers = text.match(/\d+/g).map(Number);const sum = numbers.reduce((total, n) => total + n, 0);console.log(numbers); // [12, 350, 15]console.log(sum);     // 377
Задача 3. Дата в другом формате

Превратите "2026-10-30" в "30.10.2026" одной строкой с replace и группами захвата.

Подсказка

Шаблон: /(\d{4})-(\d{2})-(\d{2})/, замена: "$3.$2.$1". Группы нумеруются с единицы.

Решение учителя 
const iso = "2026-10-30";const ru = iso.replace(/(\d{4})-(\d{2})-(\d{2})/, "$3.$2.$1");console.log(ru); // "30.10.2026"
Задача 4. Проверка пароля

Проверьте пароль: не короче 8 символов, содержит хотя бы одну букву и одну цифру.

Подсказка

Можно сделать три отдельные регулярки и объединить результаты через &&.

Решение учителя 
function isStrongPassword(value) {    return value.length >= 8        && /[A-Za-zА-Яа-я]/.test(value)        && /\d/.test(value);}console.log(isStrongPassword("qwerty12")); // true
