DOM: находим и меняем элементы

~30 минут Средний уровень Теория и Практика

До этого момента весь наш код жил в консоли. Пора выйти в мир: JavaScript создан именно для того, чтобы менять страницу. Для этого он работает с DOM.

В этом уроке мы:

  • Разберёмся, что такое DOM и как браузер его строит.
  • Научимся находить элементы через querySelector.
  • Поменяем текст, классы и стили.
  • Создадим новые элементы прямо из кода.
Аналогия

Дом: HTML - это чертёж, DOM - уже построенный дом, а JavaScript - прораб, который может переставить мебель и достроить комнату.

Что такое DOM

Когда браузер читает HTML, он превращает его в дерево объектов - Document Object Model. Каждый тег становится узлом этого дерева, а JavaScript получает доступ к нему как к обычному объекту.

Схематично страница выглядит так:

document└── html    ├── head    │   └── title    └── body        ├── h1        └── ul            ├── li            └── li

document - корень, точка входа ко всему, что есть на странице. Через него мы и будем искать элементы.

DOM - это не HTML

HTML - это текст файла. DOM - это живая структура в памяти браузера. Когда вы меняете DOM через JavaScript, файл на диске не меняется: при перезагрузке страницы всё вернётся к исходному виду.

Находим элементы

Два метода закрывают почти все задачи:

// Первый подходящий элемент или nullconst title = document.querySelector("h1");// Все подходящие элементы - коллекция NodeListconst items = document.querySelectorAll(".card");

Внутри скобок - любой CSS-селектор: тег, класс, идентификатор, атрибут, вложенность.

document.querySelector("#main");          // по iddocument.querySelector(".card");          // по классуdocument.querySelector("nav a.active");   // вложенный селекторdocument.querySelector('[data-id="7"]');  // по атрибуту

Если элемент не найден, querySelector вернёт null. Обращение к свойству null вызовет ошибку - поэтому результат стоит проверять:

const title = document.querySelector("h1");if (title) {    title.textContent = "Новый заголовок";}

querySelectorAll возвращает NodeList - не совсем массив, но с работающим forEach:

const items = document.querySelectorAll(".card");items.forEach((item) => {    item.classList.add("visible");});

Меняем текст и разметку

Самый безопасный способ изменить содержимое - textContent:

const title = document.querySelector("h1");title.textContent = "Добро пожаловать!";

Он вставляет именно текст: если внутри встретятся символы <b>, они отобразятся как текст, а не превратятся в тег.

innerHTML позволяет вставить настоящую разметку:

const box = document.querySelector(".box");box.innerHTML = "<strong>Важно:</strong> текст с разметкой";
innerHTML и пользовательские данные

Никогда не вставляйте в innerHTML то, что ввёл пользователь. Строка <img src=x onerror="..."> превратится в исполняемый код - это называется XSS-атакой. Для данных из форм используйте textContent, а элементы создавайте через createElement.

Классы и стили

Для управления классами есть classList:

const card = document.querySelector(".card");card.classList.add("active");       // добавить классcard.classList.remove("hidden");    // убрать классcard.classList.toggle("dark");      // переключитьconsole.log(card.classList.contains("active")); // true

Это предпочтительный способ менять внешний вид: стили остаются в CSS, а JavaScript только включает и выключает готовые классы.

Прямые инлайновые стили тоже возможны, но используются реже - для вычисляемых значений:

const bar = document.querySelector(".progress-bar");bar.style.width = "75%";bar.style.backgroundColor = "#ff5a00";

Обратите внимание на camelCase: в CSS свойство background-color, в JavaScript - backgroundColor.

data-атрибуты

Часто нужно привязать к элементу свои данные: идентификатор товара, номер страницы, тип кнопки. Для этого служат data- атрибуты:

<button class="buy" data-product-id="42" data-price="1990">Купить</button>
const button = document.querySelector(".buy");console.log(button.dataset.productId); // "42"console.log(button.dataset.price);     // "1990" - это строка

Имена приводятся к camelCase: data-product-id становится dataset.productId. Значения всегда строки, поэтому числа нужно приводить через Number().

Создаём элементы

Вставлять разметку через innerHTML удобно, но для динамических списков лучше создавать узлы явно:

const list = document.querySelector(".list");const item = document.createElement("li");item.textContent = "Новый пункт";item.classList.add("list-item");list.append(item);

Основные методы вставки:

  • append - добавить в конец элемента.
  • prepend - добавить в начало.
  • before / after - вставить рядом с элементом.
  • remove - удалить элемент со страницы.

Полный пример - добавляем пункт в список по клику:

const list = document.querySelector(".list");const button = document.querySelector("#add");button.addEventListener("click", () => {    const item = document.createElement("li");    item.textContent = `Пункт ${list.children.length + 1}`;    list.append(item);});

Про addEventListener подробно поговорим в следующем уроке, но общая идея уже видна: «когда произойдёт клик - выполни вот это».

Полезные свойства

const el = document.querySelector(".card");el.parentElement;      // родительel.children;           // дочерние элементыel.nextElementSibling; // следующий соседel.id;                 // idel.tagName;            // имя тега в верхнем регистре
Где запускать скрипт

Если скрипт подключён в <head> без defer, элементы ещё не существуют и querySelector вернёт null. Два рабочих варианта: подключить скрипт в конце <body> или добавить defer к тегу <script>.

Шпаргалка

  • querySelector первый элемент по селектору
  • querySelectorAll все элементы по селектору
  • textContent текст без разметки
  • innerHTML разметка (осторожно!)
  • classList add / remove / toggle
  • dataset доступ к data-атрибутам
  • createElement создать новый элемент

Если что-то не работает

  • «Cannot read properties of null». Элемент не найден: опечатка в селекторе или скрипт выполнился раньше разметки. Проверьте селектор в консоли: document.querySelector(".card").
  • Изменения не видны. Возможно, вы изменили не тот элемент или querySelectorAll вернул коллекцию, а вы работаете с ней как с одним элементом.
  • forEach не работает на коллекции. children и getElementsByClassName возвращают HTMLCollection без forEach - превратите её в массив: Array.from(...) или используйте querySelectorAll.
  • Разметка «съела» стили. После innerHTML = "..." старые дочерние элементы удалены вместе с обработчиками. Создавайте элементы заново.
  • Пользовательский текст сломал вёрстку. Используйте textContent вместо innerHTML.
  • «Элемент не найден», хотя он точно есть. Скрипт выполнился до того, как браузер построил разметку. Подключите его в конце <body> или с defer - это самая частая причина такой ситуации.

Практика

Задача 1. Новый заголовок

На странице есть <h1>. Замените его текст на «Привет из JavaScript» и добавьте класс highlight.

Подсказка

Найдите элемент через document.querySelector("h1"), измените textContent и вызовите classList.add("highlight").

Решение учителя 
const title = document.querySelector("h1");title.textContent = "Привет из JavaScript";title.classList.add("highlight");
Задача 2. Чётные строки

У списка .list подсветите классом even каждую вторую строку.

Подсказка

querySelectorAll(".list li") и forEach с индексом. Чётные индексы 0, 2, 4 - это визуально первая, третья, пятая строки. Значит, подсвечивать нужно нечётные индексы.

Решение учителя 
const items = document.querySelectorAll(".list li");items.forEach((item, index) => {    if (index % 2 === 1) {        item.classList.add("even");    }});
Задача 3. Список из массива

Дан массив ["HTML", "CSS", "JavaScript"] и пустой <ul class="skills"></ul>. Заполните список элементами массива, создавая li через createElement.

Подсказка

Найдите список, пройдитесь по массиву через forEach, создайте элемент, задайте textContent и добавьте через append.

Решение учителя 
const skills = ["HTML", "CSS", "JavaScript"];const list = document.querySelector(".skills");skills.forEach((skill) => {    const item = document.createElement("li");    item.textContent = skill;    list.append(item);});
Задача 4. Внешние ссылки

Сделайте так, чтобы все ссылки, начинающиеся с http, открывались в новой вкладке и не передавали реферер.

Подсказка

Пройдитесь по ссылкам через querySelectorAll и выставьте target и rel.

Решение учителя 
document.querySelectorAll("a").forEach((link) => {    if (link.href.startsWith("http")) {        link.target = "_blank";        link.rel = "noopener noreferrer";    }});

Что мы узнали и что дальше

JavaScript наконец добрался до страницы. Вы знаете:

  • Что такое DOM и почему это не HTML-файл.
  • Как искать элементы по CSS-селектору.
  • Как менять текст, классы, стили и атрибуты.
  • Как создавать и вставлять новые элементы.

Мы умеем менять страницу, но пока только вручную - при загрузке. Настоящий интерфейс реагирует на пользователя: клики, ввод, отправку форм. В следующем уроке разберём события - и страница станет интерактивной.
