Методы массивов и строк

~30 минут Средний уровень Теория и Практика

До сих пор для работы с массивами мы писали циклы вручную. В JavaScript есть методы, которые делают то же самое, но короче и понятнее: map, filter, reduce и другие. В реальном коде вы будете встречать их постоянно.

В этом уроке мы:

  • Научимся преобразовывать массив через map.
  • Разберём фильтрацию и поиск.
  • Сведём массив к одному значению через reduce.
  • Познакомимся с основными строковыми методами.
Аналогия

Конвейер: на каждом этапе деталь либо преобразуется, либо отбирается, либо собирается в общий итог.

map: преобразовать каждый элемент

map проходит по массиву и возвращает новый массив той же длины, где каждый элемент - результат функции:

const prices = [100, 200, 300];const withVat = prices.map((price) => price * 1.2);console.log(withVat); // [120, 240, 360]const labels = prices.map((price) => `${price} ₽`);console.log(labels); // ["100 ₽", "200 ₽", "300 ₽"]

Ключевое слово - «новый». Исходный массив не меняется. Если забыть return в колбэке, получится массив из undefined:

const broken = prices.map((price) => {    price * 1.2; // забыли return});console.log(broken); // [undefined, undefined, undefined]

filter: оставить подходящие

filter возвращает новый массив только из тех элементов, для которых колбэк вернул true:

const numbers = [5, 12, 8, 130, 44];const big = numbers.filter((n) => n > 10);console.log(big); // [12, 130, 44]

Часто фильтруют массив объектов:

const products = [    { title: "Ноутбук", price: 75000, inStock: true },    { title: "Мышь", price: 1500, inStock: true },    { title: "Монитор", price: 30000, inStock: false }];const available = products.filter((p) => p.inStock && p.price < 40000);console.log(available); // [{ title: "Мышь", ... }]

find и findIndex

find возвращает первый подходящий элемент, а не массив. Если ничего не найдено - undefined:

const users = [    { id: 1, name: "Аня" },    { id: 2, name: "Борис" }];const user = users.find((u) => u.id === 2);console.log(user.name); // "Борис"const missing = users.find((u) => u.id === 99);console.log(missing); // undefined

findIndex работает так же, но возвращает индекс или -1.

some и every

Два метода для проверки условий:

const scores = [4, 5, 3, 5];console.log(scores.some((s) => s === 5));  // true - есть хотя бы одна пятёркаconsole.log(scores.every((s) => s >= 3));  // true - все не ниже тройки

some останавливается на первом совпадении, every - на первом несовпадении. Оба возвращают boolean, а не массив.

reduce: свести к одному значению

Самый мощный и самый непонятный метод. Он проходит по массиву, накапливая результат в аккумуляторе:

const numbers = [10, 20, 30];const sum = numbers.reduce((acc, n) => acc + n, 0);console.log(sum); // 60

Разберём по шагам. Второй аргумент 0 - начальное значение аккумулятора. Дальше на каждой итерации:

  • acc = 0, n = 10 → возвращается 10.
  • acc = 10, n = 20 → 30.
  • acc = 30, n = 30 → 60.

Всегда передавайте начальное значение. Без него reduce возьмёт первый элемент как аккумулятор - и на пустом массиве выбросит ошибку.

Через reduce можно собрать и объект:

const cart = [    { title: "Ноутбук", price: 75000, count: 1 },    { title: "Мышь", price: 1500, count: 2 }];const total = cart.reduce((sum, item) => sum + item.price * item.count, 0);console.log(total); // 78000

sort с объектами

Сортировка массива объектов требует явного компаратора:

const products = [    { title: "Монитор", price: 30000 },    { title: "Мышь", price: 1500 },    { title: "Ноутбук", price: 75000 }];const cheapFirst = [...products].sort((a, b) => a.price - b.price);console.log(cheapFirst[0].title); // "Мышь"

Копия через spread здесь не случайна: sort меняет исходный массив. Если оригинальный порядок важен, копируйте перед сортировкой.

Цепочки вызовов

Методы возвращают новые массивы, поэтому их можно выстраивать в цепочку. Читается она сверху вниз, как последовательность действий:

const products = [    { title: "Ноутбук", price: 75000, inStock: true },    { title: "Мышь", price: 1500, inStock: true },    { title: "Монитор", price: 30000, inStock: false },    { title: "Кабель", price: 500, inStock: true }];const result = products    .filter((p) => p.inStock)    .map((p) => p.title)    .sort();console.log(result); // ["Кабель", "Мышь", "Ноутбук"]

Такой код описывает что нужно получить, а не как перебирать элементы. Это главное преимущество декларативного стиля.

Строковые методы

Строки неизменяемы: любой метод возвращает новую строку, а исходная остаётся прежней.

const text = "  JavaScript - это круто  ";console.log(text.trim());              // "JavaScript - это круто"console.log(text.toUpperCase());       // "  JAVASCRIPT - ЭТО КРУТО  "console.log(text.toLowerCase());console.log(text.includes("круто"));   // trueconsole.log(text.startsWith("  Java")); // trueconsole.log(text.slice(2, 12));        // "JavaScript"

Разбиение и сборка:

const csv = "яблоко,банан,груша";const fruits = csv.split(",");console.log(fruits);        // ["яблоко", "банан", "груша"]console.log(fruits.join(" | ")); // "яблоко | банан | груша"

Замена и дополнение:

const phone = "8 (999) 123-45-67";console.log(phone.replaceAll(" ", "")); // "8(999)123-45-67"const code = "42";console.log(code.padStart(5, "0")); // "00042"console.log("=".repeat(10));        // "=========="
replace заменяет только первое совпадение

replace("а", "о") заменит лишь первую «а». Для замены всех вхождений используйте replaceAll или регулярное выражение с флагом g.

Шпаргалка

  • map преобразовать каждый элемент
  • filter оставить подходящие
  • find первый подходящий элемент
  • some / every проверка условия
  • reduce свести к одному значению
  • sort сортировка (мутирует!)
  • trim убрать пробелы по краям

Если что-то не работает

  • Массив из undefined. В map забыли return или использовали фигурные скобки без него.
  • filter вернул пустой массив. Условие никогда не истинно. Проверьте типы: строка "1500" и число 1500 сравниваются по-разному.
  • «Reduce of empty array with no initial value». Не передан начальный аккумулятор. Добавьте , 0 вторым аргументом.
  • Исходный массив изменился. sort, reverse, splice мутируют массив. Копируйте через [...arr].
  • toUpperCase «не сработал». Он возвращает новую строку, а не меняет старую. Присвойте результат: text = text.toUpperCase().
  • После map список остался прежним. Метод вернул новый массив, а результат никуда не присвоили. map, filter и slice не меняют исходный массив - это не ошибка, а их свойство.

Практика

Задача 1. Имена в верхнем регистре

Дан массив имён ["аня", "борис", "вера"]. Получите массив с именами в верхнем регистре, без изменения оригинала.

Подсказка

Подойдёт map со стрелочной функцией: name.toUpperCase().

Решение учителя 
const names = ["аня", "борис", "вера"];const upper = names.map((name) => name.toUpperCase());console.log(upper); // ["АНЯ", "БОРИС", "ВЕРА"]console.log(names); // ["аня", "борис", "вера"]
Задача 2. Фильтр по цене

Дан массив товаров с полями title и price. Получите названия товаров дешевле 5000, отсортированные по возрастанию цены.

Подсказка

Сначала filter по цене, затем sort с компаратором a.price - b.price, и только потом map в названия. Порядок важен: после map сортировать будет нечего.

Решение учителя 
const products = [    { title: "Ноутбук", price: 75000 },    { title: "Мышь", price: 1500 },    { title: "Кабель", price: 500 },    { title: "Монитор", price: 30000 }];const titles = products    .filter((p) => p.price < 5000)    .sort((a, b) => a.price - b.price)    .map((p) => p.title);console.log(titles); // ["Кабель", "Мышь"]
Задача 3. Сумма корзины

В корзине три товара с полями price и count. Посчитайте итоговую сумму через reduce. Пустая корзина должна давать 0.

Подсказка

Аккумулятор начинается с нуля, а на каждом шаге прибавляется item.price * item.count. Именно начальное значение спасает от ошибки на пустой корзине.

Решение учителя 
const cart = [    { price: 1500, count: 2 },    { price: 500, count: 1 },    { price: 75000, count: 1 }];const total = cart.reduce((sum, item) => sum + item.price * item.count, 0);console.log(total); // 78500
Задача 4. Группировка по букве

Сгруппируйте массив имён по первой букве: { "А": ["Анна", "Алексей"], "Б": ["Борис"] }.

Подсказка

Подойдёт reduce с объектом-аккумулятором.

Решение учителя 
const names = ["Анна", "Борис", "Алексей"];const grouped = names.reduce((acc, name) => {    const letter = name[0];    acc[letter] = acc[letter] || [];    acc[letter].push(name);    return acc;}, {});console.log(grouped);

Что мы узнали и что дальше

Вы освоили основной инструмент работы с данными. Теперь вы знаете:

  • Как преобразовывать массив через map и отбирать элементы через filter.
  • Как искать один элемент и проверять условия.
  • Как сводить массив к одному значению через reduce.
  • Как работать со строками: обрезать, менять регистр, разбивать и собирать.

До этого весь наш код выполнялся мгновенно, строка за строкой. Но в реальности почти всё требует времени: запрос к серверу, таймер, загрузка файла. Если ждать синхронно, страница замрёт. В следующем уроке разберём асинхронность - таймеры, промисы и async/await.
