Даты и время

~30 минут Средний уровень Теория и Практика

Даты - одна из самых коварных тем в программировании. В JavaScript месяц март - это 2, воскресенье - это 0, а «сегодня» зависит от часового пояса пользователя. Разберёмся, как со всем этим работать без боли.

В этом уроке мы:

  • Научимся создавать даты и читать их части.
  • Поймём разницу между локальным временем и UTC.
  • Освоим форматирование через Intl.
  • Научимся считать разницу и прибавлять дни.
Аналогия

Часовые пояса как табло в аэропорту: момент один, а подписи в Москве и Нью-Йорке разные.

Создание даты

const now = new Date();               // текущий моментconst fromMs = new Date(0);           // 1 января 1970, UTCconst fromString = new Date("2026-10-30T12:00:00");const fromParts = new Date(2026, 9, 30); // 30 октября 2026

Обратите внимание на new Date(2026, 9, 30): месяц указывается с нуля. Девятка - это октябрь. Это историческая особенность, и забыть о ней очень легко.

Месяцы с нуля, дни недели тоже

getMonth() возвращает 0 для января и 11 для декабря. getDay() возвращает 0 для воскресенья и 6 для субботы. Если строите календарь или выбираете дату - проверяйте себя на конкретных примерах.

Чтение частей

const date = new Date(2026, 9, 30, 14, 45);console.log(date.getFullYear()); // 2026console.log(date.getMonth());    // 9  - октябрьconsole.log(date.getDate());     // 30 - день месяцаconsole.log(date.getDay());      // 5  - пятницаconsole.log(date.getHours());    // 14console.log(date.getMinutes());  // 45

Для UTC есть параллельный набор методов: getUTCFullYear, getUTCMonth и так далее. Они не зависят от часового пояса устройства.

Timestamp

Внутри дата хранится как количество миллисекунд с 1 января 1970 года UTC:

const date = new Date("2026-10-30T00:00:00Z");console.log(date.getTime());      // 1793318400000console.log(Date.now());          // текущий timestampconsole.log(new Date(1793318400000).toISOString());// "2026-10-30T00:00:00.000Z"

Timestamp удобен для сравнения и хранения: это просто число.

Форматирование

Встроенные методы вроде toString() дают нечитаемый результат. Для вывода людям используйте Intl.DateTimeFormat:

const date = new Date(2026, 9, 30, 14, 45);console.log(new Intl.DateTimeFormat("ru-RU").format(date));// "30.10.2026"console.log(new Intl.DateTimeFormat("ru-RU", {    day: "numeric",    month: "long",    year: "numeric"}).format(date));// "30 октября 2026 г."console.log(date.toLocaleDateString("ru-RU"));console.log(date.toLocaleTimeString("ru-RU", { hour: "2-digit", minute: "2-digit" }));

Для относительных формулировок есть Intl.RelativeTimeFormat:

const rtf = new Intl.RelativeTimeFormat("ru-RU", { numeric: "auto" });console.log(rtf.format(-1, "day"));  // "вчера"console.log(rtf.format(3, "day"));   // "через 3 дня"

Арифметика дат

Даты складываются как числа - через миллисекунды:

const start = new Date(2026, 0, 1);const end = new Date(2026, 11, 31);const diffMs = end - start;const diffDays = diffMs / (1000 * 60 * 60 * 24);console.log(Math.round(diffDays)); // 364

Прибавить дни можно через setDate. Метод сам корректно перейдёт на следующий месяц:

function addDays(date, days) {    const copy = new Date(date);    copy.setDate(copy.getDate() + days);    return copy;}console.log(addDays(new Date(2026, 0, 30), 5)); // 4 февраля 2026

Обратите внимание на копию: setDate меняет объект. Если исходная дата нужна дальше, копируйте её через new Date(date).

Сравнение

const a = new Date(2026, 0, 1);const b = new Date(2026, 5, 1);console.log(a < b);                 // trueconsole.log(a.getTime() === b.getTime()); // false

Сравнивать даты через === нельзя: это разные объекты, даже если момент совпадает. Сравнивайте либо операторами (они приводят к числу), либо через getTime().

Разбор даты из строки

Формат YYYY-MM-DD понимается как UTC, а DD.MM.YYYY - нет. Надёжнее разобрать вручную:

function parseRuDate(value) {    const [day, month, year] = value.split(".").map(Number);    if (!day || !month || !year) return null;    const date = new Date(year, month - 1, day);    // защита от 31.02, которая "переедет" в март    if (date.getDate() !== day || date.getMonth() !== month - 1) {        return null;    }    return date;}console.log(parseRuDate("30.10.2026")); // корректная датаconsole.log(parseRuDate("31.02.2026")); // null

Проверка на валидность

const date = new Date("не дата");console.log(date.toString());        // "Invalid Date"console.log(Number.isNaN(date.getTime())); // true

Невалидная дата не выбрасывает ошибку - она просто становится «Invalid Date». Проверяйте через Number.isNaN(date.getTime()).

Шпаргалка

  • new Date() текущий момент
  • getTime() миллисекунды с 1970
  • getMonth() месяц с нуля
  • toISOString() строка в UTC
  • Intl.DateTimeFormat формат для людей
  • setDate() прибавить дни (мутирует)

Если что-то не работает

  • Месяц на единицу меньше. Так устроен JavaScript: январь - это 0. При выводе прибавляйте единицу.
  • Дата «уехала» на день назад. Строка без времени трактуется как UTC, а локальное время может быть раньше. Задавайте дату частями или добавляйте время.
  • Исходная дата изменилась. setDate, setMonth и setFullYear мутируют объект. Копируйте перед изменением.
  • «Invalid Date». Строка не распознана. Разбирайте вручную и проверяйте через Number.isNaN.
  • Разница в днях дробная. Часовой пояс даёт дробную часть - округляйте через Math.round или считайте по UTC.
  • Дедлайн «съехал» на день. Дата без времени трактуется как UTC, а у пользователя другой часовой пояс. Для важных дат задавайте время явно или работайте в UTC.

Практика

Задача 1. Возраст

Напишите функцию getAge(birthDate), которая принимает дату рождения и возвращает полное количество лет на сегодня.

Подсказка

Вычтите годы, а затем проверьте, был ли уже день рождения в этом году: если месяц или день ещё не наступили, уменьшите результат на единицу.

Решение учителя 
function getAge(birthDate) {    const today = new Date();    let age = today.getFullYear() - birthDate.getFullYear();    const monthDiff = today.getMonth() - birthDate.getMonth();    const dayDiff = today.getDate() - birthDate.getDate();    if (monthDiff < 0 || (monthDiff === 0 && dayDiff < 0)) {        age -= 1;    }    return age;}console.log(getAge(new Date(2000, 4, 15)));
Задача 2. Красивая дата

Выведите текущую дату в формате «30 октября 2026, пятница» через Intl.DateTimeFormat.

Подсказка

Передайте в настройки day: "numeric", month: "long", year: "numeric" и weekday: "long".

Решение учителя 
const formatter = new Intl.DateTimeFormat("ru-RU", {    day: "numeric",    month: "long",    year: "numeric",    weekday: "long"});console.log(formatter.format(new Date()));// "30 октября 2026 г., пятница"
Задача 3. Дедлайн

Дан дедлайн. Выведите, сколько дней осталось, и текст «просрочено», если дата уже прошла.

Подсказка

Разница в миллисекундах делится на 1000 * 60 * 60 * 24. Округлите вверх через Math.ceil и проверьте знак.

Решение учителя 
function daysLeft(deadline) {    const diff = deadline - new Date();    const days = Math.ceil(diff / (1000 * 60 * 60 * 24));    if (days < 0) return "просрочено";    if (days === 0) return "сегодня";    return `осталось ${days} дн.`;}console.log(daysLeft(new Date(2026, 11, 31)));
Задача 4. До Нового года

Посчитайте, сколько дней осталось до 1 января следующего года.

Подсказка

Разница дат - это миллисекунды. Разделите на 1000 * 60 * 60 * 24 и округлите вверх.

Решение учителя 
const now = new Date();const nextYear = new Date(now.getFullYear() + 1, 0, 1);const days = Math.ceil((nextYear - now) / (1000 * 60 * 60 * 24));console.log(days);
