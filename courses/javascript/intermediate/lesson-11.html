События и обработчики

~30 минут Средний уровень Теория и Практика

Страница, которая меняется только при перезагрузке, - это красивая картинка. Настоящий интерфейс отвечает на действия: нажали кнопку - открылось меню, ввели текст - обновился список. В основе всего этого лежат события.

В этом уроке мы:

  • Научимся подписываться на события через addEventListener.
  • Разберём основные типы событий и объект события.
  • Поймём, зачем нужен preventDefault.
  • Освоим делегирование - приём, без которого не живёт ни один список.
Аналогия

Дверной звонок: кнопка запускает одно и то же действие, кто бы ни нажал.

Первое событие

<button class="btn">Нажми меня</button>
const button = document.querySelector(".btn");button.addEventListener("click", () => {    console.log("Клик!");});

addEventListener принимает два аргумента: имя события и функцию, которая выполнится, когда оно произойдёт. Такую функцию называют обработчиком.

Обработчик можно вынести в отдельную функцию - так проще переиспользовать и удалять:

function handleClick() {    console.log("Клик!");}button.addEventListener("click", handleClick);button.removeEventListener("click", handleClick);

Обратите внимание: передаётся имя функции без скобок. Если написать handleClick(), функция вызовется сразу, а в обработчик попадёт её результат (undefined).

Основные события

  • click - клик мышью или тапом.
  • input - ввод в поле, срабатывает на каждое изменение.
  • change - значение изменилось и поле потеряло фокус.
  • submit - отправка формы.
  • keydown - нажатие клавиши.
  • DOMContentLoaded - страница разобрана и готова.

Пример с полем ввода - живой счётчик символов:

const input = document.querySelector("#message");const counter = document.querySelector(".counter");input.addEventListener("input", () => {    counter.textContent = `${input.value.length} символов`;});

Объект события

Обработчик получает аргумент - объект с деталями произошедшего. Чаще всего нужны два свойства:

button.addEventListener("click", (event) => {    console.log(event.type);   // "click"    console.log(event.target); // элемент, по которому кликнули});
  • event.target - тот элемент, на котором произошло событие.
  • event.currentTarget - элемент, на который навешен обработчик.

Разница видна, когда обработчик стоит на контейнере, а кликают по вложенной кнопке. Об этом - в разделе про делегирование.

preventDefault

У некоторых событий есть поведение по умолчанию. Форма отправляется и перезагружает страницу, ссылка переходит по адресу, чекбокс переключается. Если это поведение нужно отменить, вызывают preventDefault():

<form class="form">    <input type="text" name="name">    <button type="submit">Отправить</button></form>
const form = document.querySelector(".form");form.addEventListener("submit", (event) => {    event.preventDefault(); // страница не перезагрузится    const name = form.elements.name.value;    console.log(`Привет, ${name}!`);});

Без этой строки браузер отправит форму и перезагрузит страницу - а вместе с ней исчезнут все результаты работы JavaScript.

Всплытие

Событие возникает на конкретном элементе, а затем «всплывает» вверх по дереву: от элемента к родителю, потом к его родителю и так до document. Это значит, что обработчик на контейнере поймает клики по всем вложенным элементам:

<div class="menu">    <button>Профиль</button>    <button>Настройки</button></div>
const menu = document.querySelector(".menu");menu.addEventListener("click", (event) => {    console.log(event.target.textContent); // текст нажатой кнопки});

Один обработчик обслуживает все кнопки сразу. Останавливается всплытие вызовом event.stopPropagation(), но злоупотреблять им не стоит: это ломает ожидаемое поведение вложенных компонентов.

Делегирование

Представьте список задач, где элементы добавляются и удаляются динамически. Вешать обработчик на каждую кнопку «удалить» - плохая идея: новые кнопки останутся без обработчиков.

Решение - повесить один обработчик на контейнер и вычислять цель через closest:

<ul class="tasks">    <li>        <span>Купить хлеб</span>        <button class="delete" data-id="1">×</button>    </li></ul>
const list = document.querySelector(".tasks");list.addEventListener("click", (event) => {    const button = event.target.closest(".delete");    if (!button) return; // клик не по кнопке - игнорируем    const item = button.closest("li");    item.remove();});

closest поднимается от цели вверх по дереву и возвращает ближайший элемент, подходящий под селектор. Если клик пришёлся по иконке внутри кнопки, он всё равно найдёт кнопку.

Почему делегирование - стандарт

Один обработчик вместо сотни, автоматическая поддержка новых элементов и меньше памяти. Именно так работают почти все реальные списки, таблицы и меню.

Снятие обработчика и once

Если обработчик нужно вызвать ровно один раз, есть опция:

button.addEventListener("click", () => {    console.log("Это сообщение появится только один раз");}, { once: true });

В остальных случаях обработчик снимают вручную через removeEventListener - с той же функцией, что передавали. Если передать новую анонимную функцию, снятие не сработает: это другой объект.

Шпаргалка

  • addEventListener подписаться на событие
  • click клик
  • input ввод в поле
  • submit отправка формы
  • event.target элемент события
  • preventDefault() отменить поведение по умолчанию
  • closest ближайший родитель по селектору

Если что-то не работает

  • Обработчик не срабатывает. Элемент не найден (проверьте селектор) или скрипт подключён раньше разметки.
  • Функция вызывается сразу при загрузке. В addEventListener передали handleClick() со скобками вместо handleClick.
  • Страница перезагружается при отправке формы. Забыли event.preventDefault().
  • Событие срабатывает дважды. Обработчик навешен повторно - например, при каждом рендере списка. Навешивайте один раз на контейнер.
  • removeEventListener не работает. Передана другая функция (новая стрелочная) вместо той же ссылки на обработчик.
  • Кнопка срабатывает через раз или дважды. Обработчик навесили повторно: например, при каждом обновлении списка. Навешивайте один раз - или снимайте старый перед новым.

Практика

Задача 1. Счётчик кликов

Есть кнопка .counter-btn и элемент .counter-value с нулём. При каждом клике увеличивайте число на экране на единицу.

Подсказка

Заведите переменную count во внешней области, увеличивайте её в обработчике и записывайте в textContent. Текст из элемента читать обратно не нужно - это строка.

Решение учителя 
const button = document.querySelector(".counter-btn");const value = document.querySelector(".counter-value");let count = 0;button.addEventListener("click", () => {    count += 1;    value.textContent = count;});
Задача 2. Живой поиск

Дан список городов и поле поиска. При вводе скрывайте через класс hidden те города, названия которых не содержат введённую строку.

Подсказка

Приводите обе строки к нижнему регистру через toLowerCase(), иначе «Москва» не найдётся по запросу «моск». Класс переключайте через classList.toggle("hidden", условие).

Решение учителя 
const search = document.querySelector("#search");const cities = document.querySelectorAll(".city");search.addEventListener("input", () => {    const query = search.value.toLowerCase().trim();    cities.forEach((city) => {        const matches = city.textContent.toLowerCase().includes(query);        city.classList.toggle("hidden", !matches);    });});

trim() убирает случайные пробелы по краям - иначе запрос « Москва» не найдёт ничего.

Задача 3. Удаление через делегирование

В списке .tasks у каждой строки есть кнопка .delete. Навесьте один обработчик на список, который удаляет нажатую строку. Проверьте, что он работает и для строк, добавленных после загрузки.

Подсказка

В обработчике сначала найдите кнопку: event.target.closest(".delete"). Если её нет - выходим. Затем ищем строку через button.closest("li") и вызываем remove().

Решение учителя 
const list = document.querySelector(".tasks");list.addEventListener("click", (event) => {    const button = event.target.closest(".delete");    if (!button) return;    button.closest("li").remove();});
Задача 4. Переключатель темы

Кнопка .theme-toggle должна включать и выключать класс dark у body.

Подсказка

Используйте classList.toggle в обработчике клика.

Решение учителя 
const button = document.querySelector(".theme-toggle");button.addEventListener("click", () => {    document.body.classList.toggle("dark");});
