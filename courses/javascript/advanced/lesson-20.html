Прототипы и классы

~35 минут Продвинутый уровень Теория и Практика

В JavaScript нет «настоящих» классов в том смысле, в каком они есть в C# или Java. Всё объектное устройство языка построено на прототипах. Классы, появившиеся в ES6, - это удобный синтаксис поверх той же прототипной модели.

В этом уроке мы:

  • Разберём, что такое прототип и прототипная цепочка.
  • Научимся создавать объекты через Object.create.
  • Освоим классы: конструктор, методы, геттеры, статику.
  • Поймём наследование и приватные поля.
Аналогия

Чертёж и дом: класс - чертёж, объект - построенный по нему дом. По одному чертежу можно построить сколько угодно домов.

Прототипная цепочка

Каждый объект в JavaScript хранит ссылку на другой объект - свой прототип. Если свойства нет в самом объекте, движок ищет его в прототипе, затем в прототипе прототипа и так далее, пока не дойдёт до null.

const animal = {    eats: true,    breathe() {        console.log("Дышу");    }};const rabbit = Object.create(animal);rabbit.jumps = true;console.log(rabbit.jumps);   // true - своё свойствоconsole.log(rabbit.eats);    // true - из прототипаrabbit.breathe();            // метод из прототипа

Схематично цепочка выглядит так:

rabbit  └── [[Prototype]]: animal        └── [[Prototype]]: Object.prototype              └── [[Prototype]]: null

Именно поэтому у любого объекта есть toString и hasOwnProperty: они лежат в Object.prototype.

Свойство против прототипа

rabbit.hasOwnProperty("jumps") вернёт true, а rabbit.hasOwnProperty("eats") - false: второе свойство унаследовано. Это важно, когда вы перебираете объект своим кодом и не хотите трогать чужие свойства.

Функции-конструкторы

До появления классов объекты создавали функциями-конструкторами. Полезно понимать этот механизм, потому что классы работают ровно так же:

function User(name, age) {    this.name = name;    this.age = age;}User.prototype.greet = function () {    console.log(`Привет, ${this.name}`);};const user = new User("Алексей", 25);user.greet(); // "Привет, Алексей"

Ключевое слово new делает четыре вещи: создаёт пустой объект, привязывает к нему this, выполняет тело функции и возвращает объект. Методы кладут в prototype, чтобы они были общими и не копировались в каждый экземпляр.

Классы

Тот же код, записанный классом:

class User {    constructor(name, age) {        this.name = name;        this.age = age;    }    greet() {        console.log(`Привет, ${this.name}`);    }}const user = new User("Алексей", 25);user.greet();

Методы класса автоматически попадают в прототип. Внутри класса всегда действует строгий режим. Вызывать класс без new нельзя - будет ошибка.

Поля и приватность

class Counter {    count = 0;          // публичное поле    #step = 1;          // приватное поле    constructor(step) {        this.#step = step;    }    increment() {        this.count += this.#step;        return this.count;    }}const counter = new Counter(2);counter.increment();console.log(counter.count); // 2console.log(counter.#step); // SyntaxError: приватное поле

Приватные поля начинаются с # и доступны только внутри класса. Это настоящее сокрытие, а не договорённость: обратиться снаружи невозможно даже через квадратные скобки.

Геттеры и сеттеры

Позволяют управлять доступом к свойству:

JavaScript 
class Temperature {
    #celsius;

    constructor(celsius) {
        this.#celsius = celsius;
    }

    get fahrenheit() {
        return this.#celsius * 9 / 5 + 32;
    }

    set fahrenheit(value) {
        this.#celsius = (value - 32) * 5 / 9;
    }

    get celsius() {
        return this.#celsius;
    }
}

const t = new Temperature(25);
console.log(t.fahrenheit); // 77

t.fahrenheit = 212;
console.log(t.celsius); // 100

Снаружи это выглядит как обычное свойство, но внутри выполняется вычисление. Удобно для валидации: в сеттере можно проверить значение и выбросить ошибку.

Статические члены

Принадлежат классу, а не экземпляру:

class MathHelper {    static PI = 3.14159;    static circleArea(radius) {        return MathHelper.PI * radius ** 2;    }}console.log(MathHelper.circleArea(2)); // 12.56636

Статические методы - это утилиты, которым не нужно состояние экземпляра. Классический пример - Array.from или Object.keys.

Наследование

JavaScript 
class Animal {
    constructor(name) {
        this.name = name;
    }

    speak() {
        return `${this.name} издаёт звук`;
    }
}

class Dog extends Animal {
    constructor(name, breed) {
        super(name);          // обязательно до this
        this.breed = breed;
    }

    speak() {
        return `${this.name} лает`;
    }
}

const dog = new Dog("Рекс", "овчарка");
console.log(dog.speak());         // "Рекс лает"
console.log(dog instanceof Dog);  // true
console.log(dog instanceof Animal); // true

super(name) вызывает конструктор родителя. Если конструктор в наследнике не объявлен, он создаётся автоматически и передаёт все аргументы родителю.

instanceof проверяет всю цепочку прототипов, поэтому собака является и Dog, и Animal, и Object.

Когда классы не нужны

Классы - инструмент, а не цель. Если у вас нет состояния и нескольких экземпляров, достаточно функций и объектов:

// Избыточноclass MathUtils {    static double(n) { return n * 2; }}// Достаточноconst double = (n) => n * 2;

Правило: класс оправдан, когда есть данные и поведение, которые живут вместе, и когда таких сущностей может быть много.

Шпаргалка

  • Object.create(proto) объект с заданным прототипом
  • class синтаксис над прототипами
  • constructor инициализация экземпляра
  • extends / super наследование
  • #field приватное поле
  • get / set управляемый доступ к свойству
  • static принадлежит классу

Если что-то не работает

  • «Class constructor cannot be invoked without 'new'». Класс вызван как функция. Нужен new User(...).
  • «Must call super constructor before accessing this». В наследнике используется this до super().
  • Метод потерялся при передаче в колбэк. Потерян this - оберните вызов или используйте bind.
  • Приватное поле «не определено». Поле объявлено в наследнике, а используется в родителе (или наоборот). Приватные поля не наследуются.
  • instanceof вернул false. Объект создан не через new этого класса или является обычным объектным литералом.
  • Метод «потерял» this. Метод передали в таймер или обработчик как функцию - контекст потерялся. Лечится обёрткой () => obj.method() или bind.

Практика

Задача 1. Класс User

Создайте класс User с полями name и email и методом getInfo(), который возвращает строку «Имя (email)». Создайте два экземпляра и выведите информацию.

Подсказка

Поля задаются в constructor через this. Метод достаточно объявить внутри класса - он автоматически попадёт в прототип.

Решение учителя 
class User {    constructor(name, email) {        this.name = name;        this.email = email;    }    getInfo() {        return `${this.name} (${this.email})`;    }}const alex = new User("Алексей", "alex@example.com");const maria = new User("Мария", "maria@example.com");console.log(alex.getInfo());console.log(maria.getInfo());
Задача 2. Наследование

Создайте класс Admin, наследующий User, с дополнительным полем permissions (массив) и методом can(action), который проверяет наличие права.

Подсказка

Не забудьте super(name, email) до обращения к this. Для проверки подойдёт this.permissions.includes(action).

Решение учителя 
class Admin extends User {    constructor(name, email, permissions) {        super(name, email);        this.permissions = permissions;    }    can(action) {        return this.permissions.includes(action);    }}const admin = new Admin("Аня", "anya@example.com", ["edit", "delete"]);console.log(admin.getInfo());  // унаследованный методconsole.log(admin.can("edit")); // true
Задача 3. Приватный счётчик

Создайте класс BankAccount с приватным полем #balance, методами deposit(amount), withdraw(amount) и геттером balance. Попытка снять больше, чем есть, должна выбрасывать ошибку.

Подсказка

В withdraw проверьте amount > this.#balance и вызовите throw new Error(...). Геттер объявляется словом get.

Решение учителя
JavaScript 
class BankAccount {
    #balance = 0;

    deposit(amount) {
        this.#balance += amount;
        return this.#balance;
    }

    withdraw(amount) {
        if (amount > this.#balance) {
            throw new Error("Недостаточно средств");
        }
        this.#balance -= amount;
        return this.#balance;
    }

    get balance() {
        return this.#balance;
    }
}

const account = new BankAccount();
account.deposit(1000);
account.withdraw(300);
console.log(account.balance); // 700
Задача 4. Товар со скидкой

Создайте класс Product с ценой и процентом скидки. Добавьте геттер finalPrice, который возвращает цену со скидкой.

Подсказка

Геттер объявляется словом get и читается как обычное свойство.

Решение учителя 
class Product {    constructor(title, price, discount = 0) {        this.title = title;        this.price = price;        this.discount = discount;    }    get finalPrice() {        return this.price * (1 - this.discount / 100);    }}const laptop = new Product("Ноутбук", 75000, 10);console.log(laptop.finalPrice); // 67500
