Файлы в браузере: File API и drag & drop

~30 минут Продвинутый уровень Теория и Практика

Пользователи загружают аватары, прикрепляют документы, перетаскивают картинки в окно. Всё это делается в браузере - без сервера, на первом этапе. В этом уроке разберём File API: выбор файлов, превью, drag & drop и скачивание.

В этом уроке мы:

  • Научимся читать выбранные файлы.
  • Сделаем превью изображения до загрузки на сервер.
  • Разберём зону drag & drop.
  • Научимся скачивать файлы, созданные в браузере.
Аналогия

Пропускной пункт: сначала проверяют документы и размер багажа, и только потом пускают. Файл проходит те же проверки.

Выбор файла

<input type="file" class="file-input" accept="image/*"><input type="file" class="file-multiple" multiple>
const input = document.querySelector(".file-input");input.addEventListener("change", () => {    const file = input.files[0];    if (!file) return;    console.log(file.name); // "photo.jpg"    console.log(file.size); // размер в байтах    console.log(file.type); // "image/jpeg"});

input.files - это список FileList. При multiple файлов может быть несколько; перебрать их можно через for...of или Array.from(input.files).

Атрибут accept подсказывает браузеру, какие файлы показывать в диалоге. Это именно подсказка: пользователь всё равно может выбрать другой файл, поэтому тип нужно проверять в коде.

Чтение файла

Современный способ - метод text(), arrayBuffer() или blob() у самого файла:

async function readFile(file) {    const text = await file.text();    console.log(text.slice(0, 200));}input.addEventListener("change", () => {    const file = input.files[0];    if (file) readFile(file);});

Старый способ - FileReader. Он всё ещё встречается в проектах:

const reader = new FileReader();reader.addEventListener("load", () => {    console.log(reader.result);});reader.readAsText(file);

Для нового кода выбирайте file.text(): короче и работает с await.

Превью изображения

const input = document.querySelector(".avatar-input");const preview = document.querySelector(".avatar-preview");input.addEventListener("change", () => {    const file = input.files[0];    if (!file || !file.type.startsWith("image/")) return;    const url = URL.createObjectURL(file);    preview.src = url;    preview.addEventListener("load", () => {        URL.revokeObjectURL(url);    }, { once: true });});

URL.createObjectURL создаёт временную ссылку на файл в памяти. Такие ссылки нужно освобождать через revokeObjectURL, иначе память будет расти - особенно если пользователь выбирает файлы многократно.

Проверка файла

function validateFile(file) {    const maxSize = 2 * 1024 * 1024; // 2 МБ    const allowed = ["image/jpeg", "image/png", "image/webp"];    if (!allowed.includes(file.type)) {        return "Поддерживаются только JPEG, PNG и WebP";    }    if (file.size > maxSize) {        return "Файл больше 2 МБ";    }    return null;}

Проверка на клиенте нужна для удобства. Настоящая проверка - на сервере: размер, тип и содержимое файла легко подделать.

Drag & drop

<div class="dropzone">Перетащите файлы сюда</div>
const zone = document.querySelector(".dropzone");zone.addEventListener("dragover", (event) => {    event.preventDefault(); // без этого drop не сработает    zone.classList.add("is-over");});zone.addEventListener("dragleave", () => {    zone.classList.remove("is-over");});zone.addEventListener("drop", (event) => {    event.preventDefault();    zone.classList.remove("is-over");    const files = Array.from(event.dataTransfer.files);    console.log(files.map((file) => file.name));});

Ключевой момент - preventDefault в dragover. Без него браузер считает элемент «не принимающим» и событие drop не возникнет. Это самая частая причина «drag & drop не работает».

Скачивание файла из браузера

Можно сформировать файл прямо в памяти и отдать пользователю:

function downloadJson(data, filename) {    const json = JSON.stringify(data, null, 2);    const blob = new Blob([json], { type: "application/json" });    const url = URL.createObjectURL(blob);    const link = document.createElement("a");    link.href = url;    link.download = filename;    link.click();    URL.revokeObjectURL(url);}downloadJson({ name: "Алексей" }, "user.json");

Тот же приём работает для CSV, текста и картинок. link.download задаёт имя файла; без него браузер может открыть содержимое вместо скачивания.

Шпаргалка

  • input.files выбранные файлы
  • file.name / size / type сведения о файле
  • file.text() прочитать как текст
  • URL.createObjectURL временная ссылка
  • revokeObjectURL освободить память
  • drop файлы перетащены
  • Blob файл в памяти

Если что-то не работает

  • drop не срабатывает. Нет preventDefault в dragover.
  • Превью не появляется. Ссылка создана, но не присвоена src, или файл не изображение.
  • Страница «съедает» перетаскивание. Обработчики нужно вешать и на document, если зона большая: иначе браузер откроет файл вместо вашей логики.
  • Память растёт. Не вызываете revokeObjectURL.
  • Файл читается как пустая строка. Читаете .value у input[type=file] - там всегда пусто, нужен .files[0].
  • Тот же файл не выбирается второй раз. Браузер считает, что значение поля не изменилось. Сбросьте input.value = "" после обработки - и диалог снова сработает.

Практика

Задача 1. Превью аватара

Сделайте поле выбора изображения и img рядом. При выборе файла показывайте превью и выводите размер в килобайтах.

Подсказка

(file.size / 1024).toFixed(1) даст килобайты. Ссылку создавайте через URL.createObjectURL(file).

Решение учителя 
const input = document.querySelector(".avatar-input");const preview = document.querySelector(".avatar-preview");const info = document.querySelector(".avatar-info");input.addEventListener("change", () => {    const file = input.files[0];    if (!file) return;    preview.src = URL.createObjectURL(file);    info.textContent = `${(file.size / 1024).toFixed(1)} КБ`;});
Задача 2. Зона перетаскивания

Сделайте зону, которая подсвечивается при перетаскивании файла и выводит список имён после отпускания. Поддержите несколько файлов.

Подсказка

Три события: dragover (с preventDefault), dragleave и drop. Файлы лежат в event.dataTransfer.files.

Решение учителя 
const zone = document.querySelector(".dropzone");const list = document.querySelector(".file-list");zone.addEventListener("dragover", (event) => {    event.preventDefault();    zone.classList.add("is-over");});zone.addEventListener("dragleave", () => zone.classList.remove("is-over"));zone.addEventListener("drop", (event) => {    event.preventDefault();    zone.classList.remove("is-over");    list.innerHTML = "";    for (const file of event.dataTransfer.files) {        const item = document.createElement("li");        item.textContent = `${file.name} (${Math.round(file.size / 1024)} КБ)`;        list.append(item);    }});
Задача 3. Скачать настройки

Сделайте кнопку, которая скачивает текущие настройки приложения в файл settings.json.

Подсказка

Соберите Blob с типом application/json, создайте ссылку и вызовите click(). Не забудьте освободить URL.

Решение учителя 
function downloadJson(data, filename) {    const blob = new Blob([JSON.stringify(data, null, 2)], {        type: "application/json"    });    const url = URL.createObjectURL(blob);    const link = document.createElement("a");    link.href = url;    link.download = filename;    link.click();    URL.revokeObjectURL(url);}document.querySelector(".export").addEventListener("click", () => {    downloadJson({ theme: "dark", fontSize: 16 }, "settings.json");});
Задача 4. Строки из CSV

Пользователь выбирает CSV-файл. Выведите количество строк в нём.

Подсказка

Прочитайте файл через await file.text() и разбейте по переводу строки.

Решение учителя 
const input = document.querySelector(".csv");input.addEventListener("change", async () => {    const file = input.files[0];    if (!file) return;    const text = await file.text();    const rows = text.trim().split("\n");    console.log(`Строк: ${rows.length}`);});
