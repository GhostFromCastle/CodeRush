Циклы: for и while

~25 минут Начальный уровень Теория и Практика

Представьте, что нужно вывести числа от 1 до 100. Копировать console.log сто раз - плохая идея. Для повторяющихся действий в программировании есть циклы.

В этом уроке мы:

  • Разберём цикл for и его три части.
  • Научимся работать с while и do...while.
  • Поймём, как выйти из цикла досрочно и как пропустить итерацию.
  • Соберём таблицу умножения вложенными циклами.
Аналогия

Беговая дорожка: шаг за шагом, пока не пройдена дистанция. Счётчик i показывает, какой круг сейчас.

Цикл for

Самый частый цикл в JavaScript. У него три части, разделённые точкой с запятой:

for (let i = 1; i <= 5; i++) {    console.log(i);}

Разберём по частям:

  • let i = 1 - начальное значение. Выполняется один раз, перед циклом.
  • i <= 5 - условие. Проверяется перед каждой итерацией. Как только станет ложным, цикл закончится.
  • i++ - шаг. Выполняется после каждой итерации.

Результат: на экране появятся числа 1, 2, 3, 4, 5 - каждое с новой строки.

Почему i

Традиция из математики: i - сокращение от index или iteration. Если циклов несколько, используют i, j, k. Для вложенных циклов по массивам часто берут осмысленные имена: row, col, userIndex.

Обратный отсчёт и шаг

Цикл не обязан идти вверх на единицу. Можно вниз:

for (let i = 5; i >= 1; i--) {    console.log(i);}console.log("Поехали!");

А можно двигаться с шагом 2 или любым другим:

for (let i = 0; i <= 10; i += 2) {    console.log(i); // 0, 2, 4, 6, 8, 10}

Цикл while

while выполняет блок, пока условие истинно. Он удобен, когда заранее неизвестно, сколько будет итераций:

let balance = 100;let days = 0;while (balance > 0) {    balance -= 30;    days++;}console.log(`Денег хватило на ${days} дня`);

Здесь мы не знаем заранее, сколько раз вычтем 30 из 100 - это выясняется по ходу.

Бесконечный цикл

Если условие никогда не станет ложным, цикл будет выполняться вечно, а вкладка - зависнет. Классическая ошибка - забыть изменить счётчик внутри while. Если это случилось, закройте вкладку: остановить такой цикл из консоли почти невозможно.

Цикл do...while

Почти как while, но условие проверяется после тела цикла. Значит, тело выполнится хотя бы один раз:

let attempt = 0;do {    attempt++;    console.log(`Попытка ${attempt}`);} while (attempt < 3);

Такой цикл удобен для меню или запроса пароля: показать один раз нужно всегда, а повторять - только при необходимости.

break и continue

Два оператора управления циклом:

  • break - полностью прерывает цикл.
  • continue - пропускает остаток текущей итерации и переходит к следующей.
for (let i = 1; i <= 10; i++) {    if (i === 7) {        break; // дальше не идём    }    if (i % 2 === 0) {        continue; // чётные пропускаем    }    console.log(i); // 1, 3, 5}

Читается так: «если дошли до семёрки - выходим. Чётные пропускаем. Остальные выводим».

Вложенные циклы

Цикл внутри цикла - нормальная ситуация. Внешний проходит по строкам, внутренний - по столбцам:

for (let i = 1; i <= 3; i++) {    for (let j = 1; j <= 3; j++) {        console.log(`${i} x ${j} = ${i * j}`);    }}

Внутренний цикл полностью выполняется на каждой итерации внешнего. Для трёх на три получится девять строк. Именно так строят таблицы умножения, сетки и матрицы.

Перебор массива

Циклы чаще всего используют для работы с коллекциями. С массивами удобнее особая форма for...of, которая выдаёт сразу значения, а не индексы:

const fruits = ["яблоко", "банан", "груша"];for (const fruit of fruits) {    console.log(fruit);}

Подробно массивы разберём через два урока, а пока запомните: если нужен индекс - используйте обычный for; если только значения - for...of.

Шпаргалка

  • for (init; cond; step) цикл с известным числом итераций
  • while (cond) цикл, пока условие истинно
  • do ... while хотя бы одна итерация гарантирована
  • break выйти из цикла
  • continue пропустить итерацию
  • for...of перебор значений массива

Если что-то не работает

  • Вкладка зависла. Бесконечный цикл: условие никогда не станет ложным. Проверьте, меняется ли счётчик внутри тела.
  • Цикл выполнился на один раз больше или меньше. Классическая ошибка «на единицу»: сравните < и <=. Для массива из пяти элементов индексы идут от 0 до 4, то есть i < 5.
  • «Assignment to constant variable» в цикле. Счётчик объявлен через const. В заголовке for нужен let.
  • break не выходит из вложенного цикла целиком. Он прерывает только тот цикл, в котором написан. Для выхода из обоих используют метки или флаг - но лучше переписать алгоритм.
  • Цикл ничего не выводит. Проверьте начальное значение и условие: возможно, оно ложно с самого начала.
  • Вкладка зависла после запуска. Скорее всего, бесконечный цикл: счётчик не меняется или условие всегда истинно. Закройте вкладку и проверьте, что внутри цикла есть изменение переменной условия.

Практика

Задача 1. Сумма чисел

Посчитайте сумму всех чисел от 1 до 100 и выведите результат.

Подсказка

Заведите переменную sum = 0 до цикла и прибавляйте к ней i на каждой итерации. Не создавайте переменную внутри цикла - она будет обнуляться.

Решение учителя 
let sum = 0;for (let i = 1; i <= 100; i++) {    sum += i;}console.log(sum); // 5050
Задача 2. FizzBuzz

Классическая задача с собеседований. Выведите числа от 1 до 15, но вместо чисел, кратных 3, печатайте «Fizz», вместо кратных 5 - «Buzz», а вместо кратных и 3, и 5 - «FizzBuzz».

Подсказка

Проверка на кратность 15 должна идти первой. Иначе для числа 15 сработает ветка с тройкой и выведет просто «Fizz». Используйте остаток от деления.

Решение учителя 
for (let i = 1; i <= 15; i++) {    if (i % 15 === 0) {        console.log("FizzBuzz");    } else if (i % 3 === 0) {        console.log("Fizz");    } else if (i % 5 === 0) {        console.log("Buzz");    } else {        console.log(i);    }}
Задача 3. Таблица умножения

Выведите таблицу умножения от 2 до 5 в виде строк «2 x 2 = 4», «2 x 3 = 6» и так далее. Понадобятся два вложенных цикла.

Подсказка

Внешний цикл - первый множитель (от 2 до 5), внутренний - второй (тоже от 2 до 5). Вывод соберите шаблонной строкой.

Решение учителя 
for (let i = 2; i <= 5; i++) {    for (let j = 2; j <= 5; j++) {        console.log(`${i} x ${j} = ${i * j}`);    }}
Задача 4. Сумма чётных

Посчитайте сумму чётных чисел от 1 до 20, используя continue.

Подсказка

Нечётные пропускайте через continue, чётные прибавляйте к сумме.

Решение учителя 
let sum = 0;for (let i = 1; i <= 20; i++) {    if (i % 2 !== 0) continue;    sum += i;}console.log(sum); // 110

Что мы узнали и что дальше

Теперь программа умеет повторять действия. Вы знаете:

  • Как устроен цикл for и что означают его три части.
  • Чем отличается while от do...while.
  • Как досрочно выйти из цикла и как пропустить итерацию.
  • Как работают вложенные циклы.

Кода становится больше, и в нём появляются повторы: одна и та же формула, один и тот же вывод, одна и та же проверка. Хорошая программа не повторяется - она выносит общую логику в отдельный блок, который можно вызвать по имени. В следующем уроке разберём функции - главный инструмент структурирования кода.
