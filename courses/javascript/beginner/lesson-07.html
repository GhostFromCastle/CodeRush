Объекты

~30 минут Начальный уровень Теория и Практика

Массивы хороши, когда элементы идут по порядку и равнозначны. Но у пользователя есть имя, почта и возраст, а у товара - название, цена и остаток на складе. Это не список, а набор характеристик. Для таких данных в JavaScript есть объекты.

В этом уроке мы:

  • Научимся создавать объекты и обращаться к свойствам.
  • Разберём вложенные объекты и методы.
  • Познакомимся с перебором и деструктуризацией.
  • Разберёмся, почему копия объекта - не всегда копия.
Аналогия

Анкета: в ней есть подписанные поля - имя, возраст, город. Объект в коде - та же анкета, только поля называются свойствами.

Создание объекта

Объект - это набор пар «ключ: значение» в фигурных скобках:

const user = {    name: "Алексей",    age: 25,    city: "Москва",    isStudent: false};console.log(user.name);  // "Алексей"console.log(user.age);   // 25

Ключи (их ещё называют свойствами) обычно пишутся без кавычек. Значением может быть что угодно: строка, число, массив, другая функция или ещё один объект.

Два способа обратиться к свойству

Через точку:

console.log(user.name);

И через квадратные скобки:

console.log(user["name"]);

Второй способ нужен, когда имя свойства лежит в переменной или содержит пробелы и дефисы:

const field = "age";console.log(user[field]); // 25const stats = { "средний балл": 4.7 };console.log(stats["средний балл"]); // 4.7

Если свойства нет, вы получите undefined - без ошибки:

console.log(user.email); // undefined

Проверить наличие свойства можно оператором in:

console.log("email" in user); // falseconsole.log("name" in user);  // true

Изменение и удаление

Объект, объявленный через const, можно менять. Запрещено только заменять сам объект целиком:

const user = { name: "Алексей" };user.age = 25;              // добавили свойствоuser.name = "Алексей К.";   // изменили значениеdelete user.age;            // удалили свойствоconsole.log(user); // { name: "Алексей К." }
Почему const не мешает менять объект

const запрещает переприсваивание переменной, то есть замену ссылки на другой объект. Содержимое объекта при этом остаётся доступным для изменения. Если нужно защитить сам объект от изменений, используют Object.freeze(user).

Вложенные объекты

Значения могут быть объектами - так строятся реальные структуры данных:

const user = {    name: "Алексей",    address: {        city: "Москва",        street: "Ленина",        building: 12    },    skills: ["JavaScript", "HTML", "CSS"]};console.log(user.address.city);      // "Москва"console.log(user.skills[0]);         // "JavaScript"console.log(user.skills.length);     // 3

Читать цепочку нужно аккуратно: если address не существует, обращение к .city вызовет ошибку. На среднем уровне разберём оператор ?., который решает эту проблему.

Методы и this

Если значение свойства - функция, оно называется методом. Внутри метода this указывает на объект, из которого метод вызван:

const user = {    name: "Алексей",    greet() {        console.log(`Привет, меня зовут ${this.name}`);    }};user.greet(); // "Привет, меня зовут Алексей"

Обратите внимание на сокращённую запись метода: greet() { ... } вместо greet: function () { ... }. Это одно и то же, но короче.

Стрелочная функция и this

Если записать метод стрелочной функцией, this внутри неё будет указывать не на объект, а на внешний контекст. В результате this.name окажется undefined. Для методов объекта используйте обычную или сокращённую запись.

Перебор свойств

Три встроенных метода дают ключи, значения и пары:

const product = {    title: "Ноутбук",    price: 75000,    inStock: true};console.log(Object.keys(product));    // ["title", "price", "inStock"]console.log(Object.values(product));  // ["Ноутбук", 75000, true]console.log(Object.entries(product)); // [["title", "Ноутбук"], ...]

Для перебора пар удобно использовать for...of вместе с деструктуризацией:

for (const [key, value] of Object.entries(product)) {    console.log(`${key}: ${value}`);}

Есть и старый цикл for...in, но он перебирает и унаследованные свойства, поэтому в современном коде его используют редко.

Деструктуризация

Если из объекта нужно достать несколько свойств, не обязательно писать user.name, user.age, user.city:

const user = { name: "Алексей", age: 25, city: "Москва" };const { name, age, city } = user;console.log(name); // "Алексей"console.log(age);  // 25

Можно переименовать переменную и задать значение по умолчанию:

const { name: userName, email = "не указан" } = user;console.log(userName); // "Алексей"console.log(email);    // "не указан"

Деструктуризация особенно удобна в параметрах функции:

function printUser({ name, age }) {    console.log(`${name}, ${age} лет`);}printUser(user);

Копирование: ссылка, а не значение

Объекты, как и массивы, передаются по ссылке:

const original = { name: "Алексей", age: 25 };const copy = original;copy.age = 30;console.log(original.age); // 30 - изменился и оригинал

Независимую копию верхнего уровня можно сделать через spread:

const copy = { ...original };copy.age = 30;console.log(original.age); // 25

Важно: spread копирует только верхний уровень. Вложенные объекты останутся общими - это называется поверхностной копией. Глубокое копирование требует отдельного подхода, о котором поговорим позже.

Шпаргалка

  • obj.key доступ к свойству
  • obj["key"] доступ по имени из переменной
  • "key" in obj проверка наличия свойства
  • Object.keys массив ключей
  • Object.values массив значений
  • Object.entries массив пар [ключ, значение]
  • { ...obj } поверхностная копия

Если что-то не работает

  • «Cannot read properties of undefined». Цепочка длиннее, чем данные: например, у пользователя нет address, а вы читаете user.address.city. Проверяйте промежуточные свойства или используйте ?..
  • this равно undefined. Метод записан стрелочной функцией. Замените на обычную или сокращённую запись.
  • Изменился «оригинал». Объект скопирован присваиванием, а не через { ...obj }.
  • Свойство не читается через точку. В имени есть дефис или пробел - используйте квадратные скобки: obj["some-key"].
  • Object.keys вернул пустой массив. Проверьте, что переменная действительно объект, а не null или массив.
  • В файл сохранилось [object Object]. Объект записали как строку без JSON.stringify. Браузер честно привёл его к тексту, а данные потерялись.

Практика

Задача 1. Профиль

Создайте объект пользователя с именем, возрастом и городом. Добавьте свойство email, измените возраст, затем выведите все пары «ключ: значение» через Object.entries.

Подсказка

Новое свойство добавляется обычным присваиванием: user.email = "...";. Для перебора используйте for (const [key, value] of Object.entries(user)).

Решение учителя 
const user = {    name: "Алексей",    age: 25,    city: "Москва"};user.email = "alex@example.com";user.age = 26;for (const [key, value] of Object.entries(user)) {    console.log(`${key}: ${value}`);}
Задача 2. Корзина

Дан объект с товарами и их количеством: { ноутбук: 1, мышь: 2, клавиатура: 1 }. Посчитайте общее количество единиц товара.

Подсказка

Object.values(cart) вернёт массив количеств [1, 2, 1]. Осталось сложить числа циклом.

Решение учителя 
const cart = { ноутбук: 1, мышь: 2, клавиатура: 1 };let total = 0;for (const count of Object.values(cart)) {    total += count;}console.log(total); // 4
Задача 3. Деструктуризация

Дан объект { name: "Аня", age: 22 }. Достаньте свойства в переменные одной строкой, причём name должно стать firstName. Затем выведите «Аня, 22 года».

Подсказка

Переименование при деструктуризации записывается через двоеточие: const { name: firstName, age } = person;.

Решение учителя 
const person = { name: "Аня", age: 22 };const { name: firstName, age } = person;console.log(`${firstName}, ${age} года`);
Задача 4. Сколько свойств

Посчитайте количество свойств в объекте { name: "Алексей", age: 25, city: "Москва" }.

Подсказка

У объекта нет length. Используйте Object.keys(obj).length.

Решение учителя 
const user = { name: "Алексей", age: 25, city: "Москва" };console.log(Object.keys(user).length); // 3
