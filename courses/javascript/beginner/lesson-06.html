Массивы

~25 минут Начальный уровень Теория и Практика

Представьте список покупок из десяти пунктов. Заводить десять отдельных переменных неудобно: их нужно перебирать, искать, сортировать. Для этого в JavaScript есть массивы.

В этом уроке мы:

  • Научимся создавать массивы и обращаться к элементам по индексу.
  • Разберём добавление и удаление элементов.
  • Познакомимся с перебором и поиском.
  • Поймём разницу между slice и splice.
Аналогия

Шкаф с пронумерованными полками: можно положить, достать и переставить, а номер полки - это индекс.

Создание массива

Массив - это упорядоченный список значений в квадратных скобках:

const fruits = ["яблоко", "банан", "груша"];const numbers = [10, 20, 30, 40];const mixed = ["текст", 42, true, null];console.log(fruits.length); // 3

Массив может хранить значения разных типов, но на практике лучше держать в нём что-то однотипное - так код понятнее.

Индексы: счёт с нуля

У каждого элемента есть номер - индекс. Первый элемент имеет индекс 0, а не 1. Это правило родом из языка C и работает во всех подобных языках.

const fruits = ["яблоко", "банан", "груша"];console.log(fruits[0]); // "яблоко"console.log(fruits[1]); // "банан"console.log(fruits[2]); // "груша"console.log(fruits[3]); // undefined - такого элемента нет

Последний элемент удобно получать через length:

const last = fruits[fruits.length - 1];console.log(last); // "груша"

Элемент можно заменить, обратившись по индексу:

fruits[1] = "апельсин";console.log(fruits); // ["яблоко", "апельсин", "груша"]
undefined вместо ошибки

Обращение к несуществующему индексу не выбрасывает ошибку - оно возвращает undefined. Из-за этого баги бывают тихими: вместо падения программа просто печатает undefined или ломается позже. Всегда проверяйте array.length, если индекс вычисляется.

Добавление и удаление

Четыре метода, которые используются ежедневно:

const queue = ["Аня", "Борис"];queue.push("Вера");      // добавить в конец     -> ["Аня", "Борис", "Вера"]queue.pop();             // убрать с конца       -> ["Аня", "Борис"]queue.unshift("Глеб");   // добавить в начало    -> ["Глеб", "Аня", "Борис"]queue.shift();           // убрать из начала     -> ["Аня", "Борис"]

push и pop работают быстро. unshift и shift заставляют пересчитывать индексы всех элементов, поэтому на больших массивах они медленнее - но для учебных задач это неважно.

Все четыре метода меняют исходный массив. Это важно: если массив был где-то ещё, он изменится и там.

Перебор массива

Самый простой способ - обычный for с индексом:

const numbers = [10, 20, 30];for (let i = 0; i < numbers.length; i++) {    console.log(`Элемент ${i}: ${numbers[i]}`);}

Если индекс не нужен, используйте for...of:

for (const number of numbers) {    console.log(number);}

И третий вариант - метод forEach, который принимает колбэк:

numbers.forEach((number, index) => {    console.log(`${index}: ${number}`);});

Все три дают одинаковый результат. Выбирайте по задаче: нужен индекс - for, нужны только значения - for...of, нужен короткий функциональный стиль - forEach.

Поиск элементов

const fruits = ["яблоко", "банан", "груша"];console.log(fruits.includes("банан"));   // trueconsole.log(fruits.indexOf("груша"));    // 2console.log(fruits.indexOf("киви"));     // -1 - не найдено

includes отвечает на вопрос «есть ли такое значение», indexOf - «под каким индексом». Если значение не найдено, indexOf возвращает -1, а не 0 - потому что 0 это валидный индекс первого элемента.

slice и splice

Эти два метода легко перепутать, хотя делают они разное.

slice - копирует часть массива, не меняя оригинал. Второй параметр не включается в результат:

const letters = ["a", "b", "c", "d", "e"];console.log(letters.slice(1, 3)); // ["b", "c"]console.log(letters.slice(2));    // ["c", "d", "e"]console.log(letters.slice(-2));   // ["d", "e"]console.log(letters);             // исходный массив не изменился

splice - вырезает элементы из массива, меняя его. Второй параметр - сколько удалить, дальше можно передать элементы для вставки:

const letters = ["a", "b", "c", "d", "e"];letters.splice(1, 2);           // удалить 2 элемента с индекса 1console.log(letters);           // ["a", "d", "e"]letters.splice(1, 0, "x", "y"); // вставить "x", "y" на позицию 1console.log(letters);           // ["a", "x", "y", "d", "e"]

Запомнить просто: slice - «отрезать кусочек и отдать», splice - «вырезать из оригинала».

join, reverse и sort

const words = ["JavaScript", "это", "круто"];console.log(words.join(" "));   // "JavaScript это круто"console.log(words.join(", "));  // "JavaScript, это, круто"const numbers = [3, 1, 10, 2];numbers.reverse();console.log(numbers); // [2, 10, 1, 3]

С sort есть подвох. По умолчанию он сортирует как строки, поэтому 10 окажется раньше 2:

const numbers = [3, 1, 10, 2];console.log(numbers.sort());           // [1, 10, 2, 3] - неправильно для чиселconsole.log(numbers.sort((a, b) => a - b)); // [1, 2, 3, 10] - правильно

Функция-компаратор должна возвращать отрицательное число, если a должно идти раньше, положительное - если позже, и ноль - если порядок неважен. Для чисел достаточно a - b (по возрастанию) или b - a (по убыванию).

Копирование массива

Присваивание массива копирует не значения, а ссылку на него:

const original = [1, 2, 3];const same = original;same.push(4);console.log(original); // [1, 2, 3, 4] - изменился и "оригинал"!

Чтобы получить независимую копию, используйте spread-оператор (подробнее - на среднем уровне):

const copy = [...original];copy.push(5);console.log(original); // [1, 2, 3, 4]

Шпаргалка

  • arr.length количество элементов
  • push / pop добавить / убрать в конце
  • shift / unshift убрать / добавить в начале
  • includes есть ли значение
  • indexOf индекс значения или -1
  • slice копия части массива
  • splice вырезать или вставить
  • join склеить в строку

Если что-то не работает

  • Вместо значения undefined. Индекс за пределами массива или опечатка в имени. Помните: последний индекс - length - 1.
  • sort расставляет числа странно. Так и должно быть: по умолчанию сортировка строковая. Передайте компаратор (a, b) => a - b.
  • Исходный массив изменился неожиданно. Использован splice вместо slice, либо массив был скопирован через присваивание, а не через spread.
  • indexOf вернул -1. Значение не найдено. Проверять нужно именно !== -1, а не «больше нуля»: индекс 0 - тоже валидный результат.
  • Массив не меняется после map или filter. Эти методы возвращают новый массив. Результат нужно сохранить в переменную.
  • Массив изменился «сам» в другом месте программы. Массивы передаются по ссылке: два имени могут указывать на один и тот же массив. Если нужна независимая копия, делайте [...arr].

Практика

Задача 1. Список покупок

Создайте массив из трёх продуктов. Добавьте четвёртый в конец, удалите первый, выведите итоговый список одной строкой через запятую.

Подсказка

Для добавления в конец - push, для удаления из начала - shift, для склейки - join(", ").

Решение учителя 
const shopping = ["хлеб", "молоко", "яйца"];shopping.push("сыр");shopping.shift();console.log(shopping.join(", ")); // молоко, яйца, сыр
Задача 2. Максимум в массиве

Найдите самое большое число в массиве [12, 5, 48, 3, 27], не используя Math.max. Понадобится цикл и переменная для текущего максимума.

Подсказка

Начните с первого элемента массива, а затем сравнивайте каждый следующий: если он больше текущего максимума - обновляйте.

Решение учителя 
const numbers = [12, 5, 48, 3, 27];let max = numbers[0];for (const number of numbers) {    if (number > max) {        max = number;    }}console.log(max); // 48
Задача 3. Перевернуть строку

Превратите строку «JavaScript» в перевёрнутую «tpircSavaJ». Подсказка: строку можно разбить на массив символов.

Подсказка

Цепочка из трёх шагов: split("") превращает строку в массив символов, reverse() переворачивает его, join("") собирает обратно.

Решение учителя 
const word = "JavaScript";const reversed = word.split("").reverse().join("");console.log(reversed); // tpircSavaJ

Обратите внимание: методы можно вызывать цепочкой. Каждый следующий работает с результатом предыдущего.

Задача 4. Среднее значение

Посчитайте среднее арифметическое элементов массива [10, 20, 30, 40].

Подсказка

Сложите элементы циклом и разделите на length.

Решение учителя 
const numbers = [10, 20, 30, 40];let sum = 0;for (const n of numbers) {    sum += n;}console.log(sum / numbers.length); // 25

Что мы узнали и что дальше

Теперь вы умеете хранить наборы значений. Вы знаете:

  • Как устроены индексы и почему счёт идёт с нуля.
  • Как добавлять и удалять элементы с обоих концов.
  • Как перебирать массив тремя способами.
  • Чем отличаются slice и splice и почему sort требует компаратора для чисел.

Массив отвечает на вопрос «что лежит под номером N». Но в реальных данных элементы редко равнозначны: у пользователя есть имя, возраст и почта, у товара - название, цена и количество. Хранить это тремя массивами - плохая идея. В следующем уроке разберём объекты - структуру «ключ: значение», на которой держится весь JavaScript.
