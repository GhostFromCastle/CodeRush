Строки: методы и шаблоны

~30 минут Начальный уровень Теория и Практика

Мы уже работали со строками: выводили текст, склеивали через плюс, вставляли значения в шаблонные литералы. Но у строк есть целый набор методов, и половина задач в реальном коде - это именно работа с текстом: обрезать пробелы, проверить домен, собрать адрес, разобрать CSV.

В этом уроке мы:

  • Разберёмся, как строка хранит символы и почему её нельзя изменить.
  • Освоим методы обрезки, поиска и замены.
  • Научимся разбивать текст на части и собирать обратно.
  • Поймём, почему «Москва» и «москва» - разные строки.
Аналогия

Бусы: бусины нанизаны по порядку, каждую можно найти по номеру, но заменить одну, не пересобрав нить, нельзя. Строка устроена так же.

Строка как последовательность символов

У каждого символа есть индекс, и счёт начинается с нуля. Свойство length показывает количество символов:

const word = "JavaScript";console.log(word.length);  // 10console.log(word[0]);      // "J"console.log(word[4]);      // "S"console.log(word[99]);     // undefined

Последний символ получают через length - 1:

console.log(word[word.length - 1]); // "t"
Строки неизменяемы

Отдельный символ нельзя заменить по индексу: word[0] = "j" молча ничего не сделает. Любой метод возвращает новую строку, а исходная остаётся прежней. Поэтому результат всегда нужно присваивать: word = word.toLowerCase().

Сборка текста

Три способа склеить строку - от худшего к лучшему:

const name = "Алексей";const city = "Москва";console.log("Привет, " + name + " из " + city);console.log(`Привет, ${name} из ${city}`);

Шаблонные литералы удобнее: внутри ${} можно писать выражения, а сама строка переносит переводы строк:

const price = 1500;const count = 3;console.log(`Итого: ${price * count} ₽`);const letter = `Уважаемый клиент!Ваш заказ на сумму ${price * count} ₽ готов.`;

Регистр и пробелы

const raw = "  JavaScript  ";console.log(raw.trim());          // "JavaScript"console.log(raw.toUpperCase());   // "  JAVASCRIPT  "console.log(raw.toLowerCase());   // "  javascript  "

trim() убирает пробелы, табы и переводы строк по краям. Это первое, что делают с данными из формы: пользователь почти всегда оставляет лишний пробел.

Частая ошибка - сравнивать строки без нормализации:

const input = " Москва ";console.log(input === "Москва");              // falseconsole.log(input.trim() === "Москва");       // true

Поиск внутри строки

const email = "alex@example.com";console.log(email.includes("@"));        // trueconsole.log(email.startsWith("alex"));   // trueconsole.log(email.endsWith(".com"));     // trueconsole.log(email.indexOf("@"));         // 4console.log(email.indexOf("!"));         // -1

indexOf возвращает -1, если ничего не найдено. Проверять наличие лучше через includes - читается понятнее и не требует сравнения с минус единицей.

Помните: поиск учитывает регистр. «Москва» не содержит «моск»:

console.log("Москва".includes("моск"));                    // falseconsole.log("Москва".toLowerCase().includes("моск"));      // true

Вырезаем часть строки

const iso = "2026-10-30";const year = iso.slice(0, 4);   // "2026"const month = iso.slice(5, 7);  // "10"const day = iso.slice(-2);      // "30"

slice(start, end) берёт символы с start включительно до end не включая. Отрицательные значения считаются с конца. Второй аргумент можно не указывать - тогда берётся всё до конца строки.

Замена

const text = "яблоко, банан, яблоко";console.log(text.replace("яблоко", "груша"));    // первый толькоconsole.log(text.replaceAll("яблоко", "груша")); // все

replace без регулярного выражения заменяет только первое вхождение. Это ловушка, на которой спотыкаются почти все: кажется, что метод сломан. Для всех вхождений нужен replaceAll (поддерживается во всех современных браузерах).

Разбить и собрать

Пара split / join - рабочий инструмент для CSV, тегов и путей:

const csv = "яблоко;банан;груша";const fruits = csv.split(";");console.log(fruits);        // ["яблоко", "банан", "груша"]console.log(fruits.join(", ")); // "яблоко, банан, груша"

Разбить на отдельные символы - split(""). Обратная операция - уже знакомый join(""):

console.log("JavaScript".split("").reverse().join("")); // tpircSavaJ

Дополнение и повтор

console.log("42".padStart(5, "0"));   // "00042"console.log("42".padEnd(5, "."));     // "42..."console.log("-".repeat(20));          // "--------------------"

padStart незаменим для номеров, кодов и времени: час 9 превращается в "09".

Сравнение строк

console.log("apple" < "banana");            // true - посимвольно, по коду символовconsole.log("ёлка".localeCompare("ель"));   // 1  - корректно для русского

Обычные < и > сравнивают коды символов, а не алфавит языка. Для сортировки русских слов используйте localeCompare:

const words = ["ёлка", "яблоко", "арбуз"];console.log(words.sort((a, b) => a.localeCompare(b)));// ["арбуз", "ёлка", "яблоко"]

Про эмодзи и длину

console.log("😀".length);        // 2 - суррогатная параconsole.log([..."😀"].length);   // 1 - настоящие символы

Некоторые символы занимают в памяти две позиции. Если длина важна для эмодзи, разворачивайте строку в массив через spread.

Шпаргалка

  • length количество символов
  • trim убрать пробелы по краям
  • includes есть ли подстрока
  • slice вырезать часть
  • replaceAll заменить все вхождения
  • split / join разбить и собрать
  • padStart дополнить до длины

Если что-то не работает

  • Метод «не меняет» строку. Он возвращает новую. Присвойте результат: text = text.trim().
  • replace заменил только первое вхождение. Так и задумано. Используйте replaceAll.
  • Поиск не находит слово. Разный регистр или лишние пробелы. Нормализуйте обе строки: trim().toLowerCase().
  • slice(0, 4) вернул пустую строку. Начало больше конца или строка короче, чем вы думаете. Проверьте length.
  • В тексте «умные» кавычки из Word. Они выглядят как обычные, но это другие символы. Набирайте код в редакторе, а не копируйте из документа.
  • Логин не находится, хотя имя введено правильно. В конце строки остался пробел или другой регистр. Нормализуйте ввод: trim().toLowerCase() - до сравнения.

Практика

Задача 1. Нормализация имени

Строка " аЛеКсЕй " должна превратиться в «Алексей»: без пробелов, с большой первой буквой и строчными остальными.

Подсказка

Сначала trim() и toLowerCase(), затем первая буква через slice(0, 1).toUpperCase() плюс остаток slice(1).

Решение учителя 
const raw = "  аЛеКсЕй  ";const clean = raw.trim().toLowerCase();const name = clean[0].toUpperCase() + clean.slice(1);console.log(name); // "Алексей"
Задача 2. Проверка адреса

Напишите функцию isSiteAddress(value), которая возвращает true, если строка начинается с https:// и заканчивается на .ru или .com. Регистр не должен иметь значения.

Подсказка

Приведите строку к нижнему регистру и используйте startsWith и endsWith. Проверку окончаний можно объединить через ||.

Решение учителя 
function isSiteAddress(value) {    const url = value.trim().toLowerCase();    const secure = url.startsWith("https://");    const domainOk = url.endsWith(".ru") || url.endsWith(".com");    return secure && domainOk;}console.log(isSiteAddress("https://example.com")); // trueconsole.log(isSiteAddress("http://example.com"));  // false
Задача 3. Подсчёт слов

Посчитайте количество слов в строке. Несколько пробелов подряд не должны считаться за отдельные слова.

Подсказка

Сначала обрежьте строку, затем разбейте по пробелу: split(" "). Но между словами может быть несколько пробелов - лучше разбить по одному или более пробелу регулярным выражением /\s+/, которое разберём чуть позже.

Решение учителя 
const text = "JavaScript   это   язык веба";const words = text.trim().split(/\s+/);console.log(words.length); // 4

Если регулярные выражения пока пугают, сработает и такой вариант: text.trim().split(" ").filter(Boolean) - он выбрасывает пустые куски.

Задача 4. Инициалы

Из строки «Алексей Кузнецов» получите «А. К.».

Подсказка

Разбейте строку по пробелу, возьмите первые буквы и добавьте точку.

Решение учителя 
const fullName = "Алексей Кузнецов";const initials = fullName    .split(" ")    .map((part) => part[0] + ".")    .join(" ");console.log(initials); // "А. К."
