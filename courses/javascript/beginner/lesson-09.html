Числа и Math

~25 минут Начальный уровень Теория и Практика

Числа кажутся простой темой, пока не начнёшь считать деньги. 0.1 + 0.2 в консоли выдаёт 0.30000000000000004, цена в чеке округляется не туда, а «случайное число от 1 до 10» иногда возвращает 0 или 11. Разберёмся, почему так происходит и как с этим жить.

В этом уроке мы:

  • Поймём, как JavaScript хранит числа и откуда берутся неточности.
  • Научимся округлять правильно и предсказуемо.
  • Освоим объект Math и генерацию случайных чисел.
  • Разберёмся с NaN, Infinity и приведением типов.
Аналогия

Касса: копейки удобнее считать целыми монетами, чем дробными рублями. Иначе на округлениях теряется копейка, а в отчёте не сходится итог.

Один тип на всё

В JavaScript нет отдельных типов для целых и дробных чисел. Есть один - number, основанный на 64-битном формате с плавающей точкой (IEEE 754).

console.log(typeof 42);      // "number"console.log(typeof 3.14);    // "number"console.log(typeof -7);      // "number"

Отсюда и берутся особенности:

console.log(0.1 + 0.2);          // 0.30000000000000004console.log(0.1 + 0.2 === 0.3);  // falseconsole.log(1 / 0);              // Infinityconsole.log(-1 / 0);             // -Infinityconsole.log(0 / 0);              // NaN
Это не баг, а цена скорости

Дробные числа хранятся в двоичном виде, и большинство десятичных дробей нельзя представить точно - так же как 1/3 нельзя записать конечной десятичной дробью. Поэтому сравнивать дробные числа «в лоб» через === нельзя. Сравнивайте с допуском: Math.abs(a - b) < 1e-9.

Округление

console.log((0.1 + 0.2).toFixed(2)); // "0.30"console.log((12.345).toFixed(2));    // "12.35"console.log((1500).toLocaleString("ru-RU")); // "1 500"

toFixed возвращает строку - это важно, если дальше нужно считать. Для денег его применяют только на последнем шаге, при выводе:

const price = 1990;const discount = 0.15;const total = price * (1 - discount);console.log(`${total.toFixed(2)} ₽`); // "1691.50 ₽"

Math: встроенная математика

console.log(Math.round(4.6));  // 5 - ближайшее целоеconsole.log(Math.floor(4.9));  // 4 - внизconsole.log(Math.ceil(4.1));   // 5 - вверхconsole.log(Math.trunc(4.9));  // 4 - отбросить дробную частьconsole.log(Math.abs(-7));     // 7 - модульconsole.log(Math.min(3, 8, 1)); // 1console.log(Math.max(3, 8, 1)); // 8console.log(Math.pow(2, 10));   // 1024console.log(Math.sqrt(81));     // 9

Осторожно с отрицательными числами: Math.floor(-4.1) даст -5, а Math.trunc(-4.1) - -4. Это разные операции.

Случайные числа

Math.random() возвращает дробное число от 0 включительно до 1 не включительно. Само по себе оно редко нужно - обычно требуется целое в диапазоне:

// целое от 0 до 9const digit = Math.floor(Math.random() * 10);// целое от min до max включительноfunction randomInt(min, max) {    return Math.floor(Math.random() * (max - min + 1)) + min;}console.log(randomInt(1, 6)); // как кубик

Формула запоминается легко: умножить на количество вариантов, прибавить минимум, округлить вниз. Без + 1 верхняя граница никогда не выпадет.

Преобразование строк в числа

console.log(Number("42"));       // 42console.log(Number("42.5"));     // 42.5console.log(Number(""));         // 0console.log(Number("Привет"));   // NaNconsole.log(parseInt("42px"));   // 42 - читает до первого нечислаconsole.log(parseFloat("3.14м")); // 3.14

Разница важна: Number требует, чтобы вся строка была числом, parseInt и parseFloat читают число с начала и игнорируют остаток. Для данных из формы чаще нужен Number: если пользователь ввёл мусор, лучше получить NaN и показать ошибку, чем молча взять половину.

Запятая вместо точки

Number("3,14") вернёт NaN, а parseInt("3,14") - 3. В русской раскладке пользователи часто вводят запятую. Заменяйте её перед преобразованием: Number(value.replace(",", ".")).

NaN и проверки

console.log(NaN === NaN);          // false - вот такая особенностьconsole.log(Number.isNaN(NaN));    // trueconsole.log(isNaN("Привет"));      // true - сначала приводит к числу

Используйте Number.isNaN: глобальная isNaN сначала пытается преобразовать значение в число, поэтому isNaN("abc") тоже истинно. А ещё есть полезные проверки:

console.log(Number.isInteger(5));    // trueconsole.log(Number.isInteger(5.5));  // falseconsole.log(Number.isFinite(1 / 0)); // false

BigInt для огромных чисел

Обычный number теряет точность после 2⁵³. Для огромных целых есть BigInt - к литералу добавляют n:

const big = 9007199254740993n;console.log(big + 1n); // 9007199254740994n

Смешивать BigInt и обычные числа в одной операции нельзя - будет ошибка. В повседневной вёрстке он нужен редко, но полезно знать, что он существует.

Шпаргалка

  • toFixed(2) округлить до копеек (строка)
  • Math.round ближайшее целое
  • Math.floor вниз
  • Math.ceil вверх
  • Math.random дробное от 0 до 1
  • Number() строка в число
  • Number.isNaN проверка «не число»

Если что-то не работает

  • 0.1 + 0.2 !== 0.3. Особенность хранения дробей. Сравнивайте с допуском или округляйте через toFixed.
  • NaN вместо числа. Строка не преобразовалась: лишние пробелы, запятая, буквы. Проверяйте Number.isNaN до вычислений.
  • Случайное число иногда равно максимуму + 1. Формула без + 1 в скобках или Math.ceil вместо floor.
  • toFixed вернул строку. Так и задумано. Для дальнейших вычислений используйте Number(total.toFixed(2)).
  • Огромное число стало неточным. Вышли за пределы безопасных целых. Нужен BigInt или строковое представление.
  • В чеке не сходится копейка. Цена хранится в дробных числах, и округление каждого шага даёт расхождение. В реальных проектах деньги считают в копейках целыми числами, а делят только при выводе.

Практика

Задача 1. Цена со скидкой

Товар стоит 2499 ₽, скидка 17%. Выведите итоговую цену с двумя знаками после запятой и пробелом между тысячами: «2 074.17 ₽».

Подсказка

Сначала посчитайте число, затем округлите через toFixed(2). Для разделителя тысяч можно применить Number(...).toLocaleString("ru-RU") с настройками дробной части.

Решение учителя 
const price = 2499;const discount = 0.17;const total = price * (1 - discount);const formatted = total.toLocaleString("ru-RU", {    minimumFractionDigits: 2,    maximumFractionDigits: 2});console.log(`${formatted} ₽`); // "2 074,17 ₽"

В русской локали разделитель - запятая. Если нужна точка, используйте total.toFixed(2).

Задача 2. Кубик

Напишите функцию rollDice(), которая возвращает целое число от 1 до 6. Проверьте её в цикле из 20 бросков и убедитесь, что числа не выходят за диапазон.

Подсказка

Формула: Math.floor(Math.random() * 6) + 1. Шесть вариантов, минимум один.

Решение учителя 
function rollDice() {    return Math.floor(Math.random() * 6) + 1;}for (let i = 0; i < 20; i++) {    console.log(rollDice());}
Задача 3. Безопасный ввод числа

Напишите функцию toNumber(value), которая принимает строку, заменяет запятую на точку, убирает пробелы и возвращает число или null, если получилось не число.

Подсказка

Приведите к строке, замените запятую, уберите пробелы через replaceAll(" ", ""), затем Number(...). Проверяйте результат через Number.isNaN.

Решение учителя 
function toNumber(value) {    const normalized = String(value)        .trim()        .replaceAll(" ", "")        .replace(",", ".");    const number = Number(normalized);    return Number.isNaN(number) ? null : number;}console.log(toNumber("1 234,56")); // 1234.56console.log(toNumber("abc"));      // null
Задача 4. Среднее с округлением

Выведите среднее трёх чисел 10, 15, 20 с двумя знаками после запятой.

Подсказка

Сложите, разделите на 3 и примените toFixed(2).

Решение учителя 
const a = 10;const b = 15;const c = 20;const avg = (a + b + c) / 3;console.log(avg.toFixed(2)); // "15.00"
