Переменные и типы данных

~25 минут Начальный уровень Теория и Практика

В прошлом уроке мы выводили готовые значения. Но программа становится полезной, когда умеет запоминать данные: имя пользователя, количество товаров, результат вычисления. Для этого нужны переменные.

В этом уроке мы:

  • Научимся создавать переменные через let и const.
  • Разберём основные типы данных: строки, числа, логические значения.
  • Познакомимся с шаблонными строками - самым удобным способом собрать текст.
  • Поймём, почему "5" + 1 даёт "51", а не 6.

Что такое переменная

Переменная - это именованная ячейка памяти. Вы кладёте в неё значение и потом обращаетесь к нему по имени. Аналогия простая: это подписанная коробка, на которой написано «возраст», а внутри лежит число 25.

В современном JavaScript переменные создают двумя способами:

let city = "Москва";const country = "Россия";console.log(city);console.log(country);
  • let - переменная, которую можно изменить позже.
  • const - константа: значение задаётся один раз и больше не меняется.

Почему не var? Он существует с первых версий языка, но ведёт себя странно: игнорирует блоки кода и позволяет использовать переменную до объявления. Сейчас var в новом коде не используют. Правило простое: по умолчанию const, а let - только если значение действительно будет меняться.

Почему const по умолчанию

Чем меньше в программе «подвижных» сущностей, тем проще искать ошибки. Если вы случайно перезапишете const, браузер сразу об этом скажет. А вот случайную перезапись let придётся искать глазами.

Основные типы данных

JavaScript - язык с динамической типизацией: тип определяется значением, а не объявлением переменной. Основных типов, с которыми вы будете работать каждый день, пять.

Строка (string)

Любой текст в кавычках. Подходят одинарные, двойные и обратные кавычки:

let name = "Алексей";let greeting = 'Привет';let template = `Обратные кавычки`;

Число (number)

Отдельного типа для целых и дробных чисел нет - это всё number:

let age = 25;let price = 199.99;let temperature = -7;

Логический тип (boolean)

Только два значения: true или false. Без кавычек - иначе это уже строка.

let isStudent = true;let hasAccess = false;

null и undefined

null - «пусто, задано намеренно». undefined - «значение не задано вообще». Разница тонкая, но важная:

let empty = null;        // пусто сознательноlet notDefined;          // значение не присвоеноconsole.log(notDefined); // undefined

typeof: узнаём тип

Оператор typeof возвращает тип значения строкой. Это лучший способ проверить, с чем вы имеете дело:

console.log(typeof "Привет");   // "string"console.log(typeof 42);         // "number"console.log(typeof true);       // "boolean"console.log(typeof undefined);  // "undefined"console.log(typeof null);       // "object" - историческая особенность языкаconsole.log(typeof 42n);        // "bigint"
typeof null - это object

Ошибка, которая живёт в JavaScript с 1995 года. Проверять «пустое» значение через typeof x === "object" нельзя - используйте строгое сравнение x === null.

Шаблонные строки

Склеивать текст через плюс быстро надоедает. Гораздо удобнее обратные кавычки: внутрь можно вставлять значения через ${...}.

let name = "Алексей";let age = 25;console.log("Меня зовут " + name + ", мне " + age + " лет");console.log(`Меня зовут ${name}, мне ${age} лет`);

Обе строки дадут одинаковый результат, но вторая читается заметно легче. Внутри ${} можно писать не только имена переменных, но и целые выражения:

let a = 7;let b = 3;console.log(`${a} + ${b} = ${a + b}`);

На экране появится 7 + 3 = 10.

Приведение типов

JavaScript умеет преобразовывать типы автоматически, и это источник половины неожиданных результатов у новичков. Классический пример:

console.log(5 + 3);      // 8console.log("5" + 3);    // "53"console.log("5" - 3);    // 2

Причина в том, что знак + умеет и складывать числа, и склеивать строки. Если хотя бы один операнд - строка, + выберет склейку. А минус строкой быть не может, поэтому "5" превращается в число.

Чтобы не полагаться на эти правила, приводите типы явно:

console.log(Number("42"));      // 42console.log(Number("Привет"));  // NaN - Not a Numberconsole.log(String(42));        // "42"console.log(Boolean(0));        // false

NaN расшифровывается как «Not a Number» и означает неудачное числовое преобразование. Проверить его можно функцией Number.isNaN().

Как называть переменные

Правила языка минимальны: имя может содержать латинские буквы, цифры, $ и _, не может начинаться с цифры и не должно совпадать с зарезервированными словами вроде let или class. Но есть правила хорошего тона:

  • camelCase. userName, totalPrice, isActive - каждое слово с большой буквы, кроме первого.
  • Имя отвечает на вопрос «что здесь лежит». a, b, data1 плохие. userAge, cartItems хорошие.
  • Логические переменные начинаются с is / has / can. isLoading, hasAccess, canPay.
  • Одно слово - один смысл. Если где-то user, а где-то person для одного и того же - это путаница.

Шпаргалка

  • let переменная, которую можно изменить
  • const константа, менять нельзя
  • typeof тип значения
  • `${...}` вставка значения в строку
  • Number() приведение к числу
  • String() приведение к строке
  • NaN результат неудачного вычисления

Если что-то не работает

  • «Uncaught TypeError: Assignment to constant variable». Вы пытаетесь переприсвоить const. Либо замените на let, либо заведите новую переменную - второе чаще правильнее.
  • «Uncaught SyntaxError: Missing initializer in const declaration». const нельзя объявить без значения: const name; не сработает, нужно const name = "Алексей";.
  • Получилось "25", а не 25. Значение пришло строкой - например, из поля ввода. Приводите через Number().
  • undefined в шаблонной строке. Переменная объявлена, но значение не присвоено, либо опечатка в имени. Проверьте typeof.
  • «... is not defined». Переменная не объявлена или объявлена в другом блоке кода. Объявление должно быть до первого использования.
  • Число из формы ведёт себя как текст. prompt и input.value всегда возвращают строку. «10» + 5 даст «105», а не 15 - приводите через Number().

Практика

Задача 1. Анкета

Создайте три константы: имя, возраст и город. Выведите одной шаблонной строкой: «Меня зовут Алексей, мне 25 лет, я из Москвы».

Подсказка

Используйте обратные кавычки и ${} вокруг имён переменных. Не забудьте, что запятые и пробелы - часть текста.

Решение учителя 
const name = "Алексей";const age = 25;const city = "Москва";console.log(`Меня зовут ${name}, мне ${age} лет, я из ${city}`);
Задача 2. Чек в магазине

Товар стоит 1200 рублей, скидка - 15%. Посчитайте итоговую сумму и выведите её одной строкой: «К оплате: 1020 рублей». Скидку храните отдельной константой.

Подсказка

Размер скидки в процентах нужно перевести в долю: 15 / 100. Итог: price - price * discount. Округлить результат можно методом toFixed(0) - он вернёт строку.

Решение учителя 
const price = 1200;const discount = 15 / 100;const total = price - price * discount;console.log(`К оплате: ${total} рублей`);

Если нужна сумма без копеек, используйте total.toFixed(0).

Задача 3. Найдите ошибки

Код должен посчитать сумму двух чисел и вывести 30. Найдите три ошибки.

const a = "10";let b = 20;b = b + 5;console.log("Сумма: " + a + b);
Подсказка

Первая ошибка - a хранит строку. Вторая - из-за этого + склеивает, а не складывает. Третья - порядок вывода: сначала числа, потом текст.

Решение учителя 
const a = 10;let b = 20;b = b + 5;console.log(`Сумма: ${a + b}`);

Внутри ${} выражение вычисляется целиком, поэтому склейки не происходит. Результат: Сумма: 35.

Задача 4. Поменяйте местами

В переменных a = 1 и b = 2 поменяйте значения местами так, чтобы получилось a = 2, b = 1.

Подсказка

Заведите третью переменную для временного хранения значения.

Решение учителя 
let a = 1;let b = 2;const temp = a;a = b;b = temp;console.log(a, b); // 2 1
