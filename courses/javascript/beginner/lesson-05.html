Функции

~30 минут Начальный уровень Теория и Практика

К этому моменту вы уже заметили: один и тот же код приходится повторять. Посчитать скидку для одного товара, потом для второго, потом для третьего - и каждый раз копировать формулу. Функции решают эту проблему: код пишется один раз, а вызывается сколько нужно.

В этом уроке мы:

  • Научимся объявлять функции и вызывать их.
  • Разберём параметры, аргументы и return.
  • Познакомимся со стрелочными функциями.
  • Поймём, что такое область видимости и колбэк.
Аналогия

Кулинарный рецепт: один раз записали - готовите сколько угодно раз, меняя только продукты (аргументы).

Зачем нужны функции

Функция - это именованный блок кода, который выполняет одну задачу. Её главная ценность не в экономии строк, а в понятности. Сравните:

const price1 = 1000;const total1 = price1 - price1 * 0.15;const price2 = 2400;const total2 = price2 - price2 * 0.15;const price3 = 500;const total3 = price3 - price3 * 0.15;

И то же самое с функцией:

function withDiscount(price, percent) {    return price - price * (percent / 100);}console.log(withDiscount(1000, 15));console.log(withDiscount(2400, 15));console.log(withDiscount(500, 15));

Правило изменилось? Меняем в одном месте, а не в трёх. Появился новый товар? Одна строка вызова. Это и есть главная причина существования функций.

Объявление и вызов

function greet(name) {    console.log(`Привет, ${name}!`);}greet("Алексей");greet("Мария");
  • function - ключевое слово.
  • greet - имя функции. Глагол: calculateTotal, showMessage, isValid.
  • name - параметр: переменная, которая получит значение при вызове.
  • greet("Алексей") - вызов. Значение в скобках называется аргументом.

Функция без параметров вызывается с пустыми скобками: sayHello().

return: результат работы

Функция может не только что-то делать, но и возвращать результат:

function add(a, b) {    return a + b;}const result = add(2, 3);console.log(result); // 5

return делает две вещи: возвращает значение и немедленно завершает функцию. Код после него не выполнится:

function checkAge(age) {    if (age < 18) {        return "доступ запрещён";    }    return "доступ разрешён";    console.log("Эта строка никогда не выполнится");}

Если функция не содержит return, она возвращает undefined. Это одна из самых частых причин ошибки «получил undefined вместо числа».

Функция должна делать одно дело

Хорошая функция умеет предсказуемо отвечать на вопрос «что она вернёт». Если внутри и расчёт, и вывод, и сохранение в базу - это уже три функции, притворяющиеся одной. Разделяйте: одна считает, другая показывает. Такой код проще тестировать и менять.

Параметры по умолчанию

Если аргумент не передали, параметр станет undefined. Чтобы этого избежать, задайте значение по умолчанию прямо в объявлении:

function greet(name = "гость") {    console.log(`Привет, ${name}!`);}greet();          // Привет, гость!greet("Мария");   // Привет, Мария!

Значение по умолчанию срабатывает только при undefined. Если передать null или пустую строку - они так и останутся.

Функциональные выражения и стрелочные функции

Кроме объявления через function, функцию можно сохранить в переменную:

const add = function (a, b) {    return a + b;};

А можно записать короче, стрелочной функцией:

const add = (a, b) => {    return a + b;};

Если тело состоит из одного выражения, его можно вернуть без return и фигурных скобок:

const add = (a, b) => a + b;const double = n => n * 2;const greet = () => "Привет!";

Стрелочные функции короче и почти всегда используются в современном коде. Но у них есть важное отличие: своё this они не создают. Подробно разберём это на продвинутом уровне, а пока запомните: в объектах-методах стрелочные функции ведут себя не так, как обычные.

Область видимости

Переменные, объявленные внутри функции, снаружи не видны:

function calculate() {    const secret = 42;    console.log(secret); // 42}calculate();console.log(secret); // ReferenceError: secret is not defined

А вот снаружи внутрь переменные видны:

const rate = 0.15;function withTax(price) {    return price + price * rate; // rate доступна}

Это называется лексической областью видимости: функция видит то, что объявлено в месте её создания. Принцип «объявляйте переменные как можно ближе к использованию» помогает не запутаться.

Колбэки: функция как аргумент

Функцию можно передать в другую функцию - как обычное значение. Такая функция называется колбэком (callback):

function processUser(name, callback) {    console.log(`Обрабатываем ${name}`);    callback(name);}processUser("Алексей", (name) => {    console.log(`Готово: ${name}`);});

Звучит абстрактно, но вы будете пользоваться этим постоянно. Вот реальный пример из следующего уровня:

const numbers = [1, 2, 3];numbers.forEach((n) => {    console.log(n * 2);});

forEach берёт вашу функцию и вызывает её для каждого элемента массива. Колбэк - это способ сказать «сделай вот это с каждым элементом», не описывая сам цикл.

Шпаргалка

  • function name() {} объявление функции
  • return вернуть результат и выйти
  • () => {} стрелочная функция
  • param = value значение по умолчанию
  • callback функция, переданная в функцию

Если что-то не работает

  • Функция возвращает undefined. Забыли return или написали его внутри if, который не сработал.
  • console.log(add(2, 3)) печатает undefined. Внутри функции использован console.log вместо return. Вывод и возврат - разные вещи.
  • Параметр равен undefined. Аргумент не передан или передан в неправильном порядке. Сравните количество и порядок параметров.
  • «greet is not a function». Имя занято чем-то другим - например, переменной. Или функция объявлена внутри другого блока и здесь недоступна.
  • Стрелочная функция «не видит» this. Для методов объекта используйте обычную функцию или сокращённую запись метода - разберём в уроке про объекты.
  • Функция «ничего не возвращает». Внутри посчитали значение, но забыли return - и получили undefined. Это не ошибка браузера, а заблуждение: вывод в консоль и возврат результата - разные вещи.

Практика

Задача 1. Приветствие

Напишите функцию greet(name), которая возвращает строку «Привет, ИМЯ!». Если имя не передано - «Привет, гость!».

Подсказка

Значение по умолчанию задаётся прямо в параметре: function greet(name = "гость"). Не забудьте return, а не console.log.

Решение учителя 
function greet(name = "гость") {    return `Привет, ${name}!`;}console.log(greet("Алексей"));console.log(greet());
Задача 2. Калькулятор

Напишите функцию calculate(a, b, operator), которая выполняет одно из четырёх действий: "+", "-", "*", "/". Для неизвестного оператора верните «неизвестная операция». Деление на ноль должно вернуть «деление на ноль».

Подсказка

Подойдёт switch по оператору. Проверку деления на ноль сделайте до вычисления - иначе получите Infinity.

Решение учителя 
function calculate(a, b, operator) {    switch (operator) {        case "+": return a + b;        case "-": return a - b;        case "*": return a * b;        case "/":            if (b === 0) return "деление на ноль";            return a / b;        default:            return "неизвестная операция";    }}console.log(calculate(10, 2, "+")); // 12console.log(calculate(10, 0, "/")); // деление на ноль
Задача 3. Проверка на чётность

Напишите стрелочную функцию isEven(n), которая возвращает true, если число чётное, и false иначе. Проверьте её на числах 4, 7 и 0.

Подсказка

Чётность - это n % 2 === 0. В стрелочной функции без фигурных скобок результат выражения возвращается автоматически. Ноль считается чётным - проверьте, что ваша функция с этим согласна.

Решение учителя 
const isEven = (n) => n % 2 === 0;console.log(isEven(4)); // trueconsole.log(isEven(7)); // falseconsole.log(isEven(0)); // true
Задача 4. Максимум из трёх

Напишите функцию maxOfThree(a, b, c), которая возвращает наибольшее из трёх чисел.

Подсказка

Можно сравнить числа вручную или использовать Math.max.

Решение учителя 
function maxOfThree(a, b, c) {    return Math.max(a, b, c);}console.log(maxOfThree(4, 9, 2)); // 9
