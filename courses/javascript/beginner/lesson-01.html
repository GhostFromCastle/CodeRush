Что такое JavaScript и первая программа

~20 минут Начальный уровень Теория и Практика

Добро пожаловать на курс JavaScript! Если вы читаете этот текст, значит, вы готовы добавить движение в свои страницы. HTML отвечает за структуру, CSS - за внешний вид, а JavaScript - за поведение. Это единственный язык, который браузер понимает из коробки, без установки чего-либо.

В этом уроке мы не будем углубляться в теорию. Мы просто:

  • Разберёмся, где вообще выполняется JavaScript.
  • Откроем консоль разработчика и запустим первую команду.
  • Подключим отдельный файл к странице и увидим результат.
Аналогия

Пульт от телевизора: HTML - корпус и экран, CSS - оформление, JavaScript - кнопки, которые заставляют всё это работать.

Почему именно JavaScript

JavaScript - это язык, который оживляет страницу. HTML-разметка сама по себе статична: по ней нельзя ничего посчитать, переключить или изменить без перезагрузки. Именно JS обрабатывает клики, проверяет формы, подгружает данные и перерисовывает интерфейс.

  • Работает везде. Движок JavaScript встроен в каждый браузер. Открыли страницу - код уже готов выполняться.
  • Один язык на всю веб-разработку. На нём пишут и то, что происходит в браузере, и серверную часть (Node.js, Deno).
  • Огромная экосистема. Библиотеки на любой вкус, от анимаций до интерфейсов и работы с картами.
  • Быстрый старт. Чтобы написать первую программу, достаточно блокнота и браузера.
JavaScript и Java - не одно и то же

Названия похожи, но это два совершенно разных языка. Java - строгий, компилируемый язык для больших систем. JavaScript - гибкий язык для браузера. Общего у них примерно столько же, сколько у слова «кот» и «котлета».

Где выполняется JavaScript

Когда браузер загружает страницу, он разбирает HTML и CSS, а затем ищет в разметке подключённые скрипты. Найденный код передаётся специальной программе - движку JavaScript. В Chrome и Edge это V8, в Firefox - SpiderMonkey, в Safari - JavaScriptCore.

Удобнее всего проверять код прямо в браузере, не трогая файлы. Для этого есть консоль разработчика:

  1. Откройте любую страницу в браузере.
  2. Нажмите F12 (или правой кнопкой → «Посмотреть код»).
  3. Перейдите на вкладку Console.

Внизу появится строка ввода. Это полноценная песочница: здесь можно выполнять любые команды и сразу видеть результат.

Первая программа: Hello, World!

Традиция в программировании: первая программа на любом языке должна вывести на экран «Hello, World!». В JavaScript для вывода в консоль используется console.log. Наберите в консоли:

console.log("Hello, World!");

Нажмите Enter - и увидите строку ниже:

Hello, World!

Поздравляем! Вы только что написали и выполнили свою первую программу на JavaScript.

Разбор: что такое console.log

Давайте посмотрим на команду по частям:

console.log("Hello, World!");
  • console - встроенный объект браузера, «окно» для вывода служебной информации.
  • Точка . - обращение к тому, что лежит внутри объекта.
  • log - метод, который печатает переданное значение.
  • Круглые скобки - вызов метода. Всё, что внутри, - данные для вывода.
  • Кавычки - это строка, то есть текст. Без кавычек браузер решит, что Hello - имя переменной, и выдаст ошибку.
Точка с запятой

Точка с запятой в конце инструкции формально необязательна - JavaScript сам понимает, где заканчивается выражение. Но привычка ставить её спасает от редких и очень неприятных ошибок. Правило простое: одна инструкция - одна точка с запятой.

Подключаем отдельный файл

В консоли удобно экспериментировать, но настоящий код живёт в файлах. Создайте рядом с HTML-страницей файл script.js и подключите его перед закрывающим тегом </body>:

<!DOCTYPE html><html lang="ru"><head>    <meta charset="UTF-8">    <title>Первая страница</title></head><body>    <h1>Моя первая страница</h1>    <script src="script.js"></script></body></html>

А в самом файле script.js напишите:

console.log("Скрипт подключён!");console.log(2 + 2);

Откройте страницу и загляните в консоль. Увидите две строки: текст и число 4. Обратите внимание: "2 + 2" в кавычках - это текст, а 2 + 2 без кавычек - вычисление. Разница принципиальная, и дальше мы будем встречаться с ней постоянно.

Атрибут defer

Если скрипт лежит в <head> и обращается к элементам страницы, он сработает раньше, чем эти элементы появятся. Добавьте defer - <script src="script.js" defer></script> - и браузер выполнит код только после построения страницы. Мы будем использовать этот приём в уроках про DOM.

Комментарии

Комментарии - это заметки для людей. Браузер их игнорирует. В JavaScript их два вида:

// Однострочный комментарий - до конца строки/*   Многострочный комментарий.   Удобен для больших пояснений.*/console.log("Код работает"); // комментарий после инструкции тоже допустим

Хорошее правило: комментарий объясняет зачем, а не что. Строка // прибавляем единицу над i++ бесполезна. А вот // компенсируем часовой пояс сервера - уже полезно.

Шпаргалка

Самое важное в одном месте:

  • console.log() вывод значения в консоль
  • F12 открыть инструменты разработчика
  • "текст" строка в кавычках
  • // однострочный комментарий
  • ; конец инструкции
  • <script src="..."> подключение файла со скриптом

Если что-то не работает

Разберём типичные проблемы, с которыми сталкиваются новички на самом первом уроке.

  • «Uncaught ReferenceError: consol is not defined». Опечатка в слове console. JavaScript чувствителен к регистру: Console, CONSOLE и consol - разные имена.
  • В консоли пусто. Проверьте, что скрипт действительно подключён и путь к файлу правильный. Если открыть консоль на другой вкладке или другом сайте, вывод будет не там.
  • «Uncaught SyntaxError: Invalid or unexpected token». Скорее всего, использованы «умные» кавычки из Word или мессенджера. Нужны обычные "..." или '...' в английской раскладке.
  • Вместо русского текста кракозябры. Добавьте в <head> строку <meta charset="UTF-8"> и сохраните файл в UTF-8.
  • Код выполнился раньше страницы. Если скрипт обращается к элементам, которых ещё нет, перенесите его в конец <body> или добавьте defer.
  • Скрипт работает в консоли, но не на странице. Чаще всего файл подключён по неверному пути или стоит в <head> без defer. Проверьте вкладку Network: если файла нет в списке, браузер его не загрузил.

Если что-то не получается - напишите нам в Telegram, разберёмся вместе.

Практика

Три задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Поздоровайтесь

Выведите в консоль две строки: «Привет, мир!» и «Я учу JavaScript». Используйте console.log.

Подсказка

Нужны две отдельные инструкции - по одной на каждую строку. Не забудьте кавычки вокруг текста и точку с запятой в конце.

Решение учителя 
console.log("Привет, мир!");console.log("Я учу JavaScript");
Задача 2. Визитка

Выведите в консоль три строки: ваше имя, возраст и город. Каждая строка должна быть на новой строке.

Подсказка

Возраст можно вывести числом, без кавычек: console.log(25);. Так вы попутно увидите разницу между строкой и числом в консоли - строка показывается в кавычках (или чёрным), число - синим.

Решение учителя 
console.log("Алексей");console.log(25);console.log("Москва");
Задача 3. Найдите ошибки

Перед вами код с ошибками. Найдите и исправьте их, чтобы программа вывела текст без ошибок в консоли.

console.log(Привет);consol.log("Как дела?");Console.log("Пока!");
Подсказка

Три ошибки: отсутствуют кавычки в первой строке, опечатка в слове console во второй, и неправильный регистр в третьей. JavaScript чувствителен к регистру.

Решение учителя 
console.log("Привет");console.log("Как дела?");console.log("Пока!");

Обратите внимание: Console с большой буквы - уже другое имя, которого в браузере нет.

Задача 4. Объясните результат

Выполните в консоли console.log("2" + 2) и console.log(2 + 2). Объясните, почему результаты разные.

Подсказка

Обратите внимание на кавычки. Если хотя бы одна сторона - строка, плюс склеивает.

Решение учителя 
console.log("2" + 2); // "22"console.log(2 + 2);   // 4

Что мы узнали и что дальше

Сегодня мы разобрались с главным вопросом: где выполняется JavaScript. Теперь вы знаете:

  • Что JavaScript отвечает за поведение страницы, а не за её структуру и внешний вид.
  • Как открыть консоль разработчика и выполнить в ней код.
  • Как подключить внешний файл через <script src="...">.
  • Что такое console.log и почему текст пишется в кавычках.
  • Как работают комментарии и зачем нужна точка с запятой.

Пока наши программы не умеют запоминать данные - каждая строка существует сама по себе. Это неудобно: любой калькулятор должен где-то хранить числа, а форма - имя пользователя. В следующем уроке мы познакомимся с переменными и типами данных: узнаем, как JavaScript хранит текст, числа и логические значения, и научимся собирать строки из кусочков. До встречи!
