JavaScript в браузере

Язык, который оживляет веб

От первой строки в консоли до собственного приложения с сохранением данных. JavaScript - единственный язык, который понимает браузер: он реагирует на клики, меняет страницу без перезагрузки, ходит за данными на сервер и держит состояние интерфейса. Курс построен вокруг практики: каждый урок - новый инструмент и маленькая работающая программа.
