API нейросетей: как подружить ИИ с вашим кодом

~35 минут Продвинутый уровень Теория и Практика

Добро пожаловать на продвинутый уровень. До этого момента мы общались с нейросетями через веб-интерфейс: открывали ChatGPT или Claude, вводили промпт, получали ответ. Это удобно для ручной работы, но что, если вы хотите, чтобы ИИ автоматически обрабатывал отзывы на вашем сайте или отвечал клиентам в Telegram-боте?

Копировать и вставлять текст вручную - не вариант. Для этого существует API (Application Programming Interface). В этом уроке мы разберёмся, что это такое, как устроены запросы к нейросетям и как написать свой первый скрипт, который общается с ИИ.

Что такое API: аналогия с рестораном

Представьте, что вы пришли в ресторан. Вы не заходите на кухню, не открываете холодильник и не готовите еду сами. Вы садитесь за столик, смотрите меню, делаете заказ официанту. Официант передает заказ на кухню, повара готовят блюдо, и официант приносит его вам.

В мире программирования API - это официант. Ваша программа (клиент) не имеет прямого доступа к мощным серверам OpenAI или Yandex. Вместо этого она отправляет специальный запрос (заказ) по интернету. Сервер компании (кухня) обрабатывает его и возвращает готовый ответ.

API - это набор правил, по которым ваш код общается с чужим сервисом. Вы говорите: «Дай мне ответ на такой-то промпт», и сервер понимает вас.

Как устроен запрос к LLM

Технически общение происходит через HTTP-запросы. Чаще всего используется метод POST. Вы отправляете на сервер JSON-файл с параметрами, а сервер возвращает JSON с ответом.

Вот как примерно выглядит запрос к API:

POST https://api.openai.com/v1/chat/completionsContent-Type: application/jsonAuthorization: Bearer ВАШ_СЕКРЕТНЫЙ_КЛЮЧ{  "model": "gpt-4o",  "messages": [    {"role": "user", "content": "Привет! Как дела?"}  ]}

Что здесь происходит:

  • URL - адрес «кухни» (сервера).
  • Authorization - пропуск. Это ваш API-ключ, который доказывает, что вы имеете право делать заказ.
  • model - какая именно модель должна отвечать (gpt-4o, gpt-3.5 и т.д.).
  • messages - само сообщение. Здесь можно передать контекст (роль системы) и историю диалога.

Ключи API и безопасность

API-ключ - это ваш пароль от сервиса. Он привязан к вашему аккаунту и вашей банковской карте (если сервис платный). Если кто-то украдет ваш ключ, он сможет тратить ваши деньги.

Поэтому существуют железные правила безопасности:

  • Никогда не публикуйте ключ в открытом доступе (на форумах, в GitHub, в скриншотах).
  • Не храните ключ прямо в коде. Если вы выложите код на GitHub, злоумышленники найдут ключ за секунды.
  • Используйте переменные окружения (файл .env) для хранения ключей на вашем компьютере или сервере.
Осторожно: платность

В отличие от бесплатного веб-интерфейса, API почти всегда платный. Вы платите за количество отправленных и полученных токенов. Поэтому при тестировании скриптов следите за лимитами, чтобы случайно не потратить лишние деньги.

Пишем первый скрипт на Python

Чтобы не писать сложные HTTP-запросы вручную, разработчики используют библиотеки. Для Python существует официальная библиотека openai, которая делает всё за вас.

Сначала её нужно установить. В терминале выполните:

pip install openai python-dotenv

Теперь создадим скрипт. Он берет промпт, отправляет его в модель и выводит ответ в консоль.

main.py 
import os
from openai import OpenAI
from dotenv import load_dotenv

load_dotenv()

client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))

response = client.chat.completions.create(
    model="gpt-3.5-turbo",
    messages=[
        {"role": "system", "content": "Ты ассистент."},
        {
            "role": "user", 
            "content": "Напиши стих про код."
        }
    ]
)

print(response.choices[0].message.content)

Обратите внимание на строку os.getenv("OPENAI_API_KEY"). Это и есть безопасный способ: ключ хранится в файле .env, который не попадает в код.

Токены и стоимость

При работе через API вы платите за токены. Вспомните первый урок: токен - это кусочек текста. Один токен - это примерно 4 символа английского текста или 2-3 символа русского.

Цена зависит от модели. Младшие модели (например, gpt-3.5-turbo) стоят копейки. Старшие (gpt-4o) стоят значительно дороже. Кроме того, входные токены (ваш промпт) стоят дешевле, чем выходные (ответ модели).

Поэтому в промптах для API часто просят: «Отвечай кратко, не более 100 слов», чтобы сэкономить бюджет.

Ограничения API (Rate Limits)

Серверы не любят, когда их перегружают. Для каждого ключа действует ограничение по количеству запросов в минуту (Rate Limit). Если ваш скрипт отправит слишком много запросов одновременно, сервер вернет ошибку 429 Too Many Requests.

В коде нужно предусматривать обработку таких ошибок и делать паузу перед повторной отправкой.

Шпаргалка

Самое важное в одном месте:

  • API интерфейс для общения программ
  • Официант аналогия API, передающего заказ на кухню
  • API-ключ секретный пароль для доступа
  • JSON формат передачи данных
  • Токены валюта, которой вы платите за API
  • Rate Limit лимит на количество запросов

Если что-то не работает

Разберём типичные проблемы при работе с API.

  • «Ошибка 401 Unauthorized». Проблема с ключом. Либо вы неправильно его скопировали, либо не передали в заголовке Authorization. Проверьте, что ключ актуален и в переменной окружения нет лишних пробелов.
  • «Ошибка 429 Too Many Requests». Вы превысили лимит запросов. Добавьте в код паузу (time.sleep(1)) или изучите документацию сервиса, чтобы узнать актуальные лимиты.
  • «Ошибка 400 Bad Request». Часто возникает, если вы передали слишком длинный текст, превысив контекстное окно модели, или ошиблись в структуре JSON.
  • «Скрипт работает, но деньги на карте кончились». Вы не установили лимиты в личном кабинете разработчика. В OpenAI и других сервисах можно (и нужно) ставить hard limit на месячные траты.

Если что-то не получается или есть вопрос - напишите в Telegram, разберёмся вместе.

Практика

Четыре задачи для закрепления материала.

Задача 1. Роль API

В чём главное преимущество использования API нейросети перед использованием обычного веб-интерфейса (чата)? Опишите два сценария, где API незаменим.

Подсказка

Подумайте о масштабе (количество запросов) и автоматизации.

Разбор

Главное преимущество - автоматизация. Веб-интерфейс требует участия человека, а API позволяет программе делать запросы самой.

Сценарии:

  • Масштабная обработка. Вам нужно перевести и проанализировать 10 000 отзывов клиентов. Вручную это займет недели. Скрипт с API сделает это за пару часов.
  • Интеграция в продукт. Вы создаете Telegram-бота, который отвечает на вопросы клиентов. Бот не может открывать сайт ChatGPT, он должен отправлять запросы к API.
Задача 2. Безопасность ключа

Разработчик написал скрипт и загрузил его на GitHub (публичный репозиторий). В коде была строка: api_key = "sk-proj-1234567890abcdef...". Какая проблема возникнет и что нужно было сделать иначе?

Подсказка

Кто угодно может увидеть этот код. Что произойдет, если злоумышленник найдет ключ?

Разбор

Ключ утечет. Боты-сканеры (например, TruffleHog) постоянно мониторят GitHub. Они найдут ключ за минуты и используют его для своих целей (например, для генерации спама), а счет придет вам.

Как надо: использовать файл .env и библиотеку python-dotenv. Файл .env нужно добавить в .gitignore, чтобы он не попадал в репозиторий.

Задача 3. Экономия токенов

Вы пишете скрипт, который отправляет в API OpenAI один и тот же длинный системный промпт (описание роли) и короткий вопрос пользователя. Как можно сэкономить деньги при работе такого скрипта?

Подсказка

Вспомните, что входные токены тоже платные. Можно ли кэшировать данные?

Разбор

Есть два способа:

  • Кэширование промптов (Prompt Caching). Некоторые провайдеры (включая OpenAI и Anthropic) позволяют кэшировать неизменяемую часть промпта (системный контекст). Если промпт длинный и часто повторяется, это сэкономит до 50-90% денег на входных токенах.
  • Сокращение промпта. Перепишите системный промпт максимально коротко, убрав «воду». Чем меньше токенов, тем дешевле.
Задача 4. Промпт для API-запроса

Вы пишете скрипт, который должен анализировать отзывы клиентов и возвращать JSON с оценкой (от 1 до 5) и кратким комментарием. Составьте системный промпт для API, который заставит модель отвечать строго в нужном формате.

Подсказка

Четко опишите структуру JSON и дайте пример. Модели лучше понимают формат, если видят образец.

Примерный ответ 
Ты анализатор отзывов. Проанализируй текстпользователя и верни ответ строго в формате JSON.JSON должен содержать два ключа:"rating" (целое число от 1 до 5) и "summary"(краткое резюме отзыва до 10 слов).Не добавляй никакого другого текста, только валидный JSON.Пример: {"rating": 4, "summary": "Хороший товар, но долгая доставка"}

Что мы узнали и что дальше

Разобрались с API нейросетей. Узнали, что API - это «официант», который передает ваши запросы на сервер и возвращает ответ. Поняли, как устроены HTTP-запросы и почему для них используется JSON. Разобрали правила безопасности при работе с API-ключами (использование .env) и принципы тарификации по токенам.

Теперь вы можете писать программы, которые используют мощь больших языковых моделей для автоматизации процессов. Это шаг от простого пользователя к создателю ИИ-инструментов.

В следующем уроке мы продолжим тему независимости от облачных сервисов. Разберёмся, что такое локальные модели (например, Llama или Mistral), как запустить нейросеть прямо на своем компьютере и зачем это нужно (спойлер: для полной приватности).
