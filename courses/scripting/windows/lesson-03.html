Условные операторы

~30 минут Windows Теория и Практика

До этого момента наши скрипты работали как поезд на рельсах: строго от первой команды к последней. Они не умели сворачивать в сторону. Но что, если пользователь ввёл неправильный пароль? Или что, если нужного файла не существует? Программа должна уметь реагировать на такие ситуации.

Сегодня мы научим скрипты принимать решения с помощью оператора if (если).

Логика в жизни и в коде

Вспомните охранника на входе в клуб. У него есть правило: «Если гостю есть 18 лет, то пропустить. Иначе - отказать».

В Batch-скриптах это записывается почти так же логично. Основной синтаксис выглядит так:

if условие команда

Если условие истинно, выполняется команда, стоящая после него. Если ложно - программа пропускает эту команду и идёт дальше.

Сравнение строк

Чаще всего мы будем сравнивать то, что ввёл пользователь, с каким-то эталоном. Например, проверять пароль или ответ на вопрос.

Для сравнения используется двойное равно ==. При этом переменные и текст обязательно нужно брать в кавычки:

@echo offset /p answer=Столица России? if "%answer%"=="Москва" echo Верно!pause

Если пользователь введёт «Москва», скрипт выведет «Верно!». Если введёт «Питер» - просто завершится (после паузы).

Зачем нужны кавычки?

Если пользователь просто нажмёт Enter, ничего не введя, переменная %answer% станет пустой. Без кавычек код превратится в if == "Москва", и командная строка выдаст синтаксическую ошибку. С кавычками код превратится в if ""=="Москва", что абсолютно безопасно и понятно системе.

Сравнение чисел

С числами немного сложнее. Знаки больше > и меньше < в командной строке Windows зарезервированы для перенаправления потоков. Поэтому для математических сравнений используются специальные буквенные сокращения:

  • equ - равно (equal)
  • neq - не равно (not equal)
  • lss - меньше (less)
  • leq - меньше или равно (less or equal)
  • gtr - больше (greater)
  • geq - больше или равно (greater or equal)
@echo offset /p age=Сколько вам лет? if %age% geq 18 echo Вы совершеннолетний.pause

Обратите внимание: здесь мы не используем кавычки, так как сравниваем числа.

Конструкция if / else

Если мы хотим, чтобы программа сделала что-то в случае успеха и что-то другое в случае провала, используется блок else (иначе).

Для записи нескольких команд используется круглые скобки:

@echo offset /p age=Сколько вам лет? if %age% geq 18 (    echo Проходите на взрослый сеанс.) else (    echo Извините, вам еще рано.)pause

Важное правило: слово else должно находиться на той же строке, что и закрывающая скобка ) от первого блока, либо на той же строке, что и команда if. Если вы перенесёте else на новую строку, скрипт выдаст ошибку.

Проверка файлов (if exist)

Скрипты часто работают с файлами. Было бы глупо пытаться удалить файл, которого нет. Для проверки существования используется конструкция if exist:

@echo offif exist "C:\Windows\notepad.exe" (    echo Блокнот установлен в системе.) else (    echo Блокнот не найден.)pause

Шпаргалка

Самое важное в одном месте:

  • if "%var%"=="text" сравнение строк
  • if %var% geq 10 сравнение чисел
  • if exist file.txt проверка файла
  • if not отрицание (если не)
  • ) else ( иначе (скобки обязательны)

Если что-то не работает

Разберём типичные ошибки при работе с условиями.

  • «else не является внутренней или внешней командой». Вы написали else на отдельной строке. Он должен идти сразу после закрывающей скобки: ) else (.
  • «Синтаксическая ошибка» при сравнении строк. Вы забыли кавычки. Всегда пишите if "%name%"=="Иван", а не if %name%=="Иван".
  • «Условие срабатывает всегда». Проверьте пробелы. Запись "%name%" == "Иван" (с пробелами вокруг ==) может привести к непредсказуемому поведению. Пишите слитно: "%name%"=="Иван".
  • «Скрипт не различает регистр букв». По умолчанию if в Windows не различает заглавные и строчные буквы. Чтобы сделать проверку строгой, добавьте флаг /i: if /i "%answer%"=="москва".

Если что-то не получается - напишите нам в Telegram, разберёмся вместе.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Проверка пароля

Напишите скрипт, который запрашивает пароль. Если пользователь вводит «12345», выведите «Доступ разрешён». В противном случае выведите «Доступ запрещён».

Подсказка

Используйте set /p, а затем конструкцию if "%pass%"=="12345" ( ... ) else ( ... ).

Решение учителя 
@echo offset /p pass=Введите пароль: if "%pass%"=="12345" (    echo Доступ разрешён) else (    echo Доступ запрещён)pause
Задача 2. Чётное или нечётное

Спросите у пользователя число. Определите, чётное оно или нет. В Batch остаток от деления вычисляется с помощью set /a result=%num% %% 2 (два знака процента, так как один знак - это спецсимвол).

Подсказка

Вычислите остаток: set /a rem=%num% %% 2. Затем проверьте: if %rem% equ 0 ( echo Чётное ) else ( echo Нечётное ).

Решение учителя 
@echo offset /p num=Введите число: set /a rem=%num% %% 2if %rem% equ 0 (    echo Это чётное число) else (    echo Это нечётное число)pause
Задача 3. Проверка файла

Создайте скрипт, который проверяет, существует ли файл secret.txt в папке со скриптом. Если существует - выведите «Файл найден, начинаю расшифровку». Если нет - создайте его с помощью команды echo Текст > secret.txt и выведите «Файл не найден, создаю новый».

Подсказка

Используйте if exist secret.txt ( ... ) else ( ... ). Внутри блока else выполните команду echo Текст > secret.txt.

Решение учителя 
@echo offif exist secret.txt (    echo Файл найден, начинаю расшифровку) else (    echo Файл не найден, создаю новый    echo Секретные данные > secret.txt)pause
Задача 4. Исправление ошибок

Перед вами код с ошибками. Найдите и исправьте их, чтобы скрипт корректно проверял возраст.

@echo offset /p age=Возраст: if %age% > 18 (    echo Взрослый)else (    echo Ребенок)
Подсказка

Во-первых, в Batch нельзя использовать знак > для сравнения. Нужно использовать gtr. Во-вторых, посмотрите на расположение слова else.

Решение учителя 
@echo offset /p age=Возраст: if %age% gtr 18 (    echo Взрослый) else (    echo Ребенок)pause

Мы заменили > на gtr и перенесли else на строку с закрывающей скобкой, чтобы избежать синтаксической ошибки.

Что мы узнали и что дальше

Наши скрипты научились думать. Теперь они могут проверять пароли, сравнивать числа и проверять наличие файлов. Это огромный шаг вперёд. Вы узнали:

  • Как использовать if для проверки условий.
  • Как сравнивать текст (с кавычками) и числа (с помощью equ, gtr и др.).
  • Как использовать конструкцию if / else для двух вариантов развития событий.
  • Как проверить существование файла через if exist.

Но пока наши программы выполняются один раз. Что, если мы хотим, чтобы скрипт работал до тех пор, пока пользователь не введёт «выход»? Для этого нужны повторения.

В следующем уроке мы разберём циклы и метки. Вы узнаете, как заставить скрипт возвращаться к началу, и как перебирать файлы в папке. До встречи!
