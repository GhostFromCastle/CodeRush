Запуск программ и автоматизация

~25 минут Windows Теория и Практика

До этого момента все наши скрипты выполнялись внутри чёрного окна командной строки. Но главная сила автоматизации раскрывается, когда скрипт начинает управлять другими программами. Представьте: вы нажимаете на один файл, а компьютер сам открывает браузер с нужными сайтами, запускает музыку и включает блокнот.

Сегодня мы научимся запускать сторонние приложения и файлы прямо из нашего скрипта.

Команда start

Основная команда для запуска программ в Windows - это start. Она говорит системе: «Запусти эту программу и не блокируй мою командную строку».

Аналогия: это как нанять таксиста. Вы говорите ему адрес (команда), он уезжает (программа открывается), а вы продолжаете заниматься своими делами (скрипт работает дальше).

Простейший пример - открыть Блокнот:

@echo offstart notepad.exepause

Если запустить этот скрипт, откроется Блокнот. При этом окно консоли останется на месте и будет ждать нажатия клавиши благодаря pause.

Открытие сайтов и папок

Команда start настолько умная, что может открывать не только exe-файлы, но и веб-сайты (в браузере по умолчанию) и папки в Проводнике.

Открываем сайт

start https://ghostfromcastle.github.io/CodeRush/

Открываем папку

start C:\Windows

Хитрость с кавычками

Здесь есть одна очень известная ловушка. Если путь к программе или файлу содержит пробелы (например, C:\Program Files\App.exe), его нужно взять в кавычки. Но если вы напишете просто start "C:\Program Files\App.exe", Windows подумает, что текст в кавычках - это заголовок окна, а не путь к программе, и выдаст ошибку.

Чтобы этого избежать, всегда ставьте пустые кавычки перед путём:

start "" "C:\Program Files\App.exe"

Первая пара кавычек "" - это пустой заголовок окна. Вторая пара "C:\..." - это уже сам путь к файлу.

В чем разница между просто именем и call?

Если вы напишете имя другого скрипта просто так, без команды start или call, управление передастся ему, и ваш текущий скрипт завершится.

Чтобы запустить один батник из другого и дождаться его завершения, используется команда call.

@echo offecho Начинаем установку...call install.batecho Установка завершена! Программа готова к работе.pause

В этом примере сообщение «Установка завершена!» появится только после того, как install.bat закончит свою работу.

Шпаргалка

Самое важное в одном месте:

  • start prog.exe запустить программу
  • start https://... открыть сайт
  • start "" "path" запуск пути с пробелами
  • call script.bat запустить другой скрипт и подождать

Если что-то не работает

Разберём типичные ошибки при запуске программ.

  • «Windows не может найти файл». Возможно, программа не находится в системной папке (System32). В таком случае нужно указывать полный путь к ней, например start "" "C:\Program Files\App\app.exe".
  • «Открывается пустое окно или ошибка при пути с пробелом». Вы забыли добавить пустые кавычки в начале: start "" "C:\My Folder\file.txt".
  • «Скрипт закрывается после запуска программы». Если вы используете call, скрипт будет ждать завершения программы. Если start - он запустит её и пойдёт дальше. Если вы хотите, чтобы окно консоли осталось, добавьте pause.
  • «Как открыть сайт в конкретном браузере, а не в том, что по умолчанию?». Используйте путь к браузеру: start chrome.exe "https://google.com".

Если что-то не получается - напишите нам в Telegram, разберёмся вместе.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Открыть калькулятор

Напишите скрипт, который запускает стандартный калькулятор Windows.

Подсказка

Файл калькулятора называется calc.exe. Используйте команду start.

Решение учителя 
@echo offstart calc.exepause
Задача 2. Все в одном

Создайте скрипт, который одновременно открывает ваш любимый сайт (например, YouTube) и Блокнот.

Подсказка

Используйте две команды start подряд. Порядок неважен, так как они запускаются асинхронно.

Решение учителя 
@echo offstart https://www.youtube.comstart notepad.exepause
Задача 3. Открыть проводник

Напишите скрипт, который открывает папку C:\Windows в Проводнике.

Подсказка

В Windows папки тоже можно открывать через start. Просто передайте путь к папке.

Решение учителя 
@echo offstart C:\Windowspause
Задача 4. Исправление ошибок

Пользователь хочет открыть файл C:\Program Files\App\data.txt. Скрипт не работает. Найдите и исправьте ошибку.

@echo offstart "C:\Program Files\App\data.txt"pause
Подсказка

Вспомните правило пустых кавычек для путей с пробелами.

Решение учителя 
@echo offstart "" "C:\Program Files\App\data.txt"pause

Мы добавили пустые кавычки "", чтобы Windows поняла, что первая пара кавычек - это не путь, а заголовок окна.

Что мы узнали и что дальше

Теперь ваши скрипты могут управлять всей операционной системой! Вы научились:

  • Запускать программы с помощью команды start.
  • Открывать сайты и папки.
  • Использовать пустые кавычки при путях с пробелами.
  • Запускать один скрипт из другого и ждать его завершения с помощью call.
