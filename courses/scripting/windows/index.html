Windows

Bat-скрипты

Файлы с расширением .bat позволяют автоматизировать запуск программ и работу с файлами в Windows. Изучим переменные, циклы и условия в командной оболочке.

7 уроков ~2.5 часа
01

Введение в Batch-скрипты

Создание первого файла .bat. Команда echo, отключение вывода команд через @echo off.
02

Переменные и ввод данных

Создание переменных через set. Запрос ввода от пользователя с помощью set /p.
03

Условные операторы

Конструкция if, проверка существования файлов (if exist), обработка кодов ошибок (errorlevel).
04

Циклы и метки

Создание меток (labels) и переходы (goto). Использование цикла for для перебора файлов.
05

Аргументы командной строки

Как передавать данные в скрипт при запуске. Использование %1, %2 и %*.
06

Запуск программ и автоматизация

Команды start и call. Создание скрипта, который открывает нужные сайты и программы.
07

Практика: скрипт бэкапа

Сборка финального скрипта, который копирует важные файлы в архив с датой в названии.
08

Даты, время и очистка

Работа с датами и временем. Создание скрипта для автоматической очистки временных файлов.
09

Работа с логами и текстом

Использование команд find, findstr и других для поиска информации в файлах.
10

Планировщик задач и права администратора

Использование планировщика задач для автоматического запуска скриптов. Работа с правами администратора.
