Переменные и ввод данных

~25 минут Windows Теория и Практика

В прошлом уроке наши скрипты были «немыми». Они просто выводили заранее написанный текст. Но настоящая программа должна уметь меняться в зависимости от ситуации. Как заставить скрипт запомнить данные и спросить их у пользователя?

Сегодня мы познакомимся с переменными. Это главный инструмент для хранения любой информации в программе.

Что такое переменная

Представьте, что у вас есть коробка с наклейкой. На наклейке написано имя (например, «user_name»), а внутри коробки лежит какое-то значение (например, «Алексей»). В любой момент вы можете заглянуть в коробку, чтобы узнать, что там лежит.

В командной строке Windows переменные создаются с помощью команды set. Синтаксис очень строгий:

set имя_переменной=значение

Например:

@echo offset name=Алексейecho Привет, %name%!pause

Обратите внимание на две вещи:

  • Перед знаком равно нельзя ставить пробелы. Если написать set name = Алексей, то в переменную name запишется пробел, а слово «Алексей» система не поймёт.
  • Чтобы вывести значение переменной на экран, её имя нужно окружить знаками процента: %name%.

Запрос данных у пользователя

Гораздо интереснее не задавать значения жёстко в коде, а спрашивать их у пользователя. Для этого используется команда set /p (от слова prompt - подсказка).

@echo offset /p name=Введите ваше имя: echo Привет, %name%!pause

Когда вы запустите этот скрипт, он выведет текст «Введите ваше имя: » и остановится, ожидая ввода. Как только вы напечатаете имя и нажмёте Enter, оно сохранится в переменную name.

Особенности ввода

Если вы пишете подсказку для ввода, лучше использовать кавычки: set /p "name=Введите имя: ". Это защитит скрипт от ошибок, если в тексте подсказки встретятся спецсимволы вроде & или |.

Арифметика в Batch

По умолчанию Windows воспринимает всё, что вводит пользователь, как текст (строку). Если вы попросите пользователя ввести два числа и попытаетесь их сложить через %num1% + %num2%, скрипт просто склеит их (например, «5» + «3» даст «53»).

Чтобы выполнять математические операции, используется флаг /a (arithmetic):

set /a result=5 + 3echo Результат: %result%

Или, если числа берутся из переменных:

set /a result=%num1% + %num2%

Шпаргалка

Самое важное в одном месте:

  • set var=value создать переменную
  • %var% получить значение
  • set /p var=Текст запросить ввод
  • set /a res=1+1 посчитать математику

Если что-то не работает

Разберём типичные ошибки при работе с переменными.

  • «Выводится пустая строка вместо значения». Вы забыли поставить знаки процента. Правильно: echo %name%, неправильно: echo name.
  • «Скрипт выдаёт ошибку Syntax error». Скорее всего, вы поставили пробелы вокруг знака равно при создании переменной. Правильно: set x=5, неправильно: set x = 5.
  • «Переменная не сохранилась после перезапуска». Batch-скрипты хранят переменные только в оперативной памяти. Как только окно закрывается, все данные исчезают. Чтобы сохранить их, нужно записывать их в текстовый файл (об этом позже).
  • «set /a не считает». Убедитесь, что вы используете флаг /a и пишете выражение без пробелов между цифрами, либо используете кавычки, если в выражении есть скобки.

Если что-то не получается - напишите нам в Telegram, разберёмся вместе.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Знакомство

Создайте скрипт, который спрашивает имя пользователя, а затем выводит фразу «Привет, [Имя]! Добро пожаловать в систему».

Подсказка

Используйте set /p для ввода и %name% для вывода.

Решение учителя 
@echo offset /p name=Как вас зовут? echo Привет, %name%! Добро пожаловать в систему.pause
Задача 2. Калькулятор возраста

Спросите у пользователя его возраст. Затем с помощью set /a вычислите, сколько ему будет лет через 10 лет, и выведите результат.

Подсказка

Сохраните возраст в переменную age. Затем создайте новую: set /a future=%age% + 10. Выведите %future%.

Решение учителя 
@echo offset /p age=Сколько вам лет? set /a future=%age% + 10echo Через 10 лет вам будет %future% лет.pause
Задача 3. Сборка папки

Спросите у пользователя его имя и название проекта. Создайте переменную, которая объединит эти данные (например, «Иван_Проект»), и выведите её на экран.

Подсказка

Создайте новую переменную через обычный set, подставив в неё значения других переменных: set result=%name%_%project%.

Решение учителя 
@echo offset /p name=Ваше имя: set /p project=Название проекта: set folder=%name%_%project%echo Будет создана папка: %folder%pause
Задача 4. Две переменные

Попросите пользователя ввести два числа. Сложите их и выведите результат. Если пользователь введёт не числа, а текст, скрипт может выдать ошибку - это нормально для базового Batch, но попробуйте сделать так, чтобы он хотя бы не закрывался сразу.

Подсказка

Используйте два раза set /p для ввода чисел. Для сложения используйте set /a result=%num1% + %num2%.

Решение учителя 
@echo offset /p num1=Первое число: set /p num2=Второе число: set /a sum=%num1% + %num2%echo Сумма: %sum%pause

Что мы узнали и что дальше

Сегодня ваши скрипты ожили. Они научились хранить данные и общаться с пользователем. Теперь вы знаете:

  • Как создавать переменные с помощью set.
  • Как получать доступ к значениям через %имя%.
  • Как запрашивать ввод данных через set /p.
  • Как выполнять математические вычисления с помощью set /a.

Но пока наши программы работают линейно: сверху вниз. Они не умеют проверять условия. Например, если пользователь введёт возраст 10, было бы логично сказать ему «Ты ещё ребёнок», а если 25 - «Ты взрослый».

В следующем уроке мы изучим условные операторы. Скрипт научится принимать решения на основе данных, которые ввёл пользователь. До встречи!
