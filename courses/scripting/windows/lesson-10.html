Планировщик и права админа

~35 минут Windows Теория и Практика

Вы прошли долгий путь. Теперь ваши скрипты могут делать бэкапы, удалять мусор и вести логи. Но у всех них есть один недостаток: чтобы они сработали, вы должны сами по ним кликнуть. А что, если вы спите в 3 часа ночи, а бэкап сделать нужно?

Настоящие профи настраивают скрипты так, чтобы система запускала их автоматически. Сегодня мы научимся работать с Планировщиком заданий (Task Scheduler) и разберём, как дать скрипту права администратора, если ему нужно удалить системные файлы.

Проверка прав администратора

По умолчанию Windows запускает программы с ограниченными правами. Если ваш скрипт попытается очистить папку C:\Windows\Temp, он получит отказ в доступе. Чтобы этого избежать, скрипт должен запускаться от имени администратора.

Хороший скрипт сам понимает, с какими правами его запустили, и предупреждает пользователя, если прав не хватает. Проверить это можно с помощью команды net session. Если у нас нет прав, она выдаст ошибку.

@echo offchcp 65001 >nulnet session >nul 2>&1if %errorlevel% neq 0 (    echo Внимание: этот скрипт нужно запускать от имени администратора!    echo Нажмите правой кнопкой мыши и выберите «Запуск от имени администратора».    pause    exit /b)echo Права администратора подтверждены. Продолжаем работу...pause

Что здесь происходит:

  • net session >nul 2>&1 - пытаемся выполнить команду, которая требует прав админа. Весь вывод (и успешный, и ошибки) скрывается (отправляется в nul).
  • %errorlevel% - это встроенная переменная, которая хранит код возврата последней команды. Если код neq 0 (не равен нулю), значит, произошла ошибка (нет прав).
  • exit /b - немедленно завершает работу скрипта, не закрывая окно консоли (если запуск был из консоли).

Работа с schtasks (Планировщик)

В Windows есть утилита schtasks, которая позволяет управлять задачами прямо из командной строки. С её помощью мы можем заставить компьютер запускать наш скрипт по расписанию.

Создание задачи

schtasks /create /tn "MyBackupTask" /tr "C:\Scripts\backup.bat" /sc daily /st 03:00

Разберём ключи:

  • /tn - Task Name, имя задачи (например, "MyBackupTask").
  • /tr - Task Run, путь к программе или скрипту, который нужно запустить.
  • /sc daily - Schedule, расписание (ежедневно).
  • /st 03:00 - Start Time, время запуска (3 часа ночи).
Осторожно с путями

Если в пути к скрипту есть пробелы (например, C:\My Scripts\backup.bat), путь в параметре /tr обязательно нужно взять в двойные кавычки. Но так как вся команда schtasks уже находится в кавычках, лучше избегать пробелов в путях.

Просмотр, запуск и удаление задачи

Чтобы узнать, создалась ли задача, можно использовать:

schtasks /query /tn "MyBackupTask"

Чтобы запустить задачу немедленно, не дожидаясь расписания:

schtasks /run /tn "MyBackupTask"

А чтобы удалить задачу (если она больше не нужна):

schtasks /delete /tn "MyBackupTask" /f

Флаг /f (force) позволяет удалить задачу без запроса подтверждения.

Шпаргалка

Самое важное в одном месте:

  • net session проверка прав админа
  • %errorlevel% код результата команды
  • schtasks /create создать задачу
  • schtasks /delete удалить задачу
  • schtasks /run запустить задачу

Если что-то не работает

Разберём типичные проблемы при работе с планировщиком.

  • «Отказано в доступе» при создании задачи. Утилита schtasks требует прав администратора. Убедитесь, что ваша консоль запущена от имени администратора.
  • «Задача создалась, но не запускается». Проверьте путь к скрипту в параметре /tr. Если там опечатка или скрипт удалён, задача будет падать с ошибкой.
  • «Скрипт работает вручную, но не работает в планировщике». Планировщик запускает скрипты в фоне, у него нет доступа к вашему рабочему столу. Убедитесь, что скрипт использует абсолютные пути (например, C:\...), а не относительные.
  • «Ошибка при удалении задачи». Возможно, задача прямо сейчас выполняется. Дождитесь её завершения или перезагрузите компьютер.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Вежливый отказ

Напишите скрипт, который проверяет наличие прав администратора. Если их нет, он должен вывести сообщение: «Запустите меня от имени администратора, пожалуйста» и закрыться.

Подсказка

Используйте команду net session >nul 2>&1 и проверьте %errorlevel%. Если он не равен 0 - выводите текст и делайте exit /b.

Решение учителя 
@echo offnet session >nul 2>&1if %errorlevel% neq 0 (    echo Запустите меня от имени администратора, пожалуйста.    pause    exit /b)echo Права есть!pause
Задача 2. Простая задача

Создайте планировщиком задачу с именем «TestTask», которая будет запускать Блокнот каждый день в 12:00.

Подсказка

Используйте schtasks /create. В параметре /tr укажите notepad.exe, в /sc - daily, в /st - 12:00.

Решение учителя 
schtasks /create /tn "TestTask" /tr "notepad.exe" /sc daily /st 12:00
Задача 3. Ручной запуск

Напишите скрипт, который немедленно запускает задачу «TestTask», созданную в предыдущем задании, а затем удаляет её из планировщика.

Подсказка

Сначала используйте schtasks /run /tn "TestTask", затем schtasks /delete /tn "TestTask" /f.

Решение учителя 
@echo offschtasks /run /tn "TestTask"schtasks /delete /tn "TestTask" /fpause
Задача 4. Финальный босс

Напишите скрипт, который проверяет права администратора. Если они есть, скрипт создаёт задачу «AutoClean», которая каждый день в 02:00 запускает скрипт очистки cleanup.bat (путь к нему: C:\Scripts\cleanup.bat). Если прав нет, скрипт выводит ошибку.

Подсказка

Оберните вызов schtasks /create в проверку if %errorlevel% equ 0 (после проверки на админа).

Решение учителя 
@echo offchcp 65001 >nulnet session >nul 2>&1if %errorlevel% neq 0 (    echo Ошибка: требуются права администратора.    pause    exit /b)echo Создаю задачу AutoClean...schtasks /create /tn "AutoClean" /tr "C:\Scripts\cleanup.bat" /sc daily /st 02:00 /fif %errorlevel% equ 0 (    echo Задача успешно создана!) else (    echo Не удалось создать задачу.)pause
