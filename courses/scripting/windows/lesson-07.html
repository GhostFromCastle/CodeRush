Практика: скрипт бэкапа

~35 минут Windows Только практика

Мы изучили все базовые инструменты: условия, циклы, аргументы и запуск программ. Пришло время собрать их вместе и написать первый по-настоящему полезный скрипт, который вы сможете использовать каждый день.

Сегодня мы создадим скрипт для резервного копирования (бэкапа). Он будет брать вашу важную папку с документами и копировать её в безопасное место, добавляя к названию текущую дату.

Зачем нужен бэкап?

Жесткие диски ломаются, файлы случайно удаляются, а вирусы могут зашифровать все данные. Настоящие профи не просто делают копии — они автоматизируют этот процесс, чтобы не забыть о нём.

Инструмент для копирования: xcopy

Обычная команда copy умеет копировать только отдельные файлы. Для копирования целых папок со вложенными директориями используется xcopy (extended copy).

У неё есть несколько важных ключей (флагов):

  • /E - копировать все папки, включая пустые.
  • /I - если папки назначения нет, считать её папкой (а не файлом).
  • /H - копировать скрытые и системные файлы.
  • /Y - не спрашивать подтверждение на перезапись файлов.

Работа с датой

Если мы каждый раз будем копировать файлы в одну и ту же папку, мы просто перезапишем старые копии. Нам нужно создавать новую папку с датой, например Backup_2026-10-25.

В Windows есть переменная %date%, которая хранит текущую дату. Но у неё есть проблема: в разных странах формат отличается (например, 25.10.2026 или 10/25/2026). А символы / и . нельзя использовать в названиях папок!

Чтобы заменить точки и слэши на дефисы (которые разрешены в названиях папок), используется трюк с заменой текста:

set "today=%date:~-4%-%date:~3,2%-%date:~0,2%"

Эта конструкция берёт подстроки из %date% (год, месяц, день) и расставляет между ними дефисы. Если у вас в системе формат даты другой, этот код может не сработать. Для простоты в этом уроке мы будем использовать команду wmic, которая всегда выдаёт дату в стандартном формате.

Сборка скрипта

Давайте создадим файл backup.bat. Напишем пошагово, что он должен делать:

  1. Получить сегодняшнюю дату в формате ГГГГ-ММ-ДД.
  2. Создать папку с названием Backup_[дата].
  3. Скопировать туда все файлы из папки Мои документы.
  4. Вывести сообщение об успехе.
@echo offchcp 65001 >nultitle Скрипт резервного копированияrem Получаем дату в формате YYYYMMDDfor /f "tokens=2 delims==" %%a in ('wmic os get localdatetime /value') do set "dt=%%a"set "today=%dt:~0,4%-%dt:~4,2%-%dt:~6,2%"set "source=C:\Users\%USERNAME%\Documents"set "backup_dir=%~dp0Backup_%today%"echo Создаю резервную копию...if not exist "%backup_dir%" md "%backup_dir%"xcopy "%source%\*.*" "%backup_dir%\" /E /I /H /Yecho.echo Готово! Файлы сохранены в папку:echo %backup_dir%pause

Разбор новых команд

  • chcp 65001 - включает кодировку UTF-8, чтобы русские буквы в консоли отображались правильно.
  • title - меняет название окна командной строки.
  • rem - комментарий (система его игнорирует).
  • %USERNAME% - это встроенная переменная Windows, которая хранит имя текущего пользователя.
  • %~dp0 - это очень важная конструкция! Она означает «диск и путь к папке, в которой лежит сам скрипт». Благодаря ей бэкап будет создаваться рядом с самим файлом backup.bat, где бы вы его ни запустили.
Осторожно с путями

В переменной source мы используем путь к документам по умолчанию. Если у вас папка «Документы» находится на другом диске или называется иначе (например, из-за OneDrive), измените путь в строке set "source=..." на свой.

Шпаргалка

Самое важное в одном месте:

  • xcopy копирование папок
  • /E /I /H /Y флаги xcopy
  • %USERNAME% имя пользователя
  • %~dp0 путь к папке скрипта
  • rem комментарий

Если что-то не работает

Разберём типичные ошибки при создании бэкапа.

  • «Недостаточно прав для выполнения операции». Скрипт пытается скопировать системные файлы. Запустите файл от имени администратора (ПКМ -> Запуск от имени администратора).
  • «Папка не найдена». Проверьте, существует ли папка, указанная в source. Если у вас Windows на английском, путь будет C:\Users\...\Documents.
  • «xcopy не является внутренней или внешней командой». Убедитесь, что в скрипте нет опечаток. Также xcopy может отсутствовать в некоторых урезанных версиях Windows (редко).
  • «Кракозябры вместо русского текста». Если вы не добавили chcp 65001, консоль может не понимать UTF-8. Однако это зависит от версии Windows.

Если что-то не получается - напишите нам в Telegram, разберёмся вместе.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Свой путь

Измените скрипт из урока так, чтобы он копировал не папку «Документы», а папку C:\Projects (или любую другую, которая есть на вашем компьютере).

Подсказка

Найдите строку set "source=..." и замените путь в кавычках на свой.

Решение учителя 
set "source=C:\Projects"
Задача 2. Дописываем время

Сделайте так, чтобы в название папки бэкапа добавлялось не только дата, но и время (часы и минуты), чтобы можно было делать несколько бэкапов за день. Например: Backup_2026-10-25_14-30.

Подсказка

Используйте переменную %time%. Но в ней есть двоеточия (14:30:15.12). Замените их на дефисы: set "tm=%time::=-%". И обрежьте лишние секунды: %tm:~0,5%.

Решение учителя 
for /f "tokens=2 delims==" %%a in ('wmic os get localdatetime /value') do set "dt=%%a"set "today=%dt:~0,4%-%dt:~4,2%-%dt:~6,2%"set "tm=%time::=-%"set "tm=%tm:~0,5%"set "backup_dir=%~dp0Backup_%today%_%tm%"
Задача 3. Проверка исходной папки

Добавьте проверку: если папки, которую мы хотим скопировать (source), не существует, скрипт должен вывести красное сообщение об ошибке и завершиться, не создавая пустую папку бэкапа.

Подсказка

Используйте if not exist "%source%" ( ... ). Внутри выведите ошибку, сделайте pause и goto :eof.

Решение учителя 
if not exist "%source%" (    echo Ошибка: Исходная папка %source% не найдена!    pause    goto :eof)
Задача 4. Очистка старых бэкапов

В папке со скриптом могут накапливаться старые бэкапы. Добавьте в конец скрипта команду, которая удаляет папки, начинающиеся на Backup_ (сделайте это в тестовой папке, чтобы не удалить лишнее).

Подсказка

Это сложная задача. Можно использовать цикл for /d %%d in (Backup_*) do rd /s /q "%%d". Ключ /d означает перебор только папок. rd - удаление папки, /s - со всем содержимым, /q - без вопросов.

Решение учителя 
for /d %%d in ("%~dp0Backup_*") do rd /s /q "%%d"

Но имейте в виду: этот код удалит все папки, начинающиеся на Backup_, прямо перед созданием новой. Будьте осторожны!

Что мы узнали и что дальше

Вы написали скрипт, который реально экономит время и защищает данные. Теперь вы знаете:

  • Как использовать xcopy для копирования папок.
  • Как получить текущую дату и время.
  • Что такое %~dp0 и %USERNAME%.
  • Как добавлять комментарии через rem.

Но это только начало. Настоящие профи не просто копируют файлы, они умеют управлять системой. В следующем уроке мы разберём даты, время и очистку системы. Вы узнаете, как безопасно удалять временные файлы, кэш и освобождать место на диске. До встречи!
