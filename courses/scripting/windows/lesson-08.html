Даты, время и очистка системы

~35 минут Windows Теория и Практика

Представьте, что вы решили разобрать шкаф. Вы достанете старые вещи, выбросите мусор и освободите место для нового. То же самое нужно делать и с компьютером. Временные файлы, старые логи, кэш браузеров - всё это накапливается и замедляет систему.

В этом уроке мы научимся заставлять скрипт понимать, какой сегодня день, и давать ему команды на безопасную очистку временных файлов. А заодно разберём, как удалять данные, которые старше определённого срока.

Переменные окружения (Где что лежит)

Windows хранит пути к важным папкам в специальных переменных окружения. Вы можете использовать их в скриптах, и они будут работать на любом компьютере с Windows, независимо от имени пользователя.

  • %USERPROFILE% - папка вашего пользователя (например, C:\Users\Alex).
  • %WINDIR% - папка с Windows (обычно C:\Windows).
  • %TEMP% - папка для временных файлов. Именно сюда программы сбрасывают мусор во время работы.
  • %APPDATA% - папка с настройками ваших программ (браузеры, игры).

Самый безопасный способ очистить компьютер - удалить файлы из %TEMP%. При правильной работе программы сами удаляют за собой мусор, но если программа вылетела, файлы остаются.

Работа с датой

В Windows есть переменная %date%, которая хранит текущую дату. В России она обычно выглядит как 25.10.2026.

Но есть проблема: точки и слэши нельзя использовать в названиях файлов и папок. Нам нужно извлечь год, месяц и день и соединить их через дефис.

В Batch это делается с помощью функции подстроки %var:~start,length%.

@echo offecho Текущая дата: %date%pause

Если запустить этот код, мы увидим, например, 25.10.2026. Тогда:

  • %date:~6,4% - возьмёт 4 символа начиная с 6-го индекса (получится «2026»).
  • %date:~3,2% - возьмёт 2 символа начиная с 3-го индекса (получится «10»).
  • %date:~0,2% - возьмёт 2 символа с самого начала (получится «25»).

Соединим их в правильную строку:

set "today=%date:~6,4%-%date:~3,2%-%date:~0,2%"

Теперь в переменной today лежит безопасная строка 2026-10-25, которую можно использовать для создания файлов.

Внимание: формат даты зависит от региона!

Если у вас в настройках Windows стоит американский формат (месяц/день/год), то код выше может не сработать. Самый надежный способ получить дату в скрипте - использовать команду wmic os get localdatetime, которая всегда выдает данные в одном и том же формате. Мы использовали её в прошлом уроке.

Очистка временных файлов

Для удаления файлов используется команда del, а для папок - rd (remove directory).

Чтобы не нажимать «Да» при каждом удалении, используют флаги:

  • /q - тихий режим (без вопросов).
  • /f - удалить даже файлы, доступные только для чтения.
  • /s - удалить из всех вложенных папок.

Пример скрипта для очистки папки с временными файлами:

@echo offecho Очистка временных файлов...del /q /f /s "%TEMP%\*.*"rd /s /q "%TEMP%\*"echo Готово!pause

Сначала мы удаляем все файлы (даже скрытые), затем - пустые папки. Но будьте осторожны: если какая-то программа прямо сейчас работает с временным файлом, Windows может выдать ошибку. Это нормально, скрипт просто пропустит этот файл.

Удаление файлов старше N дней

Иногда нужно удалять не всё подряд, а только старые логи. Для этого в Windows есть утилита forfiles.

forfiles /p "C:\Logs" /s /m *.log /d -30 /c "cmd /c del @path"
  • /p - папка, в которой ищем.
  • /s - искать во вложенных папках.
  • /m - маска файла (например, *.log).
  • /d -30 - файлы, которым больше 30 дней.
  • /c - команда, которую нужно выполнить для каждого найденного файла.

Шпаргалка

Самое важное в одном месте:

  • %TEMP% папка для мусора
  • %date% текущая дата
  • del /s /q удалить файлы
  • rd /s /q удалить папки
  • forfiles /d -30 удалить старое

Если что-то не работает

Разберём типичные ошибки при очистке и работе с датами.

  • «Доступ запрещён». Вы пытаетесь удалить файлы из системной папки без прав администратора. Запустите скрипт от имени администратора.
  • «Файл используется другой программой». Это нормально при очистке %TEMP%. Некоторые файлы защищены системой. Скрипт выдаст ошибку, но продолжит работу.
  • «Дата выводится криво». Скорее всего, у вас в системе стоит нестандартный формат даты. Используйте wmic os get localdatetime, как в уроке про бэкап.
  • «forfiles не находит файлы». Проверьте, что вы правильно указали папку в параметре /p и маску в /m.

Если что-то не получается - напишите нам в Telegram, разберёмся вместе.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Очистка TEMP

Напишите скрипт, который удаляет все файлы из папки %TEMP%. Перед удалением выведите сообщение «Начинаю очистку...», после - «Очистка завершена!».

Подсказка

Используйте del /q /f /s "%TEMP%\*.*". Не забудьте pause в конце, чтобы увидеть результат.

Решение учителя 
@echo offecho Начинаю очистку временных файлов...del /q /f /s "%TEMP%\*.*"echo Очистка завершена!pause

Вы можете заметить, что некоторые файлы не удалились. Это те файлы, которые прямо сейчас использует система, их трогать нельзя.

Задача 2. Логи старше 7 дней

Создайте папку C:\TestLogs и положите туда несколько файлов .txt. Напишите скрипт, который удаляет из этой папки все .txt файлы старше 7 дней.

Подсказка

Используйте forfiles /p "C:\TestLogs" /m *.txt /d -7 /c "cmd /c del @path".

Решение учителя 
@echo offecho Удаляю старые логи...forfiles /p "C:\TestLogs" /m *.txt /d -7 /c "cmd /c del @path"echo Готово.pause
Задача 3. Папка с датой

Напишите скрипт, который создаёт папку с названием, содержащим сегодняшнюю дату (например, Folder_2026-10-25), и выводит полный путь к ней.

Подсказка

Получите дату через wmic (как в уроке 7) или используйте подстроки %date:~6,4% (если у вас русский формат даты). Создайте папку через md.

Решение учителя 
@echo offfor /f "tokens=2 delims==" %%a in ('wmic os get localdatetime /value') do set "dt=%%a"set "today=%dt:~0,4%-%dt:~4,2%-%dt:~6,2%"set "folder=Folder_%today%"md "%folder%"echo Создана папка: %~dp0%folder%pause
Задача 4. Очистка и лог

Доработайте скрипт очистки из Задачи 1. Сделайте так, чтобы все сообщения об ошибках (например, если файл не удалось удалить) записывались в текстовый файл cleanup_log.txt в папке со скриптом.

Подсказка

Для перенаправления вывода ошибок используется конструкция 2>>. Сделайте так: del /q /f /s "%TEMP%\*.*" 2>> "%~dp0cleanup_log.txt".

Решение учителя 
@echo offecho Начинаю очистку...del /q /f /s "%TEMP%\*.*" 2>> "%~dp0cleanup_log.txt"echo Очистка завершена! Подробности в cleanup_log.txtpause

Теперь все ошибки доступа (например, «Файл занят системой») будут аккуратно записаны в текстовый файл рядом со скриптом, а не выведены на экран.

Что мы узнали и что дальше

Теперь ваши скрипты умеют заботиться о системе и работать со временем. Вы научились:

  • Использовать переменные окружения (%TEMP%).
  • Безопасно удалять временные файлы.
  • Получать текущую дату и форматировать её.
  • Использовать утилиту forfiles для удаления старых файлов.

Но удалять мусор - это только полдела. Настоящие профессионалы умеют записывать историю своих действий, чтобы потом понимать, что произошло. В следующем уроке мы подробнее разберём работу с логами и текстом. Вы узнаете, как красиво выводить данные в файл и как искать в них нужную информацию. До встречи!
