Обработка текста (grep, sed, awk)

~35 минут Linux Теория и Практика

В Linux почти всё является текстом. Конфигурации программ, логи, вывод других команд - это всё обычные строки. Именно поэтому в Linux так много мощных инструментов для работы с текстом.

Сегодня мы изучим три «тяжеловеса», которые должен знать каждый сисадмин и DevOps-инженер. Это как швейцарский нож для работы с данными: grep, sed и awk.

grep - Поисковик

Утилита grep (global regular expression print) используется для поиска строк, содержащих определённый текст или паттерн.

Аналогия: это как поиск по документу в Word (Ctrl+F), но только для терминала.

grep "Ошибка" server.log

Эта команда выведет на экран все строки из файла server.log, в которых встречается слово «Ошибка».

Полезные флаги grep:

  • -i - игнорировать регистр (найдёт и error, и Error).
  • -v - инвертировать поиск (показать строки, где этого слова нет).
  • -n - показать номер строки.
  • -r - рекурсивный поиск по всем файлам в папке.

sed - Редактор потока

sed (stream editor) - это инструмент для изменения текста «на лету», не открывая файл в редакторе. Чаще всего его используют для замены одной строки на другую.

Синтаксис замены выглядит так: sed 's/что_искать/на_что_заменить/' файл.

sed 's/apple/orange/' fruits.txt

Этот код заменит первое вхождение слова «apple» на «orange» в каждой строке файла и выведет результат на экран (сам файл не изменится).

Чтобы заменить все вхождения в строке, добавьте флаг g (global):

sed 's/apple/orange/g' fruits.txt

А чтобы изменения сохранились прямо в файле, используется флаг -i (in-place):

sed -i 's/apple/orange/g' fruits.txt

awk - Швейцарский нож

awk - это целый язык программирования для обработки текста. Он идеально подходит для работы с таблицами (например, файлами CSV или выводом команды ps).

По умолчанию awk разбивает строку на колонки по пробелам или табам. Переменные $1, $2, $3 обозначают первую, вторую и третью колонку соответственно.

Допустим, у нас есть файл users.txt:

Алексей 25 МоскваМария 30 Питер

Чтобы вывести только имена (первую колонку):

awk '{print $1}' users.txt

Чтобы вывести имя и город (первую и третью колонку):

awk '{print $1, $3}' users.txt

С помощью awk можно фильтровать строки, как в if. Например, вывести тех, кто старше 28 лет (вторая колонка):

awk '$2 > 28 {print $1}' users.txt

Конвейеры (Pipes)

Главная магия Linux заключается в том, что эти утилиты можно соединять вместе с помощью символа | (pipe). Это называется конвейером.

Конвейер берёт вывод одной команды и передаёт его на вход другой.

Пример: найти все процессы, связанные с python, и вывести только их ID (первая колонка).

ps aux | grep python | awk '{print $2}'

Как это читается: команда ps aux (список процессов) передаёт свой текст команде grep python (оставляет только строки с python), которая, в свою очередь, передаёт отфильтрованные строки команде awk, которая выводит только вторую колонку (PID).

Шпаргалка

Самое важное в одном месте:

  • grep "text" file найти строку
  • grep -i без учета регистра
  • sed 's/a/b/' заменить текст
  • awk '{print $1}' вывести колонку
  • cmd1 | cmd2 передать вывод по конвейеру

Если что-то не работает

Разберём типичные ошибки при работе с текстовыми утилитами.

  • «grep ничего не находит». Проверьте регистр. Используйте флаг -i, если не уверены в написании.
  • «sed не меняет файл». По умолчанию sed выводит результат на экран, но не трогает исходный файл. Используйте флаг -i, чтобы сохранить изменения.
  • «awk выводит странные символы». Проверьте, какие разделители в вашем файле. По умолчанию это пробелы. Если в файле запятые (CSV), укажите флаг -F,, например: awk -F, '{print $1}' file.csv.
  • «Слишком много вывода от конвейера». Если команда выводит много текста, добавьте | less в конец. Это позволит листать вывод стрелками.

Если что-то не получается - напишите нам в Telegram, разберёмся вместе.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Поиск в файле

Создайте файл test.txt с любым текстом (несколько строк). Найдите в нём строку, содержащую слово «Linux».

Подсказка

Используйте команду grep.

Решение учителя 
grep "Linux" test.txt
Задача 2. Замена в файле

В файле test.txt замените все вхождения слова «Windows» на «Linux» и сохраните изменения в файле.

Подсказка

Используйте sed с флагом -i и g, чтобы заменить все вхождения в файле.

Решение учителя 
sed -i 's/Windows/Linux/g' test.txt
Задача 3. Вывод колонки

Создайте файл fruits.csv с данными: Яблоко,50, Банан,30, Вишня,120. Используя awk, выведите только названия фруктов (первую колонку).

Подсказка

Так как разделитель - запятая, используйте awk -F, '{print $1}' fruits.csv.

Решение учителя 
awk -F, '{print $1}' fruits.csv
Задача 4. Конвейер

Выведите список всех пользователей в системе (команда cat /etc/passwd), оставьте только строки, содержащие /bin/bash (это пользователи с оболочкой), и извлеките только их имена (первая колонка до двоеточия).

Подсказка

Вам понадобится цепочка: cat /etc/passwd | grep "/bin/bash" | awk -F: '{print $1}'.

Решение учителя 
cat /etc/passwd | grep "/bin/bash" | awk -F: '{print $1}'

Этот скрипт читает файл паролей, фильтрует строки, где оболочкой является bash, и выводит только имя пользователя (до первого двоеточия).

Что мы узнали и что дальше

Вы получили в руки мощнейшие инструменты для работы с текстом. Теперь вы умеете:

  • Искать текст с помощью grep.
  • Заменять текст с помощью sed.
  • Извлекать колонки с помощью awk.
  • Соединять команды в конвейеры (|).

Эти навыки - база для любого системного администратора. Умение фильтровать и обрабатывать логи прямо из консоли экономит часы работы.
