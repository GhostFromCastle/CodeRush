Функции в Bash

~30 минут Linux Теория и Практика

Представьте, что вы пишете скрипт для установки программы. Вам нужно три раза вывести красивый заголовок с датой и временем: в начале, перед установкой и в конце. Копировать одни и те же пять строк кода - плохая практика. Если вы захотите изменить дизайн заголовка, придётся править его в трёх местах.

Для решения этой проблемы придумали функции. Это именованные блоки кода, которые можно вызывать по имени столько раз, сколько нужно.

Аналогия: функция - это как рецепт в кулинарной книге. Вы не запоминаете каждый шаг, вы просто говорите: «Приготовь по рецепту №5». Один раз записали - много раз пользуетесь.

Создание и вызов функции

В Bash функция создаётся с помощью ключевого слова function или просто скобок (). Оба варианта работают одинаково.

#!/bin/bashgreet() {    echo "Привет, мир!"}greet

Здесь мы создали функцию greet и вызвали её по имени. Функции должны быть объявлены до того, как вы их вызовете. Если поменять местами вызов и объявление, Bash выдаст ошибку.

Аргументы функции

Функции могут принимать аргументы. Внутри функции они доступны через те же переменные $1, $2 и так далее, что и аргументы скрипта.

#!/bin/bashgreet_user() {    echo "Привет, $1!"}greet_user "Алексей"greet_user "Мария"

В этом примере $1 внутри функции означает первый аргумент, переданный именно этой функции, а не всему скрипту.

Локальные переменные

По умолчанию переменные внутри функций являются глобальными. Если вы создадите переменную name внутри функции, она останется доступной и после её завершения. Это может привести к путанице.

Чтобы переменная существовала только внутри функции, перед её созданием пишут ключевое слово local:

#!/bin/bashmy_func() {    local temp="Секрет"    echo "Внутри функции: $temp"}my_funcecho "Снаружи: $temp"

Этот скрипт выведет «Внутри функции: Секрет», а во второй строке выведет пустоту, потому что переменная temp уничтожилась после выхода из функции.

Возврат значений

В Bash функции не могут вернуть строку или число так, как это делают функции в Python или JavaScript. Вместо этого они возвращают код выхода (от 0 до 255), где 0 означает успех, а любое другое число - ошибку.

Но что, если нам нужно вернуть строку (например, результат вычисления)? Есть два способа:

Способ 1. Вывести результат на экран и перехватить его (самый популярный):

#!/bin/bashget_sum() {    local a=$1    local b=$2    echo $((a + b))}result=$(get_sum 5 3)echo "Сумма: $result"

Способ 2. Использовать команду return для кода ошибки:

#!/bin/bashcheck_file() {    if [ -f "$1" ]; then        return 0    else        return 1    fi}if check_file "/etc/passwd"; then    echo "Файл найден"fi

Шпаргалка

Самое важное в одном месте:

  • name() { ... } создать функцию
  • $1, $2 аргументы функции
  • local var локальная переменная
  • result=$(func) перехват вывода
  • return 0 успешное завершение

Если что-то не работает

Разберём типичные ошибки при работе с функциями.

  • «command not found». Вы вызываете функцию до того, как она была объявлена. В Bash интерпретатор читает код сверху вниз, поэтому функции нужно писать в начале скрипта.
  • «Syntax error near unexpected token `}'». Вы забыли пробел между именем функции и фигурной скобкой, либо не поставили точку с запятой после закрывающей скобки } (если она не на новой строке).
  • Результат функции не сохраняется в переменную. Убедитесь, что вы используете $( ) вокруг вызова функции, а не просто имя. Правильно: res=$(my_func).
  • Переменная не меняется после вызова функции. По умолчанию функции не могут изменять переменные вызывающей стороны, если только вы не используете глобальные переменные (без local). Будьте осторожны с областью видимости.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Функция приветствия

Создайте функцию hello, которая выводит на экран «Привет, как дела?». Вызовите эту функцию дважды.

Подсказка

Объявите функцию в начале скрипта, внутри неё используйте echo. Затем два раза напишите имя функции.

Решение учителя 
#!/bin/bashhello() {    echo "Привет, как дела?"}hellohello
Задача 2. Сложение с аргументами

Напишите функцию add, которая принимает два числа и выводит их сумму. Вызовите её с числами 10 и 20.

Подсказка

Используйте $1 и $2 внутри функции. Вычислите сумму через echo $(( $1 + $2 )). Вызовите как add 10 20.

Решение учителя 
#!/bin/bashadd() {    echo $(( $1 + $2 ))}add 10 20
Задача 3. Перехват результата

Измените функцию add из прошлой задачи так, чтобы она возвращала результат в переменную result. Выведите результат в формате «Итог: [сумма]».

Подсказка

Используйте конструкцию result=$(add 10 20), чтобы перехватить вывод функции.

Решение учителя 
#!/bin/bashadd() {    echo $(( $1 + $2 ))}result=$(add 10 20)echo "Итог: $result"
Задача 4. Исправление ошибок

Перед вами скрипт, который не работает. Найдите и исправьте все ошибки.

#!/bin/bashgreet() {    local name="Иван"    echo "Привет, $name"}echo "Вывод: $name"greet
Подсказка

Вспомните порядок объявления и вызова функций. И где должны находиться local переменные.

Решение учителя 
#!/bin/bashgreet() {    local name="Иван"    echo "Привет, $name"}greetecho "Вывод: $name"

Во-первых, функция greet должна быть вызвана до того, как мы пытаемся прочитать $name (потому что local уничтожается после вызова). Во-вторых, вызов функции должен быть до попытки использовать переменную.

Что мы узнали и что дальше

Теперь ваши скрипты стали структурированными и готовыми к переиспользованию. Вы научились:

  • Создавать и вызывать функции.
  • Передавать аргументы в функции.
  • Использовать local для изоляции переменных.
  • Возвращать результаты через echo и перехватывать их через $().
