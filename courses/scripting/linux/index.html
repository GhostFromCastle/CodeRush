Bash-скрипты

Bash - это стандартная оболочка для большинства Linux-систем. Научитесь писать скрипты, которые экономят часы рутинной работы и автоматизируют серверные задачи.

10 уроков ~4 часа
01

Введение и первый скрипт

Что такое shebang (#!/bin/bash). Как сделать файл исполняемым и запустить его.
02

Переменные и аргументы

Объявление переменных, глобальные переменные окружения. Аргументы скрипта ($0, $1, $#).
03

Ввод данных и математика

Чтение ввода пользователя (read). Арифметические операции в Bash через $((...)).
04

Условные операторы

Конструкция if-then-else. Сравнение чисел и строк. Использование case для множественного выбора.
05

Циклы

Перебор значений (for), циклы с условием (while, until). Чтение файла построчно в цикле.
06

Функции в Bash

Создание собственных функций, передача аргументов и возврат значений.
07

Практика: скрипт сбора логов

Сборка скрипта, который проверяет место на диске и архивирует старые логи в указанную папку.
08

Обработка текста (grep, sed, awk)

Мощнейшие утилиты Linux для поиска, замены и извлечения данных из текстовых файлов.
09

Процессы и мониторинг системы

Управление процессами (ps, kill), проверка дискового пространства (df, du) и нагрузки (top).
10

Планировщик Cron и финальный проект

Автоматический запуск скриптов по расписанию. Собираем финальный скрипт для бэкапа базы данных.
