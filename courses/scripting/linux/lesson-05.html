Циклы

~30 минут Linux Теория и Практика

Представьте, что вам нужно создать 100 пустых папок для проекта. Или обработать тысячу лог-файлов, чтобы найти ошибки. Писать одну и ту же команду сто или тысячу раз - безумие. Для этого в программировании существуют циклы.

В Bash есть три основных вида циклов: for (для перебора), while (пока условие истинно) и until (пока условие ложно). Сегодня мы научимся ими пользоваться.

Цикл for

Цикл for используется, когда мы точно знаем, сколько раз нужно повторить действие, или когда нужно перебрать список элементов.

Синтаксис выглядит так:

for переменная in список; do    командыdone

Как и в условиях, блок начинается с do и заканчивается словом done (сделано).

Перебор списка значений

#!/bin/bashfor fruit in яблоко банан вишня; do    echo "Я люблю $fruit"done

Этот скрипт трижды выведет сообщение, подставляя вместо $fruit по очереди каждое слово из списка.

Перебор числового диапазона

Bash поддерживает удобный синтаксис для перебора чисел: {начало..конец}.

#!/bin/bashfor i in {1..5}; do    echo "Шаг номер $i"done

Этот цикл выполнится ровно 5 раз (от 1 до 5 включительно).

Цикл while

Цикл while (пока) выполняется до тех пор, пока условие в скобках остаётся истинным. Как только условие становится ложным - цикл завершается.

while [ условие ]; do    командыdone

Аналогия: «Пока в кастрюле есть вода - помешивай суп». Как только вода выкипела (условие нарушилось) - мешать больше не нужно.

#!/bin/bashcount=1while [ "$count" -le 3 ]; do    echo "Попытка номер $count"    count=$((count + 1))done

Важно: внутри цикла while мы должны что-то менять, чтобы условие рано или поздно стало ложным. В нашем примере мы увеличиваем count на 1. Если этого не делать, цикл будет бесконечным.

Цикл until

Цикл until (до тех пор, пока не) - это полная противоположность while. Он выполняется, пока условие ложно. Как только условие становится истинным, цикл завершается.

#!/bin/bashcount=1until [ "$count" -gt 3 ]; do    echo "Попытка $count"    count=$((count + 1))done

Этот код делает то же самое, что и предыдущий, но записан через until: «Выполняй, пока count не станет больше 3».

Полезные приемы

Бесконечный цикл

Иногда нужно, чтобы скрипт работал до тех пор, пока пользователь сам его не остановит (например, меню). Для этого используют конструкцию while true.

#!/bin/bashwhile true; do    read -p "Введите команду (или 'выход'): " cmd    if [ "$cmd" == "выход" ]; then        break    fi    echo "Вы ввели: $cmd"done

Прерывание цикла: break и continue

Команда break полностью прерывает цикл и выходит из него. Команда continue пропускает текущую итерацию и переходит к следующей.

#!/bin/bashfor i in {1..5}; do    if [ "$i" -eq 3 ]; then        continue    fi    echo "Число: $i"done

Этот скрипт выведет 1, 2, 4, 5. Число 3 будет пропущено из-за continue.

Чтение файла в цикле

Часто циклы используются для построчной обработки текстовых файлов. Делается это с помощью связки while read:

#!/bin/bashwhile IFS= read -r line; do    echo "Строка: $line"done < file.txt

Конструкция IFS= read -r - это золотой стандарт чтения файлов в Bash. Она защищает от потери пробелов и обработки обратных слэшей.

Шпаргалка

Самое важное в одном месте:

  • for i in {1..5}; do цикл по числам
  • while [ ... ]; do цикл с условием
  • until [ ... ]; do цикл обратного условия
  • do ... done тело цикла
  • break выйти из цикла
  • continue пропустить шаг
  • while read line чтение файла

Если что-то не работает

Разберём типичные ошибки при работе с циклами.

  • «Скрипт завис и не отвечает». У вас бесконечный цикл. Проверьте, меняется ли переменная внутри while, чтобы условие могло стать ложным. Если нет - добавьте изменение или используйте break.
  • «Syntax error: unexpected end of file». Вы забыли закрыть цикл словом done.
  • «Команды цикла выполняются один раз». Проверьте условия. Возможно, условие изначально ложно (например, вы проверяете [ $i -gt 5 ], когда i=1).
  • «Переменная внутри цикла не сохраняет значение». Если вы используете конвейер (например, echo ... | while read ...), цикл выполняется в подоболочке. Переменные, созданные внтури, не сохранятся после выхода. Используйте перенаправление потока (done < file) вместо конвейера.

Если что-то не получается - напишите нам в Telegram, разберёмся вместе.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. От 1 до 5

Напишите скрипт, который с помощью цикла for выводит на экран числа от 1 до 5.

Подсказка

Используйте конструкцию for i in {1..5}; do ... done. Внутри цикла выведите $i.

Решение учителя 
#!/bin/bashfor i in {1..5}; do    echo "$i"done
Задача 2. Сумма чисел

Спросите у пользователя число N. С помощью цикла посчитайте сумму всех чисел от 1 до N.

Подсказка

Создайте переменную total=0. В цикле for i in $(seq 1 $n) прибавляйте i к total через total=$((total + i)).

Решение учителя 
#!/bin/bashread -p "Введите N: " ntotal=0for i in $(seq 1 $n); do    total=$((total + i))doneecho "Сумма от 1 до $n: $total"

Команда seq 1 $n генерирует последовательность чисел от 1 до N.

Задача 3. Вечный пароль

Напишите скрипт, который бесконечно просит ввести пароль. Если введено слово «secret», выводит «Доступ разрешён» и завершается.

Подсказка

Используйте while true; do ... done. Внутри спрашивайте пароль через read и проверяйте через if. Если верно - break.

Решение учителя 
#!/bin/bashwhile true; do    read -p "Введите пароль: " pass    if [ "$pass" == "secret" ]; then        echo "Доступ разрешён"        break    else        echo "Неверный пароль"    fidone
Задача 4. Исправление ошибок

Перед вами скрипт, который должен вывести числа от 1 до 3, но он не работает. Найдите и исправьте ошибки.

#!/bin/bashfor i in {1..3}    echo "Число: $i"done
Подсказка

Посмотрите внимательно на первую строку цикла. Чего не хватает после списка?

Решение учителя 
#!/bin/bashfor i in {1..3}; do    echo "Число: $i"done

В первой строке не хватало точки с запятой и слова do перед телом цикла.

Что мы узнали и что дальше

Теперь ваши скрипты могут выполнять тысячи операций за секунды. Вы научились:

  • Использовать цикл for для перебора списков и чисел.
  • Использовать while и until для циклов с условиями.
  • Создавать бесконечные циклы и прерывать их через break.
  • Читать файлы построчно с помощью while read.

Но представьте, что у вас есть скрипт на 100 строк, и вы хотите использовать один и тот же блок кода (например, очистку логов) в разных местах. Копировать его - плохая идея. Для этого существуют функции.

В следующем уроке мы научимся создавать собственные функции, передавать им аргументы и возвращать результаты. Это сделает ваши скрипты чище и профессиональнее. До встречи!
