Практика: скрипт сбора логов

~35 минут Linux Только практика

Мы изучили все основные конструкции Bash. Пришло время написать скрипт, который приносит реальную пользу. Сегодня мы соберём скрипт для сбора и архивации логов.

На серверах логи имеют свойство накапливаться и занимать всё свободное место на диске. Если за этим не следить, сервер может упасть. Наш скрипт будет автоматически проверять место, находить старые логи и упаковывать их в архив.

Инструменты для работы

Прежде чем писать код, разберём три команды, которые нам понадобятся:

  • df -h - показывает свободное место на дисках в удобном формате (гигабайты, мегабайты).
  • du -sh folder - показывает размер конкретной папки.
  • tar -czf archive.tar.gz folder - упаковывает папку в архив (сжатый). Ключи означают: c - создать, z - сжать через gzip, f - указать имя файла.

Пишем скрипт

Давайте создадим файл log_collector.sh. Наш скрипт будет выполнять следующие шаги:

  1. Проверять, существует ли папка с логами.
  2. Создавать папку для архивов, если её нет.
  3. Упаковывать логи в архив с текущей датой.
  4. Удалять старые архивы (старше 7 дней).
#!/bin/bashLOG_DIR="/var/log/myapp"BACKUP_DIR="/backups/logs"DAYS_TO_KEEP=7if [ ! -d "$LOG_DIR" ]; then    echo "Ошибка: Папка с логами не найдена ($LOG_DIR)"    exit 1fiif [ ! -d "$BACKUP_DIR" ]; then    echo "Создаю папку для бэкапов: $BACKUP_DIR"    mkdir -p "$BACKUP_DIR"fiTODAY=$(date +%Y-%m-%d)ARCHIVE_NAME="$BACKUP_DIR/myapp_logs_$TODAY.tar.gz"echo "Начинаю архивацию логов..."tar -czf "$ARCHIVE_NAME" -C "$(dirname "$LOG_DIR")" "$(basename "$LOG_DIR")"if [ $? -eq 0 ]; then    echo "Архив успешно создан: $ARCHIVE_NAME"else    echo "Ошибка при создании архива"    exit 1fiecho "Удаляю архивы старше $DAYS_TO_KEEP дней..."find "$BACKUP_DIR" -name "*.tar.gz" -type f -mtime +$DAYS_TO_KEEP -deleteecho "Готово!"

Разбор сложных моментов

В скрипте есть несколько мест, которые могут показаться сложными:

  • -C "$(dirname "$LOG_DIR")". Флаг -C у tar меняет директорию перед архивацией. Мы используем dirname, чтобы получить путь к родительской папке логов. Это нужно для того, чтобы внутри архива не было длинных абсолютных путей.
  • $? - это специальная переменная, которая хранит код возврата последней выполненной команды. Если код равен 0 (-eq 0), значит, команда выполнилась успешно.
  • find ... -mtime +7 -delete - ищет файлы с расширением .tar.gz, которые не менялись больше 7 дней, и удаляет их. mtime означает время модификации.

Шпаргалка

Самое важное в одном месте:

  • df -h место на диске
  • tar -czf создать архив
  • $? код возврата
  • find -mtime +7 найти старые файлы
  • basename/dirname имя файла/папки

Если что-то не работает

Разберём типичные ошибки при создании скриптов для бэкапа.

  • «Permission denied». Скрипт пытается прочитать логи в /var/log или записать в /backups, но у вас нет прав. Запустите скрипт через sudo.
  • «Не хватает места на диске». Если логи весят сотни гигабайт, архивация может исчерпать всё свободное место. Используйте df -h перед запуском или архивируйте только самые старые файлы.
  • «Архив создаётся, но внутри пусто». Проверьте, что переменная LOG_DIR указывает на правильную папку и в ней есть файлы.
  • «find не удаляет старые архивы». Проверьте, что вы запускаете скрипт от имени пользователя, у которого есть права на удаление файлов в папке бэкапов.

Если что-то не получается - напишите нам в Telegram, разберёмся вместе.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Тестовая папка

Создайте тестовую папку ~/test_logs и положите в неё несколько текстовых файлов. Напишите скрипт, который архивирует эту папку в файл test_logs.tar.gz в вашей домашней директории.

Подсказка

Используйте команду tar -czf ~/test_logs.tar.gz -C ~ test_logs. Флаг -C ~ переходит в домашнюю папку, чтобы путь внутри архива был коротким.

Решение учителя 
#!/bin/bashtar -czf ~/test_logs.tar.gz -C ~ test_logsecho "Архив создан!"
Задача 2. Проверка свободного места

Напишите функцию check_space, которая проверяет свободное место на корневом разделе (/). Если свободно меньше 1 ГБ, выводит предупреждение.

Подсказка

Используйте df -h / и awk, чтобы вытащить процент использования. Или проще: выведите df -h / и проверьте визуально, но для автоматизации лучше использовать df --output=avail / | tail -1 (выдаст свободное место в килобайтах).

Решение учителя 
#!/bin/bashcheck_space() {    local free_kb=$(df --output=avail / | tail -1)    local free_mb=$((free_kb / 1024))    if [ "$free_mb" -lt 1024 ]; then        echo "Внимание! Мало места на диске: ${free_mb} МБ"    else        echo "Места достаточно."    fi}check_space
Задача 3. Сбор логов в цикле

Предположим, у вас есть папка ~/logs, а в ней три подпапки: app1, app2, app3. Напишите скрипт, который с помощью цикла по очереди архивирует каждую из них в отдельный файл.

Подсказка

Используйте цикл for dir in ~/logs/*; do ... done. Внутри цикла вызывайте tar для каждой папки.

Решение учителя 
#!/bin/bashfor dir in ~/logs/*; do    if [ -d "$dir" ]; then        name=$(basename "$dir")        tar -czf "$HOME/${name}_backup.tar.gz" -C "$HOME/logs" "$name"        echo "Готово: $name"    fidone
Задача 4. Финальный скрипт

Соберите всё вместе. Напишите скрипт, который проверяет свободное место, создаёт папку для бэкапов (если её нет), архивирует папку ~/logs с текущей датой в названии и удаляет старые архивы (старше 7 дней).

Подсказка

Используйте функции, которые мы написали в предыдущих задачах, и объедините их. Для удаления старых архивов используйте find ... -mtime +7 -delete.

Решение учителя 
#!/bin/bashBACKUP_DIR="$HOME/backups"LOG_DIR="$HOME/logs"if [ ! -d "$LOG_DIR" ]; then    echo "Папка $LOG_DIR не найдена!"    exit 1fimkdir -p "$BACKUP_DIR"TODAY=$(date +%Y-%m-%d)tar -czf "$BACKUP_DIR/logs_$TODAY.tar.gz" -C "$HOME" "logs"echo "Бэкап создан."find "$BACKUP_DIR" -name "logs_*.tar.gz" -mtime +7 -deleteecho "Старые архивы удалены."
