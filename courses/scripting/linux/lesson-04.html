Условные операторы

~20 минут Linux Теория и Практика

В прошлом уроке мы научили скрипты считать и общаться с пользователем. Но пока они работают как трамвай на рельсах: строго от первой команды к последней. Они не умеют сворачивать в сторону.

Настоящая программа должна принимать решения. Если введён правильный пароль - пустить в систему. Если файл существует - удалить его. Если число чётное - вывести одно сообщение, если нечётное - другое.

Для этого в Bash используется конструкция if (если). Сегодня мы разберём, как она работает.

Синтаксис if

В отличие от Python или C#, где условия пишутся в скобках, в Bash всё немного иначе. Основная конструкция выглядит так:

if [ условие ]; then    командыfi

Обратите внимание на несколько важных моментов:

  • [ и ] - это не просто скобки, а специальная команда (которая называется test). Между скобками и условием обязательно должны быть пробелы.
  • then - слово, которое открывает блок команд, выполняемых при истинном условии.
  • fi - слово, которое закрывает блок (это if наоборот). Забыть его - самая частая ошибка новичков.

Сравнение чисел

Как мы помним, символы > и < в Bash используются для перенаправления вывода, поэтому для сравнения чисел используются специальные буквенные сокращения:

  • -eq равно (equal)
  • -ne не равно (not equal)
  • -gt больше (greater)
  • -lt меньше (less)
  • -ge больше или равно (greater or equal)
  • -le меньше или равно (less or equal)
#!/bin/bashage=20if [ "$age" -ge 18 ]; then    echo "Вы совершеннолетний"fi

Сравнение строк

Для строк используются обычные знаки равно и не равно (одинарные или двойные):

#!/bin/bashname="Алексей"if [ "$name" == "Алексей" ]; then    echo "Привет, босс!"fi

Всегда берите переменные в двойные кавычки "$name". Если переменная окажется пустой, без кавычек условие превратится в [ == "Алексей" ], и скрипт упадёт с синтаксической ошибкой.

Также есть полезные операторы для проверки строк:

  • -z "$str" - истинно, если строка пустая (zero length).
  • -n "$str" - истинно, если строка не пустая.

Конструкция if / else

Если вы хотите сделать что-то, когда условие ложно, используется блок else (иначе):

#!/bin/bashread -p "Введите пароль: " passif [ "$pass" == "secret" ]; then    echo "Доступ разрешён"else    echo "Доступ запрещён"fi

Цепочка условий: elif

Если вариантов больше двух, используется elif (сокращение от else if):

#!/bin/bashread -p "Введите оценку (1-5): " markif [ "$mark" -eq 5 ]; then    echo "Отлично"elif [ "$mark" -eq 4 ]; then    echo "Хорошо"elif [ "$mark" -eq 3 ]; then    echo "Удовлетворительно"else    echo "Плохо"fi

Множественный выбор: case

Когда нужно проверить переменную с множеством конкретных значений (например, выбор пункта меню), длинная цепочка elif становится громоздкой. На помощь приходит case.

#!/bin/bashread -p "Выберите действие (start/stop/restart): " actioncase "$action" in    start)        echo "Запуск..."        ;;    stop)        echo "Остановка..."        ;;    restart)        echo "Перезапуск..."        ;;    *)        echo "Неизвестная команда"        ;;esac

Обратите внимание на ;; (два двоеточия с запятой). Это аналог break в других языках. А звёздочка *) срабатывает, если ни один вариант не подошёл (как else). Закрывается вся конструкция словом esac (case наоборот).

Шпаргалка

Самое важное в одном месте:

  • if [ ... ]; then начало условия
  • fi конец условия
  • -eq, -gt, -lt сравнение чисел
  • ==, != сравнение строк
  • elif иначе если
  • case ... esac множественный выбор

Если что-то не работает

Разберём типичные ошибки при работе с условиями.

  • «Syntax error near unexpected token `then'». Вы забыли точку с запятой перед then или не поставили пробелы внутри скобок [ ].
  • «unary operator expected». Вы не взяли переменную в кавычки. Если переменная пуста, [ $var == "text" ] превращается в [ == "text" ], что вызывает ошибку. Всегда пишите [ "$var" == "text" ].
  • «Ожидалось выражение» (expression expected). Вы используете знак > или < для сравнения чисел. Используйте -gt и -lt.
  • Скрипт ничего не выводит. Скорее всего, условие ложно. Попробуйте вывести значение переменной через echo перед if, чтобы проверить, что там лежит.
  • «unexpected end of file». Вы забыли закрыть блок словом fi или esac.

Если что-то не получается - напишите нам в Telegram, разберёмся вместе.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Проверка на чётность

Напишите скрипт, который запрашивает число и проверяет, является ли оно чётным. Если да - выводит «Чётное», иначе - «Нечётное».

Подсказка

Вычислите остаток от деления на 2 через rem=$((num % 2)). Затем проверьте: if [ "$rem" -eq 0 ]; then ....

Решение учителя 
#!/bin/bashread -p "Введите число: " numrem=$((num % 2))if [ "$rem" -eq 0 ]; then    echo "Чётное"else    echo "Нечётное"fi
Задача 2. Проверка существования файла

Напишите скрипт, который проверяет, существует ли файл /etc/passwd. Если существует - выводит «Файл на месте», если нет - «Файл не найден».

Подсказка

Для проверки файлов в Bash используется флаг -f. Условие будет выглядеть так: if [ -f "/etc/passwd" ]; then.

Решение учителя 
#!/bin/bashif [ -f "/etc/passwd" ]; then    echo "Файл на месте"else    echo "Файл не найден"fi
Задача 3. Калькулятор

Напишите скрипт-калькулятор. Спросите два числа и операцию (+, -, *, /). В зависимости от операции выполните нужное действие.

Подсказка

Используйте case для проверки операции. Внутри блоков вычисляйте результат через $(( )) и выводите его.

Решение учителя 
#!/bin/bashread -p "Первое число: " aread -p "Действие (+ - * /): " opread -p "Второе число: " bcase "$op" in    +) result=$((a + b)) ;;    -) result=$((a - b)) ;;    *) result=$((a * b)) ;;    /) result=$((a / b)) ;;    *) echo "Неизвестная операция" ; exit 1 ;;esacecho "Результат: $result"
Задача 4. Исправление ошибок

Перед вами скрипт, который должен проверять возраст, но он не работает. Найдите и исправьте все ошибки.

#!/bin/bashread -p "Возраст: " ageif [ $age > 18 ]; then    echo "Взрослый"else    echo "Ребенок"
Подсказка

Обратите внимание на: 1) использование знака > для чисел; 2) отсутствие кавычек у переменной; 3) закрытие блока.

Решение учителя 
#!/bin/bashread -p "Возраст: " ageif [ "$age" -gt 18 ]; then    echo "Взрослый"else    echo "Ребенок"fi

Мы заменили > на -gt, добавили кавычки вокруг переменной и закрыли конструкцию словом fi.

Что мы узнали и что дальше

Теперь ваши скрипты умеют думать и принимать решения. Вы научились:

  • Использовать конструкцию if / else / elif.
  • Сравнивать числа с помощью -eq, -gt и других операторов.
  • Сравнивать строки (с обязательными кавычками).
  • Использовать case для проверки множества вариантов.

Но что, если нам нужно повторить какое-то действие много раз? Например, перебрать все файлы в папке или спрашивать пароль, пока он не станет верным. Для этого нужны повторения.
