Ввод данных и математика

~20 минут Linux Теория и Практика

До этого момента наши скрипты работали как закрытые системы. Мы передавали им данные только при запуске (через аргументы). Но хорошая программа должна уметь вести диалог с пользователем и выполнять вычисления.

В этом уроке мы научим скрипты задавать вопросы, ждать ответа и использовать математику для решения задач.

Диалог с пользователем: команда read

Для того чтобы скрипт остановился и подождал, пока пользователь что-то введёт с клавиатуры, используется встроенная команда read.

Аналогия: это как вопрос в анкете. Вы спрашиваете «Как вас зовут?» и ставите прочерк. Пока человек не впишет имя, вы не двигаетесь дальше.

Синтаксис команды read простой: вы указываете флаг -p (от слова prompt - подсказка), пишете текст вопроса в кавычках и имя переменной, куда сохранится ответ.

#!/bin/bashread -p "Введите ваше имя: " nameecho "Привет, $name!"

Когда вы запустите этот скрипт, он выведет «Введите ваше имя: » и остановится. Введите текст, нажмите Enter, и скрипт продолжит работу, используя введённые данные.

Без подсказки

Если не использовать флаг -p, скрипт просто будет молча ждать ввода. Пользователь может подумать, что программа зависла. Всегда пишите подсказки, чтобы человек понимал, что от него хотят.

Математика в Bash

Linux и Bash изначально создавались для работы с текстом, а не для сложных вычислений. Поэтому математика здесь имеет свои особенности. По умолчанию Bash не умеет работать с дробными числами, только с целыми.

Самый современный и удобный способ выполнить арифметическую операцию - использовать двойные круглые скобки с долларом: $((выражение)).

#!/bin/basha=10b=3result=$((a + b))echo "Сумма: $result"

Внутри $(( )) можно использовать стандартные математические операторы:

  • + - сложение
  • - - вычитание
  • * - умножение
  • / - деление (целочисленное)
  • % - остаток от деления

Обратите внимание, что внутри двойных скобок перед именами переменных не нужно ставить знак доллара. Bash сам понимает, что a и b - это переменные. Писать $a + $b можно, но не обязательно.

Альтернативный способ: let

Иногда можно встретить команду let. Она работает похожим образом, но требует, чтобы выражение было записано без пробелов (или в кавычках):

let "result = a + b"

Работа с дробными числами

Если вам нужно разделить 10 на 3 и получить 3.333, стандартный Bash выдаст ошибку. Для таких вычислений используется утилита bc (Basic Calculator).

result=$(echo "scale=2; 10 / 3" | bc)echo "Результат: $result"

Параметр scale=2 указывает, сколько знаков после запятой нужно оставить. Не забудьте установить bc, если его нет в системе (обычно он есть по умолчанию).

Шпаргалка

Самое важное в одном месте:

  • read -p запросить ввод
  • $((a + b)) сложение
  • $((a * b)) умножение
  • $((a % b)) остаток от деления
  • bc калькулятор для дробей

Если что-то не работает

Разберём типичные ошибки при работе с вводом и математикой.

  • «Скрипт не ждёт ввода». Вы запустили скрипт в фоновом режиме или передали ему данные через конвейер. В интерактивном режиме read работает нормально.
  • «Деление выдаёт 0». Bash работает только с целыми числами. Если вы делите 5 на 2, результат будет 2, а не 2.5. Используйте bc для точных вычислений.
  • «Ошибка при вычислении». Проверьте, что вы используете двойные скобки $(( )), а внутри них нет лишних кавычек или невидимых символов.
  • «Переменные внутри математики не срабатывают». Убедитесь, что вы объявили их до вычисления. Если переменная пуста, Bash посчитает её за 0.

Если что-то не получается - напишите нам в Telegram, разберёмся вместе.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Знакомство

Напишите скрипт, который спрашивает у пользователя его имя и возраст, а затем выводит фразу: «[Имя], вам [возраст] лет».

Подсказка

Используйте команду read -p дважды. Первый раз сохраните результат в переменную name, второй - в age.

Решение учителя 
#!/bin/bashread -p "Ваше имя: " nameread -p "Ваш возраст: " ageecho "$name, вам $age лет"
Задача 2. Сумма чисел

Спросите у пользователя два числа и выведите их сумму. Используйте $(( )).

Подсказка

Сохраните оба числа в переменные через read. Затем создайте третью переменную, например sum=$((num1 + num2)). Выведите её.

Решение учителя 
#!/bin/bashread -p "Первое число: " num1read -p "Второе число: " num2sum=$((num1 + num2))echo "Сумма: $sum"
Задача 3. Площадь прямоугольника

Спросите у пользователя длину и ширину прямоугольника. Вычислите и выведите его площадь и периметр.

Подсказка

Площадь - это длина * ширина. Периметр - это 2 * (длина + ширина). Используйте двойные скобки для вычислений.

Решение учителя 
#!/bin/bashread -p "Длина: " lengthread -p "Ширина: " widtharea=$((length * width))perimeter=$((2 * (length + width)))echo "Площадь: $area"echo "Периметр: $perimeter"
Задача 4. Исправление ошибок

Перед вами скрипт, который должен вычислять остаток от деления, но он падает с ошибкой. Найдите и исправьте ошибку.

#!/bin/basha=10b=3result=$((a % b))echo "Остаток: result"
Подсказка

Посмотрите на последнюю строку. Как вывести значение переменной, а не её имя?

Решение учителя 
#!/bin/basha=10b=3result=$((a % b))echo "Остаток: $result"

В последней строке мы забыли поставить знак доллара перед словом result. Из-за этого выводилось просто слово, а не значение переменной.

Что мы узнали и что дальше

Теперь ваши скрипты стали интерактивными и могут выполнять вычисления. Вы научились:

  • Использовать read -p для ввода данных.
  • Выполнять математические операции с помощью $(( )).
  • Понимать, что стандартный Bash работает только с целыми числами.
  • Использовать bc для работы с дробями.

Но пока наши скрипты работают линейно: спросили, посчитали, вывели. Они не умеют проверять условия. Что, если пользователь введёт текст вместо числа? Или если мы хотим вывести разное сообщение в зависимости от результата?

В следующем уроке мы разберём условные операторы. Скрипты научатся принимать решения и реагировать на разные ситуации. До встречи!
