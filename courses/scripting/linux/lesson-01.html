Введение и первый скрипт

~20 минут Linux Теория и Практика

Если вы работаете в Linux, вы наверняка знаете, что терминал - это самый быстрый и мощный инструмент управления системой. Но вводить одни и те же команды каждый день утомительно. Именно для этого придумали Bash-скрипты.

Скрипт - это обычный текстовый файл, в котором записана последовательность команд для терминала. Вы запускаете его один раз, а система выполняет всё автоматически: настраивает сеть, делает бэкапы, проверяет логи.

Сегодня мы создадим наш первый скрипт и разберёмся, как заставить Linux его выполнить.

Что такое Bash и Shebang

Bash (Bourne Again Shell) - это командная оболочка, программа, которая читает ваши команды и передаёт их ядру Linux. Но Linux не знает, какой именно скрипт вы написали. Может, это Python? Может, это Perl?

Чтобы указать системе, что перед ней скрипт для Bash, в самую первую строку файла добавляют особую конструкцию - Shebang (произносится «ши-банг»). Она всегда начинается с решётки и восклицательного знака:

#!/bin/bash

Эта строка говорит Linux: «Эй, запусти программу /bin/bash и передай ей этот файл на выполнение». Без неё скрипт может не запуститься или выполниться неправильно.

Создаём первый скрипт

Давайте напишем программу, которая просто выведет приветствие на экран.

Шаг 1. Откройте терминал.

Шаг 2. Создайте текстовый файл с расширением .sh (от слова shell) с помощью любого текстового редактора, например nano:

nano hello.sh

Шаг 3. Напишите в файле следующий код:

#!/bin/bashecho "Hello, Linux!"

Шаг 4. Нажмите Ctrl+O, затем Enter, чтобы сохранить файл. И Ctrl+X, чтобы выйти из редактора.

Разрешение на выполнение (chmod)

Если вы сейчас попытаетесь запустить файл, система выдаст ошибку. В Windows любой файл .bat запускается двойным кликом. В Linux безопасность стоит на первом месте: по умолчанию файл считается просто текстом, и запускать его нельзя.

Чтобы дать файлу право на выполнение, используется команда chmod (change mode) с флагом +x (добавить eXecute):

chmod +x hello.sh

Теперь ваш скрипт стал исполняемым файлом.

Запуск скрипта

Запускается скрипт очень просто. Нужно написать точку, слэш и имя файла:

./hello.sh

Зачем нужна точка со слэшем? Точка означает «текущая директория». Без неё Linux не станет искать программы в текущей папке (это сделано из соображений безопасности, чтобы вы случайно не запустили вирус).

Важно: окончания строк

Если вы писали скрипт в Windows (например, в Блокноте) и перенесли его на Linux, он может не запуститься с ошибкой про \r. Windows и Linux по-разному отмечают конец строки. Используйте редакторы вроде VS Code, которые автоматически определяют ОС, или пересохраните файл прямо в Linux.

Шпаргалка

Самое важное в одном месте:

  • .sh расширение скрипта
  • #!/bin/bash shebang (первая строка)
  • echo вывод текста
  • chmod +x сделать исполняемым
  • ./script.sh запуск из текущей папки

Если что-то не работает

Разберём типичные ошибки новичков в Linux.

  • «bash: ./hello.sh: Permission denied». Вы забыли дать файлу права на выполнение. Выполните chmod +x hello.sh.
  • «bash: ./hello.sh: /bin/bash^M: bad interpreter». Проблема с окончаниями строк (CRLF). Это значит, что файл сохранялся в Windows. Введите команду sed -i 's/\r$//' hello.sh, чтобы исправить это.
  • «bash: ./hello.sh: No such file or directory». Вы находитесь не в той папке, где лежит скрипт, или ошиблись в названии файла. Проверьте путь командой ls.
  • «hello.sh: command not found». Вы забыли поставить ./ перед именем файла.

Если что-то не получается - напишите нам в Telegram, разберёмся вместе.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Приветствие

Создайте скрипт greet.sh, который выводит на экран фразу «Добро пожаловать в мир Linux!».

Подсказка

Не забудьте про shebang в первой строке и команду echo во второй. После создания не забудьте сделать файл исполняемым.

Решение учителя 
#!/bin/bashecho "Добро пожаловать в мир Linux!"
Задача 2. Несколько строк

Напишите скрипт info.sh, который выводит на экран три строки: имя текущего пользователя (команда whoami), текущую дату (команда date) и вашу текущую папку (команда pwd).

Подсказка

Просто напишите эти три команды на отдельных строках под shebang, как будто вводите их в обычный терминал.

Решение учителя 
#!/bin/bashwhoamidatepwd
Задача 3. Исправление ошибок

Перед вами скрипт, который не запускается. Найдите и исправьте все ошибки в коде.

echo "Привет"#/bin/bash
Подсказка

Ошибка кроется в порядке строк и в самой первой строке. Вспомните, как пишется shebang и на каком месте он должен быть.

Решение учителя 
#!/bin/bashecho "Привет"

Во-первых, shebang должен быть в самом начале. Во-вторых, в комментарии была опечатка: стояла решётка вместо решётки с восклицательным знаком (#/bin/bash вместо #!/bin/bash).

Задача 4. Скрипт-шпаргалка

Создайте скрипт help.sh, который выводит на экран список из трёх ваших любимых команд с коротким описанием. Оформите вывод красиво, добавив пустые строки.

Подсказка

Используйте команду echo несколько раз. Пустую строку можно вывести с помощью echo "" или просто echo.

Решение учителя 
#!/bin/bashecho "--- Моя шпаргалка ---"echo "ls - показать файлы"echo "cd - перейти в папку"echo "pwd - где я нахожусь"echo "---------------------"

Что мы узнали и что дальше

Вы сделали первый шаг в автоматизации Linux. Теперь вы знаете:

  • Что такое Bash-скрипт и как его создать.
  • Зачем нужна строка #!/bin/bash.
  • Как дать файлу права на выполнение через chmod +x.
  • Как запустить скрипт с помощью ./.

Пока наши скрипты выполняют команды по порядку, как роботы. Но настоящая сила приходит, когда скрипты начинают запоминать данные и меняться в зависимости от ситуации.

В следующем уроке мы разберём переменные и аргументы. Вы узнаете, как сохранять значения в ячейки памяти и как передавать данные в скрипт прямо при его запуске. До встречи!
