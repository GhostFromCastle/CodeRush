Процессы и мониторинг системы

~30 минут Linux Теория и Практика

Linux - это многозадачная система. Одновременно работают браузер, редактор кода, музыкальный плеер и десятки фоновых служб. Все они называются процессами.

Иногда процессы зависают, начинают потреблять всю оперативную память или бесконечно грузить процессор. В таких случаях нужно уметь найти виновника и «прибить» его. Сегодня мы научимся управлять процессами и следить за здоровьем системы.

Просмотр процессов: ps и top

Самый простой способ посмотреть, что сейчас запущено - это команда ps (process status). Без аргументов она покажет только процессы, запущенные в текущем терминале.

Чтобы увидеть все процессы в системе, используется связка ps aux (или ps -ef).

ps aux

Вывод будет большим. Основные колонки:

  • USER - кто запустил процесс.
  • PID - уникальный номер процесса (Process ID).
  • %CPU и %MEM - сколько ресурсов он потребляет.
  • COMMAND - название программы.

Но ps показывает статичную картинку. Чтобы смотреть на процессы в реальном времени, используется команда top.

top

Она обновляет список каждые пару секунд. Выход из top - клавиша q. Если у вас установлена утилита htop, она работает гораздо удобнее (с цветами и поддержкой мыши).

Убийство процессов: kill

Если программа зависла, её нужно завершить. Для этого используется команда kill, которой передаётся номер процесса (PID).

kill 1234

По умолчанию kill отправляет сигнал SIGTERM (вежливая просьба завершиться). Программа может сохранить данные и закрыться.

Если программа полностью зависла и не реагирует на вежливость, используется принудительное убийство с сигналом SIGKILL (флаг -9):

kill -9 1234

Также можно убивать процессы по имени, не зная их PID:

pkill firefox

Мониторинг диска и памяти

Помимо процессора, скриптам часто нужно проверять, не закончилось ли место на диске. Для этого есть две команды:

  • df -h (disk free) - показывает свободное место на всех дисках в удобном формате (гигабайты).
  • du -sh /path/to/folder (disk usage) - показывает, сколько занимает конкретная папка или файл.

Для проверки оперативной памяти используется команда free -h.

Шпаргалка

Самое важное в одном месте:

  • ps aux все процессы
  • top мониторинг в реальном времени
  • kill PID завершить процесс
  • kill -9 PID убить принудительно
  • df -h место на диске
  • du -sh размер папки

Если что-то не работает

Разберём типичные ошибки при работе с процессами.

  • «kill: (1234) - No such process». Процесс уже завершился (возможно, вы не успели его убить).
  • «kill: (1234) - Operation not permitted». Вы пытаетесь убить системный процесс или процесс другого пользователя. Нужно запускать команду через sudo.
  • «df -h показывает 100%». Диск заполнен. Используйте du -sh * в разных папках, чтобы найти самого прожорливого «едока» места.
  • «Не могу найти процесс в ps aux». Используйте конвейер с grep: ps aux | grep имя_программы, чтобы отфильтровать нужную строку.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Найти процесс

Откройте любой графический редактор или браузер. Найдите его PID с помощью ps aux и grep.

Подсказка

Выполните команду ps aux | grep firefox (или название другой программы). Вторая колонка - это PID.

Решение учителя 
ps aux | grep firefox
Задача 2. Проверка диска

Напишите скрипт, который выводит свободное место на корневом разделе (/) в мегабайтах.

Подсказка

Используйте df -m / (флаг -m - мегабайты). Затем через awk 'NR==2 {print $4}' вытащите нужную колонку.

Решение учителя 
#!/bin/bashfree_mb=$(df -m / | awk 'NR==2 {print $4}')echo "Свободно на /: $free_mb МБ"
Задача 3. Убить зависший процесс

Запустите в терминале команду sleep 1000 (она просто уснёт на 1000 секунд). В новом окне терминала найдите её PID и завершите её.

Подсказка

Найдите PID через ps aux | grep sleep. Затем выполните kill -9 PID.

Решение учителя 
sleep 1000 &ps aux | grep sleepkill -9
Задача 4. Самый большой файл

Напишите скрипт, который находит в текущей директории самый большой файл и выводит его размер и имя.

Подсказка

Используйте команду du -ah | sort -rh | head -n 2. Первая строка будет общей папкой, а вторая - самым большим файлом.

Решение учителя 
#!/bin/bashecho "Самый большой файл в текущей папке:"du -ah . | sort -rh | grep -v "^.*\s\.$" | head -n 1

  • Как смотреть на процессы через ps и top.
  • Как принудительно завершить зависшую программу через kill -9.
  • Как проверить свободное место с помощью df -h и du.
