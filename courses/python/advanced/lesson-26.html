Асинхронность

~45 минут Продвинутый уровень Теория и Практика

В прошлом уроке мы разобрались с многопоточностью и узнали про GIL. Мы выяснили, что потоки отлично подходят для задач ввода-вывода (сеть, файлы), но создают накладные расходы на переключение контекста.

Сегодня мы познакомимся с ещё одним, невероятно мощным и современным подходом к конкурентному выполнению задач - асинхронностью. Это то, что лежит в основе самых быстрых веб-фреймворков (FastAPI, aiohttp) и позволяет обрабатывать тысячи запросов одновременно на одном потоке.

Аналогия: повар-асинхронщик

Представьте одного повара на кухне.

  • В обычной (синхронной) программе он ставит суп на плиту и стоит, смотря на него 20 минут, ничего не делая.
  • В многопоточной он пытается одновременно резать салат и помешивать суп, но у него только две руки и одна голова (GIL), он путается и устаёт.
  • В асинхронной программе он ставит суп на плиту и говорит: «Пока варится, я нарежу салат». Через 20 минут он возвращается к супу. Он делает всё один, но не тратит время на ожидание.

Асинхронность не про параллельное выполнение (одновременно), а про конкурентное (попеременное) выполнение. Пока одна задача ждёт ответа от сети, процессор переключается на другую.

Ключевые слова: async и await

Для работы с асинхронностью в Python есть встроенный модуль asyncio. В нём есть два волшебных слова:

  • async def - объявляет корутину. Это как обычная функция, но она умеет приостанавливаться на полпути и отдавать управление другим задачам.
  • await - ставится перед операцией, которая занимает время (например, запрос в сеть или asyncio.sleep). Он говорит Python: «Я жду, иди делай что-нибудь другое».
import asyncioasync def make_tea():    print("Ставлю чайник")    await asyncio.sleep(2)    print("Чай готов!")asyncio.run(make_tea())

Функция asyncio.run() запускает главную асинхронную задачу, создаёт Event Loop (цикл событий) и управляет переключением между задачами.

Главное правило

await можно использовать только внутри функции, объявленной как async def. Внутри обычной функции await вызовет SyntaxError.

Запуск нескольких задач: asyncio.gather

Если просто написать два раза await подряд, они выполнятся последовательно. Чтобы запустить их одновременно, используют asyncio.gather():

import asyncioimport timeasync def task(name, delay):    print(f"Начал {name}")    await asyncio.sleep(delay)    print(f"Закончил {name}")async def main():    start = time.time()        await asyncio.gather(        task("А", 2),        task("Б", 3)    )        print(f"Общее время: {time.time() - start:.2f} сек")asyncio.run(main())

Эта программа выполнится за 3 секунды (по самой долгой задаче), а не за 5. Всё это время программа будет работать в одном потоке.

Шпаргалка

Самое важное в одном месте:

  • async def объявить асинхронную функцию
  • await дождаться выполнения
  • asyncio.run() запустить event loop
  • asyncio.sleep() асинхронная пауза
  • asyncio.gather() запустить задачи параллельно

Если что-то не работает

Разберём типичные проблемы при работе с асинхронностью.

  • «RuntimeWarning: coroutine '...' was never awaited». Вы вызвали асинхронную функцию, но забыли поставить перед ней await. Без этого она просто создаст объект корутины, но ничего не выполнит.
  • «SyntaxError: 'await' outside function». Вы пишете await вне функции async def.
  • «Программа зависает или работает медленно». Скорее всего, вы используете обычный time.sleep() вместо asyncio.sleep(). Обычный сон блокирует весь Event Loop, и другие задачи не могут выполняться.
  • «Не работает с обычными библиотеками». Асинхронность требует асинхронных библиотек. Обычный requests заблокирует поток. Нужно использовать aiohttp для запросов или aiosqlite для баз данных.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Первая корутина

Напишите асинхронную функцию hello(), которая выводит «Привет», ждёт 2 секунды через asyncio.sleep и выводит «Пока». Запустите её через asyncio.run().

Подсказка

Не забудьте ключевое слово await перед asyncio.sleep(2). Запуск происходит через asyncio.run(hello()).

Решение учителя 
import asyncioasync def hello():    print("Привет")    await asyncio.sleep(2)    print("Пока")asyncio.run(hello())
Задача 2. Соревнование

Создайте две корутины: runner_1 (ждёт 3 секунды) и runner_2 (ждёт 1 секунду). Запустите их одновременно через asyncio.gather. Замерьте общее время выполнения.

Подсказка

Оберните запуск в ещё одну функцию async def main(), чтобы внутри неё использовать await asyncio.gather(runner_1(), runner_2()).

Решение учителя 
import asyncioimport timeasync def runner_1():    await asyncio.sleep(3)    print("Бегун 1 финишировал")async def runner_2():    await asyncio.sleep(1)    print("Бегун 2 финишировал")async def main():    start = time.time()    await asyncio.gather(runner_1(), runner_2())    print(f"Время: {time.time() - start:.2f} сек")asyncio.run(main())

Второй бегун финиширует первым (через 1 секунду), но программа завершится только после первого (через 3 секунды).

Задача 3. Асинхронный загрузчик

Напишите функцию download_file(name), которая ждёт 2 секунды и печатает «Файл [name] загружен». Создайте 3 задачи и запустите их все одновременно.

Подсказка

Передайте в asyncio.gather три вызова вашей корутины: download_file("A"), download_file("B") и download_file("C").

Решение учителя 
import asyncioasync def download_file(name):    await asyncio.sleep(2)    print(f"Файл {name} загружен")async def main():    await asyncio.gather(        download_file("A"),        download_file("B"),        download_file("C")    )asyncio.run(main())

Все три файла «загрузятся» ровно за 2 секунды, а не за 6, так как ожидание происходит конкурентно.

Задача 4. Обработка ошибок

Создайте корутину, которая выбрасывает исключение ValueError (например, деление на ноль). Запустите её в asyncio.gather вместе с нормальной задачей. Используйте аргумент return_exceptions=True, чтобы gather не прерывался при первой же ошибке.

Подсказка

Вызов будет выглядеть так: results = await asyncio.gather(ok_task(), bad_task(), return_exceptions=True). В переменной results вместо объекта ошибки будет лежать само исключение.

Решение учителя 
import asyncioasync def ok_task():    await asyncio.sleep(1)    return "Успех"async def bad_task():    await asyncio.sleep(1)    return 1 / 0async def main():    results = await asyncio.gather(        ok_task(),        bad_task(),        return_exceptions=True    )    print(results)asyncio.run(main())

В консоли мы увидим список: ['Успех', ZeroDivisionError('division by zero')]. Программа не упала, мы получили результаты обеих задач.

Что мы узнали и что дальше

Асинхронность - это мощный инструмент, который может показаться сложным, но на деле он решает одну главную задачу: не заставлять программу ждать впустую. Теперь вы знаете:

  • Чем асинхронность отличается от многопоточности.
  • Как объявлять корутины через async def и приостанавливать их через await.
  • Как запускать несколько задач конкурентно с помощью asyncio.gather().
  • Как обрабатывать ошибки в асинхронных задачах.
