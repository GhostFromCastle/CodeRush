Проект: Telegram-бот

~45 минут Продвинутый уровень Теория и Практика

Мы изучили много теории: от переменных и циклов до баз данных, тестов и паттернов проектирования. Пришло время собрать всё это вместе и создать что-то по-настоящему полезное и осязаемое.

Сегодня мы напишем Telegram-бота. Это программа, которая работает на вашем компьютере (или сервере), общается с серверами Telegram по API и отвечает пользователям. Боты используются для всего: от службы поддержки и новостных рассылок до игр и умных помощников.

Что такое Telegram Bot API?

Telegram предоставляет разработчикам специальный интерфейс (API), через который программы могут отправлять и получать сообщения. Чтобы бот не был «анонимным», у него есть уникальный токен - длинная строка символов, которая работает как пароль.

Важно: Токен - это ключ к вашему боту. Никогда и никому его не передавайте, иначе злоумышленники смогут управлять вашим ботом.

Шаг 1. Получаем токен у BotFather

Создать бота можно прямо в самом Telegram.

  1. Откройте Telegram и в поиске найдите @BotFather (это официальный бот Telegram).
  2. Нажмите «Запустить» (/start).
  3. Отправьте команду /newbot.
  4. Придумайте имя бота (например, «Мой первый бот»).
  5. Придумайте username (он должен заканчиваться на _bot, например my_first_code_bot).

После этого BotFather пришлёт вам сообщение с токеном. Он выглядит примерно так: 123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ. Скопируйте его, он нам скоро понадобится.

Шаг 2. Устанавливаем библиотеку

Писать код для Telegram API с нуля - сложно. Поэтому используются библиотеки. Самая популярная и простая для новичков - pyTelegramBotAPI (часто называют просто telebot).

Откройте терминал в VS Code и выполните команду:

pip install pytelegrambotapi

Шаг 3. Первый код

Создайте файл bot.py и напишите следующий код. Это будет наш «Эхо-бот», который повторяет всё, что вы ему напишете.

import telebotTOKEN = "ВАШ_ТОКЕН_ЗДЕСЬ"bot = telebot.TeleBot(TOKEN)@bot.message_handler(commands=['start'])def handle_start(message):    bot.send_message(message.chat.id, "Привет! Я твой первый бот.")@bot.message_handler(content_types=['text'])def handle_text(message):    bot.send_message(message.chat.id, f"Ты написал: {message.text}")bot.polling()

Замените ВАШ_ТОКЕН_ЗДЕСЬ на токен от BotFather. Запустите файл.

Найдите своего бота в Telegram по его username, нажмите «Запустить» и напишите что-нибудь. Бот ответит вам!

Разбор кода

  • telebot.TeleBot(TOKEN) - создаёт объект бота, авторизуясь с помощью токена.
  • @bot.message_handler(commands=['start']) - декоратор (мы проходили их в уроке 21). Он говорит боту: «Если пользователь пришлёт команду /start - выполни эту функцию».
  • @bot.message_handler(content_types=['text']) - ловит любые текстовые сообщения.
  • message.chat.id - уникальный идентификатор чата пользователя. Он нужен, чтобы бот знал, кому отвечать.
  • bot.send_message() - отправляет сообщение в указанный чат.
  • bot.polling() - запускает бесконечный цикл, в котором бот «слушает» сервер Telegram на предмет новых сообщений.

Шпаргалка

Самое важное в одном месте:

  • pip install pytelegrambotapi установка библиотеки
  • telebot.TeleBot(TOKEN) создание бота
  • @bot.message_handler ловим сообщения
  • message.chat.id ID пользователя
  • bot.send_message() отправка сообщения
  • bot.polling() запуск бота

Если что-то не работает

Разберём типичные ошибки при создании ботов.

  • «ModuleNotFoundError: No module named 'telebot'». Вы не установили библиотеку. Выполните pip install pytelegrambotapi в терминале.
  • «Бот не отвечает на сообщения». Проверьте, запущен ли ваш файл bot.py и не завершился ли он с ошибкой. Также убедитесь, что вы написали bot.polling() в самом конце.
  • «telebot.apihelper.ApiTelegramException: Unauthorized». Вы неправильно скопировали токен, или он был отозван. Перевыпустите токен через BotFather.
  • «Бот отправляет сообщения по несколько раз». Скорее всего, у вас запущено несколько копий вашей программы одновременно. Закройте все лишние терминалы и перезапустите только один.
  • «Ошибка при использовании русских букв». Убедитесь, что ваш файл сохранён в кодировке UTF-8 (это стандарт для VS Code, но стоит проверить).

Если что-то не получается - напишите нам в Telegram, разберёмся вместе.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Бот-попугай

Напишите бота, который на любое текстовое сообщение отвечает: «Ты сказал: [текст пользователя]». Если пользователь напишет «пока», бот должен ответить «До встречи!» и больше не отвечать до перезапуска.

Подсказка

Внутри функции handle_text проверяйте message.text.lower(). Если это «пока», отправьте ответ, но остальной код не выполняйте (можно использовать return).

Решение учителя 
import telebotbot = telebot.TeleBot("ВАШ_ТОКЕН")@bot.message_handler(commands=['start'])def start(message):    bot.send_message(message.chat.id, "Привет! Напиши что-нибудь.")@bot.message_handler(content_types=['text'])def text_handler(message):    if message.text.lower() == "пока":        bot.send_message(message.chat.id, "До встречи!")        return        bot.send_message(message.chat.id, f"Ты сказал: {message.text}")bot.polling()
Задача 2. Бот-кубик

Создайте бота, который на команду /dice присылает случайное число от 1 до 6. Используйте модуль random.

Подсказка

Создайте отдельный хендлер с декоратором @bot.message_handler(commands=['dice']). Внутри используйте random.randint(1, 6) и отправьте результат через bot.send_message.

Решение учителя 
import telebotimport randombot = telebot.TeleBot("ВАШ_ТОКЕН")@bot.message_handler(commands=['dice'])def roll_dice(message):    result = random.randint(1, 6)    bot.send_message(message.chat.id, f"Выпало число: {result}")bot.polling()
Задача 3. Эхо-калькулятор

Научите бота считать. Если пользователь отправляет сообщение в формате «2 + 3» (или «10 - 4», «5 * 6»), бот должен посчитать результат и отправить его обратно. Используйте eval() и обработку исключений.

Подсказка

Используйте try: result = eval(message.text) и except Exception:, чтобы бот не падал, если ввести текст вместо примера. Отправьте результат в чат.

Решение учителя 
import telebotbot = telebot.TeleBot("ВАШ_ТОКЕН")@bot.message_handler(content_types=['text'])def calc(message):    try:        result = eval(message.text)        bot.send_message(message.chat.id, f"Результат: {result}")    except Exception:        bot.send_message(message.chat.id, "Я умею считать только примеры (например, 2 + 2).")bot.polling()

В реальных проектах eval() использовать опасно, так как он может выполнить любой код, который введёт пользователь. Но для учебного примера это допустимо.

Задача 4. Словарь терминов

Создайте бота, который работает как мини-словарь. У вас есть словарь Python с терминами: {"API": "Интерфейс...", "Python": "Язык программирования..."}. Бот ищет слово из сообщения в словаре и присылает определение, либо говорит, что не знает такого слова.

Подсказка

Создайте словарь dictionary = {...} в начале программы. В хендлере используйте dictionary.get(message.text). Если метод вернул None - термина нет.

Решение учителя 
import telebotbot = telebot.TeleBot("ВАШ_ТОКЕН")dictionary = {    "API": "Application Programming Interface",    "Python": "Язык программирования общего назначения",    "Код": "Набор инструкций для компьютера"}@bot.message_handler(content_types=['text'])def search_word(message):    word = message.text    definition = dictionary.get(word)        if definition:        bot.send_message(message.chat.id, f"{word}: {definition}")    else:        bot.send_message(message.chat.id, "Я не знаю такого слова.")bot.polling()
