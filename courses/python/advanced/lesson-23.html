Магические методы

~45 минут Продвинутый уровень Теория и Практика

Добро пожаловать на продвинутый уровень! До этого мы использовали классы в основном для хранения данных и вызова методов вроде dog.bark(). Но что если мы хотим, чтобы наши объекты вели себя как встроенные типы?

Например, чтобы два объекта можно было сложить через +, сравнить через ==, вывести на экран через print() в красивом виде, или узнать их длину через len(). Для этого в Python существуют магические методы (их ещё называют dunder-методами от double underscore).

Вы уже встречались с ними! Метод __init__ - это магический метод, который вызывается автоматически при создании объекта.

Что это такое и зачем они нужны

Магические методы - это методы, которые начинаются и заканчиваются двумя подчёркиваниями: __имя__. Они не вызываются напрямую (как obj.__str__()), а срабатывают автоматически при использовании определённого синтаксиса Python.

Аналогия: встроенные типы вроде списков и строк имеют свои магические методы. Когда вы пишете len("Привет"), Python на самом деле вызывает метод "Привет".__len__(). Когда вы пишете a + b для чисел, Python вызывает a.__add__(b).

Реализуя эти методы в своих классах, вы как бы «включаете» для них поддержку стандартных операторов языка.

__str__ и __repr__: как объект выглядит в виде строки

Когда вы делаете print(obj) или str(obj), Python ищет метод __str__. Если его нет, используется __repr__, а если нет и его - выводится что-то невнятное вроде <__main__.Dog object at 0x7f...>.

Давайте сделаем так, чтобы объект класса Book выводился красиво:

class Book:    def __init__(self, title, author):        self.title = title        self.author = author    def __str__(self):        return f"Книга '{self.title}' автора {self.author}"b = Book("Война и мир", "Толстой")print(b)   # Книга 'Война и мир' автора Толстой

__str__ - это «дружелюбное» представление для пользователя. А __repr__ - это техническое представление для разработчика (обычно возвращает строку, по которой можно воссоздать объект). Если вывести список объектов, Python использует именно __repr__.

__len__: длина объекта

Если вы хотите, чтобы к вашему объекту можно было применить функцию len(), реализуйте метод __len__. Он должен возвращать целое число.

class ShoppingCart:    def __init__(self):        self.items = []    def add(self, item):        self.items.append(item)    def __len__(self):        return len(self.items)cart = ShoppingCart()cart.add("Хлеб")cart.add("Молоко")print(len(cart))   # 2

__eq__: сравнение объектов

По умолчанию оператор == сравнивает объекты по их адресам в памяти (то есть obj1 is obj2). Но мы можем научить Python сравнивать объекты по их содержимому:

class Point:    def __init__(self, x, y):        self.x = x        self.y = y    def __eq__(self, other):        if not isinstance(other, Point):            return False        return self.x == other.x and self.y == other.yp1 = Point(3, 5)p2 = Point(3, 5)p3 = Point(1, 2)print(p1 == p2)   # Trueprint(p1 == p3)   # False
Сравнение и хеширование

Если вы определяете __eq__, Python автоматически делает объекты нехешируемыми (их нельзя добавлять в множества или использовать как ключи словаря). Если вам это нужно, придётся также определить метод __hash__.

Перегрузка операторов

Вы можете научить свои объекты поддерживать математические операции. Например, сложение (__add__) или умножение (__mul__):

class Vector:    def __init__(self, x, y):        self.x = x        self.y = y    def __add__(self, other):        return Vector(self.x + other.x, self.y + other.y)    def __str__(self):        return f"({self.x}, {self.y})"v1 = Vector(1, 2)v2 = Vector(3, 4)v3 = v1 + v2   # сработает __add__print(v3)      # (4, 6)

Шпаргалка

Самые полезные магические методы:

  • __init__ конструктор объекта
  • __str__ красивый вывод (print)
  • __repr__ технический вывод
  • __len__ работа с len()
  • __eq__ сравнение через ==
  • __add__ сложение через +
  • __getitem__ доступ по индексу []

Если что-то не работает

Разберём типичные ошибки при работе с магическими методами.

  • «TypeError: 'Vector' object is not callable». Вы случайно вызвали магический метод напрямую со скобками: v3 = v1.__add__(v2)(). Скобки в конце не нужны, он вызывается оператором +.
  • print() выводит страшную строку <__main__.Dog object at...>. Вы забыли определить метод __str__.
  • «TypeError: object of type 'Book' has no len()». Вы пытаетесь применить len() к объекту, у которого нет метода __len__.
  • Бесконечная рекурсия в __repr__. Внутри __str__ вы написали return str(self). Это вызовет __str__ заново. Нужно возвращать строку напрямую через f-строки.
  • Ошибка в __eq__. Если вы определили __eq__, но пытаетесь добавить объекты в set(), вы получите TypeError: unhashable type. Для исправления нужно определить метод __hash__ (можно просто return hash((self.x, self.y))).

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Красивая дробь

Создайте класс Fraction (дробь) с числителем и знаменателем. Реализуйте метод __str__, чтобы объект выводился в формате «числитель/знаменатель». Создайте дробь 3/4 и выведите её через print.

Подсказка

В методе __str__ верните строку: return f"{self.numerator}/{self.denominator}".

Решение учителя 
class Fraction:    def __init__(self, numerator, denominator):        self.numerator = numerator        self.denominator = denominator    def __str__(self):        return f"{self.numerator}/{self.denominator}"f = Fraction(3, 4)print(f)   # 3/4
Задача 2. Сложение денег

Создайте класс Money с атрибутом amount. Реализуйте метод __add__, чтобы две суммы можно было сложить через +. Верните новый объект Money с общей суммой.

Подсказка

В методе __add__(self, other) напишите return Money(self.amount + other.amount). Убедитесь, что класс Money определён до того, как вы его используете в методе.

Решение учителя 
class Money:    def __init__(self, amount):        self.amount = amount    def __add__(self, other):        return Money(self.amount + other.amount)    def __str__(self):        return f"{self.amount} руб."m1 = Money(500)m2 = Money(300)m3 = m1 + m2print(m3)   # 800 руб.
Задача 3. Длина корзины

Дан класс Playlist со списком песен songs. Реализуйте метод __len__, чтобы можно было узнать количество песен через len(playlist). Также реализуйте __getitem__, чтобы можно было обращаться к песням по индексу (playlist[0]).

Подсказка

__len__ просто возвращает len(self.songs). __getitem__(self, index) возвращает self.songs[index].

Решение учителя 
class Playlist:    def __init__(self, songs):        self.songs = songs    def __len__(self):        return len(self.songs)    def __getitem__(self, index):        return self.songs[index]pl = Playlist(["Song A", "Song B", "Song C"])print(len(pl))    # 3print(pl[1])      # Song B
Задача 4. Полноценный вектор

Создайте класс Vector с координатами x и y. Реализуйте для него:

  • __str__ для красивого вывода.
  • __eq__ для сравнения по координатам.
  • __add__ для сложения векторов.
  • __sub__ для вычитания векторов (через оператор -).
Проверьте все операции на практике.

Подсказка

Сложение: return Vector(self.x + other.x, self.y + other.y). Вычитание аналогично, только со знаком минус. Не забудьте в __eq__ проверить тип через isinstance(other, Vector), чтобы не сравнивать вектор со строкой.

Решение учителя 
class Vector:    def __init__(self, x, y):        self.x = x        self.y = y    def __str__(self):        return f"Vector({self.x}, {self.y})"    def __eq__(self, other):        if not isinstance(other, Vector):            return False        return self.x == other.x and self.y == other.y    def __add__(self, other):        return Vector(self.x + other.x, self.y + other.y)    def __sub__(self, other):        return Vector(self.x - other.x, self.y - other.y)v1 = Vector(5, 5)v2 = Vector(2, 3)print(v1 + v2)   # Vector(7, 8)print(v1 - v2)   # Vector(3, 2)print(v1 == Vector(5, 5))   # True
