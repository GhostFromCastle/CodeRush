База данных (SQLite)

~45 минут Продвинутый уровень Теория и Практика

До этого момента все данные, с которыми работали наши программы, исчезали сразу после закрытия консоли. Если мы создавали список покупок или базу студентов, после перезапуска программы он оказывался пустым.

В уроке 15 мы учились сохранять данные в обычные текстовые файлы. Но у файлов есть минусы: в них сложно искать нужную информацию, легко запутаться в формате, и они не подходят для тысяч записей. На смену им приходят базы данных.

Сегодня мы познакомимся с SQLite - самой популярной встроенной базой данных в мире. Она не требует установки сервера, весит меньше мегабайта и работает прямо из коробки в Python.

Аналогия: шкаф с картотекой

Представьте обычный текстовый файл - это как коробка, в которую вы сваливаете все бумаги вперемешку. Чтобы найти нужную, придётся перебрать всё вручную.

База данных - это шкаф с картотекой. У вас есть строгие полки (таблицы), на каждой полке - ячейки (строки или записи), и у каждой записи есть чёткие поля (столбцы или колонки): имя, возраст, телефон. Вы можете мгновенно найти нужного человека по имени, не перебирая весь шкаф.

Подключение и создание таблицы

В Python есть встроенный модуль sqlite3. Для начала работы нужно подключиться к базе данных. Если файла базы ещё нет, он создастся автоматически.

import sqlite3connection = sqlite3.connect("my_database.db")cursor = connection.cursor()

Что здесь происходит:

  • connect() - открывает (или создаёт) файл базы данных.
  • cursor - это «указка» или «пульт управления». Через него мы отправляем SQL-команды в базу.

Теперь создадим нашу первую таблицу. Например, таблицу users (пользователи) с тремя колонками: id (уникальный номер), name (имя) и age (возраст).

cursor.execute("""    CREATE TABLE IF NOT EXISTS users (        id INTEGER PRIMARY KEY AUTOINCREMENT,        name TEXT NOT NULL,        age INTEGER    )""")connection.commit()

Что значат эти команды:

  • CREATE TABLE IF NOT EXISTS - создать таблицу, если её ещё нет.
  • id INTEGER PRIMARY KEY AUTOINCREMENT - уникальный идентификатор, который сам увеличивается на 1 при каждой новой записи.
  • TEXT, INTEGER - типы данных в SQL.
  • connection.commit() - самая важная строка! Она сохраняет изменения. Без неё ничего не запишется.

Добавление данных (INSERT)

Чтобы добавить нового пользователя, используется команда INSERT.

cursor.execute("INSERT INTO users (name, age) VALUES (?, ?)", ("Алексей", 25))connection.commit()

Обратите внимание на знаки вопроса ?. Это параметризованные запросы. Мы не вставляем переменные напрямую в строку, а передаём их отдельно. Это защищает программу от взлома через SQL-инъекции (о них мы поговорим в курсе по кибербезопасности).

Чтение данных (SELECT)

Чтобы достать данные из базы, используется команда SELECT. После её выполнения нужно использовать методы fetchone() или fetchall(), чтобы получить результат.

cursor.execute("SELECT * FROM users")all_users = cursor.fetchall()for user in all_users:    print(user)

Если вам нужен только один пользователь (например, с определённым ID), используется fetchone().

cursor.execute("SELECT * FROM users WHERE id = ?", (1,))user = cursor.fetchone()print(user)

Обновление и удаление (UPDATE, DELETE)

Изменить данные можно командой UPDATE:

cursor.execute("UPDATE users SET age = ? WHERE name = ?", (26, "Алексей"))connection.commit()

А удалить - командой DELETE:

cursor.execute("DELETE FROM users WHERE id = ?", (1,))connection.commit()

Закрытие соединения

После того как вы закончили работу, хорошей практикой считается закрыть соединение с базой:

connection.close()

Шпаргалка

Самое важное в одном месте:

  • sqlite3.connect() подключиться к БД
  • connection.cursor() создать курсор
  • cursor.execute() выполнить SQL-запрос
  • connection.commit() сохранить изменения
  • fetchall() получить все строки
  • fetchone() получить одну строку
  • ? защита от инъекций

Если что-то не работает

Разберём типичные проблемы при работе с базами данных.

  • «Данные не сохраняются». Самая частая ошибка новичков: забыли вызвать connection.commit(). Без него изменения остаются в оперативной памяти, но не записываются в файл.
  • «sqlite3.OperationalError: no such table». Вы пытаетесь обратиться к таблице, которой нет. Убедитесь, что вы выполнили CREATE TABLE перед первым запросом.
  • «sqlite3.ProgrammingError: Incorrect number of bindings supplied». Количество знаков ? в запросе не совпадает с количеством элементов в кортеже, который вы передаёте.
  • «Не могу подключиться к базе, выдаёт ошибку locked». Другая программа (или другая вкладка VS Code) уже держит эту базу открытой. Закройте лишние соединения.
  • «Можно ли использовать переменные прямо в строке, без ?». Технически можно через f-строки, но никогда так не делайте. Это открывает дыру в безопасности (SQL-инъекции).

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Таблица товаров

Создайте базу данных shop.db. В ней создайте таблицу products с колонками: id (автоинкремент), title (название, текст) и price (цена, целое число). Не забудьте сохранить изменения.

Подсказка

Используйте CREATE TABLE products. Для автоинкремента пишите id INTEGER PRIMARY KEY AUTOINCREMENT. Для текста - TEXT, для цены - INTEGER.

Решение учителя 
import sqlite3connection = sqlite3.connect("shop.db")cursor = connection.cursor()cursor.execute("""    CREATE TABLE IF NOT EXISTS products (        id INTEGER PRIMARY KEY AUTOINCREMENT,        title TEXT NOT NULL,        price INTEGER    )""")connection.commit()connection.close()
Задача 2. Добавляем товары

Используя таблицу из предыдущей задачи, добавьте три товара: «Яблоко» (цена 50), «Хлеб» (цена 40) и «Молоко» (цена 80). Используйте параметризованные запросы.

Подсказка

Выполните три вызова cursor.execute с запросом INSERT INTO products (title, price) VALUES (?, ?). Не забудьте про commit() в конце.

Решение учителя 
connection = sqlite3.connect("shop.db")cursor = connection.cursor()cursor.execute("INSERT INTO products (title, price) VALUES (?, ?)", ("Яблоко", 50))cursor.execute("INSERT INTO products (title, price) VALUES (?, ?)", ("Хлеб", 40))cursor.execute("INSERT INTO products (title, price) VALUES (?, ?)", ("Молоко", 80))connection.commit()connection.close()
Задача 3. Дорогие товары

Напишите запрос, который выбирает из таблицы products только те товары, цена которых больше 45. Выведите результат на экран.

Подсказка

Используйте SQL-оператор WHERE: SELECT * FROM products WHERE price > ?. Не забудьте, что в HTML символ больше записывается как &gt; (но внутри строки Python пишите просто >).

Решение учителя 
connection = sqlite3.connect("shop.db")cursor = connection.cursor()cursor.execute("SELECT * FROM products WHERE price > ?", (45,))expensive = cursor.fetchall()for product in expensive:    print(product)connection.close()

Программа выведет «Яблоко» и «Молоко». Запрос WHERE price > 45 отфильтровал данные на уровне базы данных.

Задача 4. Мини-приложение

Напишите программу, которая в бесконечном цикле просит пользователя ввести название товара и его цену. Если пользователь вводит «выход», программа завершается. Каждый введённый товар сохраняется в базу данных shop.db.

Подсказка

Используйте while True. Внутри запрашивайте input(). Если ввод равен «выход» - делайте break. Иначе выполняйте INSERT с полученными данными. Цену не забудьте преобразовать в int().

Решение учителя 
import sqlite3connection = sqlite3.connect("shop.db")cursor = connection.cursor()while True:    title = input("Название товара (или 'выход'): ")    if title.lower() == "выход":        break    try:        price = int(input("Цена: "))    except ValueError:        print("Цена должна быть числом!")        continue    cursor.execute("INSERT INTO products (title, price) VALUES (?, ?)", (title, price))    connection.commit()    print("Товар добавлен!")connection.close()

Мы добавили обработку исключений try/except, чтобы программа не падала, если пользователь вместо цены введёт текст. Это хорошая практика при работе с пользовательским вводом.

  • Как создавать таблицы и добавлять в них данные.
