Финальный проект

~60 минут Продвинутый уровень Только практика

Вы дошли до финала! За эти 32 урока вы прошли путь от `print("Hello, World!")` до создания собственных классов, работы с базами данных и Telegram-ботов. Пришло время собрать всё это в один большой, полноценный проект.

Сегодня мы создадим Бот-менеджер задач (To-Do List). Это приложение будет сохранять ваши задачи в базу данных, позволять отмечать их выполненными и удалять. Это не просто учебное задание - это реальный инструмент, которым вы сможете пользоваться каждый день.

Архитектура проекта

Наш проект будет состоять из трёх связанных частей:

  1. База данных (SQLite): будет хранить задачи пользователей, чтобы они не пропадали при перезапуске бота.
  2. Логика бота: будет принимать команды от пользователя (добавить, показать, удалить).
  3. Обработка ошибок: мы научим бота не падать, если пользователь введёт что-то не то.

Шаг 1. Инициализация базы данных

Сначала создадим базу данных и таблицу для задач. Каждая задача должна быть привязана к конкретному пользователю (по его Telegram ID), чтобы люди не видели чужие списки дел.

import sqlite3def init_db():    connection = sqlite3.connect("todo.db")    cursor = connection.cursor()    cursor.execute("""        CREATE TABLE IF NOT EXISTS tasks (            id INTEGER PRIMARY KEY AUTOINCREMENT,            user_id INTEGER NOT NULL,            title TEXT NOT NULL,            status INTEGER DEFAULT 0        )    """)    connection.commit()    connection.close()

Шаг 2. Пишем функции для работы с БД

Хорошая практика - вынести работу с базой данных в отдельные функции. Так код бота будет чистым и понятным.

def add_task(user_id, title):    connection = sqlite3.connect("todo.db")    cursor = connection.cursor()    cursor.execute("INSERT INTO tasks (user_id, title) VALUES (?, ?)", (user_id, title))    connection.commit()    connection.close()def get_tasks(user_id):    connection = sqlite3.connect("todo.db")    cursor = connection.cursor()    cursor.execute("SELECT id, title, status FROM tasks WHERE user_id = ?", (user_id,))    tasks = cursor.fetchall()    connection.close()    return tasksdef mark_done(user_id, task_id):    connection = sqlite3.connect("todo.db")    cursor = connection.cursor()    cursor.execute("UPDATE tasks SET status = 1 WHERE id = ? AND user_id = ?", (task_id, user_id))    connection.commit()    connection.close()

Шаг 3. Собираем бота

Теперь напишем самого бота, который будет вызывать наши функции. Мы используем библиотеку telebot.

import telebotTOKEN = "ВАШ_ТОКЕН_ЗДЕСЬ"bot = telebot.TeleBot(TOKEN)@bot.message_handler(commands=['start'])def start(message):    text = "Привет! Я твой менеджер задач.\n\nКоманды:\n/add [текст] - добавить задачу\n/list - показать все задачи\n/done [id] - отметить выполненной"    bot.send_message(message.chat.id, text)@bot.message_handler(commands=['add'])def add(message):    title = message.text.replace('/add ', '').strip()    if not title:        bot.send_message(message.chat.id, "Напиши текст задачи после команды.")        return    add_task(message.from_user.id, title)    bot.send_message(message.chat.id, "Задача добавлена!")@bot.message_handler(commands=['list'])def list_tasks(message):    tasks = get_tasks(message.from_user.id)    if not tasks:        bot.send_message(message.chat.id, "У тебя пока нет задач.")        return        response = "Твои задачи:\n\n"    for t_id, title, status in tasks:        mark = "[V]" if status == 1 else "[ ]"        response += f"{mark} {t_id}. {title}\n"    bot.send_message(message.chat.id, response)@bot.message_handler(commands=['done'])def done(message):    try:        task_id = int(message.text.split()[1])        mark_done(message.from_user.id, task_id)        bot.send_message(message.chat.id, f"Задача {task_id} выполнена!")    except (IndexError, ValueError):        bot.send_message(message.chat.id, "Напиши ID задачи после команды. Например: /done 1")init_db()bot.polling()
Как это работает

Обратите внимание на команду /done. Мы используем message.text.split()[1], чтобы вытащить ID из сообщения (например, из «/done 3» мы получаем «3»). А конструкция try/except ловит ошибки, если пользователь напишет «/done привет» вместо числа.

Шпаргалка

Ключевые моменты финального проекта:

  • init_db() подготовка таблиц при старте
  • message.from_user.id уникальный ID пользователя
  • .replace('/add ', '') вырезаем команду из текста
  • try / except защита от неверного ввода

Если что-то не работает

Разберём проблемы, которые могут возникнуть при сборке такого проекта.

  • «База данных заблокирована (database is locked)». Если вы запускаете бота, и он падает с этой ошибкой, убедитесь, что вы вызываете connection.close() после каждого запроса. Не держите соединение открытым постоянно.
  • «Бот пишет, что задача добавлена, но в списке её нет». Проверьте, что в функции get_tasks вы делаете выборку именно по user_id, а не выбираете всё подряд. И что при добавлении вы передаёте корректный user_id.
  • «Команда /done не работает». Ошибка может быть в индексе split()[1]. Если пользователь напишет просто /done без числа, индекса [1] не существует. Именно для этого нужен except IndexError.

Если что-то не получается - напишите нам в Telegram, разберёмся вместе.

Практика

Это ваш финальный проект. Задания направлены на то, чтобы вы улучшили его и сделали по-настоящему своим.

Задача 1. Удаление задач

Добавьте боту команду /delete [id]. Она должна удалять задачу из базы данных. Напишите функцию delete_task(user_id, task_id) по аналогии с mark_done, используя SQL-команду DELETE.

Подсказка

Запрос будет выглядеть так: DELETE FROM tasks WHERE id = ? AND user_id = ?. Не забудьте добавить хендлер для команды delete.

Решение учителя 
def delete_task(user_id, task_id):    connection = sqlite3.connect("todo.db")    cursor = connection.cursor()    cursor.execute("DELETE FROM tasks WHERE id = ? AND user_id = ?", (task_id, user_id))    connection.commit()    connection.close()@bot.message_handler(commands=['delete'])def delete(message):    try:        task_id = int(message.text.split()[1])        delete_task(message.from_user.id, task_id)        bot.send_message(message.chat.id, f"Задача {task_id} удалена.")    except (IndexError, ValueError):        bot.send_message(message.chat.id, "Укажи ID задачи. Например: /delete 2")
Задача 2. Фильтр выполненных

Сделайте так, чтобы команда /list показывала только невыполненные задачи. Для этого измените SQL-запрос в функции get_tasks, добавив условие AND status = 0.

Подсказка

Измените строку на: SELECT id, title, status FROM tasks WHERE user_id = ? AND status = 0. В таком случае выполненные задачи просто не будут попадать в список.

Решение учителя 
def get_tasks(user_id):    connection = sqlite3.connect("todo.db")    cursor = connection.cursor()    cursor.execute("SELECT id, title, status FROM tasks WHERE user_id = ? AND status = 0", (user_id,))    tasks = cursor.fetchall()    connection.close()    return tasks
Задача 3. Статистика

Добавьте команду /stats, которая выводит, сколько всего задач у пользователя и сколько из них выполнено. Используйте SQL-функцию COUNT(*).

Подсказка

Выполните два запроса: один с условием status = 0, другой с status = 1. Используйте cursor.fetchone()[0], чтобы получить число из результата.

Решение учителя 
@bot.message_handler(commands=['stats'])def stats(message):    connection = sqlite3.connect("todo.db")    cursor = connection.cursor()        cursor.execute("SELECT COUNT(*) FROM tasks WHERE user_id = ?", (message.from_user.id,))    total = cursor.fetchone()[0]        cursor.execute("SELECT COUNT(*) FROM tasks WHERE user_id = ? AND status = 1", (message.from_user.id,))    completed = cursor.fetchone()[0]        connection.close()        bot.send_message(message.chat.id, f"Всего задач: {total}\nВыполнено: {completed}")
Задача 4. Напоминания (сложная)

Попробуйте реализовать отложенные напоминания. При добавлении задачи пользователь может указать время: /add [текст] | 15:30. Бот должен сохранить время и прислать сообщение в указанное время. Для этого вам понадобится модуль schedule или threading.Timer.

Подсказка

Это очень сложная задача для самостоятельного решения. Вам нужно будет парсить время через split('|'), сохранять его в базу и запускать отдельный поток, который будет ждать нужного момента и отправлять сообщение через bot.send_message.

Решение учителя

Этот функционал выходит за рамки базового курса, но если вам интересно, изучите библиотеку schedule. Это отличный повод для самостоятельного исследования!
