Функции: основы

~40 минут Средний уровень Теория и Практика

Добро пожаловать на средний уровень! Начальный мы закрыли - теперь вы умеете писать игры, работать с коллекциями и условиями. Но все наши программы состояли из линейного кода: сверху вниз, шаг за шагом.

Представьте, что в программе нужно трижды посчитать налог, дважды проверить пароль и пять раз вывести красивое меню. Копировать один и тот же код раз за разом - плохая идея. Если завтра изменится формула налога, вам придётся искать и править её в трёх местах, рискуя что-то упустить.

Решение этой проблемы - функции. Это именованные блоки кода, которые можно вызывать в любом месте программы. Сегодня мы научимся их создавать.

Что такое функция

Аналогия: функция - это как рецепт в поваренной книге. У рецепта есть название («Борщ»), список ингредиентов (входные данные) и последовательность действий (тело функции). Когда рецепт нужен, вы просто открываете книгу на нужной странице и готовите по нему. Не нужно каждый раз изобретать, как варить борщ.

В программировании функция позволяет один раз описать логику, дать ей имя и потом вызывать это имя тогда, когда нужно.

Создание функции

В Python функция создаётся с помощью ключевого слова def (от английского define - «определять»). Синтаксис такой:

def имя_функции():    # тело функции

Давайте создадим простую функцию, которая выводит приветствие:

def say_hello():    print("Привет!")    print("Как дела?")

Что здесь важно:

  • def - ключевое слово, начало объявления функции.
  • say_hello - имя функции. По правилам Python пишется строчными буквами, слова разделяются подчёркиванием (как переменные).
  • () - пока пустые скобки (позже мы научимся передавать туда данные).
  • : - двоеточие в конце строки - обязательно, как в условиях и циклах.
  • Отступ в 4 пробела - тело функции.
Функция сама не выполняется

Очень важно понять: когда вы написали def say_hello():, код внутри этой функции не выполнился. Вы только создали функцию - как положили рецепт в книгу. Чтобы рецепт «сработал», его нужно «приготовить». В программировании это называется вызовом функции.

Вызов функции

Чтобы выполнить код внутри функции, нужно её вызвать - написать имя функции со скобками:

def say_hello():    print("Привет!")say_hello()

Сначала Python видит объявление функции (запоминает её). Потом доходит до вызова say_hello() - и только тогда выполняет код внутри. На экране появится «Привет!».

А главное - функцию можно вызывать сколько угодно раз:

def say_hello():    print("Привет!")say_hello()say_hello()say_hello()

Программа выведет «Привет!» три раза. Мы написали логику один раз, а используем трижды.

Функции с аргументами

Функция say_hello хороша, но слишком «немая» - она всегда говорит одно и то же. Настоящие функции должны уметь принимать аргументы - данные для работы.

Аргументы указываются в скобках при объявлении функции, а при вызове в эти скобки передаются значения:

def greet(name):    print(f"Привет, {name}!")greet("Алексей")greet("Мария")

Результат:

Привет, Алексей!Привет, Мария!

Здесь name - это параметр (переменная внутри функции), а "Алексей" и "Мария" - аргументы (значения, которые мы передаём при вызове).

Аналогия с рецептом: name - это «мясо» в рецепте. Когда вы готовите, вы решаете, какое именно мясо положить: курицу или свинину. Рецепт один, а блюдо получается разным.

Можно передавать несколько аргументов, разделяя их запятой:

def introduce(name, age):    print(f"Меня зовут {name}, мне {age} лет.")introduce("Алексей", 25)

Возврат значения: return

До этого момента наши функции только выводили текст на экран. Но гораздо чаще функция должна не печатать, а возвращать результат - чтобы его можно было сохранить в переменную, передать в другую функцию или использовать в вычислениях.

Для этого есть ключевое слово return:

def add(a, b):    return a + bresult = add(3, 5)print(result)   # 8

Что здесь происходит:

  • Вызывается функция add(3, 5).
  • Внутри неё a = 3, b = 5.
  • return a + b вычисляет 3 + 5 = 8 и возвращает это число.
  • Возвращённое значение сохраняется в переменную result.

Аналогия: return - это как официант, который приносит вам заказ. Функция print просто «кричит» в зал, а return кладёт результат прямо вам на стол, чтобы вы могли с ним работать.

return завершает функцию

Как только Python встречает return, он немедленно выходит из функции. Весь код после return в этой функции выполняться не будет. Это часто используется для раннего выхода (как break в циклах).

Несколько значений из одной функции

С помощью return можно вернуть сразу несколько значений, перечислив их через запятую:

def min_max(numbers):    return min(numbers), max(numbers)minimum, maximum = min_max([4, 1, 9, 3])print(minimum)   # 1print(maximum)   # 9

Технически Python возвращает один объект - кортеж (tuple), который мы разбирали в уроке 11. А потом мы его распаковываем в две переменные.

Области видимости переменных

Важный момент: переменные, созданные внутри функции, называются локальными. Они существуют только пока выполняется функция. Снаружи их не видно:

def my_func():    secret = "внутри"    print(secret)my_func()print(secret)   # NameError! Переменной нет снаружи

Это логично: каждая функция - как отдельная комната. Внутри комнаты свои вещи, которые не лежат в общем коридоре.

А вот глобальные переменные (созданные вне функций) видны внутри:

greeting = "Привет"def show_greeting():    print(greeting)   # работает, видит глобальнуюshow_greeting()

Но менять глобальные переменные внутри функции без специального ключевого слова global нельзя. Пока это не критично, но полезно запомнить, что такое разделение есть.

Шпаргалка

Самое важное в одном месте:

  • def имя(): создать функцию
  • имя() вызвать функцию
  • def f(x, y): с аргументами
  • return значение вернуть результат
  • return a, b вернуть несколько значений
  • локальная переменная внутри функции

Если что-то не работает

Разберём типичные ошибки при работе с функциями.

  • «SyntaxError: invalid syntax» при объявлении. Проверьте двоеточие в конце строки def имя():, скобки и отсутствие пробелов в имени функции.
  • «IndentationError» внутри функции. Тело функции обязательно должно быть с отступом. Если вы написали def, а следующая строка без отступа - Python не поймёт, что она относится к функции.
  • «NameError: name 'my_func' is not defined» при вызове. Скорее всего, вы вызываете функцию до того, как объявили её. Функцию нужно сначала определить (def ...), и только потом вызывать.
  • «TypeError: my_func() missing 1 required positional argument». Вы объявили функцию с аргументом, а при вызове забыли его передать. Например, def greet(name):, а вызвали greet() без имени.
  • «Функция ничего не возвращает, в переменной None». Если в функции нет return, Python по умолчанию возвращает None. Если вы пытались сохранить результат - получите None. Добавьте return с нужным значением.
  • «Код после return не выполняется». Так и должно быть. return - это выход. Если нужно выполнить больше действий - перенесите их до return.

Если что-то не получается - напишите нам в Telegram, разберёмся вместе.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Первая функция

Создайте функцию print_separator, которая выводит на экран строку из 20 дефисов. Вызовите её три раза подряд.

Подсказка

Внутри функции используйте print("-" * 20). Вызов - это просто имя функции со скобками: print_separator().

Решение учителя 
def print_separator():    print("-" * 20)print_separator()print_separator()print_separator()
Задача 2. Приветствие с аргументом

Напишите функцию greet(name), которая принимает имя и выводит приветствие в формате «Здравствуйте, [Имя]!». Вызовите её для трёх разных имён.

Подсказка

Используйте f-строку внутри print: print(f"Здравствуйте, {name}!"). Не забудьте про отступ.

Решение учителя 
def greet(name):    print(f"Здравствуйте, {name}!")greet("Алексей")greet("Мария")greet("Иван")
Задача 3. Площадь прямоугольника

Напишите функцию rectangle_area(width, height), которая возвращает площадь прямоугольника. Вызовите её для сторон 5 и 10, сохраните результат в переменную и выведите.

Подсказка

Внутри функции используйте return width * height. При вызове результат можно сразу сохранить: area = rectangle_area(5, 10).

Решение учителя 
def rectangle_area(width, height):    return width * heightarea = rectangle_area(5, 10)print(f"Площадь: {area}")
Задача 4. Проверка пароля

Напишите функцию is_valid_password(password), которая возвращает True, если пароль длиннее 8 символов, и False в противном случае. Спросите пароль у пользователя и выведите результат проверки.

Подсказка

Функция должна возвращать логическое значение. Внутри используйте return len(password) > 8. Сравнение сразу даст True или False. При вызове результат можно проверить через if или просто вывести.

Решение учителя 
def is_valid_password(password):    return len(password) > 8pwd = input("Введите пароль: ")if is_valid_password(pwd):    print("Пароль надёжный")else:    print("Пароль слишком короткий")

Функция is_valid_password не выводит ничего на экран, а только возвращает результат. Это правильный подход: функция должна делать одну вещь, а как использовать результат - решает вызывающий код.

Что мы узнали и что дальше

Сегодня мы сделали огромный шаг вперёд - научились писать собственные функции. Теперь ваш код может быть не просто линейным набором инструкций, а структурированным и переиспользуемым. Вы узнали:

  • Что такое функция и зачем она нужна.
  • Как создавать функции через def.
  • Как вызывать функции и передавать им аргументы.
  • Как возвращать результат через return.
  • Что такое локальные и глобальные переменные.

Функции - это основа любой серьёзной программы. Чем больше проект, тем важнее разбивать его на маленькие функции, каждая из которых решает одну задачу. Тогда код становится читаемым, а ошибки - легко находимыми.

В следующем уроке мы углубимся в функции: разберём аргументы по умолчанию, именованные аргументы, *args и **kwargs, а также познакомимся с лямбда-функциями - короткими анонимными функциями в одну строку. Будет интересно!
