Аргументы и lambda

~40 минут Средний уровень Теория и Практика

В прошлом уроке мы научились создавать функции и передавать в них аргументы. Но Python - язык с огромными возможностями, и способов передать данные в функцию у него гораздо больше, чем может показаться на первый взгляд.

Сегодня мы разберём продвинутые приёмы: аргументы по умолчанию, именованные аргументы, а также загадочные *args и **kwargs. А в конце познакомимся с лямбда-функциями - короткими анонимными функциями, которые делают код невероятно элегантным.

Аргументы по умолчанию

Представьте, что вы пишете функцию для приветствия. Обычно она здоровается по-русски, но иногда нужно поздороваться на другом языке. Можно сделать так, чтобы язык был по умолчанию:

def greet(name, language="ru"):    if language == "ru":        print(f"Привет, {name}!")    elif language == "en":        print(f"Hello, {name}!")greet("Алексей")          # Привет, Алексей!greet("John", "en")       # Hello, John!

Если при вызове не передать language, функция возьмёт значение по умолчанию "ru". Если передать - использует его.

Опасная ловушка: изменяемые значения по умолчанию

Никогда не используйте списки, словари или множества в качестве значений по умолчанию! Вот классическая ошибка:

def add_item(item, my_list=[]):    my_list.append(item)    return my_listprint(add_item(1))  # [1]print(add_item(2))  # [1, 2] - почему?!

Значение по умолчанию создаётся один раз при объявлении функции. Все вызовы используют один и тот же список. Если нужно изменяемое значение по умолчанию, используйте None:

def add_item(item, my_list=None):    if my_list is None:        my_list = []    my_list.append(item)    return my_list

Именованные аргументы (Keyword Arguments)

При вызове функции можно указывать, какому параметру соответствует значение. Это называется именованными аргументами:

def create_profile(name, age, city):    print(f"{name}, {age} лет, город {city}")create_profile(age=25, name="Алексей", city="Москва")

Благодаря именам порядок аргументов больше не важен. Это делает код гораздо понятнее, особенно если у функции много параметров.

Магия *args и **kwargs

Иногда мы не знаем заранее, сколько аргументов передаст пользователь. Например, функция, которая считает сумму. Сегодня ей передают два числа, завтра - пять, послезавтра - десять.

Для этого в Python есть *args. Звёздочка говорит: «Собери все позиционные аргументы в один кортеж»:

def sum_all(*args):    print(args)   # (1, 2, 3, 4)    return sum(args)print(sum_all(1, 2, 3, 4))   # 10

А **kwargs (от keyword arguments) собирает все именованные аргументы в словарь:

def print_info(**kwargs):    for key, value in kwargs.items():        print(f"{key}: {value}")print_info(name="Алексей", age=25)

Названия args и kwargs - это просто традиция. Важны именно звёздочки. Можно назвать *numbers и **params - работать будет так же.

Лямбда-функции

Бывают ситуации, когда функция нужна всего на один раз и на одну строчку. Например, чтобы указать правило сортировки. Писать для этого целую конструкцию def - громоздко. Для таких случаев есть лямбда-функции.

Синтаксис такой: lambda аргументы: выражение.

square = lambda x: x ** 2print(square(5))   # 25

Это то же самое, что и:

def square(x):    return x ** 2

Но записано в одну строку и без имени. Можно передавать несколько аргументов:

add = lambda a, b: a + b

Где использовать лямбды?

Чаще всего лямбды применяются внутри других функций. Например, для сортировки списка словарей по определённому ключу:

users = [    {"name": "Иван", "age": 30},    {"name": "Мария", "age": 25},    {"name": "Алексей", "age": 35}]users.sort(key=lambda user: user["age"])

Или для применения какой-то операции ко всем элементам списка (функция map):

numbers = [1, 2, 3, 4]doubled = list(map(lambda x: x * 2, numbers))print(doubled)   # [2, 4, 6, 8]
Не увлекайтесь

Лямбды хороши для простых операций в одну строку. Если логика сложнее (несколько условий, циклы, многострочные вычисления) - используйте обычную функцию через def. Читаемость кода важнее краткости.

Шпаргалка

Самое важное в одном месте:

  • def f(x=10): аргумент по умолчанию
  • f(y=5, x=1) именованные аргументы
  • *args кортеж позиционных аргументов
  • **kwargs словарь именованных аргументов
  • lambda x: x + 1 анонимная функция
  • key=lambda ... лямбда для сортировки

Если что-то не работает

Разберём типичные ошибки при работе с аргументами.

  • «SyntaxError: non-default argument follows default argument». В функции нельзя ставить обязательный аргумент после аргумента по умолчанию. Неправильно: def f(a=1, b):. Правильно: def f(a, b=1):.
  • Значение по умолчанию «запоминается» между вызовами. Это та самая ловушка с изменяемыми типами (списками, словарями). Используйте None и создавайте объект внутри функции.
  • «TypeError: f() got an unexpected keyword argument». Вы передали именованный аргумент, которого нет в объявлении функции. Проверьте, как названы параметры в def.
  • «Я передал список в *args, а получил ошибку». *args собирает аргументы в кортеж. Если вы передали список, он станет первым элементом кортежа. Если хотите распаковать список в аргументы - используйте звёздочку при вызове: my_func(*my_list).
  • Лямбда возвращает «function object». Вы забыли её вызвать. square = lambda x: x ** 2 создаёт функцию. Чтобы получить результат, нужно вызвать: square(5).
  • «Lambda не может содержать условия». Может! Тернарный оператор работает: lambda x: "да" if x > 0 else "нет". А вот многострочные конструкции или циклы - нельзя.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Степень с умолчанием

Напишите функцию power(number, exponent=2), которая возводит число в степень. По умолчанию степень равна 2 (квадрат). Проверьте на power(5) и power(2, 3).

Подсказка

Используйте оператор ** для возведения в степень: return number ** exponent. Значение по умолчанию задаётся прямо в скобках: exponent=2.

Решение учителя 
def power(number, exponent=2):    return number ** exponentprint(power(5))     # 25print(power(2, 3))  # 8
Задача 2. Сумма всего

Напишите функцию sum_all(*args), которая принимает любое количество чисел и возвращает их сумму. Проверьте работу на 3 числах и на 5 числах.

Подсказка

Внутри функции args - это кортеж. Можно применить встроенную функцию sum(args). Не забудьте звёздочку в объявлении: *args.

Решение учителя 
def sum_all(*args):    return sum(args)print(sum_all(1, 2, 3))          # 6print(sum_all(10, 20, 30, 40, 50)) # 150
Задача 3. Профиль пользователя

Напишите функцию build_profile(**kwargs), которая принимает любые именованные аргументы (имя, возраст, город и т.д.) и выводит их на экран в формате «Ключ: Значение». Вызовите функцию с тремя разными параметрами.

Подсказка

Переберите словарь kwargs через .items(). В цикле выводите пару через f-строку. Вызов функции: build_profile(name="Алексей", age=25, city="Москва").

Решение учителя 
def build_profile(**kwargs):    for key, value in kwargs.items():        print(f"{key}: {value}")build_profile(name="Алексей", age=25, city="Москва")
Задача 4. Сортировка по возрасту

Дан список словарей (пользователей): [{"name": "Иван", "age": 30}, {"name": "Мария", "age": 20}, {"name": "Пётр", "age": 25}]. Отсортируйте его по возрасту (по возрастанию) с помощью лямбда-функции и выведите результат.

Подсказка

Используйте метод sort() с параметром key. В качестве ключа передайте лямбду, которая берёт возраст из словаря: key=lambda user: user["age"].

Решение учителя 
users = [    {"name": "Иван", "age": 30},    {"name": "Мария", "age": 20},    {"name": "Пётр", "age": 25}]users.sort(key=lambda user: user["age"])for user in users:    print(user["name"], "-", user["age"], "лет")

Теперь пользователи идут по возрасту: Мария (20), Пётр (25), Иван (30). Лямбда позволяет легко указать, по какому именно полю сортировать.

Что мы узнали и что дальше

Мы расширили наши знания о функциях. Теперь вы знаете:

  • Как задавать аргументы по умолчанию и какие ловушки с ними связаны.
  • Как передавать именованные аргументы и почему это удобно.
  • Как принимать переменное число аргументов через *args и **kwargs.
  • Как создавать короткие анонимные функции через lambda.

Эти приёмы делают функции невероятно гибкими. В реальной разработке вы будете встречать *args и **kwargs повсюду, особенно во фреймворках и библиотеках. А лямбды - незаменимый инструмент при работе с сортировкой и коллекциями.
