Генераторы и итераторы

~45 минут Средний уровень Теория и Практика

Представьте, что вам нужно обработать файл размером в 50 гигабайт. Если вы попытаетесь прочитать его целиком через read() или загрузить все строки в список, ваш компьютер просто зависнет из-за нехватки оперативной памяти. А что если нужно сгенерировать бесконечную последовательность чисел (например, для игрового цикла или генератора ID)? Список бесконечной длины создать невозможно.

Для решения таких задач в Python придумали итераторы и генераторы. Они позволяют обрабатывать данные по одному элементу за раз, не загружая всю последовательность в память. Это как пить воду из крана по глотку, а не пытаться выпить сразу весь бассейн.

Что такое итератор

Вы уже давно пользуетесь итераторами, даже не подозревая об этом. Когда вы пишете for item in my_list:, Python создаёт итератор и по очереди достаёт из него элементы.

Итератор - это объект, который умеет возвращать свои элементы по одному. У него есть специальный метод __next__, который достаёт следующий элемент. Когда элементы заканчиваются, он выбрасывает исключение StopIteration, и цикл for понимает, что пора остановиться.

Посмотрим, как это работает вручную с помощью функций iter() и next():

numbers = [10, 20, 30]my_iterator = iter(numbers)print(next(my_iterator))   # 10print(next(my_iterator))   # 20print(next(my_iterator))   # 30

Если вызвать next() четвёртый раз, мы получим ошибку StopIteration. Цикл for внутри себя как раз перехватывает эту ошибку и завершает работу.

Что такое генератор

Создавать итераторы вручную (через классы с методами __iter__ и __next__) довольно громоздко. К счастью, в Python есть генераторы - простой способ создавать итераторы.

Генератор - это функция, которая вместо return использует ключевое слово yield. Когда Python встречает yield, он «засыпает», запоминая своё состояние, и возвращает значение. При следующем вызове next() он просыпается и продолжает с того же места.

Аналогия: обычная функция с return - это как повар, который приготовил всё блюдо сразу и отдал его вам целиком. Функция с yield - это как конвейер на кухне: повар выдаёт по одной котлете каждый раз, когда вы подходите с тарелкой.

def countdown(n):    while n > 0:        yield n        n -= 1for num in countdown(3):    print(num)

Программа выведет 3, 2, 1. Функция countdown не вычисляет всё сразу, она «выдаёт» числа по одному по мере необходимости.

Главная выгода

Генераторы не хранят в памяти все значения. Если ваш генератор возвращает миллиард чисел, он займёт ровно столько памяти, сколько нужно для хранения текущего числа и переменной n. Обычный список из миллиарда чисел сразу исчерпал бы всю оперативную память.

Генераторные выражения

В уроке 10 мы говорили про списковые включения (list comprehension): [x * 2 for x in numbers]. Если заменить квадратные скобки на круглые, получится генераторное выражение:

numbers = [1, 2, 3, 4, 5]gen = (x * 2 for x in numbers)print(next(gen))   # 2print(next(gen))   # 4

Разница в том, что список вычисляется сразу и занимает память, а генераторное выражение вычисляет элементы лениво, по мере запроса.

Шпаргалка

Самое важное в одном месте:

  • iter() получить итератор
  • next() достать следующий элемент
  • StopIteration элементы закончились
  • yield создать генератор
  • (x for x in ...) генераторное выражение

Если что-то не работает

Разберём типичные ошибки при работе с генераторами.

  • «StopIteration». Вы вызвали next() больше раз, чем есть элементов. В циклах for эта ошибка обрабатывается автоматически, но при ручном вызове next() её нужно обрабатывать или использовать next(iterator, default_value).
  • «Функция с yield вернула None». Если вы забыли поставить yield и использовали return, функция отработает как обычная и вернёт результат (или None). Чтобы получить генератор, обязательно используйте yield.
  • «Генератор можно перебрать только один раз». Это правда. После того как генератор исчерпан, он пуст. Если нужно перебрать данные повторно - создайте генератор заново. Именно поэтому списки иногда удобнее: их можно перебирать сколько угодно раз.
  • «TypeError: 'generator' object is not subscriptable». К генератору нельзя обратиться по индексу (gen[0]). Генераторы не поддерживают индексацию, потому что они не хранят все элементы в памяти. Если нужен индекс - преобразуйте в список: list(gen)[0].

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Генератор чисел

Напишите функцию-генератор count_up_to(n), которая выдаёт числа от 1 до n включительно. Вызовите её для n=5 и выведите все числа через цикл for.

Подсказка

Используйте цикл for i in range(1, n + 1): и внутри него напишите yield i.

Решение учителя 
def count_up_to(n):    for i in range(1, n + 1):        yield ifor num in count_up_to(5):    print(num)
Задача 2. Генератор чётных чисел

Напишите генератор even_numbers(limit), который бесконечно выдаёт чётные числа (2, 4, 6, 8...). Используйте next(), чтобы вывести первые 5 чисел вручную.

Подсказка

Используйте while True: и переменную- счётчик. Если число чётное - делайте yield. Не забудьте увеличивать счётчик. Для вывода используйте next(gen) в цикле for _ in range(5):.

Решение учителя 
def even_numbers():    num = 0    while True:        num += 2        yield numgen = even_numbers()for _ in range(5):    print(next(gen))

Функция бесконечная, но благодаря тому, что это генератор, программа не зависнет и не съест всю память. Она выдаёт числа строго по запросу.

Задача 3. Генераторное выражение

Дан список чисел: [1, 2, 3, 4, 5]. Создайте генераторное выражение, которое возвращает квадраты этих чисел. Преобразуйте генератор в список и выведите его.

Подсказка

Синтаксис: (x ** 2 for x in numbers). Для преобразования в список используйте list(gen).

Решение учителя 
numbers = [1, 2, 3, 4, 5]squares_gen = (x ** 2 for x in numbers)result = list(squares_gen)print(result)   # [1, 4, 9, 16, 25]
Задача 4. Чтение файла генератором

Напишите генератор read_lines(filepath), который открывает файл и по одной строке выдаёт его содержимое через yield (без символа переноса строки). Используйте его для вывода файла test.txt, если он существует.

Подсказка

Внутри функции используйте with open(...) as f: и цикл for line in f:. Внутри цикла пишите yield line.strip(). Так файл будет читаться по одной строке, не загружая его целиком.

Решение учителя 
def read_lines(filepath):    with open(filepath, "r", encoding="utf-8") as f:        for line in f:            yield line.strip()try:    for text in read_lines("test.txt"):        print(text)except FileNotFoundError:    print("Файл не найден")

Этот подход идеален для чтения огромных логов: программа будет держать в памяти только одну строку за раз.
