Проект: Менеджер задач

~60 минут Средний уровень Итоговый проект

Вот и настал момент, когда все полученные знания нужно собрать в единое целое. За прошедшие 10 уроков мы выучили функции, модули, файлы, исключения, ООП, свойства, генераторы и декораторы.

Сегодня мы не будем изучать новую теорию. Вместо этого мы напишем полноценное приложение - консольный менеджер задач. Оно будет уметь добавлять задачи, сохранять их на диск в формате JSON, отмечать выполненными и удалять.

Вы можете гордиться этим проектом: он использует всё, что вы прошли до этого момента. Это ваш первый шаг в мир настоящей разработки.

Архитектура проекта

Прежде чем писать код, давайте подумаем о структуре. Хорошая программа не должна быть свалкой из переменных и функций. Мы разделим наш код на две сущности (класса):

  • Класс Task - описывает одну конкретную задачу (что именно нужно сделать).
  • Класс TaskManager - управляет списком всех задач (добавляет, удаляет, сохраняет в файл).

А ещё будет функция main(), которая запускает консольное меню для общения с пользователем.

Шаг 1. Класс Task

Задача должна хранить название, описание и статус (выполнена или нет). Для удобства сохранения в JSON добавим методы-конвертеры.

class Task:    def __init__(self, title, description="", is_done=False):        self.title = title        self.description = description        self.is_done = is_done    def to_dict(self):        return {            "title": self.title,            "description": self.description,            "is_done": self.is_done        }    @classmethod    def from_dict(cls, data):        return cls(            title=data["title"],            description=data.get("description", ""),            is_done=data.get("is_done", False)        )    def __str__(self):        status = "[x]" if self.is_done else "[ ]"        return f"{status} {self.title} - {self.description}"

Метод to_dict превращает объект в словарь (чтобы можно было сохранить в JSON). Метод from_dict (декоратор @classmethod позволяет вызывать его от класса) собирает объект обратно из словаря. А __str__ делает так, чтобы print(task) выводил красивую строку с галочкой.

Шаг 2. Класс TaskManager

Это «мозг» программы. Он хранит список задач и умеет с ними работать.

import jsonimport osclass TaskManager:    def __init__(self, filename="tasks.json"):        self.filename = filename        self.tasks = []        self.load_tasks()    def load_tasks(self):        if not os.path.exists(self.filename):            return        try:            with open(self.filename, "r", encoding="utf-8") as f:                data = json.load(f)                self.tasks = [Task.from_dict(item) for item in data]        except json.JSONDecodeError:            print("Ошибка чтения файла. Возможно, он поврежден.")    def save_tasks(self):        with open(self.filename, "w", encoding="utf-8") as f:            data = [task.to_dict() for task in self.tasks]            json.dump(data, f, ensure_ascii=False, indent=4)    def add_task(self, title, description=""):        self.tasks.append(Task(title, description))        self.save_tasks()        print(f"Задача '{title}' добавлена.")    def show_tasks(self):        if not self.tasks:            print("Список задач пуст.")            return        for index, task in enumerate(self.tasks, 1):            print(f"{index}. {task}")    def complete_task(self, index):        try:            task = self.tasks[index - 1]            task.is_done = True            self.save_tasks()            print(f"Задача '{task.title}' выполнена!")        except IndexError:            print("Задачи с таким номером не существует.")    def delete_task(self, index):        try:            task = self.tasks.pop(index - 1)            self.save_tasks()            print(f"Задача '{task.title}' удалена.")        except IndexError:            print("Задачи с таким номером не существует.")

Обратите внимание на важные детали:

  • При создании TaskManager мы сразу пытаемся загрузить задачи из файла через load_tasks().
  • Метод save_tasks() вызывается после каждого изменения (добавления, удаления, выполнения). Так мы гарантируем, что данные не потеряются, даже если выключить компьютер.
  • В complete_task и delete_task мы используем try/except IndexError, чтобы программа не падала, если пользователь введёт несуществующий номер.

Шаг 3. Консольное меню

Последний штрих - интерфейс для общения с пользователем.

def main():    manager = TaskManager()    while True:        print("\n--- Менеджер задач ---")        print("1. Показать задачи")        print("2. Добавить задачу")        print("3. Отметить выполненной")        print("4. Удалить задачу")        print("0. Выход")        choice = input("Выберите действие: ")        if choice == "1":            manager.show_tasks()        elif choice == "2":            title = input("Название задачи: ")            desc = input("Описание (необязательно): ")            manager.add_task(title, desc)        elif choice == "3":            manager.show_tasks()            try:                idx = int(input("Номер задачи: "))                manager.complete_task(idx)            except ValueError:                print("Ошибка: нужно ввести число.")        elif choice == "4":            manager.show_tasks()            try:                idx = int(input("Номер задачи: "))                manager.delete_task(idx)            except ValueError:                print("Ошибка: нужно ввести число.")        elif choice == "0":            print("До свидания!")            break        else:            print("Неверный выбор. Попробуйте снова.")if __name__ == "__main__":    main()

Шпаргалка

Какие технологии мы использовали в этом проекте:

  • ООП классы Task и TaskManager
  • @classmethod метод from_dict
  • __str__ красивый вывод задачи
  • json сохранение и загрузка данных
  • open() работа с файлами
  • try / except защита от неверного ввода

Если что-то не работает

Разберём типичные ошибки при работе с этим проектом.

  • «json.decoder.JSONDecodeError». Файл tasks.json повреждён или пуст. Удалите его, и программа создаст новый при следующем сохранении.
  • Данные не сохраняются. Убедитесь, что вы вызываете self.save_tasks() после каждого изменения в TaskManager. И что файл не открыт в другом редакторе (Windows может блокировать запись).
  • «IndexError» при удалении. Вы ввели номер задачи, которой нет. Программа обработает это через try/except, но проверьте, правильно ли выводятся индексы (они начинаются с 1 для пользователя, но в списке с 0).
  • Кракозябры вместо русского текста. Убедитесь, что везде при открытии файла указано encoding="utf-8".

Задача 3. Поиск задач

Добавьте метод search_tasks(keyword), который выводит только те задачи, в названии которых встречается ключевое слово (без учёта регистра). Добавьте пункт в меню.

Подсказка

Приводите и ключевое слово, и названия задач к нижнему регистру через .lower(). Используйте оператор in для проверки вхождения.

Решение учителя 
    def search_tasks(self, keyword):        keyword = keyword.lower()        found = [t for t in self.tasks if keyword in t.title.lower()]        if not found:            print("Ничего не найдено.")            return        for index, task in enumerate(found, 1):            print(f"{index}. {task}")
Задача 4. Приоритет задачи

Добавьте в класс Task атрибут priority (по умолчанию «обычный»). Обновите методы сохранения и загрузки, чтобы приоритет тоже сохранялся. При выводе задач отображайте приоритет в квадратных скобках.

Подсказка

Добавьте параметр в __init__, в to_dict и from_dict. Не забудьте поменять __str__, чтобы он выводил [приоритет].

Решение учителя 
class Task:    def __init__(self, title, description="", is_done=False, priority="обычный"):        self.title = title        self.description = description        self.is_done = is_done        self.priority = priority    def to_dict(self):        return {            "title": self.title,            "description": self.description,            "is_done": self.is_done,            "priority": self.priority        }    @classmethod    def from_dict(cls, data):        return cls(            title=data["title"],            description=data.get("description", ""),            is_done=data.get("is_done", False),            priority=data.get("priority", "обычный")        )    def __str__(self):        status = "[x]" if self.is_done else "[ ]"        return f"{status} [{self.priority}] {self.title} - {self.description}"
