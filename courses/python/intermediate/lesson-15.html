Работа с файлами

~75 минут Средний уровень Теория и Практика

До этого момента все наши программы были как старые консольные игры без сохранений. Вы запускали программу, вводили данные, получали результат, закрывали окно - и всё исчезало навсегда. Как только переменные уничтожались, информация терялась.

Представьте, что вы пишете игру, и хотите сохранить рекорд игрока. Или делаете менеджер задач, где список дел не должен пропадать после выключения компьютера. Для этого нужно научиться сохранять данные на жёсткий диск. Сегодня мы разберёмся, как Python работает с файлами и путями, освоим два популярных формата обмена данными - JSON и CSV, - а в конце научимся работать с датами и временем.

Открытие файла: open()

Чтобы начать работать с файлом, его нужно открыть. Для этого в Python есть встроенная функция open(). Она принимает два главных аргумента: имя файла и режим работы.

Аналогия: файл - это тетрадь. Режим работы - это то, зачем вы её открыли: чтобы почитать (чтение), чтобы начать писать с чистого листа (запись) или чтобы дописать что-то в конец (добавление).

Режимы работы

Самые важные режимы:

  • "r" (read) - чтение. Открывает файл только для чтения. Если файла нет - программа выдаст ошибку. Это режим по умолчанию.
  • "w" (write) - запись. Создаёт файл, если его нет. Если файл есть - он полностью стирается, и запись начинается с пустого листа.
  • "a" (append) - добавление. Открывает файл для записи в конец. Старое содержимое сохраняется, новые данные дописываются после них.

Конструкция with

Прежде чем начать читать и писать, давайте разберём важнейшую конструкцию with. В старых языках программирования после работы с файлом нужно было вручную вызывать метод .close():

f = open("file.txt", "w")f.write("Привет")f.close()

Проблема в том, что если во время записи произойдёт ошибка, до строки close() программа не дойдёт. Файл останется открытым, что может привести к повреждению данных или блокировке файла системой.

Современный и правильный способ - использовать менеджер контекста with:

with open("file.txt", "w") as f:    f.write("Привет")

Всё, что внутри блока with, выполняется при открытом файле. Как только блок заканчивается (или происходит ошибка), Python автоматически закрывает файл. Это гарантирует безопасность.

Всегда используйте with

Никогда не используйте open() без with, если только у вас нет очень веской причины. Конструкция with - это стандарт написания кода на Python, который делает код безопасным и чистым.

Запись в файл

Теперь, когда мы умеем безопасно открывать файлы, давайте что-нибудь запишем:

with open("example.txt", "w", encoding="utf-8") as f:    f.write("Первая строка\n")    f.write("Вторая строка\n")

Обратите внимание на три вещи:

  • encoding="utf-8" - мы явно указываем кодировку. Это критически важно для русского языка (кириллицы), иначе на Windows вместо букв могут появиться «кракозябры».
  • f.write() - метод для записи строки.
  • \n - символ переноса строки. Метод write не добавляет перенос автоматически. Если его не указать, обе строки склеятся в одну.

Чтение из файла

Читать файл можно несколькими способами.

Прочитать всё целиком: read()

with open("example.txt", "r", encoding="utf-8") as f:    content = f.read()    print(content)

Метод read() возвращает весь текст файла одной большой строкой. Подходит для небольших файлов.

Читать построчно: цикл for

Если файл большой (например, лог на гигабайт), читать его целиком в память - плохая идея. Лучше читать по одной строке в цикле:

with open("example.txt", "r", encoding="utf-8") as f:    for line in f:        print(line.strip())

Конструкция for line in f: автоматически берёт по одной строке за раз. Метод .strip() удаляет невидимый символ переноса строки (\n) в конце, чтобы print не делал двойных пробелов.

Современная работа с путями: pathlib

До этого мы передавали в open() просто строку с именем файла: "example.txt". Это работает, пока все файлы лежат в одной папке. Но в реальных проектах файлы разложены по подпапкам: data/users.json, logs/app.log, static/images/logo.png. И тут начинается путаница с косыми чертами.

На Windows путь пишется через обратный слеш: data\users.json. На macOS и Linux - через прямой: data/users.json. Если писать пути вручную как строки, придётся всё время помнить про эту разницу. А если ещё нужно собрать путь из частей или создать папку, если её нет, - код становится громоздким.

Решение - модуль pathlib, который появился в Python 3.4 и сегодня считается стандартом для работы с путями. Он предоставляет класс Path, который ведёт себя как объект, а не как строка.

Аналогия: строка с путём - это как адрес, написанный на салфетке. Объект Path - это как GPS-навигатор: он сам знает, где поставить слеш, умеет проверять, существует ли дом, создавать папки и показывать содержимое.

Создание пути

from pathlib import Pathfile_path = Path("data") / "users.json"print(file_path)   # data/users.json (или data\users.json на Windows)

Обратите внимание на оператор /. В pathlib он перегружен: вместо деления он соединяет части пути. При этом Python сам подставит правильный разделитель для вашей операционной системы. Это значит, что код Path("data") / "users.json" будет одинаково работать на любой платформе.

Проверки

Метод .exists() проверяет, существует ли файл или папка:

path = Path("data/users.json")if path.exists():    print("Файл найден")else:    print("Файла нет")

Если нужно понять, файл это или папка:

print(path.is_file())   # True, если это файлprint(path.is_dir())    # True, если это папка

Создание папок

Метод .mkdir() создаёт папку. С параметром parents=True он создаст все промежуточные папки, а с exist_ok=True не выдаст ошибку, если папка уже есть:

Path("logs/2026").mkdir(parents=True, exist_ok=True)

Одна строка заменяет собой os.makedirs с проверкой на существование. Если бы мы писали на старом os, код выглядел бы длиннее и его было бы легче сломать.

Быстрое чтение и запись

Самое приятное в Path - короткие методы для частых операций:

file = Path("notes.txt")file.write_text("Привет, мир!", encoding="utf-8")content = file.read_text(encoding="utf-8")print(content)   # Привет, мир!

Метод .write_text() открывает файл, пишет и закрывает его в одну строку. .read_text() - так же читает. Под капотом они используют with open(...), так что безопасность гарантирована. Единственный минус - нет режима добавления ("a"). Для добавления в конец придётся использовать обычный open.

Информация о файлах

Объект Path умеет возвращать имя, расширение и размер файла:

file = Path("data/report.csv")print(file.name)       # report.csvprint(file.stem)       # reportprint(file.suffix)     # .csvprint(file.parent)     # dataprint(file.stat().st_size)   # размер в байтах

Это очень удобно, когда нужно, например, перебрать все файлы в папке и обработать только .json:

for file in Path("data").iterdir():    if file.suffix == ".json":        print(f"Найден JSON: {file.name}")

Метод .iterdir() возвращает все файлы и папки внутри директории. Это гораздо удобнее, чем связка os.listdir и os.path.join.

pathlib или os.path?

Долгое время стандартом был модуль os.path с функциями вроде os.path.exists(), os.path.join(). Он работает до сих пор и вы встретите его в чужом коде. Но в новых проектах pathlib - стандарт: он лаконичнее, объектно-ориентирован и не требует помнить десятки разных функций.

JSON: универсальный формат данных

Обычный текст хорош для заметок и простых списков. Но что если нужно сохранить сложную структуру - например, словарь с настройками или список объектов с полями? Собирать это вручную из строк - мучение. Для таких задач придумали JSON (JavaScript Object Notation).

JSON - это текстовый формат, который выглядит почти как словари и списки Python. Он используется практически везде: в веб-API, в конфигурационных файлах, для обмена данными между программами.

Вот как выглядит JSON с данными пользователя:

{    "name": "Алексей",    "age": 25,    "skills": ["Python", "SQL"],    "is_active": true}

Обратите внимание на сходства и отличия от Python:

  • Ключи обязательно в двойных кавычках.
  • Вместо True и False пишется true и false.
  • None превращается в null.

Сериализация: dumps() и loads()

Для работы с JSON в Python есть встроенный модуль json. Две главные функции:

  • json.dumps(obj) - превращает объект Python в строку JSON (dump string).
  • json.loads(text) - превращает строку JSON обратно в объект Python (load string).
import jsondata = {"name": "Алексей", "age": 25, "skills": ["Python", "SQL"]}json_string = json.dumps(data)print(json_string)restored = json.loads(json_string)print(restored["name"])   # Алексей

Важный момент: по умолчанию dumps() превращает кириллицу в escape-последовательности вида \u0410. Чтобы сохранить русские буквы как есть, используйте параметр ensure_ascii=False:

json_string = json.dumps(data, ensure_ascii=False)

А параметр indent делает вывод красивым, с отступами. Удобно, если вы хотите, чтобы файл читал человек:

json_string = json.dumps(data, ensure_ascii=False, indent=2)

Запись и чтение JSON-файла

Для работы напрямую с файлами есть функции json.dump() и json.load() (без буквы s на конце). Они принимают вторым аргументом объект файла:

import jsonfrom pathlib import Pathdata = {    "name": "Алексей",    "age": 25,    "skills": ["Python", "SQL"]}with open("user.json", "w", encoding="utf-8") as f:    json.dump(data, f, ensure_ascii=False, indent=2)

Чтение делается симметрично:

with open("user.json", "r", encoding="utf-8") as f:    loaded = json.load(f)    print(loaded["skills"])   # ['Python', 'SQL']

Что если файл повреждён?

JSON-файл - это обычный текст. Если его случайно отредактировать и нарушить структуру (например, поставить лишнюю запятую или забыть кавычку), при чтении возникнет ошибка json.JSONDecodeError. В следующем уроке мы научимся такие ошибки красиво ловить, а пока просто знайте: если программа упала с этой ошибкой - проверьте содержимое файла.

CSV: таблицы в текстовом виде

Второй по популярности формат - CSV (Comma-Separated Values, «значения, разделённые запятыми»). Это просто таблица, где строки разделены переносами, а колонки - запятыми (или точкой с запятой).

Пример CSV-файла с оценками студентов:

Имя,Возраст,ОценкаАлексей,25,5Мария,23,4Иван,27,3

CSV отлично подходит для простых таблиц и открывается в Excel, Google Sheets и любой другой программе для работы с данными. Для работы с ним в Python есть встроенный модуль csv.

Параметр newline=""

При записи CSV-файла на Windows всегда указывайте newline="" при открытии файла. Иначе между строками появятся пустые строки из-за разницы в символах переноса. Это не баг Python, а особенность операционной системы.

Запись: csv.writer

import csvwith open("students.csv", "w", encoding="utf-8", newline="") as f:    writer = csv.writer(f)    writer.writerow(["Имя", "Возраст", "Оценка"])    writer.writerow(["Алексей", 25, 5])    writer.writerow(["Мария", 23, 4])

Метод writerow() принимает список значений и записывает его как одну строку CSV, автоматически расставляя запятые. Если нужно записать сразу несколько строк - есть writerows(), который принимает список списков.

Чтение: csv.reader

with open("students.csv", "r", encoding="utf-8") as f:    reader = csv.reader(f)    for row in reader:        print(row)

Каждая строка файла превращается в список строк. Даже числа приходят как строки: ["Алексей", "25", "5"]. Если нужны числа - придётся преобразовывать через int() или float().

Чтение по названиям колонок: csv.DictReader

Работать с индексами вроде row[1] неудобно: забыл порядок колонок - получил баг. Гораздо удобнее обращаться по имени. DictReader автоматически берёт первую строку файла как заголовки и возвращает каждую запись как словарь:

with open("students.csv", "r", encoding="utf-8") as f:    reader = csv.DictReader(f)    for row in reader:        print(f"{row['Имя']}: оценка {row['Оценка']}")

Вывод:

Алексей: оценка 5Мария: оценка 4

Согласитесь, читать такой код гораздо приятнее. DictReader - стандартный выбор, когда в файле есть заголовки.

Дата и время: модуль datetime

Почти любые данные рано или поздно хочется привязать ко времени. В логах нужна отметка, когда произошло событие. В менеджере задач - дедлайн. В отчётах - «на момент 15 марта». Для всего этого в Python есть модуль datetime.

Аналогия: datetime - это как календарь с часами в одном флаконе. Один объект хранит и дату, и время, и умеет отвечать на вопросы вроде «а сколько времени пройдёт до завтра?».

Текущие дата и время

from datetime import datetime, datenow = datetime.now()print(now)            # 2026-10-26 14:32:15.123456print(now.year)       # 2026print(now.month)      # 10print(now.day)        # 26print(now.hour)       # 14today = date.today()print(today)          # 2026-10-26

datetime.now() возвращает текущие дату и время. date.today() - только дату, без часов. У объекта datetime есть отдельные атрибуты .year, .month, .day, .hour, .minute, .second.

Форматирование: strftime

Хранить дату в виде 2026-10-26 14:32:15 удобно для машины, но не для человека. Метод .strftime() (string format time) превращает дату в строку по указанному шаблону:

now = datetime.now()print(now.strftime("%d.%m.%Y"))       # 26.10.2026print(now.strftime("%d %B %Y"))       # 26 October 2026print(now.strftime("%H:%M"))          # 14:32print(now.strftime("%d.%m.%Y %H:%M")) # 26.10.2026 14:32

Основные коды форматирования:

  • %Y - год четырьмя цифрами (2026).
  • %m - месяц двумя цифрами (01-12).
  • %d - день двумя цифрами (01-31).
  • %H - часы в 24-часовом формате.
  • %M - минуты.
  • %S - секунды.
  • %B - полное название месяца.

Разбор строки в дату: strptime

Обратная операция: у нас есть строка с датой, а нужно получить объект datetime. Метод .strptime() (string parse time) разбирает строку по шаблону:

text = "26.10.2026 14:32"dt = datetime.strptime(text, "%d.%m.%Y %H:%M")print(dt)        # 2026-10-26 14:32:00print(dt.year)   # 2026

Шаблон должен точно совпадать с форматом строки. Если строка записана как "26/10/2026", а шаблон вы указали "%d.%m.%Y", получите ошибку ValueError.

Разница между датами: timedelta

Можно вычитать одну дату из другой - получится объект timedelta (временной интервал):

from datetime import datetime, timedeltastart = datetime(2026, 1, 1)end = datetime(2026, 12, 31)diff = end - startprint(diff.days)   # 364tomorrow = datetime.now() + timedelta(days=1)print(tomorrow)

timedelta можно прибавлять к дате или вычитать из неё. Это самый удобный способ посчитать «через сколько дней наступит событие» или «какой день был ровно 30 дней назад».

deadline = datetime(2026, 12, 31)now = datetime.now()if deadline > now:    remaining = deadline - now    print(f"До дедлайна: {remaining.days} дней")else:    print("Дедлайн уже прошёл")

Дата в JSON

JSON не знает о датах - там есть только строки, числа, bool и null. Поэтому при сохранении в JSON дату превращают в строку через .isoformat() (стандартный формат ISO 8601):

import jsonfrom datetime import datetimetask = {    "title": "Сдать проект",    "created_at": datetime.now().isoformat()}json_string = json.dumps(task, ensure_ascii=False)print(json_string)

При чтении дату разбирают обратно через datetime.fromisoformat():

restored = json.loads(json_string)dt = datetime.fromisoformat(restored["created_at"])print(dt.year)   # 2026

Такой подход - стандарт де-факто: в JSON даты всегда хранят строками в ISO-формате, а преобразование делают при чтении и записи.

Шпаргалка

Самое важное в одном месте:

  • Path("dir") / "file" собрать путь
  • .exists() проверить существование
  • .read_text() / .write_text() быстрое чтение/запись
  • .suffix / .stem расширение / имя без него
  • json.dumps() / loads() строка ↔ объект
  • json.dump() / load() файл ↔ объект
  • ensure_ascii=False русский в JSON
  • csv.writer / reader запись и чтение CSV
  • csv.DictReader CSV по названиям колонок

Если что-то не работает

Разберём типичные проблемы при работе с файлами, JSON, CSV и датами.

  • «FileNotFoundError: No such file or directory». Вы пытаетесь открыть на чтение файл, которого нет. Проверьте имя и расширение. Помните, что файл должен лежать в той же папке, откуда вы запускаете скрипт (или указывайте полный путь).
  • Все русские буквы превратились в «кракозябры». Проблема с кодировкой. Всегда добавляйте encoding="utf-8" при открытии файла. Это спасёт вас от проблем с кириллицей.
  • Файл создаётся, но он пустой. Вы открыли его в режиме "w", но забыли вызвать f.write(). Открытие файла само по себе не пишет в него данные.
  • Каждая новая запись стирает предыдущую. Вы используете режим "w" (write), который перезаписывает файл с нуля. Если нужно добавлять данные, сохраняя старые, используйте режим "a" (append).
  • Весь текст слипся в одну строку. Метод write() не добавляет перенос автоматически. В конце строки нужно явно указывать \n: f.write("Текст\n").
  • «json.JSONDecodeError: Expecting value». Ваш JSON-файл повреждён: лишняя запятая, незакрытая кавычка, пустой файл. Откройте файл и проверьте структуру. Полезно прогнать содержимое через любой онлайн-валидатор JSON, чтобы найти ошибку.
  • JSON содержит «кракозябры» вида \u0410\u043b\u0435.... Вы забыли параметр ensure_ascii=False при json.dump() или json.dumps().
  • В CSV-файле появились пустые строки между данными. На Windows это классическая проблема. Решение - открывать файл на запись с параметром newline="": open(..., "w", newline="").
  • CSV-файл открывается в Excel одной колонкой. Скорее всего, у вас в системе разделитель - точка с запятой (частая ситуация в русской локали). Либо укажите в Excel разделитель вручную, либо используйте в коде csv.writer(f, delimiter=";") и csv.reader(f, delimiter=";").
  • «TypeError: unsupported operand type(s) for /: 'str' and 'str'» при работе с pathlib. Оператор / перегружен только для объектов Path. Превратите строку в путь: Path("data") / "file.json", а не "data" / "file.json".
  • «FileNotFoundError» при попытке записи через pathlib. Если родительской папки не существует, .write_text() упадёт. Сначала создайте папку: Path("logs").mkdir(parents=True, exist_ok=True).
  • «ValueError: time data ... does not match format». Шаблон в strptime не совпадает с форматом строки. Проверьте каждую часть: если в строке 26.10.2026, то шаблон должен быть %d.%m.%Y, а не %d/%m/%Y.
  • «TypeError: can't subtract offset-naive and offset-aware datetimes». Одна из дат - с часовым поясом, другая без. Используйте либо только «наивные» даты (datetime.now()), либо только «осознанные» (datetime.now(timezone.utc)). Не смешивайте.

Если что-то не получается - напишите нам в Telegram, разберёмся вместе.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Дневник с датой

Программа должна спросить три заметки и добавить их в файл diary.txt с новой строки. Перед каждой заметкой должна стоять текущая дата в формате [26.10.2026 14:32]. Используйте режим "a", модуль datetime и pathlib.

Подсказка

Создайте Path("diary.txt"). В цикле спрашивайте заметку и получайте текущее время через datetime.now().strftime("%d.%m.%Y %H:%M"). Открывайте файл через open("a", encoding="utf-8") и пишите строку вида f"[{now}] {note}\n".

Решение учителя 
from datetime import datetimefrom pathlib import Pathfile = Path("diary.txt")with open(file, "a", encoding="utf-8") as f:    for i in range(3):        note = input(f"Заметка {i + 1}: ")        now = datetime.now().strftime("%d.%m.%Y %H:%M")        f.write(f"[{now}] {note}\n")

В файле появятся строки вроде [26.10.2026 14:32] Купить хлеб. Если запустить программу ещё раз, старые записи сохранятся благодаря режиму "a".

Задача 2. JSON-конфиг

Создайте словарь с настройками приложения: theme (тема), language (язык), font_size (размер шрифта) и last_update (дата последнего обновления в формате ISO через datetime.now().isoformat()). Сохраните его в файл config.json в читаемом виде (с отступами и русскими буквами). Затем прочитайте файл обратно, разберите строку даты через datetime.fromisoformat() и выведите год последнего обновления.

Подсказка

Для записи используйте json.dump(data, f, ensure_ascii=False, indent=2). Для чтения - json.load(f). После чтения возьмите loaded["last_update"] и передайте в datetime.fromisoformat().

Решение учителя 
import jsonfrom datetime import datetimesettings = {    "theme": "тёмная",    "language": "русский",    "font_size": 14,    "last_update": datetime.now().isoformat()}with open("config.json", "w", encoding="utf-8") as f:    json.dump(settings, f, ensure_ascii=False, indent=2)with open("config.json", "r", encoding="utf-8") as f:    loaded = json.load(f)updated = datetime.fromisoformat(loaded["last_update"])print(f"Тема: {loaded['theme']}")print(f"Последнее обновление: {updated.year} год")

ISO-формат даты (2026-10-26T14:32:15.123456) - это универсальный стандарт, который одинаково понимают все языки программирования. Именно поэтому его используют в JSON вместо «человеческих» форматов вроде 26.10.2026.

Задача 3. Таблица оценок

Создайте CSV-файл grades.csv с заголовками Имя, Предмет, Оценка, Дата. Добавьте три записи с текущей датой в формате 26.10.2026. Не забудьте про newline="".

Подсказка

Получите дату один раз до цикла: today = datetime.now().strftime("%d.%m.%Y"). Откройте файл с newline="" и используйте writer.writerow() для каждой строки, передавая today последним элементом.

Решение учителя 
import csvfrom datetime import datetimetoday = datetime.now().strftime("%d.%m.%Y")with open("grades.csv", "w", encoding="utf-8", newline="") as f:    writer = csv.writer(f)    writer.writerow(["Имя", "Предмет", "Оценка", "Дата"])    writer.writerow(["Алексей", "математика", 5, today])    writer.writerow(["Мария", "физика", 4, today])    writer.writerow(["Иван", "информатика", 5, today])

Дата записывается как обычная строка - CSV не знает о типах данных. При чтении она вернётся строкой, и если понадобится - можно будет разобрать через datetime.strptime().

Задача 4. Анализ оценок

Прочитайте файл grades.csv из предыдущей задачи через csv.DictReader. Посчитайте средний балл по всем студентам и выведите имена тех, у кого оценка 5. Затем сохраните отчёт в файл report.json с полями: average (средний балл), excellent_students (список имён), generated_at (дата генерации отчёта в ISO-формате).

Подсказка

Соберите все оценки в список grades, а отличников - в excellent. Средний балл: sum(grades) / len(grades). Для отчёта создайте словарь и сохраните через json.dump(..., ensure_ascii=False, indent=2). Дату для отчёта получите через datetime.now().isoformat().

Решение учителя 
import csvimport jsonfrom datetime import datetimegrades = []excellent = []with open("grades.csv", "r", encoding="utf-8") as f:    reader = csv.DictReader(f)    for row in reader:        grade = int(row["Оценка"])        grades.append(grade)        if grade == 5:            excellent.append(row["Имя"])average = sum(grades) / len(grades)report = {    "average": round(average, 2),    "excellent_students": excellent,    "generated_at": datetime.now().isoformat()}with open("report.json", "w", encoding="utf-8") as f:    json.dump(report, f, ensure_ascii=False, indent=2)print(f"Средний балл: {average:.2f}")print(f"Отличники: {', '.join(excellent)}")

В результате получится сразу два файла: исходный CSV с данными и новый JSON с готовым отчётом. Такой формат удобен для программ-парсеров: они прочитают report.json и выведут статистику без повторной обработки таблицы.
