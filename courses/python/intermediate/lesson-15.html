Работа с файлами

~40 минут Средний уровень Теория и Практика

До этого момента все наши программы были как старые консольные игры без сохранений. Вы запускали программу, вводили данные, получали результат, закрывали окно - и всё исчезало навсегда. Как только переменные уничтожались, информация терялась.

Представьте, что вы пишете игру, и хотите сохранить рекорд игрока. Или делаете менеджер задач, где список дел не должен пропадать после выключения компьютера. Для этого нужно научиться сохранять данные на жёсткий диск. И сегодня мы разберёмся, как Python работает с файлами.

Открытие файла: open()

Чтобы начать работать с файлом, его нужно открыть. Для этого в Python есть встроенная функция open(). Она принимает два главных аргумента: имя файла и режим работы.

Аналогия: файл - это тетрадь. Режим работы - это то, зачем вы её открыли: чтобы почитать (чтение), чтобы начать писать с чистого листа (запись) или чтобы дописать что-то в конец (добавление).

Режимы работы

Самые важные режимы:

  • "r" (read) - чтение. Открывает файл только для чтения. Если файла нет - программа выдаст ошибку. Это режим по умолчанию.
  • "w" (write) - запись. Создаёт файл, если его нет. Если файл есть - он полностью стирается, и запись начинается с пустого листа.
  • "a" (append) - добавление. Открывает файл для записи в конец. Старое содержимое сохраняется, новые данные дописываются после них.

Конструкция with

Прежде чем начать читать и писать, давайте разберём важнейшую конструкцию with. В старых языках программирования после работы с файлом нужно было вручную вызывать метод .close():

f = open("file.txt", "w")f.write("Привет")f.close()

Проблема в том, что если во время записи произойдёт ошибка, до строки close() программа не дойдёт. Файл останется открытым, что может привести к повреждению данных или блокировке файла системой.

Современный и правильный способ - использовать менеджер контекста with:

with open("file.txt", "w") as f:    f.write("Привет")

Всё, что внутри блока with, выполняется при открытом файле. Как только блок заканчивается (или происходит ошибка), Python автоматически закрывает файл. Это гарантирует безопасность.

Всегда используйте with

Никогда не используйте open() без with, если только у вас нет очень веской причины. Конструкция with - это стандарт написания кода на Python, который делает код безопасным и чистым.

Запись в файл

Теперь, когда мы умеем безопасно открывать файлы, давайте что-нибудь запишем:

with open("example.txt", "w", encoding="utf-8") as f:    f.write("Первая строка\n")    f.write("Вторая строка\n")

Обратите внимание на три вещи:

  • encoding="utf-8" - мы явно указываем кодировку. Это критически важно для русского языка (кириллицы), иначе на Windows вместо букв могут появиться «кракозябры».
  • f.write() - метод для записи строки.
  • \n - символ переноса строки. Метод write не добавляет перенос автоматически. Если его не указать, обе строки склеятся в одну.

Чтение из файла

Читать файл можно несколькими способами.

Прочитать всё целиком: read()

with open("example.txt", "r", encoding="utf-8") as f:    content = f.read()    print(content)

Метод read() возвращает весь текст файла одной большой строкой. Подходит для небольших файлов.

Читать построчно: цикл for

Если файл большой (например, лог на гигабайт), читать его целиком в память - плохая идея. Лучше читать по одной строке в цикле:

with open("example.txt", "r", encoding="utf-8") as f:    for line in f:        print(line.strip())

Конструкция for line in f: автоматически берёт по одной строке за раз. Метод .strip() удаляет невидимый символ переноса строки (\n) в конце, чтобы print не делал двойных пробелов.

Шпаргалка

Самое важное в одном месте:

  • with open() as f: безопасное открытие файла
  • "r" чтение (по умолчанию)
  • "w" запись (стирает старое)
  • "a" добавление в конец
  • encoding="utf-8" правильная кодировка
  • f.write(text) записать строку
  • f.read() прочитать всё
  • for line in f: читать построчно

Если что-то не работает

Разберём типичные проблемы при работе с файлами.

  • «FileNotFoundError: No such file or directory». Вы пытаетесь открыть на чтение файл, которого нет. Проверьте имя и расширение. Помните, что файл должен лежать в той же папке, откуда вы запускаете скрипт (или указывайте полный путь).
  • Все русские буквы превратились в «кракозябры». Проблема с кодировкой. Всегда добавляйте encoding="utf-8" при открытии файла. Это спасёт вас от проблем с кириллицей.
  • Файл создаётся, но он пустой. Вы открыли его в режиме "w", но забыли вызвать f.write(). Открытие файла само по себе не пишет в него данные.
  • Каждая новая запись стирает предыдущую. Вы используете режим "w" (write), который перезаписывает файл с нуля. Если нужно добавлять данные, сохраняя старые, используйте режим "a" (append).
  • Весь текст слипся в одну строку. Метод write() не добавляет перенос автоматически. В конце строки нужно явно указывать \n: f.write("Текст\n").

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Первая запись

Напишите программу, которая спрашивает у пользователя его имя и записывает его в файл name.txt. Используйте режим "w" и encoding="utf-8".

Подсказка

Сначала получите ввод через input(). Затем откройте файл: with open("name.txt", "w", encoding="utf-8") as f: и запишите туда имя через f.write().

Решение учителя 
name = input("Введите имя: ")with open("name.txt", "w", encoding="utf-8") as f:    f.write(name)
Задача 2. Дневник

Программа должна спросить три заметки и добавить их в файл diary.txt с новой строки. Используйте режим "a" (добавление), чтобы не стирать предыдущие записи, если запустить программу несколько раз.

Подсказка

Спросите три заметки (можно через цикл for i in range(3):). Внутри with open(..., "a") используйте f.write(заметка + "\n"). Не забудьте про символ переноса строки.

Решение учителя 
with open("diary.txt", "a", encoding="utf-8") as f:    for i in range(3):        note = input(f"Заметка {i + 1}: ")        f.write(note + "\n")
Задача 3. Чтение файла

Откройте файл diary.txt (который вы сделали в прошлой задаче) и прочитайте его построчно в цикле. Выведите каждую строку на экран, предваряя её номером: «1. Текст».

Подсказка

Используйте enumerate() для нумерации строк: for index, line in enumerate(f):. Не забудьте line.strip(), чтобы убрать лишние переносы.

Решение учителя 
with open("diary.txt", "r", encoding="utf-8") as f:    for index, line in enumerate(f, start=1):        print(f"{index}. {line.strip()}")

Параметр start=1 в enumerate делает так, что нумерация начинается с единицы, а не с нуля.

Задача 4. Копирование файла

Напишите программу, которая копирует содержимое одного файла в другой. Спросите у пользователя имена исходного и нового файлов. Прочитайте исходный и запишите всё в новый.

Подсказка

Вам понадобятся два блока with. В первом откройте исходный файл на чтение ("r") и сохраните текст в переменную через f.read(). Во втором откройте новый файл на запись ("w") и запишите туда эту переменную.

Решение учителя 
source = input("Исходный файл: ")target = input("Новый файл: ")with open(source, "r", encoding="utf-8") as f:    content = f.read()with open(target, "w", encoding="utf-8") as f:    f.write(content)print("Файл скопирован!")

Обратите внимание: мы сначала полностью прочитали файл, закрыли его (блок with закончился), и только потом открыли новый. Это безопасный подход.

Что мы узнали и что дальше

Сегодня мы преодолели важнейший барьер - научились сохранять данные на диск. Теперь ваши программы могут не просто работать в моменте, но и накапливать информацию, сохранять прогресс и обмениваться данными. Вы узнали:

  • Зачем нужны файлы и какие бывают режимы открытия (r, w, a).
  • Почему конструкция with лучше ручного close().
  • Как записывать данные через write() и добавлять перенос строки \n.
  • Как читать файлы целиком через read() и построчно через for line in f:.
  • Почему так важно указывать encoding="utf-8".
