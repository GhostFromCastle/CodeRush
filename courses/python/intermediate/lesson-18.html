ООП: наследование

~45 минут Средний уровень Теория и Практика

В прошлом уроке мы научились создавать классы и объекты. Мы сделали класс Dog с именем, возрастом и методом лая. Это было здорово, но давайте представим, что нам нужно добавить ещё классы Cat, Cow и Horse.

У всех этих животных будут общие черты: имя, возраст, метод eat() (кушать), метод sleep() (спать). Если мы будем копировать код из класса Dog в класс Cat, а потом в Cow, мы нарушим главное правило программиста - DRY (Don't Repeat Yourself - не повторяйся).

К счастью, в ООП есть механизм, который позволяет не копировать код, а брать его из другого класса и расширять. Этот механизм называется наследование.

Суть наследования

Аналогия: представьте биологическую классификацию. Есть общее понятие «Животное». У всех животных есть общие свойства (они дышат, едят, спят). А потом уже идут подвиды: Млекопитающие, Птицы, Рыбы. Млекопитающие унаследовали от Животных умение дышать и есть, но добавили своё - умение выкармливать детёнышей молоком.

В программировании то же самое. Есть родительский класс (или базовый, суперкласс) с общими свойствами. И есть дочерние классы (подклассы), которые забирают всё от родителя и добавляют что-то своё.

Создание базового класса

Давайте создадим класс Animal (Животное) с общими данными и действиями:

class Animal:    def __init__(self, name, age):        self.name = name        self.age = age    def eat(self):        print(f"{self.name} кушает")    def sleep(self):        print(f"{self.name} спит")

Теперь создадим дочерний класс Dog. Для этого в скобках после имени класса указываем, от кого он наследуется:

class Dog(Animal):    def bark(self):        print(f"{self.name} говорит: Гав!")

И всё! Класс Dog автоматически получил конструктор __init__, методы eat() и sleep() от класса Animal. Нам не нужно их переписывать. Мы добавили только уникальный метод bark().

Проверим:

my_dog = Dog("Бадди", 3)my_dog.eat()    # Бадди кушает (метод родителя)my_dog.sleep()  # Бадди спит (метод родителя)my_dog.bark()   # Бадди говорит: Гав! (свой метод)

Функция super()

Что делать, если дочернему классу нужны свои дополнительные атрибуты? Например, у собаки есть порода (breed), а у кошки - количество жизней (lives).

В этом случае нам нужно написать в дочернем классе свой метод __init__. Но как не потерять при этом name и age? Для этого используется функция super(). Она вызывает метод родительского класса:

class Dog(Animal):    def __init__(self, name, age, breed):        super().__init__(name, age)        self.breed = breed    def bark(self):        print(f"{self.name} ({self.breed}) говорит: Гав!")

Строка super().__init__(name, age) означает: «Обратись к родительскому классу (Animal) и выполни его инициализатор с этими аргументами». Так родитель создаст атрибуты name и age, а мы после этого добавим breed.

Переопределение методов

Иногда поведение родителя нас не устраивает. Например, метод eat() у животного просто пишет «кушает». А мы хотим, чтобы кошка ела рыбу, а собака - косточку.

Мы можем переопределить метод в дочернем классе. То есть написать метод с тем же именем, и Python будет использовать версию из дочернего класса:

class Cat(Animal):    def eat(self):        print(f"{self.name} ест рыбу")

Если мы вызовем eat() у кошки, сработает переопределённый метод. А если у собаки - останется метод родителя (раз мы его не меняли).

Полиморфизм

Это сложное слово означает простую вещь: объекты разных классов могут иметь одинаковый интерфейс (одинаковые методы), но вести себя по-разному.

Представьте, что у нас есть список самых разных животных: собака, кошка, корова. У каждого из них мы можем вызвать метод speak() (голос). Но каждая скажет что-то своё.

Добавим метод speak() в базовый класс Animal и переопределим его в каждом дочернем:

class Animal:    # ... (конструктор пропущен для краткости)    def speak(self):        print("Издаёт звук")class Dog(Animal):    def speak(self):        print("Гав!")class Cat(Animal):    def speak(self):        print("Мяу!")class Cow(Animal):    def speak(self):        print("Му!")

Теперь магия полиморфизма:

animals = [Dog("Бадди", 3), Cat("Мурка", 2), Cow("Зорька", 4)]for animal in animals:    animal.speak()

На экране появится:

Гав!Мяу!Му!

Обратите внимание на цикл for. Мы не проверяем if isinstance(animal, Dog). Мы просто вызываем speak() у каждого объекта. Python сам знает, какой именно метод нужно выполнить. Это и есть полиморфизм - один вызов, разное поведение.

Шпаргалка

Самое важное в одном месте:

  • class Child(Parent): наследование
  • super().__init__() вызов родительского конструктора
  • Переопределение замена метода родителя
  • Полиморфизм один метод, разное поведение
  • isinstance() проверка типа объекта

Если что-то не работает

Разберём типичные ошибки при наследовании.

  • «TypeError: __init__() missing...» в дочернем классе. Вы создали в дочернем классе свой __init__, но забыли вызвать super().__init__(...). Без этого родительские атрибуты не создадутся.
  • Изменения в родителе не применяются к дочернему классу. Такое бывает, если вы перезапутались в иерархии классов или случайно переопределили метод, который не хотели. Всегда проверяйте, в каком классе находится метод.
  • «AttributeError: 'Child' object has no attribute...». Вы пытаетесь обратиться к атрибуту в дочернем классе, который был создан в родительском, но конструктор родителя не был вызван.
  • Путаница в порядке аргументов. При вызове super().__init__() нужно передавать аргументы в том же порядке, в каком они объявлены в родительском классе.

Задача 1. Транспорт

Создайте базовый класс Vehicle (Транспорт) с атрибутом speed и методом move(), который выводит «Транспорт движется со скоростью [speed] км/ч». Создайте дочерний класс Car и добавьте в него метод honk(), который выводит «Би-бип!».

Подсказка

Создайте класс Vehicle с __init__. Создайте class Car(Vehicle):. В классе Car определите только метод honk. Не забудьте вызвать super().__init__(speed), если переопределяете конструктор (или не переопределяйте его).

Решение учителя 
class Vehicle:    def __init__(self, speed):        self.speed = speed    def move(self):        print(f"Транспорт движется со скоростью {self.speed} км/ч")class Car(Vehicle):    def honk(self):        print("Би-бип!")car = Car(60)car.move()car.honk()
Задача 2. Переопределение

Используйте классы из прошлой задачи. Переопределите метод move() в классе Car, чтобы он выводил «Машина едет со скоростью [speed] км/ч». Проверьте, что у объекта Car вызывается новый метод.

Подсказка

Внутри класса Car просто создайте метод def move(self): и напишите там нужный print. Python автоматически выберет метод из дочернего класса.

Решение учителя 
class Car(Vehicle):    def move(self):        print(f"Машина едет со скоростью {self.speed} км/ч")    def honk(self):        print("Би-бип!")car = Car(80)car.move()

Создайте базовый класс Employee (Сотрудник) с именем и зарплатой. Создайте дочерний класс Manager (Менеджер), который дополнительно принимает количество подчинённых. Используйте super() для инициализации общих полей.

В классе Manager создайте __init__(self, name, salary, team_size). Первой строкой вызовите super().__init__(name, salary). Затем сохраните self.team_size = team_size.

Задача 4. Полиморфизм на практике

Создайте базовый класс Shape (Фигура) с методом area(), который возвращает 0. Создайте дочерние классы Square (квадрат со стороной) и Circle (круг с радиусом). Переопределите метод area() в каждом из них для правильного расчёта площади. Создайте список из разных фигур и в цикле выведите их площади.

Подсказка

Для круга используйте import math и формулу math.pi * self.radius ** 2. В цикле просто вызывайте shape.area() для каждого элемента списка.

Решение учителя 
import mathclass Shape:    def area(self):        return 0class Square(Shape):    def __init__(self, side):        self.side = side    def area(self):        return self.side ** 2class Circle(Shape):    def __init__(self, radius):        self.radius = radius    def area(self):        return math.pi * self.radius ** 2shapes = [Square(5), Circle(3), Square(10)]for shape in shapes:    print(f"Площадь: {shape.area():.2f}")

Обратите внимание: в цикле мы не знаем, какая именно фигура лежит в переменной shape. Но благодаря полиморфизму, вызов area() сработает правильно для каждой.

Что мы узнали и что дальше

Наследование - это мощнейший инструмент ООП. Он позволяет строить иерархии классов, переиспользовать код и избегать дублирования. Теперь вы знаете:

  • Как создавать дочерние классы на основе родительских.
  • Как вызывать родительский конструктор через super().
  • Как переопределять методы родителя.
  • Что такое полиморфизм и как он работает в циклах.

В следующем уроке мы разберём ещё одну важную концепцию ООП - свойства (properties). Вы узнаете, как сделать атрибуты объекта защищёнными от случайного изменения извне, и как использовать декоратор @property для создания умных геттеров и сеттеров. До встречи!
