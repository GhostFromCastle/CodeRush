ООП: классы и объекты

~45 минут Средний уровень Теория и Практика

До этого момента мы писали программы, используя функции и базовые типы данных: числа, строки, списки, словари. Такой подход называется процедурным программированием. Он отлично работает для небольших скриптов.

Но представьте, что вы пишете игру. У вас есть игрок, враги, оружие, карта. Как описать игрока? У него есть имя, уровень здоровья, координаты на карте, инвентарь. И он умеет двигаться, атаковать, получать урон.

Мы могли бы хранить данные игрока в словаре, а действия - в отдельных функциях. Но это неудобно: данные отдельно, функции отдельно. Настоящие программы используют другой подход - объектно-ориентированное программирование (ООП). Оно позволяет объединить данные и действия над ними в единое целое.

Класс и объект: чертёж и здание

В основе ООП лежат два понятия: класс и объект.

  • Класс - это шаблон, чертёж, описание того, какими свойствами и поведением будут обладать объекты.
  • Объект (экземпляр) - это конкретная вещь, созданная по этому чертежу.

Аналогия: класс - это архитектурный чертёж дома. На нём указано, где будут стены, двери, окна. Но по этому чертежу самому по себе жить нельзя. А объект - это конкретный построенный дом по этому чертежу. Можно построить десять домов по одному чертежу - они будут разными (разные адреса, жильцы), но структура у них будет одинаковая.

Создание класса

Класс в Python создаётся с помощью ключевого слова class. Названия классов принято писать с большой буквы:

class Dog:    pass

Мы создали класс Dog (Собака). Пока он пустой (внутри стоит pass - заглушка). Но теперь мы можем создать сколько угодно объектов (собак) по этому чертежу:

my_dog = Dog()your_dog = Dog()

С точки зрения Python, my_dog и your_dog - это два разных объекта одного класса. Пока они абсолютно пустые и одинаковые, но это уже настоящие сущности в памяти.

Атрибуты: данные объекта

Пустая собака - это скучно. Давайте дадим нашим объектам свойства (характеристики). В ООП такие свойства называются атрибутами.

Самый простой способ задать атрибуты - присвоить их объекту напрямую:

my_dog = Dog()my_dog.name = "Бадди"my_dog.age = 3print(my_dog.name)   # Баддиprint(my_dog.age)    # 3

Мы создали атрибуты name и age прямо на лету. Но это работает только для my_dog. У your_dog этих атрибутов пока нет. Так делать неудобно.

Метод __init__: конструктор

Чтобы каждый объект создавался уже с нужными данными, используют специальный метод __init__ (конструктор). Он автоматически вызывается при создании объекта:

class Dog:    def __init__(self, name, age):        self.name = name        self.age = age

Обратите внимание на параметр self. Это обязательный первый параметр в методах класса. Когда мы создаём объект, self автоматически указывает на этот конкретный объект. Читается как «эта конкретная собака».

Строки self.name = name означают: «Возьми переданное имя и сохрани его как атрибут name у этого конкретного объекта».

Теперь при создании объекта мы обязаны передать аргументы:

dog1 = Dog("Бадди", 3)dog2 = Dog("Рекс", 5)print(dog1.name)   # Баддиprint(dog2.name)   # Рекс

Методы: поведение объекта

Кроме данных, объекты умеют что-то делать. Действия объекта называются методами. Это обычные функции, объявленные внутри класса, но первым аргументом они всегда принимают self:

class Dog:    def __init__(self, name, age):        self.name = name        self.age = age    def bark(self):        print(f"{self.name} говорит: Гав!")    def get_human_age(self):        return self.age * 7

Теперь наши собаки умеют лаять и узнавать свой возраст по человеческим меркам:

dog = Dog("Бадди", 3)dog.bark()                     # Бадди говорит: Гав!print(dog.get_human_age())     # 21

Обратите внимание: при вызове метода мы не передаём self. Python делает это автоматически. Мы просто вызываем dog.bark().

Всё есть объект

Помните, в уроке 9 мы говорили, что в Python всё является объектом? Теперь вы понимаете, почему. Строки, числа и списки - это тоже экземпляры своих классов. Например, строка - это объект класса str, у неё есть методы .upper(), .split() и другие. Просто их классы написали разработчики Python, а свои классы вы теперь пишете сами.

Шпаргалка

Самое важное в одном месте:

  • class Name: создать класс
  • obj = Name() создать объект
  • def __init__(self, ...): конструктор
  • self ссылка на текущий объект
  • obj.attr доступ к атрибуту
  • obj.method() вызов метода

Если что-то не работает

Разберём типичные ошибки новичков при работе с классами.

  • Забыли self в параметрах метода. Если вы напишете def bark(): вместо def bark(self):, при вызове dog.bark() Python попытается передать объект как аргумент, но не найдёт для него места и выдаст TypeError.
  • «TypeError: __init__() missing 1 required positional argument». Вы создаёте объект Dog(), но не передали обязательные аргументы name и age. Если в __init__ есть параметры, при создании их нужно передать.
  • «AttributeError: 'Dog' object has no attribute 'name'». Вы пытаетесь обратиться к атрибуту, который не был создан в __init__. Проверьте, что вы задали его через self.name = ....
  • Забыли self. при обращении к атрибуту внутри метода. Если вы напишете print(name) вместо print(self.name), Python будет искать локальную переменную name и выдаст ошибку NameError.
  • Путаница между классом и объектом. Если написать Dog.name, Python попытается найти атрибут name у самого класса, а не у конкретной собаки. Это сработает, если у класса есть атрибуты, но атрибуты объектов доступны только через dog.name.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Книга

Создайте класс Book с конструктором __init__, который принимает название книги и автора. Создайте два объекта этого класса и выведите их атрибуты на экран.

Подсказка

Класс: class Book:. Внутри def __init__(self, title, author):. Сохраните атрибуты через self.title и self.author. Создайте объекты: book1 = Book("Война и мир", "Толстой").

Решение учителя 
class Book:    def __init__(self, title, author):        self.title = title        self.author = authorbook1 = Book("Война и мир", "Лев Толстой")book2 = Book("Мастер и Маргарита", "Михаил Булгаков")print(f"{book1.title} - {book1.author}")print(f"{book2.title} - {book2.author}")
Задача 2. Прямоугольник

Создайте класс Rectangle с шириной и высотой. Добавьте методы area() (площадь) и perimeter() (периметр). Создайте прямоугольник 5 на 10 и выведите его площадь и периметр.

Подсказка

В конструкторе сохраните self.width и self.height. Метод площади: return self.width * self.height. Метод периметра: return 2 * (self.width + self.height).

Решение учителя 
class Rectangle:    def __init__(self, width, height):        self.width = width        self.height = height    def area(self):        return self.width * self.height    def perimeter(self):        return 2 * (self.width + self.height)rect = Rectangle(5, 10)print(f"Площадь: {rect.area()}")print(f"Периметр: {rect.perimeter()}")
Задача 3. Банковский счёт

Создайте класс BankAccount с балансом (начинается с 0). Добавьте метод deposit(amount), который увеличивает баланс, и метод withdraw(amount), который уменьшает баланс, но не позволяет уйти в минус.

Подсказка

В методе withdraw используйте if amount <= self.balance:. Если денег достаточно - вычитайте, иначе выводите сообщение «Недостаточно средств».

Решение учителя 
class BankAccount:    def __init__(self):        self.balance = 0    def deposit(self, amount):        self.balance += amount        print(f"Пополнение на {amount}. Баланс: {self.balance}")    def withdraw(self, amount):        if amount <= self.balance:            self.balance -= amount            print(f"Снятие {amount}. Баланс: {self.balance}")        else:            print("Недостаточно средств")acc = BankAccount()acc.deposit(1000)acc.withdraw(300)acc.withdraw(1000)
Задача 4. Студент

Создайте класс Student с именем и пустым списком оценок. Добавьте метод add_grade для добавления оценки, и метод average_grade, который считает средний балл. Если оценок нет, метод должен возвращать 0.

Подсказка

Список оценок создавайте в конструкторе: self.grades = []. Для среднего балла проверьте, пуст ли список. Если нет - используйте sum(self.grades) / len(self.grades).

Решение учителя 
class Student:    def __init__(self, name):        self.name = name        self.grades = []    def add_grade(self, grade):        self.grades.append(grade)    def average_grade(self):        if not self.grades:            return 0        return sum(self.grades) / len(self.grades)student = Student("Алексей")student.add_grade(5)student.add_grade(4)student.add_grade(5)print(f"{student.name}, средний балл: {student.average_grade():.2f}")

Что мы узнали и что дальше

Сегодня вы прикоснулись к парадигме, которая лежит в основе 99% современных программ - объектно-ориентированному программированию. Мы узнали:

  • Что такое класс (чертёж) и объект (готовое изделие).
  • Как создавать классы с помощью class.
  • Что такое конструктор __init__ и как он работает.
  • Зачем нужен параметр self и что он означает.
  • Как создавать атрибуты (данные) и методы (поведение) объекта.

Классы и объекты позволяют моделировать реальный мир в коде. Вместо набора разрозненных переменных и функций у вас появляются сущности со своим характером и поведением. Это делает код гораздо понятнее и надёжнее.
