Переменные и типы данных

~30 минут Начальный уровень Теория и Практика

В прошлом уроке мы написали первую программу, которая вывела на экран «Hello, World!». Но это был просто текст, который мы написали заранее. Настоящие программы умеют хранить данные, изменять их и работать с ними. Например, калькулятор должен помнить числа, с которыми работает, а игра - счёт игрока.

Сегодня мы познакомимся с главными инструментами для этого: переменными и типами данных. Именно на них строится всё программирование. Без них вы не сможете написать ни одной осмысленной программы.

Что такое переменная

Представьте, что у вас есть коробки с наклейками. В одну вы кладёте числа, в другую - слова, в третью - что-то логическое. Каждая коробка имеет своё имя, чтобы вы могли легко её найти и достать нужное содержимое.

Переменная - это именно такая коробка. Это именованная область памяти, в которой хранится какое-то значение. Вы даёте ей имя один раз - и потом можете обращаться к ней по этому имени, читать и менять содержимое.

В Python переменная создаётся очень просто:

name = "Алексей"

Что здесь произошло:

  • name - это имя переменной. Так мы будем обращаться к «коробке».
  • = - это знак присваивания. Читается как «положить в коробку». Не путайте с математическим «равно».
  • "Алексей" - это значение, которое мы кладём в коробку.

После этого мы можем использовать переменную в программе:

name = "Алексей"print(name)

Программа выведет Алексей. Функция print посмотрела в коробку с именем name, достала оттуда значение и показала на экране.

Как менять переменные

Главное удобство переменных в том, что их содержимое можно менять. Возьмём ту же переменную name и положим в неё новое значение:

name = "Алексей"print(name)name = "Мария"print(name)

Первая печать выведет Алексей, вторая - Мария. Мы буквально «вытряхнули» старое значение и положили новое. Старое пропадает - переменная хранит только одно значение в каждый момент времени.

А вот так можно увеличить число на единицу:

score = 0print(score)score = score + 10print(score)

Программа сначала выведет 0, а потом 10. Строка score = score + 10 читается так: «Возьми текущее значение из score, прибавь к нему 10 и положи обратно в score».

Знак равенства в программировании

В математике x = 5 означает «x равен пяти». В программировании это команда «положи в x значение 5». Поэтому запись x = x + 1 в математике бессмысленна, а в программировании - абсолютно нормальна: «возьми старое x, прибавь 1, положи обратно».

Правила именования

Имя переменной - это не просто произвольный текст. Есть несколько правил, которые нужно соблюдать, иначе Python не поймёт, что вы имеете в виду:

  • Начинается с буквы или подчёркивания. Имя name или _name работает, а 1name - нет, потому что начинается с цифры.
  • Может содержать буквы, цифры и подчёркивания. user_name2 - можно, user-name - нельзя (дефис запрещён, он воспринимается как знак вычитания).
  • Чувствительно к регистру. Name и name - это две разные переменные. Python различает строчные и заглавные буквы.
  • Нельзя использовать зарезервированные слова. Есть слова вроде if, for, print, class, которые «заняты» языком. Если попробуете назвать переменную if - получите ошибку.

Помимо обязательных правил, есть соглашения о том, как писать красиво:

  • Осмысленные имена. user_age понятнее, чем x или a1.
  • Стиль snake_case. В Python принято писать имена переменных строчными буквами, а слова разделять подчёркиванием: first_name, total_price, is_active.
  • Коротко, но понятно. price - хорошо, p - плохо, но total_price_after_discount - слишком длинно.

Основные типы данных

Каждое значение в Python имеет свой тип. Это как категория содержимого в коробке: число - это число, текст - это текст, истина - это истина. Самые важные типы, с которыми вы будете работать каждый день:

int - целые числа

Это числа без дробной части: 1, -5, 100, 0. Могут быть отрицательными и положительными:

age = 25temperature = -10year = 2026

float - числа с плавающей точкой

Это числа с дробной частью. В Python они пишутся через точку, а не запятую (это важно!):

height = 1.75pi = 3.14159temperature = -3.5

Если написать height = 1,75 с запятой - Python воспримет это как два отдельных числа, а не одно. Запятая в Python используется для других целей (перечисление аргументов, кортежи).

str - строки

Это текст в кавычках. Мы уже работали со строками в первом уроке:

name = "Алексей"city = 'Москва'message = "Привет, мир!"

Строкой может быть одно слово, предложение, абзац, цифры в кавычках ("123" - это строка, а не число).

bool - логический тип

Это либо True (истина), либо False (ложь). Всего два значения. Используется для условий и проверок:

is_student = Truehas_license = False

Обратите внимание: True и False пишутся с большой буквы. Это часть синтаксиса Python.

Функция type(): как узнать тип

Иногда нужно узнать, что за тип у переменной. Для этого есть функция type():

print(type(25))         # <class 'int'>print(type(3.14))       # <class 'float'>print(type("hello"))    # <class 'str'>print(type(True))       # <class 'bool'>

Функция type возвращает тип значения. Это полезно, когда вы не уверены, что именно лежит в переменной.

Динамическая типизация

В Python одна и та же переменная может менять тип в процессе работы программы. Это называется динамической типизацией:

x = 10print(type(x))   # intx = "теперь строка"print(type(x))   # strx = 3.14print(type(x))   # float

В других языках (например, в C#) пришлось бы объявлять новую переменную другого типа. Python более гибкий. Правда, с гибкостью приходит и ответственность: иногда легко забыть, что там лежит, и получить ошибку.

Хорошая практика

Даже если Python позволяет менять тип, лучше этого не делать без необходимости. Если переменная называется age - пусть там всегда будет число. Это делает код понятнее и помогает избежать багов.

Преобразование типов

Иногда нужно превратить один тип в другой. Например, пользователь ввёл число как текст (так работает input(), но об этом в следующем уроке) - а нам нужно с ним что-то посчитать. Для этого есть функции преобразования:

  • int(x) - превращает в целое число.
  • float(x) - превращает в число с точкой.
  • str(x) - превращает в строку.
  • bool(x) - превращает в True или False.

Примеры:

a = int("42")       # строка -> число 42b = float("3.14")   # строка -> число 3.14c = str(100)        # число -> строка "100"d = int(3.99)       # float -> int, дробная часть отбрасывается

Обратите внимание на последний пример: int(3.99) вернёт 3, а не 4. Python не округляет, а просто отбрасывает дробную часть.

Если попробовать преобразовать что-то неподходящее - получим ошибку:

int("привет")   # ошибка! Нельзя превратить текст в число

Шпаргалка

Самое важное в одном месте:

  • имя = значение создать переменную
  • int целое число
  • float число с точкой
  • str строка
  • bool True или False
  • type(x) узнать тип
  • int(), str(), float() преобразование типов
  • snake_case стиль именования переменных

Если что-то не работает

Разберём типичные ошибки при работе с переменными и типами.

  • «SyntaxError: invalid syntax» рядом с именем переменной. Скорее всего, имя начинается с цифры (1name = 5) или содержит запрещённый символ (дефис, пробел). Имя должно начинаться с буквы или подчёркивания.
  • «NameError: name 'x' is not defined». Вы используете переменную x, но нигде её не создали. Или создали в другом месте программы, куда отсюда не видно. Проверьте, что строка x = ... выполнилась раньше, чем print(x).
  • «TypeError: can only concatenate str (not "int") to str». Вы пытаетесь сложить строку и число через +: "Возраст: " + 25. Python не умеет склеивать разные типы. Решение - привести число к строке: "Возраст: " + str(25). Или использовать f-строки (о них в следующем уроке).
  • «ValueError: invalid literal for int() with base 10: 'привет'». Вы пытаетесь преобразовать текст в число, но в тексте нет числа. int("привет") не работает. Проверьте, что строка содержит только цифры.
  • Путаница с запятой и точкой в float. В Python дробные числа пишутся через точку: 3.14, а не 3,14. С запятой Python воспримет это как два числа.
  • «Переменная меняет значение сама». Такого в Python не бывает. Если print показывает не то, что вы ожидали - проверьте, не перезаписываете ли вы переменную где-то выше по коду. Возможно, у вас две переменные с одинаковыми именами.
  • Имена Name и name. Python различает регистр. Если вы создали name, а обращаетесь к Name - получите NameError.

Если что-то не получается - напишите нам в Telegram, разберёмся вместе.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Визитная карточка

Создайте четыре переменные: name (ваше имя), age (ваш возраст), city (город, в котором живёте) и is_student (True, если учитесь, иначе False). Выведите все четыре значения через print.

Подсказка

Строки - в кавычках, число - без кавычек, логическое значение - True или False с большой буквы. Вывести можно как четыре отдельных print, так и в одну строку через запятую.

Решение учителя 
name = "Алексей"age = 25city = "Москва"is_student = Trueprint(name, age, city, is_student)

Python автоматически добавит пробелы между значениями. Вывод получится примерно такой: Алексей 25 Москва True.

Задача 2. Калькулятор покупки

В магазине вы купили: хлеб за 45 рублей, молоко за 89.5 рубля и сыр за 320 рублей. Создайте три переменные с ценами, посчитайте общую сумму и выведите её на экран.

Подсказка

Создайте три переменные: например, bread, milk, cheese. Сумму можно сохранить в отдельной переменной total или посчитать прямо в print. Не забудьте про точку в 89.5.

Решение учителя 
bread = 45milk = 89.5cheese = 320total = bread + milk + cheeseprint("Общая сумма:", total)

Программа выведет Общая сумма: 454.5. Обратите внимание, что total получается типа float, потому что среди слагаемых есть 89.5.

Задача 3. Что за тип

Для каждого значения определите его тип (int, float, str или bool). Проверьте себя, запустив print(type(...)) в Python.

  1. 42
  2. "42"
  3. 3.14
  4. True
  5. "True"
  6. -7.5
  7. 0
Подсказка

Смотрите на кавычки и наличие точки. Если есть кавычки - это str. Если есть точка (и нет кавычек) - float. Если True/False без кавычек - bool. Всё остальное - int.

Решение учителя
  1. 42 - int. Целое число без кавычек и без точки.
  2. "42" - str. Число в кавычках - это текст.
  3. 3.14 - float. Есть точка - значит, дробное число.
  4. True - bool. Логическое значение.
  5. "True" - str. В кавычках - это строка «True», а не логическое значение.
  6. -7.5 - float. Отрицательное, но с точкой - всё равно float.
  7. 0 - int. Ноль - это целое число.
Задача 4. Преобразование типов

Что выведет каждая из этих строк? Сначала подумайте сами, потом проверьте в Python.

  1. print(int("100") + 50)
  2. print(str(100) + "50")
  3. print(int(3.99))
  4. print(float("2.5") * 2)
  5. print(type(str(42)))
Подсказка

Внимательно смотрите на типы после преобразования. Если после str() - это строка, и + будет склеивать. Если после int() - это число, и + будет складывать.

Решение учителя
  1. 150. Строка "100" превращается в число 100, потом к нему прибавляется 50.
  2. 10050. Число 100 превращается в строку, а потом две строки склеиваются.
  3. 3. Дробная часть отбрасывается (не округляется!).
  4. 5.0. Строка превращается в 2.5, умножается на 2 = 5.0 (это float).
  5. <class 'str'>. Число 42 становится строкой.

Особенно коварна вторая строка. Многие ожидают 150, но получают 10050, потому что после str() это уже не число, а текст.

Что мы узнали и что дальше

Сегодня мы разобрались с фундаментом программирования - переменными и типами данных. Теперь вы знаете:

  • Что такое переменная и как её создать (имя = значение).
  • Что такое типы данных: int, float, str, bool.
  • Как узнать тип через type().
  • Как преобразовать один тип в другой: int(), str(), float().
  • Как правильно именовать переменные: snake_case, осмысленные имена, не начинать с цифры.

Этого уже достаточно, чтобы писать простые программы, которые хранят числа и что-то с ними делают. Но пока наши программы не могут общаться с пользователем: все данные задаются прямо в коде. А что если мы хотим спросить у пользователя его имя или число? Об этом - в следующем уроке.
