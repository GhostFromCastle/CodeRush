Случайные числа и модуль random

~30 минут Начальный уровень Теория и Практика

Представьте игральный кубик, который всегда выпадает на 6. Или карточную игру, где карты каждый раз раздаются в одном и том же порядке. Или компьютерного врага, который ходит по строго заданному маршруту. Скучно, предсказуемо и неинтересно.

Именно случайность делает игры живыми, генераторы паролей - надёжными, а симуляции - реалистичными. И сегодня мы научимся добавлять случайность в наши программы. Для этого в Python есть встроенный модуль random.

Что такое модуль

До этого момента мы использовали только то, что Python даёт «из коробки»: print, input, len. Но язык программирования - это не только базовые функции. В нём есть огромная библиотека готовых инструментов, организованных в модули.

Аналогия: Python - это большой ящик с инструментами. Базовые функции - это молоток и отвёртка, которые всегда под рукой. А модули - это специализированные ящики: один с инструментами для математики, другой для работы с файлами, третий для случайных чисел. Вы берёте нужный ящик, только когда он вам понадобится.

Чтобы начать использовать модуль, его нужно импортировать (от английского import - «ввозить»). Это делается одной строкой в начале программы:

import random

После этого все функции модуля random становятся доступны через точку: random.имя_функции().

Случайное целое число: randint()

Самая полезная функция для начала - random.randint(a, b). Она возвращает случайное целое число в диапазоне от a до b включительно.

Сразу обратите внимание: в отличие от range(), здесь обе границы включаются. random.randint(1, 6) может вернуть 1, 2, 3, 4, 5 или 6 - как настоящий кубик.

import randomdice = random.randint(1, 6)print(f"Выпало: {dice}")

Если запустить эту программу несколько раз - каждый раз будет новое число. Иногда 4, иногда 1, иногда 6. Это и есть случайность.

Случайное дробное число: random()

Функция random.random() (без аргументов) возвращает случайное дробное число от 0.0 до 1.0, причём 1.0 не включается:

import randomnumber = random.random()print(number)   # например, 0.732391...

Это число часто используется для вероятностей. Например, если нужно, чтобы что-то произошло с вероятностью 30%:

if random.random() < 0.3:    print("Событие произошло!")

Потому что random.random() с равной вероятностью вернёт любое число от 0 до 1. А 30% чисел из этого диапазона меньше 0.3 - значит, условие сработает примерно в 30% случаев.

Случайный выбор из коллекции: choice()

А что если нужно выбрать случайный элемент из какого-то набора? Например, случайное слово из списка или случайную букву из строки? Для этого есть random.choice():

import randomword = random.choice("Python")print(word)   # одна из букв: P, y, t, h, o или nfruits = random.choice(["яблоко", "банан", "вишня"])print(fruits)

В первом примере функция выбирает случайный символ из строки. Во втором - случайный элемент из списка (списки мы будем разбирать в уроке 10, но базовая идея понятна: набор значений в квадратных скобках).

Перемешивание: shuffle()

Иногда нужно не просто выбрать один элемент, а перемешать весь набор. Например, чтобы раздать карты в случайном порядке. Для этого есть random.shuffle():

import randomcards = ["6", "7", "8", "9", "10", "J", "Q", "K", "A"]random.shuffle(cards)print(cards)   # например, ['A', '8', 'Q', '6', '10', 'K', 'J', '7', '9']

Важно: shuffle меняет список на месте и ничего не возвращает. То есть нельзя написать new_cards = random.shuffle(cards) - вы получите None. Просто вызывайте функцию, и список cards изменится сам.

Можно ли доверять случайности?

В компьютере не бывает «настоящей» случайности. Процессор работает по строгим алгоритмам, и если запустить программу дважды с одинаковыми начальными условиями - получится одинаковый результат.

Поэтому то, что делает модуль random, называется псевдослучайными числами. Они выглядят случайными, ведут себя как случайные, но на самом деле вычисляются по хитрой формуле. Для игр, генерации паролей и большинства повседневных задач этого достаточно.

Настоящая случайность для безопасности

Если вы когда-нибудь будете писать что-то, связанное с безопасностью (генерация криптографических ключей, токенов, паролей для банка) - использовать random нельзя. Для таких задач есть отдельный модуль secrets, который использует аппаратный генератор случайности. Но это тема далёкого будущего. Сейчас нам хватит и random.

Функция seed(): управляемая случайность

Иногда нужно, чтобы случайность была воспроизводимой. Например, если вы тестируете игру, и хотите, чтобы при каждом запуске карты раздавались одинаково. Для этого используют функцию random.seed():

import randomrandom.seed(42)print(random.randint(1, 100))   # всегда одно и то же числоprint(random.randint(1, 100))   # всегда одно и то же число

С одинаковым seed последовательность «случайных» чисел всегда будет одинаковой. Если не задавать seed - Python берёт его из системного времени, и каждый запуск даёт новую последовательность.

Для игр и обычных программ seed() обычно не нужен. Но полезно знать, что такая функция существует.

Шпаргалка

Самое важное в одном месте:

  • import random подключить модуль
  • randint(a, b) случайное целое от a до b включительно
  • random() случайное дробное от 0.0 до 1.0
  • choice(seq) случайный элемент из коллекции
  • shuffle(seq) перемешать коллекцию на месте
  • seed(n) фиксированная последовательность

Если что-то не работает

Разберём типичные ошибки при работе со случайными числами.

  • «NameError: name 'random' is not defined». Забыли строку import random в начале файла. Без неё Python не знает, что такое random.
  • «NameError: name 'randint' is not defined». Вы написали randint(1, 6) вместо random.randint(1, 6). При импорте import random функции вызываются через точку с именем модуля.
  • Одно и то же число при каждом запуске. Проверьте, не вызываете ли вы random.seed() с одинаковым аргументом в начале программы. Если seed фиксирован - числа всегда будут одинаковыми.
  • «IndexError» при использовании choice. Скорее всего, вы передали пустую строку или пустой список. choice не может выбрать элемент из ничего.
  • «TypeError» при вызове shuffle. Строки перемешать нельзя - они неизменяемы. shuffle работает только с изменяемыми коллекциями, например списками.
  • shuffle вернул None. Это нормальное поведение. shuffle меняет список на месте и ничего не возвращает. Не нужно записывать результат в новую переменную.
  • «randint(1, 6) даёт 6, а range(1, 6) - нет». Да, это важное отличие. randint включает правую границу, range - нет. Так задумано, потому что randint - это как кубик: от 1 до 6 включительно.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Игральный кубик

Сымитируйте бросок игрального кубика: выведите случайное целое число от 1 до 6.

Подсказка

Используйте random.randint(1, 6). Не забудьте import random в начале программы.

Решение учителя 
import randomdice = random.randint(1, 6)print(f"Выпало: {dice}")

Запустите программу несколько раз - каждый раз будет новое число. Если хотите имитировать бросок двух кубиков - просто вызовите randint дважды и сложите результаты.

Задача 2. Генератор цвета

Создайте программу, которая выводит случайный цвет из списка: «красный», «жёлтый», «зелёный», «синий», «белый», «чёрный».

Подсказка

Создайте переменную со списком цветов в квадратных скобках и передайте её в random.choice().

Решение учителя 
import randomcolors = ["красный", "жёлтый", "зелёный", "синий", "белый", "чёрный"]color = random.choice(colors)print(f"Ваш цвет: {color}")

Метод choice выбирает один элемент из списка с одинаковой вероятностью. Если запустить программу несколько раз, будут появляться разные цвета.

Задача 3. Генератор пароля

Создайте простой генератор пароля: программа должна собрать пароль из 8 случайных символов. Используйте строку с доступными символами (буквы и цифры) и цикл for.

Подсказка

Создайте строку символов, например "abcdefghijklmnopqrstuvwxyz0123456789". Заведите пустую переменную для пароля. В цикле for i in range(8): выбирайте случайный символ через random.choice(chars) и добавляйте его к паролю через +=.

Решение учителя 
import randomchars = "abcdefghijklmnopqrstuvwxyz0123456789"password = ""for i in range(8):    password += random.choice(chars)print(f"Ваш пароль: {password}")

Цикл выполняется 8 раз. На каждом шаге выбирается случайный символ и добавляется к строке пароля. Обратите внимание на password += ... - это короткая запись password = password + ....

Задача 4. Угадай число (заготовка)

Напишите программу, которая загадывает случайное число от 1 до 100 и просит пользователя его угадать. В цикле while спрашивайте число, пока пользователь не угадает. На каждой попытке подсказывайте: «Загаданное число больше» или «Загаданное число меньше».

Подсказка

Загадайте число через random.randint(1, 100). Внутри цикла while True: спрашивайте ввод через int(input(...)). Сравнивайте через if / elif / else. Если угадал - выводите поздравление и делайте break.

Решение учителя 
import randomsecret = random.randint(1, 100)attempts = 0while True:    guess = int(input("Угадайте число от 1 до 100: "))    attempts += 1    if guess < secret:        print("Загаданное число больше")    elif guess > secret:        print("Загаданное число меньше")    else:        print(f"Поздравляю! Вы угадали за {attempts} попыток.")        break

Это классическая игра, которая объединяет всё, что мы прошли: случайные числа, ввод данных, условия, циклы и f-строки. В следующем уроке мы сделаем похожую игру, но уже полноценную - «Орёл или Решка».
