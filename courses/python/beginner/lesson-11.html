Коллекции: кортежи, множества и словари

~60 минут Начальный уровень Теория и Практика

Это финальный урок начального уровня. Мы уже отлично знакомы со списками - они универсальны и подходят для большинства задач. Но иногда списки - не самый лучший выбор.

Например, координаты точки на карте (x, y) вряд ли должны меняться. Список имён гостей не должен содержать дубликатов. А телефонную книгу удобнее хранить не как список имён и список номеров, а как пары «Имя - Номер». Для всех этих случаев в Python есть другие коллекции: кортежи, множества и словари. А в конце урока мы познакомимся с модулем collections - набором готовых инструментов, которые делают работу с коллекциями ещё удобнее.

Кортежи (tuple): неизменяемые списки

Кортеж - это очень похоже на список, но с одним важным отличием: его нельзя изменить после создания. Мы уже знаем из урока 9, что такие данные называются неизменяемыми.

Создаётся кортеж с помощью круглых скобок ():

point = (10, 20)rgb = (255, 128, 0)person = ("Алексей", 25)

Работа с индексами точно такая же, как у списков:

print(point[0])    # 10print(point[-1])   # 20

Но если попытаться изменить элемент - получим ошибку:

point[0] = 5   # TypeError!
Зачем нужны кортежи?

Если данные не должны меняться, кортеж защищает их от случайной порчи. Это как запечатанный конверт: внутри лежит важное, но изменить содержимое, не порвав конверт, нельзя. Плюс кортежи работают чуть быстрее списков и могут использоваться там, где списки запрещены (например, в качестве ключей словаря).

Распаковка кортежа

Очень удобная фишка Python - можно сразу разложить элементы кортежа по отдельным переменным:

point = (10, 20)x, y = pointprint(x)   # 10print(y)   # 20

Это часто используется при возврате нескольких значений из функции (о функциях поговорим на среднем уровне).

Множества (set): только уникальные элементы

Множество - это коллекция, которая хранит только уникальные элементы и не имеет порядка. Если вы добавите дубликат - он просто проигнорируется.

Создаётся с помощью фигурных скобок {} или функции set():

numbers = {1, 2, 3, 3, 3}print(numbers)   # {1, 2, 3} - дубликаты исчезли

Из-за отсутствия порядка нельзя обратиться к элементу по индексу - numbers[0] вызовет ошибку. Зато можно проверять наличие элемента через in (и это работает очень быстро):

if 2 in numbers:    print("Двойка есть в множестве")

Главное применение: удаление дубликатов

Самый частый способ использования множеств - превратить список с дубликатами в список без них. Делается это одной строкой:

my_list = [1, 2, 2, 3, 3, 3, 4]unique = list(set(my_list))print(unique)   # [1, 2, 3, 4] (порядок может отличаться)

Операции над множествами

Множества в Python поддерживают математические операции:

  • Объединение | - все элементы из обоих множеств.
  • Пересечение & - только те элементы, которые есть в обоих.
  • Разность - - элементы первого, которых нет во втором.
a = {1, 2, 3}b = {3, 4, 5}print(a | b)   # {1, 2, 3, 4, 5} (объединение)print(a & b)   # {3} (пересечение)print(a - b)   # {1, 2} (разность)

Словари (dict): ключ - значение

Словарь - это самая мощная и самая часто используемая коллекция после списка. Он хранит данные в виде пар «ключ: значение».

Аналогия: обычный толковый словарь. У вас есть слово (ключ), и есть его определение (значение). Зная слово, вы мгновенно находите определение.

Создаётся словарь тоже с помощью фигурных скобок, но с двоеточиями:

person = {    "name": "Алексей",    "age": 25,    "city": "Москва"}

Доступ и изменение

Чтобы получить значение, используется ключ в квадратных скобках:

print(person["name"])   # Алексейprint(person["age"])    # 25

Если обратиться к несуществующему ключу - будет ошибка KeyError. Чтобы избежать этого, можно использовать метод get(), который вернёт None (или указанное значение по умолчанию), если ключа нет:

print(person.get("email"))              # Noneprint(person.get("email", "не указан")) # не указан

Добавление и изменение значений происходит одинаково - по ключу:

person["age"] = 26            # изменилиperson["email"] = "a@mail.ru" # добавили

Перебор словаря

Пройтись по словарю можно тремя способами:

for key in person.keys():    print(key)              # имена ключейfor value in person.values():    print(value)            # значенияfor key, value in person.items():    print(f"{key}: {value}") # пары ключ-значение

Последний вариант используется чаще всего. Метод .items() возвращает пары «ключ-значение», которые сразу можно распаковывать в две переменные.

Ключи должны быть неизменяемыми

В качестве ключей словаря можно использовать только неизменяемые типы: строки, числа, кортежи. Списки использовать нельзя - они изменяемые, а значит, могут сломать структуру словаря. Если попробуете, получите ошибку TypeError: unhashable type.

Модуль collections: расширенные коллекции

Всё, что мы разобрали до этого момента, - базовые коллекции, встроенные в Python. Но в стандартной библиотеке есть модуль collections с готовыми инструментами для типовых задач. Три из них особенно полезны и встречаются в любом реальном коде.

Аналогия: базовые коллекции - это как кухонный нож. Им можно сделать всё, но для нарезки хлеба удобнее хлебный нож, а для чистки овощей - овощечистка. Модуль collections - это набор таких специализированных инструментов.

Counter: счётчик элементов

Одна из самых частых задач - посчитать, сколько раз встречается каждый элемент. Например, сколько раз каждое слово встречается в тексте. Обычно для этого используют словарь и цикл:

words = ["яблоко", "банан", "яблоко", "вишня", "банан", "яблоко"]counts = {}for word in words:    if word in counts:        counts[word] += 1    else:        counts[word] = 1print(counts)   # {'яблоко': 3, 'банан': 2, 'вишня': 1}

Работает, но 6 строк кода - многовато для такой простой задачи. Counter делает то же самое одной строкой:

from collections import Counterwords = ["яблоко", "банан", "яблоко", "вишня", "банан", "яблоко"]counts = Counter(words)print(counts)   # Counter({'яблоко': 3, 'банан': 2, 'вишня': 1})

Counter - это подкласс словаря, поэтому с ним работают все методы dict: обращение по ключу, .get(), .items() и другие. Плюс есть несколько собственных полезных методов:

print(counts["яблоко"])              # 3print(counts.most_common(2))        # [('яблоко', 3), ('банан', 2)]print(sum(counts.values()))         # 6 (всего элементов)

Метод .most_common(n) возвращает n самых частых элементов в виде списка кортежей. Это готовый инструмент для анализа текста, логов, статистики.

defaultdict: словарь с автоматическими значениями

Помните проблему из начала раздела? Когда мы считали слова, приходилось писать проверку if word in counts перед каждым обращением. Иначе на новом слове вылетал бы KeyError.

defaultdict решает эту проблему элегантно: при обращении к несуществующему ключу он автоматически создаёт его со значением по умолчанию.

from collections import defaultdictwords = ["яблоко", "банан", "яблоко", "вишня", "банан", "яблоко"]counts = defaultdict(int)for word in words:    counts[word] += 1print(dict(counts))   # {'яблоко': 3, 'банан': 2, 'вишня': 1}

Что изменилось:

  • Вместо обычного {} создаём defaultdict(int). Аргумент int - это «фабрика» значений по умолчанию. int() без аргументов возвращает 0.
  • При первом обращении к новому слову counts[word] Python автоматически создаёт ключ со значением 0, и уже к нему прибавляется 1.
  • Проверка if word in counts больше не нужна - она исчезла из кода.

Вместо int можно передать list - тогда при обращении к новому ключу создастся пустой список. Это удобно, когда нужно сгруппировать данные по какому-то признаку:

from collections import defaultdictstudents = [    ("Алексей", "математика"),    ("Мария", "физика"),    ("Алексей", "физика"),    ("Иван", "математика"),    ("Мария", "химия")]by_subject = defaultdict(list)for name, subject in students:    by_subject[subject].append(name)print(dict(by_subject))

Вывод:

{'математика': ['Алексей', 'Иван'], 'физика': ['Мария', 'Алексей'], 'химия': ['Мария']}

namedtuple: кортеж с именами полей

У кортежа есть неудобство: обращаться к элементам приходится по индексам. Через месяц вы уже не помните, что такое person[0] - имя или возраст. namedtuple решает эту проблему: он создаёт кортеж, у которого поля имеют имена, но при этом он остаётся таким же лёгким и неизменяемым.

from collections import namedtuplePerson = namedtuple("Person", ["name", "age"])p = Person("Алексей", 25)print(p.name)    # Алексей (обращение по имени!)print(p.age)     # 25print(p[0])      # Алексей (по индексу тоже работает)

Ключевая особенность: namedtuple - это тот же неизменяемый кортеж, но с удобным доступом по именам. Он весит столько же, сколько обычный кортеж, но код с ним читается гораздо лучше.

Распаковка тоже работает:

name, age = pprint(name)   # Алексей

Когда использовать namedtuple? Когда у вас есть данные, которые логически связаны, не должны меняться и имеют чёткую структуру: координата, RGB-цвет, запись из базы данных, точка на графике. Для изменяемых структур лучше подходит обычный класс (об этом на среднем уровне).

Когда что использовать

У нас теперь семь видов коллекций (с учётом модуля collections). Как выбрать нужную?

  • Список (list) - когда важен порядок, элементы могут повторяться, и вы планируете их менять. Покупки в корзине, список студентов.
  • Кортеж (tuple) - когда данные не должны меняться. Координаты, дата рождения, настройки, которые нельзя редактировать.
  • Множество (set) - когда нужна уникальность и порядок неважен. Уникальные теги, ID посетителей, удаление дубликатов.
  • Словарь (dict) - когда данные связаны как «ключ - значение». Телефонная книга, JSON-подобные данные, настройки приложения.
  • Counter - когда нужно посчитать количество элементов.
  • defaultdict - когда нужен словарь с автоматическими значениями по умолчанию (особенно для группировки или подсчёта).
  • namedtuple - когда нужна структура с именованными полями, но неизменяемая.

Шпаргалка

Самое важное в одном месте:

  • () кортеж (неизменяемый)
  • {} множество или словарь
  • {"key": "value"} словарь
  • set() удалить дубликаты
  • a | b, a & b объединение, пересечение
  • dict["key"] доступ к значению
  • .get(key) безопасный доступ
  • .items() перебор пар
  • Counter(seq) подсчёт элементов
  • .most_common(n) топ-n самых частых
  • defaultdict(int) словарь с 0 по умолчанию
  • defaultdict(list) словарь со списками
  • namedtuple(...) кортеж с именами

Если что-то не работает

Разберём типичные ошибки при работе с новыми коллекциями.

  • «TypeError: 'tuple' object does not support item assignment». Вы пытаетесь изменить элемент кортежа. Кортежи неизменяемы. Если нужно изменить - придётся создавать новый кортеж.
  • «TypeError: 'set' object is not subscriptable». Вы пытаетесь обратиться к элементу множества по индексу (my_set[0]). У множеств нет индексов. Если нужен конкретный элемент - используйте цикл или преобразуйте во временный список.
  • «KeyError» при работе со словарём. Вы обращаетесь к ключу, которого нет. Проверьте через if key in my_dict: или используйте my_dict.get(key).
  • «TypeError: unhashable type: 'list'». Вы пытаетесь использовать список как ключ словаря или добавить его в множество. Списки изменяемы, а значит, не могут быть ключами. Используйте кортежи (tuple), если нужно несколько значений в ключе.
  • Пустые фигурные скобки создают словарь. Если написать my_collection = {}, это будет пустой словарь, а не множество. Для пустого множества нужно использовать set().
  • «NameError: name 'Counter' is not defined». Забыли импорт. В начале файла должна быть строка from collections import Counter (или defaultdict, namedtuple - по аналогии).
  • «NameError: name 'defaultdict' is not defined». Та же причина - забыт импорт из collections.
  • «KeyError» при обращении к defaultdict. Такого не должно случиться - defaultdict автоматически создаёт ключи. Проверьте, что вы действительно создали объект через defaultdict(...), а не через обычный {}.
  • «AttributeError: 'tuple' object has no attribute 'name'». Вы пытаетесь обратиться к полю по имени у обычного кортежа, а не у namedtuple. Убедитесь, что создали его через namedtuple(...), и что имя поля написано точно так же, как при создании.
  • «TypeError: Cannot overwrite attribute ... in namedtuple». Вы пытаетесь изменить атрибут namedtuple. Он неизменяем. Если нужны изменяемые структуры с полями - используйте обычный класс или dataclass (на среднем уровне).

Практика

Четыре задачи по возрастающей сложности. Это последние задачи начального уровня, поэтому они объединяют несколько тем.

Задача 1. Координаты

Создайте кортеж point с двумя числами (координатами x и y). С помощью распаковки сохраните их в переменные x и y. Выведите на экран фразу: «Координата X: 10, координата Y: 20».

Подсказка

Создайте кортеж: point = (10, 20). Для распаковки напишите x, y = point. Вывод сделайте через f-строку.

Решение учителя 
point = (10, 20)x, y = pointprint(f"Координата X: {x}, координата Y: {y}")
Задача 2. Уникальные слова

Дан список слов с повторениями: ["яблоко", "банан", "яблоко", "вишня", "банан", "арбуз"]. Получите список только уникальных слов и выведите его. Используйте множества.

Подсказка

Преобразуйте список во множество через set(words), чтобы убрать дубликаты. Затем преобразуйте обратно в список через list().

Решение учителя 
words = ["яблоко", "банан", "яблоко", "вишня", "банан", "арбуз"]unique_words = list(set(words))print(unique_words)

Порядок элементов в множестве не сохраняется, поэтому итоговый список может выглядеть в любом порядке. Если порядок важен, лучше использовать цикл с проверкой if word not in unique_words:.

Задача 3. Телефонная книга

Создайте словарь с телефонами трёх друзей. Спросите у пользователя имя и выведите его номер. Если такого имени нет в словаре - вежливо сообщите об этом.

Подсказка

Для безопасного поиска используйте метод .get(). Если он вернёт None - значит, имени нет.

Решение учителя 
phones = {    "Иван": "+7-900-123-45-67",    "Мария": "+7-900-765-43-21",    "Алексей": "+7-900-555-55-55"}name = input("Введите имя: ")phone = phones.get(name)if phone:    print(f"Номер {name}: {phone}")else:    print("Такого контакта нет.")
Задача 4. Анализ текста через Counter

Спросите у пользователя предложение. Разбейте его на слова через split(). С помощью collections.Counter посчитайте, сколько раз встречается каждое слово. Выведите три самых частых слова через .most_common(3) и общее количество слов в тексте.

Подсказка

Импортируйте: from collections import Counter. Создайте счётчик: counts = Counter(words). Для топа используйте counts.most_common(3), для общего количества - sum(counts.values()).

Решение учителя 
from collections import Countertext = input("Введите предложение: ")words = text.split()counts = Counter(words)print("Топ-3 слова:")for word, count in counts.most_common(3):    print(f"  {word}: {count} раз")print(f"Всего слов: {sum(counts.values())}")

В реальной задаче частотного анализа ещё приводят слова к нижнему регистру и убирают знаки препинания - иначе «Яблоко» и «яблоко» посчитаются как разные слова. Но для базового примера достаточно и этого. Обратите внимание, как Counter сократил логику: вместо 8-10 строк с проверками мы написали 3 строки.
