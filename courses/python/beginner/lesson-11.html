Коллекции: кортежи, множества и словари

~45 минут Начальный уровень Теория и Практика

Это финальный урок начального уровня. Мы уже отлично знакомы со списками - они универсальны и подходят для большинства задач. Но иногда списки - не самый лучший выбор.

Например, координаты точки на карте (x, y) вряд ли должны меняться. Список имён гостей не должен содержать дубликатов. А телефонную книгу удобнее хранить не как список имён и список номеров, а как пары «Имя - Номер». Для всех этих случаев в Python есть другие коллекции: кортежи, множества и словари.

Кортежи (tuple): неизменяемые списки

Кортеж - это очень похоже на список, но с одним важным отличием: его нельзя изменить после создания. Мы уже знаем из урока 9, что такие данные называются неизменяемыми.

Создаётся кортеж с помощью круглых скобок ():

point = (10, 20)rgb = (255, 128, 0)person = ("Алексей", 25)

Работа с индексами точно такая же, как у списков:

print(point[0])    # 10print(point[-1])   # 20

Но если попытаться изменить элемент - получим ошибку:

point[0] = 5   # TypeError!
Зачем нужны кортежи?

Если данные не должны меняться, кортеж защищает их от случайной порчи. Это как запечатанный конверт: внутри лежит важное, но изменить содержимое, не порвав конверт, нельзя. Плюс кортежи работают чуть быстрее списков и могут использоваться там, где списки запрещены (например, в качестве ключей словаря).

Распаковка кортежа

Очень удобная фишка Python - можно сразу разложить элементы кортежа по отдельным переменным:

point = (10, 20)x, y = pointprint(x)   # 10print(y)   # 20

Это часто используется при возврате нескольких значений из функции (о функциях поговорим на среднем уровне).

Множества (set): только уникальные элементы

Множество - это коллекция, которая хранит только уникальные элементы и не имеет порядка. Если вы добавите дубликат - он просто проигнорируется.

Создаётся с помощью фигурных скобок {} или функции set():

numbers = {1, 2, 3, 3, 3}print(numbers)   # {1, 2, 3} - дубликаты исчезли

Из-за отсутствия порядка нельзя обратиться к элементу по индексу - numbers[0] вызовет ошибку. Зато можно проверять наличие элемента через in (и это работает очень быстро):

if 2 in numbers:    print("Двойка есть в множестве")

Главное применение: удаление дубликатов

Самый частый способ использования множеств - превратить список с дубликатами в список без них. Делается это одной строкой:

my_list = [1, 2, 2, 3, 3, 3, 4]unique = list(set(my_list))print(unique)   # [1, 2, 3, 4] (порядок может отличаться)

Операции над множествами

Множества в Python поддерживают математические операции:

  • Объединение | - все элементы из обоих множеств.
  • Пересечение & - только те элементы, которые есть в обоих.
  • Разность - - элементы первого, которых нет во втором.
a = {1, 2, 3}b = {3, 4, 5}print(a | b)   # {1, 2, 3, 4, 5} (объединение)print(a & b)   # {3} (пересечение)print(a - b)   # {1, 2} (разность)

Словари (dict): ключ - значение

Словарь - это самая мощная и самая часто используемая коллекция после списка. Он хранит данные в виде пар «ключ: значение».

Аналогия: обычный толковый словарь. У вас есть слово (ключ), и есть его определение (значение). Зная слово, вы мгновенно находите определение.

Создаётся словарь тоже с помощью фигурных скобок, но с двоеточиями:

person = {    "name": "Алексей",    "age": 25,    "city": "Москва"}

Доступ и изменение

Чтобы получить значение, используется ключ в квадратных скобках:

print(person["name"])   # Алексейprint(person["age"])    # 25

Если обратиться к несуществующему ключу - будет ошибка KeyError. Чтобы избежать этого, можно использовать метод get(), который вернёт None (или указанное значение по умолчанию), если ключа нет:

print(person.get("email"))              # Noneprint(person.get("email", "не указан")) # не указан

Добавление и изменение значений происходит одинаково - по ключу:

person["age"] = 26            # изменилиperson["email"] = "a@mail.ru" # добавили

Перебор словаря

Пройтись по словарю можно тремя способами:

for key in person.keys():    print(key)              # имена ключейfor value in person.values():    print(value)            # значенияfor key, value in person.items():    print(f"{key}: {value}") # пары ключ-значение

Последний вариант используется чаще всего. Метод .items() возвращает пары «ключ-значение», которые сразу можно распаковывать в две переменные.

Ключи должны быть неизменяемыми

В качестве ключей словаря можно использовать только неизменяемые типы: строки, числа, кортежи. Списки использовать нельзя - они изменяемые, а значит, могут сломать структуру словаря. Если попробуете, получите ошибку TypeError: unhashable type.

Когда что использовать

У нас теперь четыре вида коллекций. Как выбрать нужную?

  • Список (list) - когда важен порядок, элементы могут повторяться, и вы планируете их менять. Покупки в корзине, список студентов.
  • Кортеж (tuple) - когда данные не должны меняться. Координаты, дата рождения, настройки, которые нельзя редактировать.
  • Множество (set) - когда нужна уникальность и порядок неважен. Уникальные теги, ID посетителей, удаление дубликатов.
  • Словарь (dict) - когда данные связаны как «ключ - значение». Телефонная книга, JSON-подобные данные, настройки приложения.

Шпаргалка

Самое важное в одном месте:

  • () кортеж (неизменяемый)
  • {} множество или словарь
  • {"key": "value"} словарь
  • set() удалить дубликаты
  • a | b, a & b объединение, пересечение
  • dict["key"] доступ к значению
  • .get(key) безопасный доступ
  • .items() перебор пар

Если что-то не работает

Разберём типичные ошибки при работе с новыми коллекциями.

  • «TypeError: 'tuple' object does not support item assignment». Вы пытаетесь изменить элемент кортежа. Кортежи неизменяемы. Если нужно изменить - придётся создавать новый кортеж.
  • «TypeError: 'set' object is not subscriptable». Вы пытаетесь обратиться к элементу множества по индексу (my_set[0]). У множеств нет индексов. Если нужен конкретный элемент - используйте цикл или преобразуйте во временный список.
  • «KeyError» при работе со словарём. Вы обращаетесь к ключу, которого нет. Проверьте через if key in my_dict: или используйте my_dict.get(key).
  • «TypeError: unhashable type: 'list'». Вы пытаетесь использовать список как ключ словаря или добавить его в множество. Списки изменяемы, а значит, не могут быть ключами. Используйте кортежи (tuple), если нужно несколько значений в ключе.
  • Пустые фигурные скобки создают словарь. Если написать my_collection = {}, это будет пустой словарь, а не множество. Для пустого множества нужно использовать set().

Практика

Четыре задачи по возрастающей сложности. Это последние задачи начального уровня, поэтому они объединяют несколько тем.

Задача 1. Координаты

Создайте кортеж point с двумя числами (координатами x и y). С помощью распаковки сохраните их в переменные x и y. Выведите на экран фразу: «Координата X: 10, координата Y: 20».

Подсказка

Создайте кортеж: point = (10, 20). Для распаковки напишите x, y = point. Вывод сделайте через f-строку.

Решение учителя 
point = (10, 20)x, y = pointprint(f"Координата X: {x}, координата Y: {y}")
Задача 2. Уникальные слова

Дан список слов с повторениями: ["яблоко", "банан", "яблоко", "вишня", "банан", "арбуз"]. Получите список только уникальных слов и выведите его. Используйте множества.

Подсказка

Преобразуйте список во множество через set(words), чтобы убрать дубликаты. Затем преобразуйте обратно в список через list().

Решение учителя 
words = ["яблоко", "банан", "яблоко", "вишня", "банан", "арбуз"]unique_words = list(set(words))print(unique_words)

Порядок элементов в множестве не сохраняется, поэтому итоговый список может выглядеть в любом порядке. Если порядок важен, лучше использовать цикл с проверкой if word not in unique_words:.

Задача 3. Телефонная книга

Создайте словарь с телефонами трёх друзей. Спросите у пользователя имя и выведите его номер. Если такого имени нет в словаре - вежливо сообщите об этом.

Подсказка

Для безопасного поиска используйте метод .get(). Если он вернёт None - значит, имени нет.

Решение учителя 
phones = {    "Иван": "+7-900-123-45-67",    "Мария": "+7-900-765-43-21",    "Алексей": "+7-900-555-55-55"}name = input("Введите имя: ")phone = phones.get(name)if phone:    print(f"Номер {name}: {phone}")else:    print("Такого контакта нет.")
Задача 4. Анализ текста

Спросите у пользователя предложение. Разбейте его на слова через split(). Подсчитайте, сколько раз встречается каждое слово. Выведите результат в формате «Слово: количество». Используйте словарь.

Подсказка

Создайте пустой словарь counts = {}. В цикле по словам проверяйте, есть ли уже слово в словаре. Если есть - увеличивайте счётчик. Если нет - создавайте новый ключ со значением 1.

Решение учителя 
text = input("Введите предложение: ")words = text.split()counts = {}for word in words:    if word in counts:        counts[word] += 1    else:        counts[word] = 1for word, count in counts.items():    print(f"{word}: {count}")

Это классический алгоритм частотного анализа. Позже вы узнаете, что его можно записать короче с помощью метода .get(word, 0) + 1, но для понимания базовой логики полезно начать с явного условия.
