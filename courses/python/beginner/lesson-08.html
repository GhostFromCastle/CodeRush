Практика: игра «Орёл или Решка» и модуль math

~40 минут Начальный уровень Теория и Практика

Мы прошли большой путь. Вы уже умеете работать с числами, строками, условиями, циклами и случайными числами. Пришло время собрать всё это вместе и написать первую настоящую игру, в которую можно играть с компьютером.

А во второй части урока мы познакомимся с модулем math - верным помощником для любых математических вычислений: от квадратного корня до округления чисел.

Часть 1: Игра «Орёл или Решка»

Правила простые. Компьютер «подбрасывает монету» - загадывает «Орёл» или «Решка». Игрок должен угадать, что выпало. Если угадал - ему зачисляется очко. Если нет - очко получает компьютер.

Чтобы игра была интересной, мы сделаем её бесконечной: после каждого броска спрашиваем игрока, хочет ли он сыграть ещё раз.

Шаг 1. Подготовка

Подключим модуль случайных чисел и создадим переменные для счёта:

import randomplayer_score = 0computer_score = 0

Шаг 2. Игровой цикл

Наш основной цикл будет выглядеть так:

while True:    # 1. Компьютер загадывает сторону монеты    # 2. Игрок делает ставку    # 3. Сравниваем результаты и начисляем очки    # 4. Спрашиваем, хочет ли игрок продолжить

Шаг 3. Логика одного раунда

В Python можно использовать random.choice для выбора из списка вариантов:

    coin = random.choice(["Орёл", "Решка"])    print(f"\nМонета подброшена...")    guess = input("Ваша ставка (Орёл/Решка): ").capitalize()

Обратите внимание на .capitalize(). Если игрок введёт «орёл» с маленькой буквы, метод сделает первую букву заглавной («Орёл»). Это спасёт нас от ситуации, когда программа не узнаёт правильный ответ из-за регистра.

Шаг 4. Проверка результата

    if guess not in ["Орёл", "Решка"]:        print("Неверный ввод! Введите 'Орёл' или 'Решка'.")        continue    if guess == coin:        print("Вы угадали!")        player_score += 1    else:        print(f"Вы не угадали. Выпал {coin}.")        computer_score += 1    print(f"Счёт: Вы {player_score} : {computer_score} Компьютер")

Если игрок введёт что-то непонятное (например, «123» или «Питон»), мы используем continue, чтобы пропустить остаток раунда и спросить заново, не засчитывая это как поражение.

Шаг 5. Продолжение игры

    play_again = input("\nСыграть ещё раз? (да/нет): ").lower()    if play_again != "да":        print("\nСпасибо за игру!")        break

Мы используем .lower(), чтобы принимать и «да», и «ДА», и «Да». Всё, что не является «да» - завершает игру.

Полный код игры

Соберём всё вместе:

import randomplayer_score = 0computer_score = 0print("Добро пожаловать в игру 'Орёл или Решка'!")while True:    coin = random.choice(["Орёл", "Решка"])    print("\nМонета подброшена...")    guess = input("Ваша ставка (Орёл/Решка): ").capitalize()    if guess not in ["Орёл", "Решка"]:        print("Неверный ввод! Введите 'Орёл' или 'Решка'.")        continue    if guess == coin:        print("Вы угадали!")        player_score += 1    else:        print(f"Вы не угадали. Выпал {coin}.")        computer_score += 1    print(f"Текущий счёт: Вы {player_score} : {computer_score} Компьютер")    play_again = input("\nСыграть ещё раз? (да/нет): ").lower()    if play_again != "да":        print("\nСпасибо за игру!")        break
Как улучшить игру

Эту игру можно улучшать до бесконечности. Например, добавить ограничение: «играем до 5 побед». Или считать процент побед. Или сделать так, чтобы монета выпадала не 50/50, а с разной вероятностью (например, Орёл выпадает в 30% случаев). Идей для практики - масса!

Часть 2: Модуль math

Теперь переключимся с игр на математику. Python не был бы языком программирования, если бы не умел хорошо считать. Для сложных вычислений есть модуль math. Подключается он так же, как и random:

import math

Округление: ceil() и floor()

Обычная функция round() округляет по правилам математики (0.5 и выше - вверх, меньше - вниз). Но иногда нужно строго принудительное округление:

import mathprint(math.ceil(3.1))    # 4 (всегда вверх)print(math.ceil(3.9))    # 4 (всегда вверх)print(math.floor(3.1))   # 3 (всегда вниз)print(math.floor(3.9))   # 3 (всегда вниз)
  • math.ceil() (от ceiling - «потолок») всегда округляет вверх, до ближайшего целого.
  • math.floor() (от floor - «пол») всегда округляет вниз.

Где это нужно? Например, если вы делите пиццу на куски и хотите узнать, сколько коробок нужно, чтобы упаковать всё. Округлять вниз нельзя - часть пиццы останется на улице. Нужен ceil.

Квадратный корень: sqrt()

Функция math.sqrt() извлекает квадратный корень:

import mathprint(math.sqrt(25))     # 5.0print(math.sqrt(144))    # 12.0print(math.sqrt(2))      # 1.41421356...

Корень часто нужен в геометрии, физике, графике. Например, расстояние между двумя точками на плоскости считается через корень из суммы квадратов.

Число Пи: math.pi

math.pi - это константа, равная числу Пи (3.14159...). Она хранится с высокой точностью и пригодится в любых вычислениях с кругами:

import mathradius = 5area = math.pi * radius ** 2print(f"Площадь круга: {area:.2f}")   # 78.54

Модуль числа: fabs()

Иногда нужно узнать, насколько число далеко от нуля (модуль числа). Стандартная функция abs() делает это и без модуля math, но math.fabs() всегда возвращает результат в виде float:

import mathprint(math.fabs(-10))   # 10.0print(abs(-10))         # 10

Шпаргалка

Самое важное в одном месте:

  • import math подключить математический модуль
  • math.ceil(x) округление вверх
  • math.floor(x) округление вниз
  • math.sqrt(x) квадратный корень
  • math.pi число Пи
  • .capitalize() первая буква заглавная
  • .lower() всё в нижний регистр

Если что-то не работает

Разберём типичные проблемы при создании игр и использовании math.

  • «NameError: name 'math' is not defined». Забыли подключить модуль через import math в начале файла.
  • «Программа не узнаёт правильный ответ». Возможно, пользователь ввёл «орёл» с маленькой буквы, а программа сравнивает с «Орёл». Используйте .capitalize() или .lower(), чтобы привести ввод к единому виду.
  • «Игра зациклилась и не завершается». Проверьте, есть ли break в нужном месте. Если его нет в ветке выхода, цикл while True будет крутиться вечно.
  • «math.sqrt() выдаёт ошибку». Скорее всего, вы пытаетесь найти корень из отрицательного числа. В обычной математике такого не бывает, поэтому Python выбрасывает ValueError: math domain error.
  • «Ошибка с math.ceil()». Функция ожидает число. Если передать строку (например, забыли преобразовать ввод через int() или float()) - получите TypeError.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Улучшенная игра

Измените игру «Орёл или Решка» так, чтобы игра заканчивалась, когда один из игроков наберёт 3 победы. В конце выведите победителя.

Подсказка

Вместо while True: используйте условие while player_score < 3 and computer_score < 3:. После цикла проверьте, у кого больше очков, и выведите победителя.

Решение учителя 
import randomplayer_score = 0computer_score = 0while player_score < 3 and computer_score < 3:    coin = random.choice(["Орёл", "Решка"])    guess = input("Ваша ставка (Орёл/Решка): ").capitalize()    if guess not in ["Орёл", "Решка"]:        print("Неверный ввод!")        continue    if guess == coin:        player_score += 1        print("Вы угадали!")    else:        computer_score += 1        print(f"Вы не угадали. Выпал {coin}.")    print(f"Счёт: Вы {player_score} : {computer_score} Компьютер\n")if player_score > computer_score:    print("Вы победили!")else:    print("Победил компьютер!")
Задача 2. Калькулятор круга

Напишите программу, которая спрашивает радиус круга и выводит его площадь и длину окружности. Используйте константу math.pi. Формулы: площадь = π * r², длина = 2 * π * r.

Подсказка

Радиус получайте через float(input(...)), потому что радиус может быть дробным. Возведение в квадрат в Python записывается как ** 2. Для красоты вывода используйте :.2f.

Решение учителя 
import mathradius = float(input("Введите радиус: "))area = math.pi * (radius ** 2)circumference = 2 * math.pi * radiusprint(f"Площадь: {area:.2f}")print(f"Длина окружности: {circumference:.2f}")
Задача 3. Гипотенуза

По теореме Пифагора гипотенуза прямоугольного треугольника равна корню из суммы квадратов катетов. Спросите у пользователя два катета и вычислите гипотенузу с помощью math.sqrt.

Подсказка

Формула: c = math.sqrt(a**2 + b**2). Катеты вводите через float().

Решение учителя 
import matha = float(input("Первый катет: "))b = float(input("Второй катет: "))c = math.sqrt(a ** 2 + b ** 2)print(f"Гипотенуза: {c:.2f}")
Задача 4. Упаковка коробок

В магазине есть 45 товаров. В одну коробку помещается 8 товаров. Сколько коробок понадобится, чтобы упаковать все товары? Используйте math.ceil. Выведите результат.

Подсказка

Количество коробок - это 45 / 8, что равно 5.625. Простое деление не подходит - нельзя взять «половину коробки». Используйте math.ceil(45 / 8), и получите 6 коробок.

Решение учителя 
import mathtotal_items = 45items_per_box = 8boxes = math.ceil(total_items / items_per_box)print(f"Понадобится коробок: {boxes}")

Если бы мы использовали обычное деление и отбросили дробную часть, мы бы получили 5 коробок. Но 5 * 8 = 40, а у нас 45 товаров. Пять товаров остались бы на улице. Округление вверх решает проблему.
