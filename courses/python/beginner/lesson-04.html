Условия: if, elif, else

~35 минут Начальный уровень Теория и Практика

В прошлом уроке мы научили программы спрашивать у пользователя данные. Но пока они ведут себя как попугаи: что бы пользователь ни ввёл, программа просто повторяет это или выводит заготовленный текст.

Настоящая программа должна принимать решения. Если пользователь ввёл возраст меньше 18 - одно сообщение, если больше - другое. Если ввёл правильный пароль - пустить в систему, если нет - отказать. Если число чётное - одно действие, нечётное - другое.

Для этого в Python есть условия - if, elif и else. Сегодня мы разберёмся, как они работают, и научим программы думать.

Логика на примере из жизни

Представьте охранника на входе в клуб. У него есть правило: «Если человеку есть 18 лет - пропустить. Иначе - сказать "Приходите позже"».

Обратите внимание на структуру правила:

  • Условие - «человеку есть 18 лет». Может быть истинным или ложным.
  • Действие при истине - «пропустить».
  • Действие при лжи - «сказать приходите позже».

Именно так работает и if / else в Python. Вы пишете условие, и программа выбирает, какой код выполнить.

Операторы сравнения

Чтобы написать условие, нужно сравнить что-то с чем-то. Для этого есть операторы сравнения:

  • == равно (два знака!)
  • != не равно
  • > больше
  • < меньше
  • >= больше или равно
  • <= меньше или равно
Составные операторы - это два символа подряд

В математике «больше или равно» пишется одним символом ≥, а «меньше или равно» - ≤. В Python таких символов нет. Вместо них используются два обычных символа подряд:

  • >= - это сначала знак «больше», потом знак «равно», без пробела между ними.
  • <= - это сначала знак «меньше», потом знак «равно», без пробела между ними.

Если попробовать ввести символ ≥ с клавиатуры (или скопировать из статьи в интернете), Python выдаст ошибку SyntaxError: invalid character - он просто не знает такого символа.

Один знак или два?

Очень частая ошибка новичков: писать if x = 5: вместо if x == 5:. Один знак = - это присваивание (положить значение). Два знака == - это сравнение (проверить, равно ли). В условиях всегда используется ==.

Результат сравнения всегда логический тип bool: либо True, либо False. Это то, что мы разбирали в уроке 2.

print(5 > 3)       # Trueprint(5 < 3)       # Falseprint(10 == 10)   # Trueprint("a" == "b") # False

Базовый if

Самый простой вариант - выполнить что-то, только если условие истинно:

age = 20if age >= 18:    print("Вы совершеннолетний")

Что здесь важно:

  • if - ключевое слово, начало условия.
  • age >= 18 - само условие. В данном случае - «возраст больше или равен 18».
  • : - двоеточие в конце строки. Оно обязательно! Python по нему понимает, что дальше начинается блок кода.
  • Отступ в 4 пробела на следующей строке. Это критично - отступ показывает Python, что код относится к условию.

Читается так: «Если возраст больше или равен 18 - выполнить код с отступом». Если возраст 16, программа просто пропустит строку с print и пойдёт дальше.

Отступы в Python - это не стиль, а синтаксис

В большинстве языков блок кода обрамляется фигурными скобками {}. В Python вместо скобок - отступы. Если отступ неправильный, программа не запустится. VS Code обычно сам делает правильный отступ по нажатию Tab или при нажатии Enter после двоеточия.

if / else: две ветки

А если мы хотим, чтобы что-то произошло и в случае лжи? Для этого есть else:

age = 16if age >= 18:    print("Проходите")else:    print("Извините, вам ещё нет 18")

Теперь у нас две ветки:

  • Если age >= 18 истинно - выполнится первая ветка.
  • Иначе (else) - вторая.

Всегда выполняется только одна из них. Программа как будто стоит на развилке: пошла налево - направо уже не попадёт.

elif: цепочка проверок

А что если вариантов больше двух? Например, программа ставит оценку по количеству баллов:

  • 90 и выше - отлично (5).
  • 70-89 - хорошо (4).
  • 50-69 - удовлетворительно (3).
  • Меньше 50 - не сдал (2).

Для таких случаев используется elif (сокращение от else if, «иначе если»):

score = 85if score >= 90:    print("Отлично")elif score >= 70:    print("Хорошо")elif score >= 50:    print("Удовлетворительно")else:    print("Не сдал")

Как это работает:

  • Python проверяет условия сверху вниз.
  • Как только нашёл первое истинное - выполнил его блок и вышел из всей цепочки. Остальные варианты даже не проверяются.
  • Если ни одно условие не сработало - выполнится else.

В нашем примере score = 85. Первое условие (90) ложное, второе (70) - истинное. Программа выведет «Хорошо» и на этом остановится. До проверки третьего условия дело не дойдёт.

Важен порядок

Порядок elif имеет значение. Если написать первым условие score >= 50, то оно сработает даже для оценки 95 - и программа ответит «Удовлетворительно». Условия нужно располагать от самого строгого к самому мягкому.

Логические операторы

Иногда одного условия недостаточно. Например, для получения прав нужно, чтобы человек был совершеннолетним и сдал экзамен. Здесь на помощь приходят логические операторы:

  • and - «и». Истинно, только если оба условия истинны.
  • or - «или». Истинно, если хотя бы одно из условий истинно.
  • not - «не». Меняет значение на противоположное.

Примеры:

age = 20passed_exam = Trueif age >= 18 and passed_exam:    print("Можно получить права")

Здесь оба условия должны быть истинными. Если хотя бы одно ложно - программа не сработает.

day = "суббота"if day == "суббота" or day == "воскресенье":    print("Выходной!")

Здесь достаточно одного совпадения. Подходит и суббота, и воскресенье.

Проверка на принадлежность: in и not in

Иногда нужно проверить, входит ли значение в какой-то набор. Для этого есть оператор in:

role = "admin"if role in ["admin", "moderator"]:    print("У вас есть доступ")

Это удобнее, чем писать длинную цепочку через or. А ещё in работает со строками - проверяет, входит ли подстрока:

text = "Привет, мир!"if "мир" in text:    print("Нашли слово")

Вложенные условия

Одно условие может быть вложено в другое. Например, сначала проверим, вошёл ли пользователь, а потом - есть ли у него права администратора:

is_logged_in = Trueis_admin = Falseif is_logged_in:    if is_admin:        print("Привет, администратор!")    else:        print("Привет, пользователь!")else:    print("Пожалуйста, войдите в систему")

Обратите внимание на отступы: чем глубже вложенность, тем больше отступов. Обычно стараются не делать больше 2-3 уровней вложенности, иначе код становится сложно читать.

Шпаргалка

Самое важное в одном месте:

  • if условие: выполнить, если истинно
  • elif условие: иначе проверить другое
  • else: иначе (без условия)
  • == равно (два знака!)
  • != не равно
  • and / or / not логические операторы
  • in проверка вхождения
  • : + отступ обязательная часть блока

Если что-то не работает

Разберём типичные ошибки при работе с условиями.

  • «SyntaxError: invalid character '≥'» или «invalid character '≤'». Скорее всего, вы ввели математический символ «больше или равно» или «меньше или равно» одним знаком. В Python таких символов нет. Нужно писать два обычных символа подряд: >= (сначала >, потом =) или <= (сначала <, потом =). Без пробела между ними.
  • «SyntaxError: invalid syntax» рядом с if. Три частые причины: забыли двоеточие в конце условия; использовали один знак = вместо ==; в условии незакрытая скобка или кавычка.
  • «IndentationError: expected an indented block». Забыли отступ на следующей строке после if. Python ожидает, что код внутри условия будет сдвинут вправо.
  • «IndentationError: unexpected indent». Наоборот, лишний отступ там, где не нужно. Например, вы отступили код, который должен быть вне условия.
  • Условие срабатывает всегда, хотя не должно. Проверьте порядок elif. Если самое «слабое» условие стоит первым, оно «перехватит» все случаи. Условия всегда идут от строгого к мягкому.
  • «Программа ничего не выводит». Скорее всего, условие ложное. Попробуйте временно вывести print(условие) перед if, чтобы увидеть, True там или False. Или добавьте else с сообщением - тогда при любом исходе что-то будет видно.
  • Сравнение строк и чисел. 5 == "5" вернёт False, потому что это разные типы. Если пользователь ввёл число, а вы его не преобразовали через int(), сравнение с числом не сработает. Всегда преобразуйте input() в нужный тип.
  • «Слишком много условий». Если у вас 10 вложенных if - это сигнал, что логику пора разбить на функции. Но об этом в следующих уроках.

Если что-то не получается - напишите нам в Telegram, разберёмся вместе.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Чётное или нечётное

Спросите у пользователя целое число и выведите, чётное оно или нечётное. Используйте остаток от деления (оператор %).

Подсказка

Остаток от деления на 2 равен 0 для чётных чисел. Условие: if number % 2 == 0:. Не забудьте преобразовать input() в int().

Решение учителя 
number = int(input("Введите число: "))if number % 2 == 0:    print("Чётное")else:    print("Нечётное")

Оператор % возвращает остаток от деления. Например, 10 % 2 даёт 0, а 7 % 2 - 1.

Задача 2. Проверка пароля

Напишите программу, которая спрашивает пароль и сравнивает с заранее заданным ("qwerty123"). Если пароль правильный - вывести «Доступ разрешён», иначе - «Неверный пароль».

Подсказка

Сохраните правильный пароль в переменную в начале. Потом спросите у пользователя. Сравните через ==. Обратите внимание: сравнение строк чувствительно к регистру - "Qwerty" и "qwerty" не равны.

Решение учителя 
correct_password = "qwerty123"password = input("Введите пароль: ")if password == correct_password:    print("Доступ разрешён")else:    print("Неверный пароль")

В реальной программе пароль никогда не хранят в открытом виде. Но для учебного примера подойдёт. Как правильно хранить пароли - поговорим в курсе по кибербезопасности.

Задача 3. Оценка по баллам

Напишите программу, которая по введённому количеству баллов (от 0 до 100) ставит оценку. Правила: 90-100 - «Отлично», 70-89 - «Хорошо», 50-69 - «Удовлетворительно», меньше 50 - «Не сдал». Используйте if / elif / else.

Подсказка

Проверяйте от большего к меньшему. Первое условие: if score >= 90:. Второе: elif score >= 70:. И так далее. Обратите внимание, что для второго условия не нужно писать score < 90 - до него дойдут только те, у кого первое условие оказалось ложным.

Решение учителя 
score = int(input("Введите баллы (0-100): "))if score >= 90:    print("Отлично")elif score >= 70:    print("Хорошо")elif score >= 50:    print("Удовлетворительно")else:    print("Не сдал")
Задача 4. Високосный год

Високосный год - это год, который делится на 4 без остатка, но при этом не делится на 100 (кроме тех лет, что делятся на 400). Напишите программу, которая по введённому году определяет, високосный он или нет.

Подсказка

Условие сложное, но его можно записать одной строкой: (year % 4 == 0 and year % 100 != 0) or year % 400 == 0. Обратите внимание на скобки - они задают приоритет: сначала проверяется «делится на 4 и не делится на 100», потом «или делится на 400».

Решение учителя 
year = int(input("Введите год: "))if (year % 4 == 0 and year % 100 != 0) or year % 400 == 0:    print(f"{year} - високосный год")else:    print(f"{year} - не високосный год")

Проверьте на разных годах: 2024 - високосный (делится на 4), 2023 - нет, 2000 - високосный (делится на 400), 1900 - нет (делится на 100, но не на 400).

Что мы узнали и что дальше

Сегодня программы научились главному - принимать решения. Это тот самый момент, когда код из «линейного сценария» превращается в настоящую логику. Теперь вы знаете:

  • Что такое условия и зачем они нужны.
  • Операторы сравнения: ==, !=, >, <, >=, <=.
  • Конструкции if, elif, else.
  • Логические операторы and, or, not.
  • Проверку вхождения через in.
  • Вложенные условия и важность отступов.

Теперь ваши программы могут различать ситуации. Пароль верный - пустить, возраст маленький - не пустить. Оценка хорошая - похвалить, плохая - пожурить. Это огромный шаг вперёд.

Но всё это пока работает один раз. Программа спросила, ответила и завершилась. А что если пользователь хочет сыграть ещё партию? Или ввести пароль три раза? Или перебрать все числа от 1 до 100?

В следующем уроке мы разберём циклы - while и for. Они позволяют повторять один и тот же код много раз, пока выполняется какое-то условие. Это откроет дорогу к настоящим играм, перебору, работе с коллекциями. До встречи!
