Все типы данных под капотом

~30 минут Начальный уровень Теория

Мы уже знакомы с переменными и базовыми типами: числами, строками, логическими значениями. До этого момента мы использовали их как «чёрные ящики»: положили значение, достали значение, вроде всё работает.

Но чтобы двигаться дальше и в следующем уроке разобраться со списками, нам нужно заглянуть «под капот». Понять, как Python на самом деле хранит данные в памяти. И самое главное - узнать про изменяемые и неизменяемые типы. Это одна из тех концепций, которая отличает новичка от понимающего разработчика.

Всё есть объект

В Python работает известный принцип: всё является объектом. Число 42 - объект. Строка "Привет" - объект. Даже сама функция print - объект.

У каждого объекта в Python есть три важные характеристики:

  • Значение - то, что в нём хранится (например, число 42).
  • Тип - к какому классу он относится (например, int).
  • Идентификатор (id) - уникальный номер, который показывает, где объект лежит в памяти компьютера.

Именно идентификатор помогает нам понять, что происходит «под капотом», когда мы меняем переменную. Посмотреть его можно с помощью встроенной функции id(). Она возвращает длинное число - адрес объекта.

Неизменяемые типы (Immutable)

Сначала разберём типы, которые нельзя изменить после создания. К ним относятся все те, с которыми мы работали до сих пор:

  • int (целые числа)
  • float (дробные числа)
  • str (строки)
  • bool (True/False)
  • tuple (кортежи, о них в уроке 11)

Что значит «неизменяемый»? Это значит, что если объект создан, вы не можете изменить его содержимое. Вы можете только создать новый объект.

Давайте посмотрим на примере строки:

text = "Python"print(id(text))   # например, 140234...text = text.upper()print(id(text))   # адрес изменился!print(text)       # PYTHON

Когда мы вызвали .upper(), старая строка "Python" никуда не делась. Она просто осталась в памяти (пока её не удалит сборщик мусора). А переменная text теперь указывает на новую строку "PYTHON", которая лежит по другому адресу.

Числа работают так же. Когда мы делаем x = x + 1, мы не меняем число 5 на 6. Мы создаём новый объект «6» и перенаправляем переменную на него.

Аналогия с камнем

Неизменяемый тип - это как высеченная надпись на камне. Чтобы получить другую надпись, вы не можете стереть старую. Вы должны взять новый камень и высечь на нём новое слово. Старый камень при этом остаётся нетронутым.

Изменяемые типы (Mutable)

Совсем по-другому работают изменяемые типы. Вы можете менять их содержимое, не создавая новый объект. К таким типам относятся:

  • list (списки, урок 10)
  • dict (словари, урок 11)
  • set (множества, урок 11)

Мы ещё не проходили списки, но для понимания сути можно представить их как контейнер с ячейками. Давайте посмотрим на примере списка (просто запомните синтаксис квадратных скобок):

my_list = [1, 2, 3]print(id(my_list))   # например, 200456...my_list.append(4)print(id(my_list))   # адрес тот же самый!print(my_list)       # [1, 2, 3, 4]

Обратите внимание: идентификатор id не изменился, хотя мы добавили новый элемент. Это значит, что мы изменили сам объект «на месте», а не создали новый. Именно поэтому списки называются изменяемыми.

Аналогия с маркерной доской

Изменяемый тип - это как маркерная доска. Вы можете стереть на ней старую надпись и написать новую, используя ту же самую доску. Сама доска (объект в памяти) при этом не меняется.

Зачем это знать?

Может показаться, что это просто скучная теория. Но на самом деле понимание этой разницы спасёт вас от очень коварных багов в будущем.

Представьте, что у вас есть изменяемый объект, и вы передали его в функцию или присвоили другой переменной. Так как объект один и тот же (по одному адресу в памяти), любые изменения через одну переменную сразу отразятся на другой. Иногда это то, что нужно. А иногда - источник многочасовой отладки.

С неизменяемыми типами такого не бывает: если вы «меняете» строку или число, создаётся новый объект, а старая переменная продолжает указывать на старый (и неизменный) объект. Это безопаснее.

Пока просто держите в голове: строки и числа - неизменяемые, списки и словари - изменяемые. А в следующих уроках вы своими глазами увидите, как это работает.

Функции для работы с типами

В Python есть два отличных инструмента для работы с типами данных.

type()

Мы уже знакомы с функцией type() из урока 2. Она возвращает точный тип объекта:

print(type(42))          # <class 'int'>print(type("Привет"))    # <class 'str'>print(type(3.14))        # <class 'float'>

isinstance()

Функция isinstance() делает почти то же самое, но возвращает логическое значение True или False. Она проверяет, принадлежит ли объект к указанному типу:

x = 42print(isinstance(x, int))    # Trueprint(isinstance(x, str))    # Falseprint(isinstance(x, float))  # False

В чём разница? type(x) == int тоже работает, но isinstance считается более «питоновским» (правильным) способом. В будущем, когда мы дойдём до ООП (Объектно-ориентированного программирования), вы узнаете, что isinstance умеет работать с наследованием классов. А ещё он позволяет проверить сразу несколько типов:

x = 42print(isinstance(x, (int, float)))   # True, потому что 42 - это int

Приведение типов и «ложные» значения

Мы уже знаем, как приводить типы: int(), str(), float(). Но давайте посмотрим на bool(). Какие значения при превращении в логический тип дают False?

В Python есть понятие «ложных» (falsy) значений. К ним относятся:

  • False (само собой)
  • 0 и 0.0 (ноль)
  • "" (пустая строка)
  • None (специальное значение «ничего»)
  • Пустые коллекции (пустой список [], пустой словарь {})

Всё остальное считается «истинным» (truthy).

print(bool(0))         # Falseprint(bool(42))        # Trueprint(bool(""))        # Falseprint(bool("Python"))  # True

Это очень часто используется в условиях. Вместо того чтобы писать if len(text) > 0:, опытные программисты пишут просто if text: (если строка не пустая - выполнить код).

Шпаргалка

Самое важное в одном месте:

  • id(obj) адрес объекта в памяти
  • type(obj) точный тип объекта
  • isinstance(obj, тип) проверка на принадлежность к типу
  • Неизменяемые int, float, str, bool, tuple
  • Изменяемые list, dict, set
  • Falsy 0, "", None, [], {}

Если что-то не работает

Разберём типичные заблуждения, связанные с типами данных.

  • «Я изменил строку, но старая переменная осталась прежней». Строки неизменяемы. Методы вроде .upper() не меняют строку, а возвращают новую. Нужно перезаписать переменную: text = text.upper().
  • «При сравнении type(x) == int всё работает, зачем нужен isinstance?». Для простых случаев разницы нет. Но isinstance лучше, потому что он корректно работает с подклассами (например, True - это bool, но он также является подклассом int). Привыкайте использовать isinstance.
  • «Почему 0 в условии if ведёт себя как False?». Потому что ноль - это «ложное» значение в Python. Если нужна строгая проверка на None (а не на ноль), используйте if x is None:.
  • «Хочу изменить символ в строке через индекс». Это невозможно. Строки неизменяемы. Нужно собирать новую строку через срезы и сложение, как мы делали в уроке 6.

Если что-то не получается - напишите нам в Telegram, разберёмся вместе.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Проверка типов

Создайте три переменные: число, строку и логическое значение. С помощью isinstance проверьте каждую из них на соответствие своему типу и выведите результат.

Подсказка

Используйте конструкцию вида isinstance(age, int). Результат сразу можно передать в print - он выведет True или False.

Решение учителя 
age = 25name = "Алексей"is_student = Trueprint(isinstance(age, int))print(isinstance(name, str))print(isinstance(is_student, bool))

Все три строки выведут True. Если попробовать проверить age на тип str - получим False.

Задача 2. id() для строк

Создайте строку, выведите её id. Затем «измените» строку (например, переведя её в верхний регистр). Снова выведите id. Объясните в комментарии или текстом, почему id изменился.

Подсказка

Строки неизменяемы. При вызове метода .upper() создаётся новый объект в памяти, а переменная начинает указывать на него. Поэтому id меняется.

Решение учителя 
text = "python"print(id(text))text = text.upper()print(id(text))

Вы увидите два разных числа. Это доказывает, что строка в памяти не изменилась - просто переменная text теперь указывает на новую строку "PYTHON", созданную методом .upper().

Задача 3. Falsy-значения

Что выведет каждая из этих строк? Сначала подумайте сами, потом проверьте в Python.

  1. print(bool(0))
  2. print(bool(0.0))
  3. print(bool("0"))
  4. print(bool(" "))
  5. print(bool(-1))
Подсказка

Помните список «ложных» значений: 0, 0.0, "", None. Всё, что не входит в этот список, даёт True. Обратите внимание на строки: "0" - это строка, а не число.

Решение учителя
  1. False. Ноль - это ложное значение.
  2. False. Ноль с точкой тоже.
  3. True. Это строка, и она не пустая. Для Python неважно, что в ней символ нуля.
  4. True. Строка с одним пробелом тоже не пустая.
  5. True. Любое число, кроме нуля, - истина. Даже отрицательное.
Задача 4. Безопасный ввод

Напишите программу, которая просит у пользователя ввести число. Если он ввёл пустую строку (просто нажал Enter) - программа должна вывести «Вы ничего не ввели» и завершиться, не пытаясь преобразовать пустоту в число.

Подсказка

Сначала запросите строку через input(). Затем проверьте её на «ложность»: if not user_input:. Если строка пустая - эта проверка сработает (потому что пустая строка - это Falsy). Если не пустая - преобразуйте в число через int().

Решение учителя 
user_input = input("Введите число: ")if not user_input:    print("Вы ничего не ввели")else:    number = int(user_input)    print(f"Вы ввели число {number}")

Проверка if not user_input: читается как «если ввод ложный» (пустой). Если пользователь всё-таки что-то ввёл - идём в else и безопасно преобразуем строку в число.
