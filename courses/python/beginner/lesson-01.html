Установка Python и первая программа

~25 минут Начальный уровень Теория и Практика

Добро пожаловать на курс Python! Если вы читаете этот текст, значит, вы готовы сделать первый шаг в мир программирования. И это здорово - потому что Python считается одним из самых дружелюбных языков для старта.

В этом уроке мы не будем углубляться в сложную теорию. Мы просто:

  • Установим Python на компьютер.
  • Настроим удобную программу для написания кода.
  • Напишем первую программу и заставим её работать.

Почему именно Python

Python - это как велосипед с тренировочными колёсиками в мире программирования. На нём легко начать, а когда вы освоитесь - сможете пересаживаться на любой другой «транспорт» без страха упасть. Вот почему его выбирают для обучения:

  • Простой синтаксис. Код на Python читается почти как обычный английский. Вместо десятка скобок и точек с запятой - отступы и понятные слова.
  • Огромная экосистема. На Python пишут веб-приложения, анализируют данные, обучают нейросети, автоматизируют рутину. Это буквально язык «на все случаи жизни».
  • Востребованность. Это один из самых популярных языков в мире. Вакансии для Python-разработчиков есть в любой крупной компании.

Установка Python

Сначала нам нужен сам интерпретатор Python - программа, которая понимает код и выполняет его. Это как двигатель автомобиля: без него машина не поедет.

Шаг 1. Скачивание

Заходите на официальный сайт python.org/downloads. Сайт сам предложит нужную версию для вашей операционной системы (Windows, macOS или Linux). Нажимайте большую жёлтую кнопку скачивания.

Шаг 2. Установка на Windows

Откройте скачанный файл. Появится окно установщика. Вот самый важный момент, который упускают 90% новичков:

Галочка "Add Python to PATH"

В самом низу окна установщика есть галочка «Add python.exe to PATH». Обязательно поставьте её! Если этого не сделать, компьютер не будет знать, где находится Python, и вы не сможете запускать программы из командной строки.

После этого нажимайте «Install Now» и ждите завершения. Обычно процесс занимает пару минут.

Шаг 3. Установка на macOS

Скачайте установщик .pkg, откройте его и следуйте инструкциям на экране. Всё автоматически, никаких хитрых галочек.

Шаг 4. Проверка

Чтобы убедиться, что всё прошло успешно, откройте терминал (на Windows - «Командную строку» или PowerShell). Введите:

python --version

Если в ответ вы увидели что-то вроде Python 3.12.0 - всё отлично, установка прошла успешно. Если компьютер ругается, что команда не найдена - перечитайте шаг 2 (та самая галочка PATH) или попробуйте вместо слова python ввести python3.

Установка VS Code

Писать код можно в блокноте, но это как строить дом зубочисткой - теоретически возможно, но ужасно неудобно. Поэтому используем специальную программу - редактор кода.

На курсе мы будем использовать Visual Studio Code (VS Code). Он бесплатный, лёгкий, работает на всех системах и поддерживает Python из коробки.

Шаги:

  1. Скачайте VS Code с официального сайта code.visualstudio.com.
  2. Установите как обычную программу (Next → Next → Install).
  3. Откройте VS Code. Слева на панели найдите иконку с квадратиками (Extensions или Расширения).
  4. В поиске введите Python. Первое расширение от Microsoft - то, что нужно. Нажмите Install.

Всё, теперь мы готовы писать код!

А что насчёт PyCharm?

PyCharm - это более «тяжёлый» редактор, заточенный именно под Python. Он удобнее для больших проектов, но для обучения VS Code проще и быстрее. Если у вас уже есть PyCharm - можете использовать его, весь код из уроков будет работать одинаково.

Первая программа: Hello, World!

Традиция в программировании: первая программа на любом языке должна вывести на экран «Hello, World!» («Привет, мир!»). С неё мы и начнём.

Шаг 1. Создаём файл

Откройте VS Code. Через меню File → New File создайте новый файл. Сохраните его (Ctrl+S или Cmd+S) на рабочем столе под названием hello.py. Расширение .py критично - оно говорит компьютеру, что это файл на Python.

Шаг 2. Пишем код

Введите в файл одну строчку:

print("Hello, World!")

Шаг 3. Запускаем

В VS Code в правом верхнем углу есть кнопка с треугольником «Play» (Запустить). Нажмите её. Внизу откроется панель терминала, и вы увидите:

Hello, World!

Поздравляем! Вы только что написали и запустили свою первую программу. Это исторический момент - именно так начинают все программисты мира.

Разбор: что такое print

Давайте посмотрим, что именно мы написали:

print("Hello, World!")
  • print - это функция. Функция - это как команда, которую умеет выполнять Python. Функция print буквально переводится как «печать» и выводит текст на экран.
  • Круглые скобки () - показывают, что перед нами вызов функции. Всё, что внутри скобок, функция принимает как «входные данные».
  • Кавычки "..." - это строка. Строка - это текст. Кавычки говорят Python: «воспринимай это как текст, а не как команду». Без кавычек Python попытается понять слово Hello как какую-то команду и выдаст ошибку.
Кавычки бывают разные

В Python можно использовать и двойные кавычки "...", и одинарные '...'. Оба варианта работают одинаково. Главное правило: кавычки должны быть парными (открывающая и закрывающая - одного типа). Нельзя смешивать: print("Hello') вызовет ошибку.

Несколько строк

Если нужно вывести несколько строк, можно использовать несколько функций print подряд. Каждая с новой строчки:

print("Привет!")print("Меня зовут Алексей")print("Я учусь программировать на Python")

Когда вы запустите этот код, каждая строчка появится на экране с новой строки. Это потому, что print по умолчанию добавляет перевод строки в конце.

А если нужно вывести несколько слов в одну строку, можно передать их в print через запятую:

print("Привет,", "мир!")

На экране появится: Привет, мир!. Обратите внимание: Python сам добавил пробел между словами.

Шпаргалка

Самое важное в одном месте:

  • python --version проверка установки
  • hello.py расширение файла Python
  • print() вывод текста на экран
  • "текст" строка в двойных кавычках
  • 'текст' строка в одинарных кавычках
  • () вызов функции

Если что-то не работает

Разберём типичные проблемы, с которыми сталкиваются новички на самом первом уроке.

  • «'python' не является внутренней или внешней командой». Скорее всего, вы не поставили галочку «Add Python to PATH» при установке. Переустановите Python, отметив эту галочку. Или попробуйте ввести python3 --version вместо python.
  • «SyntaxError: invalid syntax». Синтаксическая ошибка. Проверьте: все ли кавычки на месте, нет ли лишних пробелов в команде, правильно ли написано слово print (не Print, не prnt - Python чувствителен к регистру).
  • «SyntaxError: invalid character in identifier». Скорее всего, вы использовали «умные» кавычки из Word или мессенджера ("..." или '...') вместо обычных ("..."). Скопируйте кавычки прямо из урока или наберите их вручную в английской раскладке.
  • «NameError: name 'Hello' is not defined». Вы забыли кавычки. Python увидел слово Hello и подумал, что это имя переменной или функции, а не текст. Оберните текст в кавычки: print("Hello").
  • «Ничего не происходит, когда я нажимаю Run». Проверьте, сохранили ли вы файл с расширением .py. VS Code иногда не может запустить файл без расширения.
  • «Вместо русского текста какие-то кракозябры». Проблема с кодировкой. Убедитесь, что файл сохранён в UTF-8. В VS Code это можно сделать через меню в правом нижнем углу (там обычно написано "UTF-8").

Если что-то не получается - напишите нам в Telegram, разберёмся вместе.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Поздоровайтесь

Напишите программу, которая выводит на экран две строки: «Привет, мир!» и «Меня зовут [ваше имя]». Используйте функцию print.

Подсказка

Используйте две функции print подряд - по одной на каждую строку. Не забудьте кавычки вокруг текста.

Решение учителя 
print("Привет, мир!")print("Меня зовут Алексей")
Задача 2. Стихотворение

Выведите на экран любое четверостишие (4 строчки). Каждая строчка должна быть на новой строке.

Подсказка

Четыре функции print подряд - по одной на каждую строчку стихотворения. Это самый простой способ.

Решение учителя 
print("У лукоморья дуб зелёный,")print("Златая цепь на дубе том:")print("И днём и ночью кот учёный")print("Всё ходит по цепи кругом;")
Задача 3. Рисуем рамку

Выведите на экран простую рамку из символов звёздочек. Например, такую:

***********        ** Python **        ***********
Подсказка

Используйте пять функций print. В каждой - строка с нужным количеством символов. Обратите внимание на пробелы внутри рамки - их важно сохранить.

Решение учителя 
print("**********")print("*        *")print("* Python *")print("*        *")print("**********")
Задача 4. Найдите ошибки

Перед вами код с ошибками. Найдите и исправьте их, чтобы программа успешно запустилась и вывела текст.

print(Привет)print("Как дела?"Print("Пока!")
Подсказка

Три ошибки: отсутствуют кавычки в первой строке, не хватает закрывающей скобки во второй, и неправильный регистр в третьей (Python чувствителен к регистру).

Решение учителя 
print("Привет")print("Как дела?")print("Пока!")

Обратите внимание: слово print пишется только строчными буквами. Print с большой буквы - уже другая команда (которой в Python не существует), и программа выдаст ошибку.

Что мы узнали и что дальше

Сегодня мы сделали первый, самый важный шаг: установили Python, настроили редактор и написали первую программу. Теперь вы знаете:

  • Что такое Python и зачем он нужен.
  • Как установить его и не забыть галочку «Add Python to PATH».
  • Что такое VS Code и как настроить его для работы.
  • Как создать файл с расширением .py и запустить его.
  • Что такое функция print и что такое строка в кавычках.

Возможно, это кажется простым - но именно с этих шагов начинается путь любого программиста. Уже сейчас вы можете выводить на экран текст, а значит, делать первые шаги в автоматизации и творчестве.

В следующем уроке мы познакомимся с переменными - «коробочками», в которых можно хранить числа, текст и другие данные. Это то, без чего не обходится ни одна программа. Мы научимся создавать переменные, узнаем, какие бывают типы данных, и напишем несколько программ, которые работают с числами и словами. До встречи!
