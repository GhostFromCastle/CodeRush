Навигация по файловой системе

~25 минут Windows Теория и Практика

В прошлом уроке мы научились отдавать команды. Но пока мы находимся в одной папке и не умеем перемещаться по компьютеру. Представьте, что вы в огромном здании, где сотни комнат, и вам нужно попасть в конкретную. Без навигации не обойтись.

Сегодня мы научимся ходить по папкам, смотреть их содержимое и понимать, где мы находимся в данный момент.

Где я?

В любой момент вы можете узнать, в какой папке находитесь. Для этого есть команда cd без аргументов (или pwd в PowerShell). Она выведет полный путь.

cd

Вы увидите что-то вроде C:\Users\ВашеИмя. Это ваша текущая директория.

Команда dir (список файлов)

Чтобы посмотреть, что лежит в текущей папке, используется команда dir (от слова directory - папка).

dir

Терминал выведет список всех файлов и папок. Вы увидите их имена, дату создания и размер.

Полезные флаги dir:

  • /a - показать скрытые файлы (например, системные).
  • /s - показать файлы во всех вложенных папках.
  • /w - вывести в широком формате (по несколько в строку).

Команда cd (переход по папкам)

Команда cd (change directory) меняет текущую папку. Это как войти в комнату.

Чтобы перейти в папку, которая находится внутри текущей:

cd Documents

Вы вошли в папку «Документы». Теперь можете снова использовать dir, чтобы посмотреть, что внутри.

Чтобы вернуться на один уровень вверх (в родительскую папку):

cd ..

Чтобы перейти в корень текущего диска (например, на диск C):

cd \

Переход на другой диск

В Windows есть несколько дисков (C, D, E и т.д.). Если вы находитесь на диске C, и хотите перейти на диск D, просто введите его букву с двоеточием:

D:

Приглашение командной строки изменится на D:\>. Теперь вы работаете с другим диском. Вернуться обратно можно так же: C:.

Очистка экрана (cls)

После множества команд экран терминала превращается в кашу. Чтобы очистить его и начать «с чистого листа», используется команда cls (clear screen).

cls

Вся история команд исчезнет, останется только приглашение.

Подсказка для команд

Если вы не помните точное название файла или папки, начните вводить его и нажмите Tab. Терминал сам дополнит имя. Например, начните писать cd Doc и нажмите Tab - если такая папка есть, она подставится автоматически.

Шпаргалка

Самое важное в одном месте:

  • cd где я?
  • dir список файлов
  • cd имя_папки зайти в папку
  • cd .. вернуться назад
  • cd \ в корень диска
  • D: перейти на диск D
  • cls очистить экран

Если что-то не работает

Разберём типичные ошибки при навигации.

  • «Системе не удаётся найти указанный путь». Вы ошиблись в названии папки или пытаетесь зайти в несуществующую директорию. Проверьте, что вы находитесь в правильном месте (используйте dir).
  • «Синтаксическая ошибка в имени файла». Вы забыли кавычки, а в пути к папке есть пробел. Например, папка Program Files содержит пробел. Правильно: cd "Program Files".
  • «Не удаётся перейти на диск». Вы указали букву диска, которого нет в системе. Проверьте в «Моём компьютере», какие диски у вас есть.
  • «Команда dir ничего не показывает». Вы находитесь в пустой папке. Это нормально.

Если что-то не получается - напишите нам в Telegram, разберёмся вместе.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Осмотр дома

Перейдите в вашу домашнюю папку (если вы не там) и выведите список файлов, которые в ней находятся.

Подсказка

Чтобы вернуться домой из любого места, используйте cd %USERPROFILE% или cd ~ (в PowerShell). Затем выполните dir.

Решение учителя 
cd %USERPROFILE%dir

В PowerShell можно написать просто cd ~.

Задача 2. Вверх по лестнице

Находясь в домашней папке, поднимитесь на один уровень вверх (в папку Users). Затем посмотрите, какие другие пользователи есть на компьютере (команда dir).

Подсказка

Для перехода на уровень вверх используется cd ... После этого выполните dir.

Решение учителя 
cd ..dir
Задача 3. Путешествие на диск D

Перейдите на диск D: (если у вас его нет - на любой другой доступный диск, кроме C). Посмотрите его содержимое. Затем вернитесь обратно на диск C.

Подсказка

Для смены диска просто напишите его букву с двоеточием.

Решение учителя 
D:dirC:
Задача 4. Исправление ошибок

Пользователь хочет перейти в папку Program Files, но получает ошибку. Найдите и исправьте ошибку.

cd C:\Program Files
Подсказка

В названии папки есть пробел. Терминал думает, что вы хотите перейти в две разные папки.

Решение учителя 
cd "C:\Program Files"

Мы взяли путь в кавычки, чтобы терминал воспринял его как единое целое.

Что мы узнали и что дальше

Теперь вы можете свободно перемещаться по файловой системе Windows, как заправский системный администратор. Вы узнали:

  • Как узнать текущую папку (cd).
  • Как посмотреть содержимое папки (dir).
  • Как переходить в другие папки (cd имя) и возвращаться назад (cd ..).
  • Как переключаться между дисками.
  • Как очистить экран (cls).

Мы научились ходить по папкам, но пока не умеем их создавать, копировать или удалять. В следующем уроке мы разберём работу с файлами и папками. Вы научитесь создавать, копировать, перемещать и удалять данные прямо из терминала. До встречи!
