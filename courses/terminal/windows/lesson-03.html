Работа с файлами и папками

~25 минут Windows Теория и Практика

В прошлом уроке мы научились перемещаться по файловой системе. Но что, если нам нужно не просто посмотреть, а что-то создать или изменить? Представьте, что вы переехали в новую квартиру. Сначала вы расставляете мебель (создаёте папки), потом раскладываете вещи (копируете файлы), а иногда выбрасываете мусор (удаляете лишнее).

Сегодня мы научимся делать всё это прямо из терминала.

Создание папок: mkdir

Команда mkdir (make directory) создаёт новую папку. Это как построить новую комнату в доме.

mkdir NewProject

Эта команда создаст папку NewProject в текущей директории. Если папка уже существует, терминал выдаст ошибку.

Можно создать сразу несколько папок через пробел:

mkdir folder1 folder2 folder3

А если добавить флаг /p, можно создавать вложенные папки, даже если родительских ещё нет:

mkdir /p Projects\CodeRush\Lessons

Копирование файлов: copy

Команда copy копирует файл из одного места в другое. Вы как будто делаете ксерокопию документа.

copy file.txt D:\Backup\file.txt

Эта команда скопирует файл file.txt в папку D:\Backup. Если папки назначения нет, будет ошибка.

Также можно копировать файлы по маске (все файлы с расширением .txt):

copy *.txt D:\Backup\

Перемещение файлов: move

Команда move не копирует, а перемещает файл. Это как взять вещь и переставить её в другой шкаф. Исходный файл исчезает.

move file.txt D:\Archive\file.txt

Этой же командой можно переименовать файл:

move old_name.txt new_name.txt

Удаление файлов: del

Команда del (delete) удаляет файлы. Будьте осторожны: в терминале нет «Корзины», файлы удаляются безвозвратно.

del file.txt

Если добавить флаг /f, можно удалить файл, доступный только для чтения.

del /f read_only.txt

Удаление папок: rmdir

Для удаления папок используется команда rmdir (remove directory).

rmdir EmptyFolder

Эта команда удалит папку, только если она пуста. Если внутри есть файлы, терминал выдаст ошибку.

Чтобы удалить папку вместе со всем содержимым, используется флаг /s:

rmdir /s OldFolder

Терминал спросит подтверждение. Если добавить флаг /q (quiet), он удалит всё без лишних вопросов:

rmdir /s /q OldFolder
Будьте осторожны!

Команда rmdir /s /q удаляет папку со всем содержимым без подтверждения. Внимательно проверяйте путь перед нажатием Enter. Восстановить данные будет крайне сложно.

Шпаргалка

Самое важное в одном месте:

  • mkdir создать папку
  • copy копировать файл
  • move переместить файл
  • del удалить файл
  • rmdir удалить папку
  • rmdir /s /q удалить папку со всем содержимым

Если что-то не работает

Разберём типичные ошибки при работе с файлами.

  • «Файл не найден». Вы ошиблись в имени файла или находитесь не в той папке. Используйте dir, чтобы проверить содержимое.
  • «Отказано в доступе». Вы пытаетесь удалить или изменить системный файл. Запустите терминал от имени администратора (правая кнопка мыши -> «Запуск от имени администратора»).
  • «Папка не пуста». Вы используете rmdir без флага /s для папки, в которой есть файлы. Добавьте /s.
  • «Слишком длинное имя файла». Windows имеет ограничение на длину пути (около 260 символов). Попробуйте переместить папку ближе к корню диска.

Если что-то не получается - напишите нам в Telegram, разберёмся вместе.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Стройка века

Создайте папку с названием TestFolder в вашей текущей директории.

Подсказка

Используйте команду mkdir.

Решение учителя 
mkdir TestFolder
Задача 2. Бэкап важного

Создайте текстовый файл important.txt с любым содержимым в текущей папке. Скопируйте его в папку TestFolder.

Подсказка

Файл можно создать командой echo текст > important.txt. Затем используйте copy important.txt TestFolder\.

Решение учителя 
echo "Секретные данные" > important.txtcopy important.txt TestFolder\
Задача 3. Переезд

Переименуйте файл important.txt в archive.txt.

Подсказка

Используйте команду move, указав старое и новое имя файла.

Решение учителя 
move important.txt archive.txt
Задача 4. Генеральная уборка

Удалите файл archive.txt и папку TestFolder со всем её содержимым.

Подсказка

Для файла используйте del. Для папки - rmdir /s /q.

Решение учителя 
del archive.txtrmdir /s /q TestFolder

Что мы узнали и что дальше

Теперь вы можете управлять файлами так же быстро, как заправский хакер из фильмов. Вы узнали:

  • Как создавать папки (mkdir).
  • Как копировать файлы (copy).
  • Как перемещать и переименовывать файлы (move).
  • Как удалять файлы (del) и папки (rmdir).

Но терминал умеет работать не только с файлами. Он может управлять программами и процессами, которые запущены в системе. В следующем уроке мы разберём системные команды. Вы научитесь смотреть, какие программы сейчас работают, и как их принудительно закрыть, если они зависли. До встречи!
