Терминал

Управление компьютером через командную строку

Интерфейс командной строки кажется сложным только на первый взгляд. На самом деле это самый быстрый и мощный способ управлять компьютером. Научитесь базовым командам, навигации по файловой системе и работе с утилитами.

С какой ОС вы работаете?

Выберите операционную систему, чтобы начать изучение терминала. Не переживайте, если вы работаете в одной, но хотите узнать про другую - вы всегда можете переключиться.

Windows

Командная строка Windows

В этом разделе мы изучим PowerShell и классическую командную строку (cmd). Вы научитесь управлять файлами, запускать программы и использовать встроенные утилиты.

  • Навигация по файловой системе
  • Базовые команды (dir, cd, copy)
  • Работа с сетью (ping, ipconfig)
  • Введение в PowerShell

Linux

Командная строка Linux

Познакомитесь с Bash (Bourne Again Shell). Это стандарт для серверов и многих профессионалов. Навигация, права доступа, работа с пакетами и утилитами.

  • Основы работы в оболочке Bash
  • Файлы и директории (ls, cd, mkdir)
  • Права доступа и sudo
  • Управление пакетами (apt, dnf)
