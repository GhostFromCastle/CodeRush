JSON и сериализация

~45 минут Продвинутый уровень Теория и Практика

В прошлом уроке мы научились читать и писать текстовые файлы. Но есть одна проблема: если нужно сохранить сложный объект с десятком полей (пользователя, товар, настройки), писать и парсить его вручную - это утомительно и чревато ошибками.

Представьте, что вам нужно сохранить список студентов. Можно придумать свой формат: каждая строка - студент, поля разделены запятыми. Но что делать, если в имени встретится запятая? А если завтра добавится новое поле? А если тот же файл должен читать сайт на JavaScript и мобильное приложение на Swift?

Решением всех этих проблем стал JSON - универсальный текстовый формат данных, который понимают практически все языки программирования. Сегодня мы разберёмся, как выглядит JSON, как превращать объекты C# в JSON и обратно, и как настраивать этот процесс под свои нужды.

Что такое JSON

JSON расшифровывается как JavaScript Object Notation - «нотация объектов JavaScript». Но не пугайтесь слова «JavaScript»: JSON - это самостоятельный формат, и с ним прекрасно работают Python, C#, Java, Go и десятки других языков.

Аналогия: JSON - это как универсальный язык международного общения. Вы говорите на русском, ваш коллега - на английском, а данные передаёте на эсперанто, который понимают оба. Так и здесь: C#-программа и Python-программа не понимают внутренние структуры друг друга, но JSON читают обе.

По сути, JSON - это текст, который описывает данные в виде пар «ключ-значение». Выглядит это так:

{  "name": "Алексей",  "age": 25,  "isStudent": true}

Что здесь происходит:

  • Фигурные скобки обозначают объект.
  • Ключи - это строки в двойных кавычках ("name").
  • Значения могут быть строками, числами, булевыми значениями (true / false), массивами, вложенными объектами или null.
  • Двоеточие разделяет ключ и значение.
  • Запятая разделяет пары.

JSON поддерживает и массивы - списки значений в квадратных скобках:

{  "name": "Алексей",  "skills": ["C#", "LINQ", "ASP.NET"]}

И вложенные объекты:

{  "name": "Алексей",  "address": {    "city": "Москва",    "zip": "101000"  }}

Всё это - JSON. Он читается человеком (хотя и без подсветки синтаксиса выглядит как каша), но при этом легко парсится программами.

Сериализация и десериализация

Два слова, которые вы теперь будете слышать часто:

  • Сериализация - превращение объекта C# в строку JSON. Объект «упаковывается» в текстовый формат.
  • Десериализация - обратный процесс: из строки JSON создаётся объект C#.

Аналогия: сериализация - это как упаковать мебель в плоские коробки, чтобы её удобно было перевезти. Десериализация - собрать мебель обратно. Внутри объект тот же, меняется только форма хранения.

Класс JsonSerializer

В современном C# есть встроенная библиотека для работы с JSON - System.Text.Json. Она не требует установки сторонних пакетов и работает из коробки.

Для начала работы достаточно подключить пространство имён:

using System.Text.Json;

Сериализация: объект -> JSON

Возьмём простой класс:

class User{    public string Name { get; set; }    public int Age { get; set; }    public bool IsStudent { get; set; }}

И превратим объект в JSON:

User user = new User{    Name = "Алексей",    Age = 25,    IsStudent = true};string json = JsonSerializer.Serialize(user);Console.WriteLine(json);

Вывод будет примерно такой:

{"Name":"Алексей","Age":25,"IsStudent":true}

Обратите внимание: имена полей сохраняются как есть - с заглавной буквы, как в C#. Порядок тоже сохраняется. Если класс содержит вложенные объекты или списки - они тоже сериализуются автоматически.

Десериализация: JSON -> объект

Обратный процесс выглядит так:

string json = "{\"Name\":\"Мария\",\"Age\":30,\"IsStudent\":false}";User user = JsonSerializer.Deserialize<User>(json);Console.WriteLine(user.Name);Console.WriteLine(user.Age);

Метод Deserialize<T> принимает строку JSON и возвращает объект типа T. Все поля автоматически заполняются из JSON по именам.

Свойства, а не поля

По умолчанию System.Text.Json сериализует только публичные свойства (public string Name { get; set; }). Обычные поля (public string Name;) будут проигнорированы. Это одна из самых частых ошибок у новичков. Если хотите, чтобы поле тоже попало в JSON - либо превратите его в свойство, либо добавьте атрибут [JsonInclude].

Настройки сериализации

Иногда стандартное поведение не подходит. Например, вы работаете с API, который ожидает имена полей в стиле camelCase (с маленькой буквы) - как это принято в JavaScript. Или хотите, чтобы JSON был отформатирован красиво, с отступами и переносами, а не в одну строку.

Для этого используется объект JsonSerializerOptions:

var options = new JsonSerializerOptions{    WriteIndented = true,    PropertyNamingPolicy = JsonNamingPolicy.CamelCase};string json = JsonSerializer.Serialize(user, options);

Результат:

{  "name": "Алексей",  "age": 25,  "isStudent": true}

Два ключевых параметра:

  • WriteIndented - если true, JSON выводится с отступами и переносами строк. Удобно для логов и чтения глазами. Если false (по умолчанию) - всё в одну строку. Компактнее для передачи по сети.
  • PropertyNamingPolicy - правило именования. CamelCase превращает Name в name, IsStudent в isStudent. Часто требуется для совместимости с API.

Есть и другие полезные опции:

  • DefaultIgnoreCondition = JsonIgnoreCondition.WhenWritingNull - не включать в JSON поля со значением null. Уменьшает размер и делает JSON чище.
  • AllowTrailingCommas = true (при десериализации) - разрешить запятые в конце объектов. Не все парсеры такое принимают, но некоторые API отдают такой JSON.
  • PropertyNameCaseInsensitive = true (при десериализации) - игнорировать регистр при сопоставлении имён. Полезно, когда не уверены, придёт ли Name или name.

Работа с вложенными объектами

JSON отлично справляется со сложными структурами. Рассмотрим пример: заказ с товарами и адресом доставки.

class Address{    public string City { get; set; }    public string Street { get; set; }}class Item{    public string Name { get; set; }    public int Quantity { get; set; }    public decimal Price { get; set; }}class Order{    public int Id { get; set; }    public Address Delivery { get; set; }    public List<Item> Items { get; set; }}

Сериализация такого объекта создаст многоуровневый JSON:

{  "Id": 1,  "Delivery": {    "City": "Москва",    "Street": "Тверская, 1"  },  "Items": [    { "Name": "Книга", "Quantity": 2, "Price": 500 },    { "Name": "Ручка", "Quantity": 5, "Price": 50 }  ]}

А десериализация автоматически восстановит всю структуру: Delivery станет объектом Address, Items - списком Item. Всё это происходит «само», без единой строчки ручного кода.

JSON и файлы

Самый частый сценарий - сохранить объект в файл и прочитать его обратно. Соединяем то, что знаем: File.WriteAllText из урока 28 и JsonSerializer из этого урока.

var options = new JsonSerializerOptions{    WriteIndented = true};string json = JsonSerializer.Serialize(user, options);File.WriteAllText("user.json", json);

Чтение обратно:

string json = File.ReadAllText("user.json");User user = JsonSerializer.Deserialize<User>(json);

Просто и элегантно. Именно так сохраняют настройки, состояние игр, списки задач, кэшированные данные. Одна строка на запись, одна на чтение.

Асинхронные версии

Как и с файлами, для JSON есть асинхронные методы: JsonSerializer.SerializeAsync и JsonSerializer.DeserializeAsync. Они работают напрямую с потоками (Stream), а не со строками. В реальных приложениях - особенно в ASP.NET и десктопных программах - лучше использовать именно их. Обычные версии подходят для маленьких файлов и учебных задач.

Шпаргалка

Самое важное в одном месте:

  • JSON универсальный текстовый формат данных
  • Сериализация объект -> строка JSON
  • Десериализация строка JSON -> объект
  • JsonSerializer встроенный класс System.Text.Json
  • Serialize(obj) объект в JSON
  • Deserialize<T>(json) JSON в объект
  • WriteIndented отформатированный JSON
  • CamelCase имена полей с маленькой буквы

Если что-то не работает

Разберём типичные ошибки при работе с JSON в C#.

  • «Поле не попало в JSON». Самая частая ошибка. System.Text.Json сериализует только публичные свойства, а не поля. Если у вас public string Name; - ничего не произойдёт. Замените на public string Name { get; set; }.
  • «При десериализации все поля остаются null». Причины обычно две: либо в JSON другие имена полей (например, name вместо Name), либо свойства не публичные. Решение - PropertyNameCaseInsensitive = true в настройках.
  • «JsonException: The JSON value could not be converted». Тип в JSON не совпадает с типом в C#. Например, в JSON число как строка ("age": "25"), а в классе - int. Или наоборот. Проверьте, что типы данных совпадают.
  • «Не получается десериализовать дату». По умолчанию System.Text.Json ожидает даты в формате ISO 8601 (2025-03-15T14:30:00). Если API отдаёт в другом формате - понадобится кастомный конвертер.
  • «Циклическая ссылка при сериализации». Классика: у Author есть список Books, а у каждой Book - ссылка обратно на Author. JSON пытается сериализовать бесконечную цепочку и падает. Решение - либо разорвать связь, либо использовать атрибут [JsonIgnore] на одном из полей.
  • «Строка с JSON слишком длинная, читать невозможно». Используйте WriteIndented = true. Это добавит отступы и переносы - JSON станет читаемым. Минус - размер файла вырастет на 10-20%.
  • «А если JSON невалидный?» Deserialize выбросит JsonException. Всегда оборачивайте десериализацию в try / catch, особенно если JSON приходит из внешнего источника (API, файл, введённый пользователем).

Если что-то не получается - напишите нам в Telegram, разберёмся вместе.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Простая сериализация

Создайте класс Book с полями Title (строка), Author (строка) и Year (число). Создайте объект с любимой книгой, сериализуйте его в JSON и выведите на экран.

Подсказка

Не забудьте: поля должны быть свойствами (public string Title { get; set; }), иначе они не попадут в JSON. Для сериализации используйте JsonSerializer.Serialize(book).

Решение учителя 
using System.Text.Json;class Book{    public string Title { get; set; }    public string Author { get; set; }    public int Year { get; set; }}static void Main(string[] args){    Book book = new Book    {        Title = "Мастер и Маргарита",        Author = "Михаил Булгаков",        Year = 1967    };    string json = JsonSerializer.Serialize(book);    Console.WriteLine(json);}
Задача 2. Список объектов

Используя класс Book из прошлой задачи, создайте список из трёх книг. Сериализуйте список в JSON с параметром WriteIndented = true, чтобы было читаемо. Затем десериализуйте JSON обратно в список и выведите названия книг.

Подсказка

JsonSerializer спокойно работает со списками. Сериализуйте List<Book> напрямую. А для обратной операции используйте Deserialize<List<Book>>(json).

Решение учителя 
static void Main(string[] args){    var books = new List<Book>    {        new Book { Title = "Война и мир", Author = "Толстой", Year = 1869 },        new Book { Title = "Преступление и наказание", Author = "Достоевский", Year = 1866 },        new Book { Title = "Отцы и дети", Author = "Тургенев", Year = 1862 }    };    var options = new JsonSerializerOptions { WriteIndented = true };    string json = JsonSerializer.Serialize(books, options);    Console.WriteLine(json);    List<Book> restored = JsonSerializer.Deserialize<List<Book>>(json);    Console.WriteLine("\nНазвания книг:");    foreach (var b in restored)    {        Console.WriteLine(b.Title);    }}
Задача 3. camelCase для API

Создайте класс Product с полями ProductName, UnitPrice и InStock. Сериализуйте его так, чтобы в JSON имена полей были в camelCase (productName, unitPrice, inStock). Выведите результат.

Подсказка

Используйте JsonSerializerOptions с PropertyNamingPolicy = JsonNamingPolicy.CamelCase. Проверьте результат: первая буква каждого поля должна стать строчной.

Решение учителя 
class Product{    public string ProductName { get; set; }    public decimal UnitPrice { get; set; }    public bool InStock { get; set; }}static void Main(string[] args){    var product = new Product    {        ProductName = "Ноутбук",        UnitPrice = 75000m,        InStock = true    };    var options = new JsonSerializerOptions    {        WriteIndented = true,        PropertyNamingPolicy = JsonNamingPolicy.CamelCase    };    string json = JsonSerializer.Serialize(product, options);    Console.WriteLine(json);}

Результат будет:

{  "productName": "Ноутбук",  "unitPrice": 75000,  "inStock": true}
Задача 4. Сохранение в файл

Напишите программу, которая:

  1. Создаёт список из трёх пользователей (класс User с полями Name и Age).
  2. Сериализует список в JSON с отступами.
  3. Записывает JSON в файл users.json.
  4. Читает файл обратно, десериализует и выводит всех пользователей в формате «Имя: возраст».

Подсказка

Соедините File.WriteAllText из урока 28 с JsonSerializer.Serialize из этого урока. Для чтения - File.ReadAllText и Deserialize<List<User>>. Не забудьте подключить using System.Text.Json;.

Решение учителя 
class User{    public string Name { get; set; }    public int Age { get; set; }}static void Main(string[] args){    string path = "users.json";    var users = new List<User>    {        new User { Name = "Алексей", Age = 25 },        new User { Name = "Мария", Age = 30 },        new User { Name = "Иван", Age = 22 }    };    var options = new JsonSerializerOptions { WriteIndented = true };    string json = JsonSerializer.Serialize(users, options);    File.WriteAllText(path, json);    string readJson = File.ReadAllText(path);    List<User> loaded = JsonSerializer.Deserialize<List<User>>(readJson);    Console.WriteLine("Загруженные пользователи:");    foreach (var u in loaded)    {        Console.WriteLine($"{u.Name}: {u.Age}");    }}

Теперь ваша программа умеет сохранять структурированные данные в файл и читать их обратно. Это основа для любого приложения с настройками, списками задач, историей операций.

Что мы узнали и что дальше

Сегодня мы разобрались с JSON - универсальным форматом данных, без которого не обходится ни одно современное приложение. Узнали, что такое сериализация и десериализация, научились работать с классом JsonSerializer из System.Text.Json.

Разобрали:

  • Как превратить объект C# в строку JSON через Serialize.
  • Как восстановить объект из строки через Deserialize<T>.
  • Как настроить формат: отступы, стиль именования camelCase, игнорирование null.
  • Как работать с вложенными объектами и списками - JSON делает это автоматически.
  • Как сохранять объекты в файл и читать их обратно.

Теперь ваши программы умеют не только сохранять простые тексты, но и передавать структурированные данные. Именно так работает взаимодействие с API: вы отправляете JSON-запрос, получаете JSON-ответ, десериализуете в объект и работаете с ним как с обычным C#-классом.
