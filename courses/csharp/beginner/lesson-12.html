Switch, тернарный оператор и ещё пара конструкций

~25 минут Начальный уровень Теория и Практика

Это последний урок начального уровня. Мы уже знаем почти всё, что нужно для базового программирования. Осталась пара инструментов, которые не влезли в предыдущие уроки, но о которых вы обязательно услышите в чужом коде. Это switch, тернарный оператор и пара небольших конструкций для циклов.

Разберём их - и на этом начальный уровень будет полностью закрыт.

Проблема длинных if / else if

Вспомните четвёртый урок. Когда вариантов много, мы писали длинные цепочки условий:

int day = 3;if (day == 1){    Console.WriteLine("Понедельник");}else if (day == 2){    Console.WriteLine("Вторник");}else if (day == 3){    Console.WriteLine("Среда");}else if (day == 4){    Console.WriteLine("Четверг");}else if (day == 5){    Console.WriteLine("Пятница");}else{    Console.WriteLine("Выходной");}

Работает - но выглядит громоздко. И здесь мы каждый раз пишем day ==, хотя проверяем одну и ту же переменную. Есть более удобный инструмент для таких случаев - оператор switch.

Оператор switch

switch переводится как «переключатель». Его идея: мы говорим «вот эта переменная, проверь её значение, и в зависимости от него выполни одно из действий». Синтаксис:

int day = 3;switch (day){    case 1:        Console.WriteLine("Понедельник");        break;    case 2:        Console.WriteLine("Вторник");        break;    case 3:        Console.WriteLine("Среда");        break;    case 4:        Console.WriteLine("Четверг");        break;    case 5:        Console.WriteLine("Пятница");        break;    default:        Console.WriteLine("Выходной");        break;}

Результат тот же, что и у цепочки if / else if, но код читается легче. Разберём по частям:

  • switch (day) - «проверь значение переменной day».
  • case 1: - «если значение равно 1, выполни то, что идёт ниже».
  • break; - «выход из switch». Обязателен после каждого блока.
  • default: - «во всех остальных случаях». Аналог else.

Компьютер заходит в switch, сравнивает значение с каждым case по очереди. Как только совпало - выполняет блок и выходит. Если ни один не совпал - выполняется default.

Про break

Без break компьютер не остановится, а «провалится» в следующий case и выполнит его тоже. В C# это запрещено на уровне компилятора - если забудете break, Visual Studio подчеркнёт строку красным. Так что случайно не забудете, но знать эту особенность полезно.

Когда switch удобен

switch - идеальный инструмент, когда выполняются три условия:

  • Проверяется одна переменная (или выражение).
  • Вариантов много - 3 и больше.
  • Проверка идёт на равенство конкретному значению, а не на диапазон.

Если у вас проверка вида «если age >= 18» или «если login == "admin" && password == "1234"» - это if, а не switch. switch не умеет работать с диапазонами и составными условиями напрямую.

Switch со строками

В отличие от некоторых других языков, в C# switch работает не только с числами, но и со строками:

Console.Write("Введи команду: ");string command = Console.ReadLine().ToLower();switch (command){    case "start":        Console.WriteLine("Запускаю...");        break;    case "stop":        Console.WriteLine("Останавливаю...");        break;    case "help":        Console.WriteLine("Доступные команды: start, stop, help");        break;    default:        Console.WriteLine("Неизвестная команда");        break;}

Мы использовали .ToLower() из шестого урока - теперь команды START, Start и start обрабатываются одинаково. Удобно.

Объединение case

Иногда несколько case должны привести к одному и тому же действию. Их можно объединять, написав подряд без тела:

int day = 6;switch (day){    case 1:    case 2:    case 3:    case 4:    case 5:        Console.WriteLine("Рабочий день");        break;    case 6:    case 7:        Console.WriteLine("Выходной");        break;}

Читается так: «если 1, 2, 3, 4 или 5 - рабочий день. Если 6 или 7 - выходной». Гораздо компактнее, чем пять отдельных блоков с одинаковым содержимым.

Тернарный оператор

Вернёмся ненадолго к условиям. Иногда нужно сделать простую проверку и по результату выбрать одно из двух значений. Например:

int age = 20;string status;if (age >= 18){    status = "взрослый";}else{    status = "ребёнок";}

Семь строк ради одной проверки. Есть способ записать это в одну строку - тернарный оператор. Называется так, потому что в нём три части:

string status = age >= 18 ? "взрослый" : "ребёнок";

Читается это так: «если age >= 18 - возьми значение "взрослый", иначе - "ребёнок"». Символ ? как бы спрашивает «что, если да?», а : разделяет два варианта.

Схема такая:

условие ? значение_если_истина : значение_если_ложь

Ещё пример - сразу в выводе:

int score = 85;Console.WriteLine(score >= 60 ? "Сдал" : "Не сдал");

Программа выведет «Сдал», потому что 85 ≥ 60.

Когда использовать тернарный оператор

Тернарный оператор удобен для простых проверок, где результат - это одно или другое значение. Если в блоках if / else больше одной строки или действия сложнее, чем просто «выбрать значение», - используйте обычный if / else. Тернарник существует не чтобы всё сокращать, а чтобы делать код чище в правильных местах.

Дополнительно: две конструкции для циклов

Мы прошли циклы в пятом уроке, но там разобрали только for и while. Осталось ещё две вещи, о которых стоит знать: continue и do while.

Оператор continue

Мы знаем break - он полностью прерывает цикл. А continue работает мягче: он пропускает текущую итерацию и сразу переходит к следующей. 

for (int i = 1; i <= 10; i++){    if (i % 2 == 0)    {        continue;    }    Console.WriteLine(i);}

Эта программа выводит только нечётные числа от 1 до 10. Как это работает: когда i чётное, мы говорим «пропусти эту итерацию» - и Console.WriteLine не выполняется, цикл сразу переходит к следующему i.

Тот же результат можно получить через обычное условие if (i % 2 != 0). Но иногда continue делает код чище: сначала «отсекаем» всё ненужное, потом работаем с остальным.

Цикл do while

Это родственник обычного while с одним отличием: условие проверяется после тела цикла, а не перед ним. То есть тело выполнится хотя бы один раз - всегда, даже если условие изначально ложно.

int number;do{    Console.Write("Введи положительное число: ");    number = int.Parse(Console.ReadLine());}while (number <= 0);

Эта программа просит число, и если оно не положительное - просит снова. И так до тех пор, пока пользователь не введёт что-то больше нуля. Идеально для валидации ввода.

Разница между while и do while:

  • while - сначала проверяем, потом делаем. Если условие ложно - тело не выполнится ни разу.
  • do while - сначала делаем, потом проверяем. Тело выполнится минимум один раз, даже если условие ложно.

Кстати, именно do while пригодился бы в игре «Угадай число» из восьмого урока, если бы вы захотели добавить «Играть ещё раз?». Цикл покажет игру хотя бы один раз, а потом спросит - и если пользователь ответит «нет», завершится.

Шпаргалка

Самое важное в одном месте:

  • switch (x) проверка на равенство
  • case 1: случай «если x == 1»
  • break; выход из switch
  • default: все остальные случаи
  • условие ? a : b тернарный оператор
  • continue; пропустить итерацию
  • do { ... } while (...); цикл с проверкой после

Если что-то не работает

Новые конструкции компактные, но у каждой есть свои подводные камни. Проверьте по списку:

  • «Control cannot fall through from one case label to another». Забыли break после case. В C# это обязательное правило, и компилятор не даст собрать программу, пока не добавите break.
  • switch не видит совпадений. Проверьте тип переменной и типы значений в case. Нельзя сравнивать int со строкой "1" - это разные типы.
  • Тернарный оператор возвращает не то, что нужно. Проверьте порядок: условие ? значение_если_истина : значение_если_ложь. Условие первым, до знака вопроса. И : разделяет две ветки.
  • Обе ветки тернарника должны возвращать один и тот же тип. Нельзя написать age >= 18 ? "взрослый" : 0 - первая ветка даёт string, вторая int. Компилятор выдаст ошибку.
  • «; expected» после do while. У этого цикла точка с запятой ставится после while (условие), а не после закрывающей скобки тела. Обратите внимание: while (number <= 0); - с точкой с запятой в конце.
  • continue зацикливает программу. Если в цикле while стоит continue до изменения счётчика, счётчик никогда не изменится, и цикл будет крутиться вечно. Убедитесь, что i++ идёт до continue или в самом for.
  • Бесконечный цикл в do while. Если тело цикла не меняет условие - оно никогда не станет ложным. Убедитесь, что внутри цикла переменная из while (...) как-то изменяется.

Практика

Четыре задачи. У каждой - подсказка и решение учителя.

Задача 1. Месяцы

Пользователь вводит номер месяца (1–12). Выведите название месяца. Если номер вне диапазона - «Неверный месяц».

Подсказка

Используйте switch. Для каждого месяца - свой блок case с выводом и break. А для всех остальных значений - default.

Решение учителя 
Console.Write("Введи номер месяца: ");int month = int.Parse(Console.ReadLine());switch (month){    case 1:  Console.WriteLine("Январь");   break;    case 2:  Console.WriteLine("Февраль");  break;    case 3:  Console.WriteLine("Март");     break;    case 4:  Console.WriteLine("Апрель");   break;    case 5:  Console.WriteLine("Май");      break;    case 6:  Console.WriteLine("Июнь");     break;    case 7:  Console.WriteLine("Июль");     break;    case 8:  Console.WriteLine("Август");   break;    case 9:  Console.WriteLine("Сентябрь"); break;    case 10: Console.WriteLine("Октябрь");  break;    case 11: Console.WriteLine("Ноябрь");   break;    case 12: Console.WriteLine("Декабрь");  break;    default: Console.WriteLine("Неверный месяц"); break;}

Обратите внимание: каждая короткая команда уместилась в одну строку - так код становится компактнее, а читать его всё равно легко.

Задача 2. Калькулятор

Спросите у пользователя два числа и знак операции (+, -, *, /). Выведите результат. Используйте switch.

Подсказка

Сначала получите два числа через double.Parse. Знак операции - строка, её сравнивать через case "+": и так далее. Для деления используйте double, чтобы не потерять дробную часть.

Решение учителя 
Console.Write("Первое число: ");double a = double.Parse(Console.ReadLine());Console.Write("Второе число: ");double b = double.Parse(Console.ReadLine());Console.Write("Операция (+, -, *, /): ");string op = Console.ReadLine();switch (op){    case "+":        Console.WriteLine($"{a} + {b} = {a + b}");        break;    case "-":        Console.WriteLine($"{a} - {b} = {a - b}");        break;    case "*":        Console.WriteLine($"{a} * {b} = {a * b}");        break;    case "/":        if (b == 0)        {            Console.WriteLine("На ноль делить нельзя");        }        else        {            Console.WriteLine($"{a} / {b} = {a / b}");        }        break;    default:        Console.WriteLine("Неизвестная операция");        break;}

Обратите внимание: внутри case "/" у нас обычный if / else - потому что проверка «деление на ноль» уже не вписывается в равенство. switch и if отлично работают вместе.

Задача 3. Тернарный оператор

Спросите у пользователя число. С помощью тернарного оператора определите, чётное оно или нет, и выведите результат одной строкой.

Подсказка

Проверка на чётность - number % 2 == 0. Тернарный оператор выглядит так: условие ? "чётное" : "нечётное". Можно сразу вставить его внутрь интерполяции.

Решение учителя 
Console.Write("Введи число: ");int number = int.Parse(Console.ReadLine());Console.WriteLine(number % 2 == 0 ? "Чётное" : "Нечётное");

Всё в одной строке. Обратите внимание: результат тернарного оператора - это значение, поэтому его можно сразу передать в Console.WriteLine. Внутри интерполяции он тоже работает без проблем.

Задача 4. Меню на switch

Сделайте простое меню: пользователь вводит команду add, list, remove или quit. Программа выполняет соответствующее действие (например, просто выводит фразу «Добавляю...»). Если пользователь ввёл quit - выходим из программы.

Подсказка 1

Понадобится бесконечный цикл while (true). На каждой итерации спрашивайте команду и выполняйте её через switch. Команда quit должна сделать break - но не внутри switch, а из внешнего цикла.

Подсказка 2

Есть проблема: break внутри case "quit": выйдет из switch, а не из цикла. Чтобы выйти из цикла, используйте return; - он завершает программу целиком. Это простой способ для нашего случая.

Решение учителя 
while (true){    Console.Write("Команда (add / list / remove / quit): ");    string command = Console.ReadLine().ToLower();    switch (command)    {        case "add":            Console.WriteLine("Добавляю...");            break;        case "list":            Console.WriteLine("Показываю список...");            break;        case "remove":            Console.WriteLine("Удаляю...");            break;        case "quit":            Console.WriteLine("Пока!");            return;        default:            Console.WriteLine("Неизвестная команда");            break;    }}

Команда return завершает программу целиком - это простой способ выйти из бесконечного цикла. Позже, на среднем уровне, мы разберём более правильные способы, но для меню этого достаточно.
