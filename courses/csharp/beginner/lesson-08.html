Практика: игра «Угадай число»

~35 минут Начальный уровень Проект

Сегодня мы соберём первую настоящую игру. Не «привет, мир», не калькулятор - а игру, в которую можно играть и которая реагирует на действия пользователя. Игра называется «Угадай число»: программа загадывает число, а игрок пытается его отгадать, получая подсказки «больше» или «меньше».

Это не просто упражнение. Мы будем использовать всё, чему научились за семь уроков: переменные, ввод данных, условия, циклы, строки и случайные числа. Если что-то из прошлого подзабылось - это нормально, будем разбираться по ходу. А в конце мы даже заглянем немного в будущее и познакомимся с первой магией - методами.

Аналогия

Игра «горячо-холодно»: вы не знаете, где спрятано, но каждая подсказка сужает поиск. Программа делает то же с числом.

Что должна уметь игра

Прежде чем писать код, давайте опишем игру словами, как будто объясняем её другу:

  1. Программа загадывает случайное число от 1 до 100.
  2. Игрок вводит своё предположение.
  3. Программа говорит: «больше», «меньше» или «угадал!».
  4. Если не угадал - игрок пробует снова.
  5. Когда угадал - программа поздравляет и показывает количество попыток.

Отличный план. Теперь будем собирать игру по шагам - от простого к сложному. Каждый шаг добавляет одну новую деталь, и к концу урока получится готовая игра.

Шаг 1. Загадываем число

Первое, что нужно сделать - научить программу загадывать число. Мы уже умеем это делать из прошлого урока, используя Random:

Random rnd = new Random();int secret = rnd.Next(1, 101);

rnd.Next(1, 101) - это число от 1 до 100. Помним правило: минимум включается, максимум нет. Значит, 101 надо писать именно так, чтобы 100 тоже могло выпасть.

Переменную назвали secret - «секретное число». Имя должно говорить о том, что внутри. Не n, не x, а secret. Когда через месяц вы вернётесь к этому коду, сразу поймёте, что здесь загадано.

Для отладки

Пока пишете игру, полезно временно добавить строку Console.WriteLine($"Подсказка: {secret}"); - она покажет загаданное число. Так проще проверять логику. Когда игра заработает - уберите эту строку.

Шаг 2. Спрашиваем пользователя

Теперь нужно получить от игрока число. Здесь пригодится связка из третьего урока - Console.Write для вопроса и int.Parse(Console.ReadLine()) для получения числа: 

Console.Write("Угадай число от 1 до 100: ");int guess = int.Parse(Console.ReadLine());

Если запустить сейчас, программа загадает число, спросит ваше, но ничего не сделает - просто завершится. Это нормально, мы ещё не написали проверку. Переходим к следующему шагу.

Шаг 3. Сравниваем и подсказываем

Теперь самое интересное - сравнить предположение игрока с секретным числом и выдать подсказку. Здесь понадобятся условия из четвёртого урока:

if (guess == secret){    Console.WriteLine("Угадал!");}else if (guess < secret){    Console.WriteLine("Загаданное число больше");}else{    Console.WriteLine("Загаданное число меньше");}

Разберём логику:

  • Если guess == secret - числа совпали, победа.
  • Если guess < secret - игрок назвал меньше, чем было загадано. Значит, загаданное число больше. Не наоборот! Здесь новички часто путаются.
  • Иначе (значит, guess > secret) - игрок назвал слишком много, загаданное число меньше.

Шаг 4. Зацикливаем игру

Сейчас игра даёт только одну попытку. Это скучно - нужно повторять, пока игрок не угадает. Заворачиваем ввод и проверку в бесконечный цикл while (true) с выходом через break, как в пятом уроке: 

while (true){    Console.Write("Угадай число от 1 до 100: ");    int guess = int.Parse(Console.ReadLine());    if (guess == secret)    {        Console.WriteLine("Угадал!");        break;    }    else if (guess < secret)    {        Console.WriteLine("Загаданное число больше");    }    else    {        Console.WriteLine("Загаданное число меньше");    }}

Обратите внимание: break стоит внутри блока if, который срабатывает, только когда число угадано. Пока игрок ошибается, цикл продолжается. Как только угадал - выходим из цикла и идём дальше.

Шаг 5. Выносим проверку в отдельный метод

Прежде чем мы добавим подсчёт попыток, давайте обратим внимание на наш цикл. Смотрите, сколько всего внутри while: и ввод, и проверки, и вывод. Код становится громоздким.

В программировании есть замечательный инструмент, который позволяет «завернуть» кусок кода в отдельную коробочку и дать ей имя. Эта коробочка называется метод. Подробно мы будем проходить их в уроке 13, но давайте уже сейчас попробуем - на таком простом примере это будет очень кстати.

Давайте вынесем проверку числа в отдельный метод CheckGuess. Вот как он выглядит:

static bool CheckGuess(int guess, int secret){    if (guess == secret)    {        return true;    }    else if (guess < secret)    {        Console.WriteLine("Загаданное число больше");    }    else    {        Console.WriteLine("Загаданное число меньше");    }    return false;}

Давайте разберём эту магию:

  • static - пока просто пишите это слово, если создаёте метод внутри Program. Это обязательно.
  • bool - это тип того, что метод нам вернёт. bool значит «правда или ложь» (true или false). Метод будет отвечать на вопрос: «Игрок угадал?».
  • CheckGuess - имя метода, которое мы придумали сами.
  • (int guess, int secret) - в скобках мы говорим, что метод будет принимать два числа: то, что ввёл игрок, и то, что загадано.
  • return true; - если числа совпали, метод возвращает «правду» и сразу завершается.
  • return false; - если не совпали, метод доходит до этой строчки и возвращает «ложь».

Метод нужно писать внутри класса Program, но за пределами Main. Обычно его пишут прямо после закрывающей скобки Main.

А теперь посмотрите, каким чистым стал наш цикл в Main:

while (true){    Console.Write("Угадай число от 1 до 100: ");    int guess = int.Parse(Console.ReadLine());    if (CheckGuess(guess, secret))    {        Console.WriteLine("Угадал!");        break;    }}

Читается как обычный текст: «Спроси число. Если метод CheckGuess говорит, что угадал - выведи "Угадал!" и выйди из цикла». Всю грязную работу по сравнению чисел метод делает сам.

Что это было?

Мы только что использовали метод. Пока не переживайте, если не всё уложилось в голове. На данном этапе достаточно понять главную идею: мы можем дать имя куску кода и вызывать его по этому имени. Это делает основную программу короче и понятнее. А глубоко и подробно мы разберём методы в среднем уровне курса.

Шаг 6. Считаем попытки

Хочется знать, за сколько попыток игрок справился. Для этого нужен счётчик - как в пятом уроке, когда мы считали сумму чисел. Создаём переменную перед циклом и увеличиваем внутри:

int attempts = 0;while (true){    Console.Write("Угадай число от 1 до 100: ");    int guess = int.Parse(Console.ReadLine());    attempts++;    if (CheckGuess(guess, secret))    {        Console.WriteLine("Угадал!");        break;    }}

Строка attempts++ стоит сразу после ввода - увеличиваем счётчик один раз на каждую попытку игрока. Нет разницы, угадал он или нет - попытка была, значит, считаем.

Шаг 7. Поздравляем с победой

После выхода из цикла игрок победил, и у нас есть количество попыток. Осталось красиво его поздравить:

Console.WriteLine($"Победа! Ты угадал число {secret} за {attempts} попыток.");

Полный код игры

Соберём всё вместе. Именно так выглядит готовый код - целиком, от начала до конца:

C# 
using System;

namespace ConsoleApp1
{
    internal class Program
    {
        static void Main(string[] args)
        {
            Random rnd = new Random();
            int secret = rnd.Next(1, 101);
            int attempts = 0;

            Console.WriteLine("Я загадал число от 1 до 100. Попробуй угадать!");

            while (true)
            {
                Console.Write("Твоё предположение: ");
                int guess = int.Parse(Console.ReadLine());
                attempts++;

                if (CheckGuess(guess, secret))
                {
                    Console.WriteLine("Угадал!");
                    break;
                }
            }

            Console.WriteLine($"Победа! Ты угадал число {secret} за {attempts} попыток.");
        }

        static bool CheckGuess(int guess, int secret)
        {
            if (guess == secret)
            {
                return true;
            }
            else if (guess < secret)
            {
                Console.WriteLine("Загаданное число больше");
            }
            else
            {
                Console.WriteLine("Загаданное число меньше");
            }

            return false;
        }
    }
}

Запустите игру и сыграйте несколько раз. Меняйте число каждый раз - попробуйте угадать за минимум попыток. Оптимальная стратегия: каждый раз называть середину оставшегося диапазона, тогда число от 1 до 100 угадывается максимум за 7 попыток.

Шпаргалка

  • Random.Next(1, 101) случайное число от 1 до 100
  • int.TryParse безопасный разбор числа
  • while (true) цикл до победы
  • break выйти из цикла
  • attempts++ счётчик попыток
  • CheckGuess подсказка «больше/меньше»

Если что-то не работает

Игра собрана из кусочков разных уроков - и ошибки могут прийти откуда угодно. Проверьте по списку:

  • Программа падает с ошибкой при вводе. Скорее всего, пользователь ввёл текст вместо числа, и int.Parse не смог его преобразовать. Пока мы не умеем такое обрабатывать - это тема среднего уровня. Договоримся: вводим только цифры.
  • «Число больше» и «число меньше» путаются местами. Классическая ловушка. Запомните: если введённое число guess меньше загаданного secret, значит, загаданное больше - надо искать выше. И наоборот.
  • Программа зациклилась и не выходит. Проверьте, что break стоит внутри if (CheckGuess(...)) и что метод возвращает true, когда угадал.
  • Счётчик попыток всегда показывает 1 или 0. Убедитесь, что attempts++ стоит внутри цикла, после получения guess.
  • Ошибка: «The name 'CheckGuess' does not exist». Метод CheckGuess написан за пределами класса Program или вы забыли написать слово static перед bool.
  • Ошибка: «Not all code paths return a value». В методе CheckGuess не хватает return в самом конце. Если числа не равны - метод должен вернуть false.

Если ничего не помогло - напишите нам в Telegram, поможем разобраться.

Идеи для улучшения

Игра работает, но её можно сделать интереснее. Попробуйте реализовать одну или несколько из этих идей - каждая потребует совсем немного кода.

Ограничение попыток

Дайте игроку только 7 попыток. Если не угадал за 7 - программа сообщает секретное число и проигрывает.

Спрашивать имя игрока

В начале игры узнайте имя и обращайтесь к игроку по нему: «Привет, Алексей! Попробуй угадать…».

Подсказка «горячо-холодно»

Добавьте в метод CheckGuess ещё одну проверку. Посчитайте разницу между введённым и загаданным числом с помощью Math.Abs(guess - secret) (модуль числа). Если разница маленькая (меньше 5) - напишите дополнительно «Горячо!». Если большая - «Холодно».

Практика

Игра уже работает, но настоящий код отличается от учебного тем, что умеет переживать плохой ввод и неожиданные действия пользователя. Четыре задачи ниже - это те улучшения, которые чаще всего просят на первой работе.

Задача 1. Защита от букв

Сейчас программа падает, если вместо числа ввести текст. Замените int.Parse на int.TryParse и повторяйте ввод, пока пользователь не введёт корректное целое число.

Подсказка

int.TryParse возвращает bool: true, если разбор удался, и записывает результат в переменную через out. Поставьте его в цикл while (true) и выходите через break при успехе.

Решение учителя 
int guess;while (true){    Console.Write("Твоё предположение: ");    if (int.TryParse(Console.ReadLine(), out guess))    {        break;    }    Console.WriteLine("Нужно целое число. Попробуй ещё раз.");}
Задача 2. Играть ещё?

После победы спросите: «Сыграть ещё? (да/нет)». Если ответ «да» - начинайте новый раунд с новым секретным числом, иначе завершайте программу. Общий счёт побед выведите в конце.

Подсказка

Внешний цикл do ... while для раундов, внутри - счётчик побед. Секретное число генерируйте заново в начале каждого раунда.

Решение учителя 
int wins = 0;string answer;do{    // здесь играем раунд и получаем победу или поражение    wins++;    Console.Write("Сыграть ещё? (да/нет): ");    answer = Console.ReadLine();} while (answer == "да");Console.WriteLine($"Побед: {wins}");
Задача 3. Семь попыток

Ограничьте раунд семью попытками. После каждой попытки выводите, сколько осталось, а если игрок не угадал - покажите загаданное число.

Подсказка

Замените while (true) на for (int i = 1; i <= 7; i++) и храните флаг bool guessed, чтобы после цикла понять результат.

Решение учителя 
bool guessed = false;for (int i = 1; i <= 7; i++){    Console.Write($"Попытка {i} из 7: ");    int guess = int.Parse(Console.ReadLine());    if (CheckGuess(guess, secret))    {        guessed = true;        break;    }}if (!guessed){    Console.WriteLine($"Не угадал. Было число {secret}");}
Задача 4. Найдите ошибки

Код работает на правильном вводе, но в реальной жизни ведёт себя плохо. Найдите две проблемы.

while (true){    int guess = int.Parse(Console.ReadLine());    if (CheckGuess(guess, secret))    {        Console.WriteLine("Победа!");    }}
Подсказка

Первая проблема - int.Parse на тексте. Вторая - после победы цикл не заканчивается, потому что нет break.

Решение учителя 
while (true){    if (!int.TryParse(Console.ReadLine(), out int guess))    {        Console.WriteLine("Введите число");        continue;    }    if (CheckGuess(guess, secret))    {        Console.WriteLine("Победа!");        break;    }}

Что мы узнали и что дальше

Сегодня мы собрали первую настоящую игру. Это был большой шаг - от разрозненных фрагментов кода к работающей программе, которую можно запустить, показать другу и похвастаться.

Но самое главное - мы сделали первый, пусть и осторожный, шаг в мир методов. Мы увидели, как можно дать имя куску кода и тем самым разгрузить основной цикл игры. Пусть сейчас это кажется просто «магической строчкой», но фундамент уже заложен.
