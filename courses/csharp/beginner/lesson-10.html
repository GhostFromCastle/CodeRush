Массивы

~30 минут Начальный уровень Теория и Практика

Все переменные, которые мы создавали до этого, хранили одно значение: одно число, одну строку, один флаг. Это удобно для небольших задач, но представьте, что вам нужно сохранить оценки тридцати учеников класса. Создавать тридцать переменных score1, score2, score3 и так далее - это безумие.

Для таких случаев в программировании есть массивы. Это одна переменная, внутри которой хранится целая коллекция значений. Сегодня мы научимся их создавать, заполнять и перебирать.

Что такое массив

Представьте себе коробку для яиц. В ней десять ячеек, и в каждую можно положить что-то одинаковое - например, яйцо. Массив - это точно такая же коробка, только для чисел, строк или любых других данных.

У массива есть три главные характеристики:

  • Тип. Все элементы массива - одного типа. Либо все int, либо все string, либо все double. Смешивать нельзя.
  • Длина. Сколько ячеек внутри. Задаётся один раз при создании и не меняется.
  • Индексы. Номера ячеек. Начинаются с 0, а не с 1 - как и у строк.

Если у нас массив из пяти чисел, то у него пять ячеек с индексами 0, 1, 2, 3, 4. Последний индекс всегда на единицу меньше длины. Это правило мы уже видели в строках - здесь оно работает точно так же.

Создание массива

Массив создаётся почти как обычная переменная, но с квадратными скобками после типа:

int[] numbers = new int[5];

Разберём эту строку по частям:

  • int[] - тип «массив целых чисел». Квадратные скобки здесь означают «это не одно число, а целая коллекция чисел».
  • numbers - имя массива.
  • new int[5] - команда «создай массив из пяти ячеек типа int».

После этой строки у нас есть коробка на пять ячеек. Все они пока заполнены нулями - это значение по умолчанию для типа int. Для string по умолчанию будет null (пустое значение), для bool - false. Об этом мы поговорим чуть позже.

Заполняем массив

Заполнить массив можно двумя способами: по одному элементу или сразу всё вместе.

Способ 1: по одному элементу

Обращаемся к каждой ячейке по её индексу и кладём туда значение:

int[] numbers = new int[5];numbers[0] = 10;numbers[1] = 20;numbers[2] = 30;numbers[3] = 40;numbers[4] = 50;

Синтаксис такой же, как при обращении к символу строки: имя массива и индекс в квадратных скобках. Если написать numbers[2] = 30, то в третью ячейку (помним - индексы с нуля!) мы положили тридцать.

Способ 2: сразу с инициализацией

Если значения уже известны, можно записать их в одну строку, через запятую:

int[] numbers = { 10, 20, 30, 40, 50 };

Здесь мы не указываем длину явно - C# сам её посчитает: видит пять чисел, значит, длина массива пять. Такой способ часто используется, когда данные заданы заранее. Обратите внимание: фигурные скобки { } - это не блок кода, как в if, а список значений.

Читаем значения из массива

Прочитать элемент массива можно тем же способом - по индексу. И дальше делать с ним что угодно: выводить, складывать, сравнивать.

int[] numbers = { 10, 20, 30, 40, 50 };Console.WriteLine(numbers[0]);Console.WriteLine(numbers[4]);Console.WriteLine(numbers[1] + numbers[2]);

Программа выведет:

10
50
50

Третья строка складывает 20 и 30 и получает 50. Как видите, с элементами массива можно работать точно так же, как с обычными переменными - просто обращаться к ним чуть длиннее.

Длина массива: .Length

Как и у строки, у массива есть свойство .Length, которое показывает количество ячеек:

int[] numbers = { 10, 20, 30, 40, 50 };Console.WriteLine(numbers.Length);

Программа выведет 5. Свойство .Length доступно только для чтения - длину массива нельзя изменить после создания. Если нужно больше ячеек - придётся создать новый массив.

Перебираем массив циклом for

Заполнять и читать массив по одному элементу удобно, когда их мало. Но если у нас массив из ста чисел - это уже не вариант. Здесь на помощь приходит цикл for из пятого урока:

int[] numbers = { 10, 20, 30, 40, 50 };for (int i = 0; i < numbers.Length; i++){    Console.WriteLine(numbers[i]);}

Разберём логику:

  • Счётчик i идёт от 0. Это индекс элемента массива.
  • Условие i < numbers.Length - «пока не дошли до конца массива».
  • На каждом шаге мы берём numbers[i] - элемент под номером i.

Обратите внимание: мы не пишем число 5 напрямую. Используем numbers.Length. Это важно: если завтра массив станет больше, код продолжит работать без изменений. Такой стиль называется «код, устойчивый к изменениям».

Не путайте длину и последний индекс

Частая ошибка: написать i <= numbers.Length (со знаком «меньше или равно»). Кажется логичным: «до последнего элемента включительно». Но это неверно! Если длина 5, последний индекс - 4. Условие i <= 5 пропустит i = 5, а элемента с индексом 5 в массиве нет - программа упадёт с ошибкой «индекс вне границ». Всегда используйте <, а не <=.

Заполняем массив с клавиатуры

Один из самых частых сценариев: пользователь вводит данные, а мы складываем их в массив. Например, попросим ввести пять чисел и посчитаем их сумму:

int[] numbers = new int[5];int sum = 0;for (int i = 0; i < numbers.Length; i++){    Console.Write($"Введи число {i + 1}: ");    numbers[i] = int.Parse(Console.ReadLine());    sum += numbers[i];}Console.WriteLine($"Сумма всех чисел: {sum}");

Здесь всё логично: цикл идёт по всем индексам, на каждой итерации мы просим число и сразу кладём его в соответствующую ячейку. В i + 1 при выводе - простая косметика, чтобы пользователь видел «число 1» вместо «число 0».

Поиск максимума в массиве

Ещё одна классическая задача - найти наибольшее значение. Идея простая: запоминаем первый элемент как «пока что максимум», а потом сравниваем его с остальными.

int[] numbers = { 15, 42, 8, 99, 23 };int max = numbers[0];for (int i = 1; i < numbers.Length; i++){    if (numbers[i] > max)    {        max = numbers[i];    }}Console.WriteLine($"Максимум: {max}");

Обратите внимание: цикл начинается с i = 1, а не с нуля. Почему? Потому что нулевой элемент мы уже взяли как стартовое значение. Сравнивать его с самим собой смысла нет. Такой приём - «начальное значение из первого элемента» - используется очень часто.

Работа с массивом строк

Массивы бывают не только из чисел. Вот массив из строк - например, список покупок:

string[] shopping = { "Хлеб", "Молоко", "Сыр", "Яйца" };for (int i = 0; i < shopping.Length; i++){    Console.WriteLine($"{i + 1}. {shopping[i]}");}

Программа выведет пронумерованный список:

1. Хлеб
2. Молоко
3. Сыр
4. Яйца

С массивами строк работают точно так же, как с массивами чисел - разницы в синтаксисе нет. Только вместо int[] пишем string[].

Что внутри нового массива

Если создать массив и не заполнить его, все ячейки получат «значение по умолчанию». Для чисел это 0, для bool - false, а вот для string - null, то есть «ничего». Кстати, если попытаться вывести null на экран, программа ничего не покажет - просто пустую строку.

Шпаргалка по массивам

Самое важное в одном месте:

  • int[] arr = new int[5]; создать пустой массив
  • int[] arr = { 1, 2, 3 }; создать и сразу заполнить
  • arr[i] элемент по индексу
  • arr[i] = 5; записать значение
  • arr.Length длина массива
  • for (int i = 0; i < arr.Length; i++) перебор всех элементов

Если что-то не работает

Массивы - тема, где ошибки чаще всего связаны с индексами и границами. Проверьте по списку:

  • «IndexOutOfRangeException». Вы обратились к элементу, которого в массиве нет. Если массив из 5 элементов, индексы идут от 0 до 4. Последний индекс - это .Length - 1, а не .Length.
  • Цикл пропускает последний элемент или падает на нём. Классическая ошибка: i <= numbers.Length вместо i < numbers.Length. Запомните: < Length - правильно, <= Length - ошибка.
  • Массив создан, но при выводе все значения нули. Это нормально: если не заполнить массив, все ячейки получают значение по умолчанию. Для int это 0, для bool - false, для string - null.
  • «Use of unassigned local variable». Переменная объявлена, но не заполнена. Проверьте, что массив создан через new или через { ... }, и что все элементы, к которым вы обращаетесь, уже имеют значения.
  • Попытка изменить .Length. Длину массива после создания изменить нельзя. Если нужно больше ячеек - создавайте новый массив. Для гибких коллекций используйте List, о котором поговорим в следующем уроке.
  • Смешивание типов в массиве. Массив может хранить только элементы одного типа: либо все int, либо все string. Попытка положить строку в массив чисел вызовет ошибку компиляции.
  • Поиск максимума возвращает 0. Если массив из отрицательных чисел, а вы начали с max = 0 - получите неверный результат. Правильно: max = numbers[0], то есть первый элемент массива как стартовое значение.

Практика

Четыре задачи по возрастающей сложности. У каждой - подсказка и решение учителя. Сначала обязательно попробуйте сами.

Задача 1. Простой массив

Создайте массив из пяти чисел и выведите все его элементы на экран - каждое на новой строке.

Подсказка

Создайте массив через int[] numbers = { ... }; и пройдитесь по нему циклом for. Условие цикла - i < numbers.Length. Внутри - Console.WriteLine(numbers[i]).

Решение учителя 
int[] numbers = { 10, 25, 30, 47, 52 };for (int i = 0; i < numbers.Length; i++){    Console.WriteLine(numbers[i]);}

Числа можно взять любые - важно понять структуру цикла. Мы уже видели это в теории, теперь закрепим на практике.

Задача 2. Сумма и среднее

Дан массив чисел. Посчитайте их сумму и среднее арифметическое. Выведите оба результата.

Подсказка 1

Сумма считается через аккумулятор - как в пятом уроке. Создайте int sum = 0 перед циклом и прибавляйте каждый элемент внутри. Среднее - это sum, поделённое на длину.

Подсказка 2

Среднее арифметическое - это дробное число. Чтобы C# не потерял точность, используйте double для результата и приведите хотя бы одно из чисел к double через (double).

Решение учителя 
int[] numbers = { 10, 20, 30, 40, 50 };int sum = 0;for (int i = 0; i < numbers.Length; i++){    sum += numbers[i];}double average = (double)sum / numbers.Length;Console.WriteLine($"Сумма: {sum}");Console.WriteLine($"Среднее: {average}");

Если бы мы написали sum / numbers.Length без приведения к double - C# отбросил бы дробную часть и выдал бы «30» вместо «30.0». Приведение (double) заставляет его работать с дробными. Это стандартный приём - запомните.

Задача 3. Ввод с клавиатуры

Спросите у пользователя пять чисел и сохраните их в массив. Затем выведите массив на экран в обратном порядке (последний элемент - первым).

Подсказка 1

Первый цикл - обычный: от 0 до конца, читаем число в numbers[i]. Второй цикл - от numbers.Length - 1 вниз до 0 включительно. Шаг - i--.

Подсказка 2

Во втором цикле условие нужно записать как i >= 0. Обратите внимание: если использовать i > 0, то нулевой элемент не выведется.

Решение учителя 
int[] numbers = new int[5];for (int i = 0; i < numbers.Length; i++){    Console.Write($"Число {i + 1}: ");    numbers[i] = int.Parse(Console.ReadLine());}Console.WriteLine("В обратном порядке:");for (int i = numbers.Length - 1; i >= 0; i--){    Console.WriteLine(numbers[i]);}

Второй цикл - новый для нас. Здесь счётчик идёт не вверх, а вниз: начинаем с последнего индекса и доходим до нуля. Условие i >= 0 - включая ноль. Как только i станет −1, цикл завершится.

Задача 4. Сколько чётных

Дан массив чисел. Посчитайте, сколько из них чётные, и выведите результат.

Подсказка 1

Создайте счётчик int count = 0. Пройдитесь циклом по массиву. Внутри проверьте, чётное ли число.

Подсказка 2

Чётное число делится на 2 без остатка. В C# остаток от деления считается оператором %. Если numbers[i] % 2 == 0 - число чётное, увеличивайте счётчик.

Решение учителя 
int[] numbers = { 7, 12, 5, 8, 20, 33, 42 };int count = 0;for (int i = 0; i < numbers.Length; i++){    if (numbers[i] % 2 == 0)    {        count++;    }}Console.WriteLine($"Чётных чисел: {count}");

Оператор % называется «остаток от деления». Например, 7 % 2 = 1, а 8 % 2 = 0. Если остаток ноль - число делится на 2 нацело, значит, оно чётное. Этот приём используется постоянно, запомните его.

Что мы узнали и что дальше

Сегодня в нашем арсенале появилась первая настоящая коллекция - массив. Мы научились его создавать двумя способами, читать и записывать элементы по индексу, узнавать длину через .Length и перебирать все элементы циклом for. А ещё разобрали несколько классических приёмов: поиск максимума, подсчёт суммы, обход массива в обратном порядке, поиск чётных чисел.

Массивы - это фундамент для всего, что связано с хранением данных. Большая часть задач в программировании сводится к тому, чтобы «пройти по коллекции и что-то с ней сделать». Мы разобрали самый базовый способ - через for и индексы.

Но у массивов есть один недостаток - их размер нельзя менять. Если мы создали массив на пять элементов, то добавить шестой уже не получится. Именно поэтому в C# есть другие коллекции, более гибкие. В следующем уроке мы познакомимся с двумя самыми используемыми:

  • List<T> - «резиновый массив», в который можно добавлять и удалять элементы на ходу.
  • Dictionary<TKey, TValue> - «словарь», который хранит пары «ключ → значение» и мгновенно находит данные по ключу.

В следующих уроках мы закроем последние темы начального уровня: подробно разберём List и Dictionary с циклом foreach, а затем - оператор switch, тернарный оператор и ещё пару конструкций. А уже после этого двинемся в средний уровень, где будем писать более серьёзные проекты.
