Установка .NET и первая программа

~20 минут Начальный уровень Теория и Практика

Добро пожаловать в первый урок! Здесь мы не будем грузить вас сложными терминами. Просто поставим всё нужное и запустим вашу первую программу. К концу урока вы уже увидите на экране результат своего кода.

Что такое C# и зачем он нужен

Представьте, что компьютер - это иностранец, который понимает только свой язык. Чтобы объяснить ему, что делать, нужен «переводчик». C# - это один из таких языков. Вы пишете на нём команды, а компьютер их выполняет.

C# придумала компания Microsoft. На нём пишут игры (например, в Unity), приложения для Windows, сайты и программы для банков. Он считается одним из самых удобных языков для старта - синтаксис понятный, а сообщество огромное: если что-то не получается, ответ почти всегда можно найти в интернете.

Что нам понадобится

Чтобы писать код, нам нужны всего две вещи:

  • Программа, в которой мы будем писать. Она называется «среда разработки» - это как текстовый редактор, но с большим количеством подсказок и кнопок специально для программистов.
  • Инструмент, который превращает наш текст в рабочую программу. Он называется «.NET SDK». Хорошая новость: он установится сам вместе с редактором, отдельно скачивать его не придётся.

Шаг 1. Скачиваем Visual Studio

Мы будем использовать Visual Studio 2026 Community - это бесплатная программа от Microsoft, созданная специально для C#. В ней уже есть всё, что нужно новичку: подсказки, подсветка кода, автоматические исправления ошибок и кнопка «Запустить».

Скачать её можно на официальном сайте: visualstudio.microsoft.com/ru/downloads. Найдите кнопку «Скачать Visual Studio Community» и запустите установщик.

Шаг 2. Устанавливаем

Когда установщик откроется, он покажет список «рабочих нагрузок» - это как разделы в меню, где собрано всё для конкретной задачи. Нам нужен раздел «Разработка классических приложений .NET». Поставьте рядом с ним галочку и нажмите «Установить».

Установка займёт от 10 до 30 минут - это нормально. Программа скачивает много файлов. Можно пока пойти налить чай.

Если компьютер слабый или это Mac

Visual Studio 2026 хочет минимум 4 ГБ оперативной памяти, а для комфортной работы - 8 ГБ и больше. Если ваш компьютер слабее или вы на macOS/Linux, есть альтернатива - Visual Studio Code с расширением C# Dev Kit. Это тоже от Microsoft, но гораздо легче. Всё, что мы делаем в курсе, там тоже работает.

Шаг 3. Создаём первый проект

Откройте Visual Studio. Перед вами появится стартовое окно - выберите «Создать проект».

Откроется список шаблонов. Найдите «Консольное приложение» - это самая простая программа, которая выводит текст в чёрное окошко. Именно с неё начинают все.

На следующем экране:

  • Имя проекта: впишите HelloWorld. Так называется классическая первая программа в мире - «Привет, мир!».
  • Расположение: выберите любую папку, где вам удобно хранить проекты.
  • Галочка «Не использовать операторы верхнего уровня»: поставьте её. Что это значит - объясним чуть позже, когда у нас будет больше контекста. Пока просто поставьте.
  • Нажмите «Создать».

Visual Studio откроется и сама напишет за вас код первой программы. Нам останется только нажать кнопку «Запустить» - но давайте сначала разберёмся, что там написано.

Шаг 4. Смотрим, что за код нам дали

В центре экрана вы увидите файл с названием Program.cs и примерно такой текст:

using System;namespace ConsoleApp1{    internal class Program    {        static void Main(string[] args)        {            Console.WriteLine("Hello, World!");        }    }}

Сначала это выглядит как шифр. Но на самом деле всё проще, чем кажется. Разберём по строчкам.

Строка 1: using System;

Это как сказать компьютеру: «Я собираюсь пользоваться стандартным набором инструментов». Внутри System живёт главный инструмент, который умеет выводить текст на экран.

Строка 3: namespace ConsoleApp1

Это ещё одна «обёртка» вокруг всего кода. Слово namespace переводится как «пространство имён», а ConsoleApp1 - имя, которое Visual Studio подставила по названию проекта. Что это значит и зачем нужно - разберём чуть позже, когда у нас будет больше контекста. Пока просто знайте: это внешний контейнер, внутри которого живёт всё остальное.

Строка 5: internal class Program

В C# весь код живёт внутри «коробки», которая называется класс. Здесь наша коробка называется Program - «Программа». Слово internal пока не важно - это характеристика доступа, о которой поговорим в среднем уровне. Пока читайте эту строку просто как class Program.

Строка 7: static void Main(string[] args)

Это точка входа. Когда вы запускаете программу, компьютер ищет именно этот метод и начинает выполнять всё, что внутри него. Можно представить это как «дверь», через которую компьютер входит в вашу программу. Про string[] args пока можно не думать - это аргументы командной строки, до них мы дойдём позже.

Строка 9: Console.WriteLine("Hello, World!");

А вот это - сама команда. Console - это как окошко, в которое программа может что-то написать. WriteLine - «напиши строку». Всё вместе читается как: «Экран, напиши Hello, World!».

Про фигурные скобки { }

Они группируют код. Открывающая { говорит «здесь начинается блок», закрывающая } - «здесь он заканчивается». Как ящик: что внутри - то и относится к этому ящику. Именно поэтому у нас три пары скобок друг в друге - для namespace, для класса и для Main.

Пока не нужно всё запоминать

Не переживайте, если что-то пока не уложилось в голове. Через пару уроков вы будете смотреть на этот код, и он будет казаться абсолютно очевидным. Мы разберём каждую деталь отдельно.

Шаг 5. Запускаем программу

Найдите вверху зелёную кнопку с треугольником - на ней написано что-то вроде «HelloWorld» или «Запустить». Нажмите на неё (или клавишу F5).

Через пару секунд откроется чёрное окошко - Терминал / Консоль, в котором будет написано:

Hello, World!

Поздравляем - вы только что запустили свою первую программу. Это работает именно так, как вы написали (точнее, как за вас написала Visual Studio, но сейчас это не важно).

Шаг 6. Меняем текст на свой

Теперь самое интересное - а давайте заставим программу сказать что-то другое. Найдите строку:

Console.WriteLine("Hello, World!");

и замените текст в кавычках на свой. Например:

Console.WriteLine("Привет, я учу C#!");
Console.WriteLine("И это моя первая программа.");

Мы добавили ещё одну строку - теперь программа скажет две фразы подряд. Запустите ещё раз (кнопка с треугольником или F5) и посмотрите, что изменилось.

Обратите внимание: каждый WriteLine пишет текст с новой строки. Если бы мы использовали Write без «Line», текст печатался бы в одну строку без переносов.

Практика

Четыре задачи для закрепления материала. У каждой есть подсказка и решение учителя. Сначала обязательно попробуйте сами.

Задача 1. Визитная карточка

Напишите программу, которая выводит на экран три строки: ваше имя, ваш город и цель изучения C#. Каждая строка должна выводиться с новой строки.

Пример результата:

Меня зовут Алексей
Я живу в Москве
Хочу стать разработчиком
Подсказка

Используйте три отдельных команды Console.WriteLine. Не забудьте поставить точку с запятой в конце каждой строки.

Решение учителя 
Console.WriteLine("Меня зовут Алексей");Console.WriteLine("Я живу в Москве");Console.WriteLine("Хочу стать разработчиком");

Каждая команда WriteLine автоматически переносит курсор на следующую строку, поэтому код выведется в три строки.

Задача 2. Рамка из звездочек

Выведите на экран слово «ПРИВЕТ», обрамленное в рамку из звездочек. Каждая строка рамки и текст должны быть отдельными командами Console.WriteLine.

Пример результата:

**********
* ПРИВЕТ *
**********
Подсказка

Вам понадобятся три строки: верхняя рамка, текст с рамкой по бокам и нижняя рамка. Обратите внимание на пробелы вокруг слова «ПРИВЕТ», чтобы оно было по центру.

Решение учителя 
Console.WriteLine("**********");Console.WriteLine("* ПРИВЕТ *");Console.WriteLine("**********");
Задача 3. Стихотворение

Выведите на экран любое четверостишие (например, из известного стихотворения). Каждая строчка должна быть отдельной строкой в консоли.

Подсказка

Просто используйте четыре команды Console.WriteLine подряд.

Решение учителя 
Console.WriteLine("Мороз и солнце; день чудесный!");Console.WriteLine("Еще ты дремлешь, друг прелестный -");Console.WriteLine("Пора, красавица, проснись:");Console.WriteLine("Открой сомкнуты негой взоры...");
Задача 4. ASCII-картинка

Используя символы клавиатуры (звездочки, слеши, дефисы), нарисуйте в консоли простой домик. Используйте несколько команд Console.WriteLine.

Пример результата:

   /\
  /  \
 /____\
 |    |
 |____|
Подсказка

Следите за количеством пробелов в начале каждой строки, чтобы домик не съехал вбок. Символ обратного слеша \ в C# нужно экранировать: писать \\.

Решение учителя 
Console.WriteLine("   /\\");Console.WriteLine("  /  \\");Console.WriteLine(" /____\\");Console.WriteLine(" |    |");Console.WriteLine(" |____|");

Обратите внимание на двойной слеш \\. В C# одиночный слеш \ - это специальный символ (например, \n для переноса строки), поэтому чтобы вывести его на экран, нужно поставить два слеша.

Что мы узнали и что дальше

Мы прошли долгий путь: скачали и установили Visual Studio, создали проект, разобрали код первой программы и даже поменяли текст под себя. Это самая сложная часть урока - дальше будет легче.

В следующем уроке разберёмся с переменными - это как «коробочки», в которых можно хранить любые данные: числа, текст, галочки. Именно с них начинается настоящая логика программ.
