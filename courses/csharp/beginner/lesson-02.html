Переменные и типы данных

~20 минут Начальный уровень Теория и Практика

В первом уроке мы заставили программу сказать «Hello, World!» - но она просто повторила за нами готовую фразу. Настоящая программа должна уметь хранить данные и работать с ними. Сегодня мы разберёмся, как это делать с помощью переменных.

Важно: куда вставлять код

Прежде чем мы начнём, давайте на всякий случай освежим структуру программы. В прошлом уроке Visual Studio сгенерировала нам файл Program.cs. Если вы ставили галочку «Не использовать операторы верхнего уровня», он выглядит примерно так:

using System;namespace ConsoleApp1{    internal class Program    {        static void Main(string[] args)        {            Console.WriteLine("Hello, World!");        }    }}

Весь новый код в этом уроке нужно писать внутрь метода Main - то есть между его открывающей { и закрывающей }.

Новые строки кода добавляйте в тот же блок, где стоит Console.WriteLine - на одном уровне с ним, с тем же отступом.

Что будет, если вставить не туда

Если случайно вставить код не в Main, а, например, до class Program или после закрывающей скобки Main, программа не запустится. Visual Studio подчеркнёт строки красным и покажет ошибку. Не пугайтесь - это значит, что код лежит не на своём месте. Верните его внутрь Main - и всё заработает.

Что такое переменная

Представьте, что у вас на столе стоит несколько коробочек. В каждой лежит что-то своё: в одной - число, в другой - слово, в третьей - галочка. На каждой коробочке наклеена бумажка с именем, чтобы вы могли сказать компьютеру: «Возьми то, что в коробочке age».

Переменная - это и есть такая коробочка. Только вместо бумажки у неё есть имя, вместо содержимого - значение, и всё это живёт в памяти компьютера. Мы можем положить в неё что-то, потом достать, потом заменить на другое.

Главная мысль

Переменная - это именованное место в памяти, где хранится какое-то значение. Как ящик с наклейкой.

Зачем нужны типы

Компьютер очень педантичен: он хочет знать заранее, что именно лежит в коробочке - число, слово или что-то ещё. Потому что с числом можно складывать, а со словом - склеивать. Это разные действия.

Поэтому в C# у каждой переменной есть тип. Проще говоря, тип - это «форма» коробки: только для чисел, только для слов, только для галочек. Нам на первое время хватит четырёх типов.

Четыре главных типа

  • int - целые числа: 1, 42, -7, 2026. Без дробной части.
  • double - числа с дробной частью: 3.14, 99.9, -0.5. Название читается «дабл».
  • string - текст, то есть набор символов в кавычках: "Привет", "Hello, World!", "C#".
  • bool - логический тип, только два значения: true (истина) или false (ложь). Используется для галочек и проверок.

Не пытайтесь запомнить всё сразу. Через пару уроков вы будете использовать их на автомате, а пока просто знайте, что они есть.

Создаём первую переменную

Переменную в C# создают в два шага: сначала указывают тип и имя, а потом кладут в неё значение. Звучит сложно, но на практике это выглядит вот так. Эти четыре строки пишем внутри Main: 

int age = 25;string name = "Алексей";double pi = 3.14;bool isStudent = true;

Разберём каждую строку:

Строка 1: int age = 25;

Мы говорим компьютеру: «Создай коробочку для целых чисел, назови её age и положи туда число 25». Обратите внимание на знак = - он здесь не значит «равно» в математическом смысле. Он значит «положи справа в коробку слева».

Строка 2: string name = "Алексей";

То же самое, но для текста. Тип string (строка), имя name («имя»), а значение обязательно в двойных кавычках - иначе C# подумает, что это название какой-то команды, а не текст.

Строка 3: double pi = 3.14;

Число с дробной частью. Дробная часть отделяется точкой, а не запятой, как в русском языке. Это важно - если поставить запятую, C# запутается.

Строка 4: bool isStudent = true;

Логическое значение. true и false - это ключевые слова в C#, их нельзя писать с большой буквы, и нельзя взять в кавычки. Это как ответ «да/нет» на вопрос.

Используем переменные в выводе

Теперь самое интересное - давайте заставим программу напечатать содержимое наших коробочек. Пишем так (снова внутри Main):

int age = 25;string name = "Алексей";Console.WriteLine("Привет, " + name + "!");Console.WriteLine("Тебе " + age + " лет.");

Обратите внимание на строки 3 и 4. Мы используем +, чтобы склеить текст с переменной. Знак плюс в C# умеет не только складывать числа - если хотя бы одна сторона является текстом, он «соединяет» их в один текст.

На экране появится:

Привет, Алексей!
Тебе 25 лет.

Мы вставили пробелы внутри кавычек, чтобы между словами не было «слипания». Попробуйте убрать пробел - увидите, как получится «Привет,Алексей!». Мелочь, но так работают все строки.

Про кавычки

Внутри кавычек компьютер воспринимает текст буквально - в том числе пробелы и знаки. Именно поэтому все слова снаружи переменных и должны быть в кавычках: иначе C# подумает, что вы обращаетесь к какой-то переменной или команде.

Меняем значение

Переменная называется так именно потому, что её значение можно менять. Например, у пользователя может измениться возраст:

int age = 25;Console.WriteLine(age);age = 26;Console.WriteLine(age);

Программа напечатает:

25
26

Обратите внимание: в строке 3 мы не пишем int ещё раз. Тип указывается только в момент создания переменной. Когда вы просто присваиваете новое значение, достаточно написать имя и знак «равно».

Запомните разницу

int age = 25; - «создай коробочку и положи туда 25».
age = 26; - «найди коробочку age и замени её содержимое на 26».

Считаем числа

С числами можно делать обычные арифметические операции: складывать, вычитать, умножать и делить. Например:

int a = 10;int b = 3;int sum = a + b;Console.WriteLine("Сумма: " + sum);

Программа выведет Сумма: 13. Всё, что справа от знака «равно», сначала вычисляется, а потом результат кладётся в переменную слева. То есть компьютер сначала складывает 10 и 3, а потом создаёт переменную sum и кладёт туда 13.

Работаем с текстом

Со строками тоже можно делать полезные штуки. Например, соединять их вместе - мы уже видели это через +. Но есть способ ещё удобнее, который называется интерполяция. Сравните:

string name = "Алексей";int age = 25;Console.WriteLine("Меня зовут " + name + ", мне " + age + " лет.");Console.WriteLine($"Меня зовут {name}, мне {age} лет.");

Строки 3 и 4 выводят одно и то же. Но во второй мы поставили перед кавычкой знак $ и написали переменные прямо в тексте, обернув их в { }. Так гораздо удобнее: не надо разрывать фразу плюсами и следить за пробелами.

Интерполяция - это то, что вы будете использовать постоянно. Постарайтесь её запомнить.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя. Сначала обязательно попробуйте сами.

Задача 1. Визитка

Создайте три переменные: имя (string), возраст (int) и рост (double). Выведите их на экран одной строкой через интерполяцию.

Пример результата:

Меня зовут Алексей, мне 25 лет, мой рост 1.85 м.
Подсказка

Используйте $"..." перед строкой и вставьте переменные в фигурных скобках {name}. Для роста используйте тип double и напишите число через точку (например, 1.85).

Решение учителя 
string name = "Алексей";int age = 25;double height = 1.85;Console.WriteLine($"Меня зовут {name}, мне {age} лет, мой рост {height} м.");
Задача 2. Среднее арифметическое

Создайте три переменные с целыми числами (например, оценки ученика). Найдите их сумму и среднее арифметическое. Выведите оба результата.

Подсказка

Сумма вычисляется через +. Среднее - это сумма, поделённая на 3. Обратите внимание: если вы поделите int на int, дробная часть отбросится. Чтобы этого избежать, приведите одно из чисел к double: (double)sum / 3.

Решение учителя 
int grade1 = 4;int grade2 = 5;int grade3 = 3;int sum = grade1 + grade2 + grade3;double average = (double)sum / 3;Console.WriteLine($"Сумма: {sum}");Console.WriteLine($"Среднее: {average}");
Задача 3. Чек в магазине

Создайте переменные для названия товара (string), его цены (double) и количества (int). Выведите на экран чек в формате:

Товар: Кофе
Цена: 599.99
Количество: 3
Итого: 1799.97
Подсказка

Итоговую стоимость можно посчитать в отдельной переменной: double total = price * count;. Для вывода используйте интерполяцию.

Решение учителя 
string product = "Кофе";double price = 599.99;int count = 3;double total = price * count;Console.WriteLine($"Товар: {product}");Console.WriteLine($"Цена: {price}");Console.WriteLine($"Количество: {count}");Console.WriteLine($"Итого: {total}");
Задача 4. Логические значения

Создайте переменные isStudent (студент ли вы) и hasJob (есть ли у вас работа). Присвойте им значения true или false. Выведите их на экран.

Подсказка

Тип переменных должен быть bool. Значения пишутся с маленькой буквы без кавычек.

Решение учителя 
bool isStudent = true;bool hasJob = false;Console.WriteLine($"Студент: {isStudent}");Console.WriteLine($"Есть работа: {hasJob}");

Если что-то не работает

Не переживайте, если при запуске появилась ошибка. В 99% случаев это одно из типичных мест, которые легко поправить. Проверьте по списку:

  • Visual Studio подчёркивает код красным. Скорее всего, вы вставили строки не внутрь Main, а за его пределами. Вернитесь к началу урока, там наглядно показано, куда писать код.
  • «The name 'Console' does not exist». Проверьте самую первую строку файла - должна быть using System;. Если её случайно удалили, допишите обратно.
  • «; expected». Забыли точку с запятой в конце строки. В C# каждая инструкция заканчивается символом ;.
  • Ругается на дробное число. Поставьте точку, а не запятую: 3.14, а не 3,14.
  • «Cannot implicitly convert type 'string' to 'int'». Вы пытаетесь положить текст в переменную для чисел (или наоборот). Проверьте, что у каждой переменной правильный тип.

Если ничего не помогло - напишите нам в Telegram, поможем разобраться.

Что мы узнали и что дальше

Сегодня мы разобрались с самыми важными вещами: что такое переменные, зачем нужны типы, какие типы бывают и как с ними работать. Это фундамент - без переменных не будет ни одной настоящей программы.

В следующем уроке мы сделаем наши программы интерактивными: научим их задавать вопросы пользователю и получать от него ответы. Это называется «ввод данных». Вы разберётесь с командой Console.ReadLine и узнаете, как превращать введённый текст в числа. Настоящий диалог с пользователем - вот что нас ждёт.
