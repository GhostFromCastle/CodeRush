StringBuilder

~30 минут Средний уровень Теория и Практика

В шестом уроке мы научились склеивать строки через знак +. Это удобно, когда строк две или три: "Привет, " + name + "!". Но есть ситуация, когда такой подход превращается в катастрофу.

Представьте, что вам нужно собрать длинный текст из 10 000 строк. Например, сформировать отчет или вывести таблицу. Если делать это через `+` в цикле, программа начнет работать очень медленно.

Сегодня мы разберёмся, почему так происходит, и познакомимся с инструментом, который решает эту проблему - StringBuilder.

Почему `+` в цикле - это плохо

В C# строки (string) - это неизменяемые (immutable) объекты. Это значит, что после создания строки её нельзя изменить. Вообще.

Когда вы пишете text += "новая строка", C# не дописывает текст в конец существующей строки. Вместо этого он:

  1. Берет старую строку.
  2. Берет новую строку.
  3. Создает в памяти третью, совершенно новую строку, в которую копирует старую и новую.
  4. Старую строку выбрасывает в мусор.

Если мы склеиваем 10 000 строк в цикле, то на первой итерации создается 1 строка, на второй - еще 2, на третьей - еще 3. Итого в памяти будет создано более 50 миллионов символов! Компьютер будет тратить всё время на копирование памяти и сборку мусора.

Аналогия

Представьте, что вы пишете книгу. Вместо того чтобы просто дописывать слова на следующей странице, вы каждый раз переписываете всю книгу с нуля заново, чтобы добавить одно предложение. И так 10 000 раз. Вы сойдете с ума. Именно это и происходит со строкой через `+`.

Класс StringBuilder

StringBuilder (сборщик строк) решает эту проблему. Это как блокнот: вы просто дописываете в него новые строки, и он не создает каждый раз всё заново. Он хранит список изменений и создает финальную строку только тогда, когда вы сами об этом попросите.

Для использования StringBuilder нужно подключить пространство имен:

using System.Text;

Теперь создадим объект:

StringBuilder sb = new StringBuilder();

Основные методы

  • sb.Append(текст) - добавить текст в конец (аналог +=).
  • sb.AppendLine(текст) - добавить текст и перейти на новую строку.
  • sb.Clear() - очистить содержимое.
  • sb.ToString() - получить итоговую строку (то, ради чего всё и делалось).

Вот как выглядит правильное решение задачи с 10 000 строк:

StringBuilder sb = new StringBuilder();for (int i = 1; i <= 10000; i++){    sb.AppendLine($"Строка номер {i}");}string result = sb.ToString();Console.WriteLine(result);

Обратите внимание: мы вызываем ToString() в самом конце, когда всё собрано. Только в этот момент в памяти создастся одна финальная строка. Остальное время StringBuilder просто хранил кусочки текста.

Когда использовать StringBuilder

Не нужно везде и всегда использовать StringBuilder. Если вам нужно склеить три-четыре строки, обычный `+` работает быстрее и выглядит понятнее. Используйте StringBuilder, если:

  • Вы собираете текст в цикле.
  • Вам нужно склеить более 10-15 строк.
  • Вы генерируете HTML-код, SQL-запросы или большие отчеты.

Другие полезные методы

Помимо добавления в конец, StringBuilder умеет делать и другие вещи:

AppendFormat

Аналог интерполяции, но работает быстрее. Позволяет вставить значения в строку по шаблону:

string name = "Алексей";int age = 25;sb.AppendFormat("Пользователь: {0}, Возраст: {1}\n", name, age);

Фигурные скобки с цифрами - это плейсхолдеры. В них подставляются аргументы, переданные после строки (начиная с нулевого).

Insert и Replace

Insert вставляет текст в определенную позицию (по индексу), а Replace заменяет все вхождения подстроки:

sb.Insert(0, "Привет! ");sb.Replace("Привет", "Здравствуй");

Свойство Length

Как и у строки, у StringBuilder есть Length, который показывает текущую длину.

Замер производительности

Хотите увидеть разницу своими глазами? Вот код с использованием класса Stopwatch из System.Diagnostics, который замеряет время выполнения.

using System;using System.Text;using System.Diagnostics;class Program{    static void Main()    {        Stopwatch sw = new Stopwatch();        sw.Start();        string result = "";        for (int i = 0; i < 10000; i++)        {            result += i.ToString();        }        sw.Stop();        Console.WriteLine($"Строки (через +): {sw.ElapsedMilliseconds} мс");        sw.Restart();        StringBuilder sb = new StringBuilder();        for (int i = 0; i < 10000; i++)        {            sb.Append(i.ToString());        }        string result2 = sb.ToString();        sw.Stop();        Console.WriteLine($"StringBuilder: {sw.ElapsedMilliseconds} мс");    }}

Если вы запустите этот код, то увидите, что разница может достигать нескольких секунд против нескольких миллисекунд. В реальных проектах это критично.

Шпаргалка

Самое важное в одном месте:

  • using System.Text; подключить пространство имен
  • new StringBuilder() создать сборщик
  • sb.Append(x) добавить в конец
  • sb.AppendLine(x) добавить с новой строки
  • sb.ToString() получить готовую строку
  • sb.Clear() очистить
  • sb.Replace(a, b) заменить

Если что-то не работает

Разберём типичные проблемы при работе со StringBuilder.

  • «The type or namespace name 'StringBuilder' could not be found». Забыли добавить using System.Text; в самом верху файла.
  • Программа выводит на экран «System.Text.StringBuilder» вместо текста. Вы пытаетесь вывести сам объект sb в Console.WriteLine, но забыли вызвать .ToString().
  • Не работает метод .Length или .ToUpper(). Помните, что StringBuilder - это не строка. У него нет методов строк (например, ToUpper, Split, Trim). Сначала получите строку через .ToString(), а потом уже вызывайте методы.
  • «IndexOutOfRangeException» в Insert. Вы пытаетесь вставить текст на позицию, которой не существует. Индекс должен быть от 0 до sb.Length.

Если что-то не получается - напишите нам в Telegram, разберёмся вместе.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Красивая рамка

Напишите программу, которая выводит слово «Привет» внутри красивой рамки из символов =.

========
Привет!
========
Подсказка

Создайте StringBuilder. Сначала добавьте строку из символов =. Потом слово. В конце снова рамку. Не забудьте про AppendLine для переноса строк.

Решение учителя 
StringBuilder sb = new StringBuilder();sb.AppendLine("========");sb.AppendLine("Привет!");sb.AppendLine("========");Console.WriteLine(sb.ToString());
Задача 2. Генерация списка

Создайте список строк (например, список покупок). Используя StringBuilder и цикл foreach, соберите все элементы в одну строку, где каждый элемент начинается с новой строки и с дефиса. Выведите результат.

Подсказка

Внутри цикла используйте метод AppendLine("- " + item).

Решение учителя 
var products = new List<string> { "Хлеб", "Молоко", "Сыр" };StringBuilder sb = new StringBuilder();foreach (string item in products){    sb.AppendLine("- " + item);}Console.WriteLine(sb.ToString());
Задача 3. Генератор HTML

Напишите программу, которая создает простую HTML-страницу с заголовком и параграфом. Используйте StringBuilder для сборки тегов <html>, <head>, <body>, <h1> и <p>. Сохраните результат в строку и выведите в консоль.

Подсказка

Добавляйте теги по одному через AppendLine. Это идеальный пример использования StringBuilder, так как HTML состоит из множества строк.

Решение учителя 
StringBuilder html = new StringBuilder();html.AppendLine("<html>");html.AppendLine("<head><title>Моя страница</title></head>");html.AppendLine("<body>");html.AppendLine("  <h1>Добро пожаловать!</h1>");html.AppendLine("  <p>Этот код собран через StringBuilder.</p>");html.AppendLine("</body>");html.AppendLine("</html>");Console.WriteLine(html.ToString());

Обратите внимание, что в C# для вывода HTML-тегов в консоль нам пришлось экранировать угловые скобки: &lt; вместо <. В реальном коде при сохранении в файл этого делать не нужно.

Задача 4. Очистка и повторное использование

Создайте StringBuilder. Добавьте в него три любые строки. Выведите результат. Затем очистите его с помощью Clear() и добавьте три других строки. Снова выведите результат. Убедитесь, что старые строки исчезли.

Подсказка

Метод Clear() не удаляет сам объект, а просто делает его пустым. Вы можете продолжать добавлять в него новые данные.

Решение учителя 
StringBuilder sb = new StringBuilder();sb.AppendLine("Первая строка");sb.AppendLine("Вторая строка");sb.AppendLine("Третья строка");Console.WriteLine("До очистки:");Console.WriteLine(sb.ToString());sb.Clear();sb.AppendLine("Совсем новый текст");sb.AppendLine("И еще один");Console.WriteLine("После очистки:");Console.WriteLine(sb.ToString());
