Классы и объекты

~35 минут Средний уровень Теория и Практика

Это очень важный урок. Если до этого мы работали с отдельными переменными (числами, строками, массивами), то сейчас мы научимся создавать свои собственные типы данных. Это называется объектно-ориентированным программированием, и без этого не обходится ни один серьёзный проект.

Проблема, которую нужно решить

Представьте, что мы пишем программу для университета. Нам нужно хранить данные о студентах. У каждого студента есть имя, возраст и средний балл.

Давайте попробуем сделать это теми инструментами, что у нас уже есть. Первое, что приходит в голову - три отдельных переменных на одного студента:

string student1Name = "Алексей";int student1Age = 20;double student1Gpa = 4.5;

Работает. Но если студентов станет десять? Придётся создавать тридцать переменных с именами student1Name, student2Name и так далее. А если сто?

Можно попробовать параллельные массивы: один для имён, один для возрастов, один для баллов. Уже лучше, но сложно гарантировать, что names[3] и ages[3] относятся к одному и тому же студенту. Один неверный индекс - и данные перепутаются.

И самое главное: нет ощущения, что все три значения принадлежат одному студенту. Они просто лежат рядом, но никак не связаны.

Именно для таких случаев придумали классы. Класс позволяет собрать связанные данные в одну коробку и дать этой коробке имя.

Что такое класс и объект

Аналогия простая. Представьте анкету. Обычная бумажная анкета с полями: имя, возраст, средний балл. Анкета - это шаблон, по которому мы заполняем данные о конкретном студенте.

В C# класс - это как пустая анкета. Она описывает, какие поля будут у каждого студента. Но сама по себе она ничего не хранит.

Объект - это уже заполненная анкета. Конкретный студент с конкретным именем, возрастом и баллом.

Главная мысль

Класс - это чертёж. Объект - это построенный по чертежу дом. По одному чертежу можно построить тысячу домов, и каждый будет отдельным объектом со своими жильцами. Точно так же по одному классу можно создать тысячу объектов, и у каждого будут свои значения в полях.

Первый класс

Давайте опишем класс Student - шаблон для студента. Вот как это выглядит:

class Student{    public string Name;    public int Age;    public double Gpa;}

Разберём по частям:

  • class Student - "создаю новый класс с именем Student". По стилю C# имена классов пишутся с большой буквы.
  • { ... } - тело класса, где перечисляются его поля.
  • public string Name; - поле имени. Тип string, имя Name.
  • public int Age; - поле возраста. Тип int.
  • public double Gpa; - поле среднего балла. Тип double.

Слово public означает "публичный". Пока просто запомните: для полей класса нужно писать public, чтобы мы могли обращаться к ним из Main.

Где писать класс

Класс Student нужно объявить внутри класса Program, но за пределами Main. Проще всего - сразу после Main, перед закрывающей скобкой класса Program. 

using System;namespace ConsoleApp1{    internal class Program    {        static void Main(string[] args)        {            ...        }        class Student        {            public string Name;            public int Age;            public double Gpa;        }    }}

Создаём первый объект

Класс Student - это только шаблон. Чтобы создать конкретного студента, нужно написать в Main вот такую строку: 

Student alexey = new Student();

Разберём:

  • Student слева - тип переменной. То есть alexey будет объектом типа Student.
  • alexey - имя переменной.
  • new Student() - команда "создай новый объект по шаблону Student".

После этой строки у нас есть объект alexey. Все его поля пока пустые: имя null, возраст 0, средний балл 0.

Заполняем поля объекта

Теперь нужно положить в поля конкретные значения. Обращаемся к ним через точку:

Student alexey = new Student();alexey.Name = "Алексей";alexey.Age = 20;alexey.Gpa = 4.5;

Точка работает как "принадлежность". alexey.Name читается как "имя Алексея". Мы говорим компьютеру: "возьми поле Name у объекта alexey и положи туда строку".

Читаем поля объекта

Читается так же - через точку:

Console.WriteLine(alexey.Name);Console.WriteLine(alexey.Age);Console.WriteLine(alexey.Gpa);

Создаём нескольких студентов

А вот где классы раскрываются во всей красе. Давайте создадим трёх студентов:

Student alexey = new Student();alexey.Name = "Алексей";alexey.Age = 20;alexey.Gpa = 4.5;Student maria = new Student();maria.Name = "Мария";maria.Age = 19;maria.Gpa = 4.8;

Два объекта - два отдельных студента. У каждого свои значения в полях. Они не мешают друг другу. Изменение maria.Age никак не влияет на alexey.Age.

А теперь - самое интересное. Объекты можно складывать в коллекции, как мы делали с числами и строками. Вот массив студентов:

Student[] group = { alexey, maria };foreach (Student student in group){    Console.WriteLine($"{student.Name}, {student.Age} лет");}

Представьте, что теперь у нас сто студентов. Мы просто создаём сто объектов и складываем их в список. Кода - пять строк, а порядок идеальный: каждый студент вместе со всеми своими данными.

Методы внутри класса

Поля - это данные. Но класс может не только хранить данные, но и делать что-то. Для этого внутри класса описывают методы.

Давайте добавим нашему студенту метод, который печатает о нём информацию:

class Student{    public string Name;    public int Age;    public double Gpa;    public void Print()    {        Console.WriteLine($"{Name}, {Age} лет, средний балл {Gpa}");    }}

Внутри метода Print мы используем поля Name, Age и Gpa без указания объекта. Это работает потому, что метод находится внутри класса - он как бы "знает" про свои поля.

А вызывается метод через точку, как и поля:

alexey.Print();maria.Print();

Каждый объект печатает про себя. И если завтра мы решим поменять формат вывода - правим только внутри метода, а не в каждом месте программы.

Метод, который меняет поля

Метод может не только читать поля, но и менять их. Добавим студенту метод "отметить день рождения": 

public void CelebrateBirthday(){    Age++;    Console.WriteLine($"{Name} отмечает день рождения. Теперь ему {Age}.");}

Теперь можно делать так:

alexey.CelebrateBirthday();

Возраст объекта alexey увеличится на 1. У maria возраст не изменится - у неё свой день рождения.

Конструктор

Создавать объект и потом отдельно заполнять поля через точку - неудобно. Если у нас двадцать полей, придётся написать двадцать строк. А если забудем заполнить одно - получим ошибку в самый неподходящий момент.

Решить эту проблему помогает конструктор. Это специальный метод, который вызывается автоматически при создании объекта. Его задача - сразу заполнить все важные поля.

Вот как выглядит класс Student с конструктором:

class Student{    public string Name;    public int Age;    public double Gpa;    public Student(string name, int age, double gpa)    {        Name = name;        Age = age;        Gpa = gpa;    }    public void Print()    {        Console.WriteLine($"{Name}, {Age} лет, средний балл {Gpa}");    }}

Обратите внимание:

  • Имя совпадает с именем класса - Student. Это обязательное правило.
  • Нет типа возврата, даже void не пишется.
  • Внутри - присваивание параметров полям. Параметр name (с маленькой буквы) кладём в поле Name (с большой).

Теперь создавать студентов стало проще:

Student alexey = new Student("Алексей", 20, 4.5);Student maria = new Student("Мария", 19, 4.8);

Одна строка на студента. Все поля заполнены сразу. Ничего не забудем.

Аналогия

Конструктор - это как заполнение анкеты прямо при рождении. Вы не выдаёте человеку пустой бланк и не просите заполнить позже. Вы сразу говорите: "Вот его имя, возраст и балл". Анкета заполнена с первой секунды.

Конструктор по умолчанию

Заметили, что раньше мы писали new Student() без аргументов, и это работало? Дело в том, что C# автоматически создаёт конструктор без параметров, если вы не написали свой.

Но как только вы написали свой конструктор (с параметрами), C# перестаёт создавать автоматический. Теперь new Student() без аргументов перестанет работать.

Собираем всё вместе

Давайте посмотрим на полную программу.

using System;namespace ConsoleApp1{    internal class Program    {        static void Main(string[] args)        {            Student alexey = new Student("Алексей", 20, 4.5);            Student maria = new Student("Мария", 19, 4.8);            alexey.Print();            maria.Print();            alexey.CelebrateBirthday();            alexey.Print();        }        class Student        {            public string Name;            public int Age;            public double Gpa;            public Student(string name, int age, double gpa)            {                Name = name;                Age = age;                Gpa = gpa;            }            public void Print()            {                Console.WriteLine($"{Name}, {Age} лет, средний балл {Gpa}");            }            public void CelebrateBirthday()            {                Age++;                Console.WriteLine($"{Name} отмечает день рождения. Теперь ему {Age}.");            }        }    }}

Это уже настоящая маленькая программа со своей структурой. Данные о студентах хранятся в одном месте, действия над ними - тоже. Всё логично и связано.

Шпаргалка

Самое важное в одном месте:

  • class Name { } объявление класса
  • new Name() создание объекта
  • obj.Field обращение к полю
  • obj.Method() вызов метода объекта
  • public Name(...) конструктор

Если что-то не работает

Классы - тема, где легко запутаться в самых разных мелочах. Проверьте по списку:

  • "An object reference is required for the non-static field, method, or property". Вы пытаетесь обратиться к обычному методу или полю класса, не создав объект. Например, пишете Print() вместо alexey.Print(). Создайте объект через new.
  • "'Student' does not contain a constructor that takes 0 arguments". Вы написали свой конструктор с параметрами, а теперь пытаетесь вызвать new Student() без аргументов. C# не создаёт автоматический конструктор, если вы написали свой. Либо добавьте свой конструктор без параметров, либо всегда передавайте аргументы.
  • "A namespace cannot directly contain members such as fields or methods". Скорее всего, класс Student случайно объявлен вне класса Program, прямо в namespace.
  • "Cannot access private member". Поле или метод помечены как private, а вы пытаетесь к ним обратиться снаружи. Проверьте, что нужное поле или метод имеют public.
  • Ошибка в конструкторе: параметр и поле имеют одно имя. Такое public Student(string Name) { Name = Name; } не работает так, как вы думаете. Параметр с именем Name "закрывает" поле с тем же именем. Назовите параметр по-другому (name с маленькой буквы).
  • Один объект изменяется, а ожидаете, что изменятся все. Каждый объект - отдельная коробка со своими значениями. Изменение одного не влияет на другие.

Если ничего не помогло - напишите нам в Telegram, поможем разобраться.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Класс Book

Создайте класс Book с полями Title, Author и Year. Создайте два объекта с разными книгами и выведите их на экран.

Подсказка

Типы полей: Title и Author - string, Year - int. Все три - с public. Класс создавайте после Main, внутри Program. Объект создаётся через new, поля заполняются через точку.

Решение учителя 
class Book{    public string Title;    public string Author;    public int Year;}static void Main(string[] args){    Book first = new Book();    first.Title = "Мастер и Маргарита";    first.Author = "Михаил Булгаков";    first.Year = 1967;    Book second = new Book();    second.Title = "Преступление и наказание";    second.Author = "Фёдор Достоевский";    second.Year = 1866;    Console.WriteLine($"{first.Title} - {first.Author}, {first.Year}");    Console.WriteLine($"{second.Title} - {second.Author}, {second.Year}");}
Задача 2. Метод внутри класса

Добавьте в класс Book из прошлой задачи метод Print, который печатает информацию о книге в формате "Автор, "Название" (год)". Вызовите метод для обеих книг.

Подсказка

Метод возвращает void, без параметров. Внутри - один Console.WriteLine с интерполяцией. Кавычки внутри строки можно поставить как символы \".

Решение учителя 
class Book{    public string Title;    public string Author;    public int Year;    public void Print()    {        Console.WriteLine($"{Author}, \"{Title}\" ({Year})");    }}static void Main(string[] args){    Book first = new Book();    first.Title = "Мастер и Маргарита";    first.Author = "Михаил Булгаков";    first.Year = 1967;    Book second = new Book();    second.Title = "Преступление и наказание";    second.Author = "Фёдор Достоевский";    second.Year = 1866;    first.Print();    second.Print();}

Обратите внимание на \" внутри строки - так в C# записываются кавычки внутри строки.

Задача 3. Конструктор для книги

Добавьте в класс Book конструктор, который принимает название, автора и год. Создайте три книги одной строкой каждая. Выведите их через метод Print.

Подсказка

Конструктор называется Book (как класс), без типа возврата. Параметры: string title, string author, int year. Внутри - присваивания вида Title = title;.

Решение учителя 
class Book{    public string Title;    public string Author;    public int Year;    public Book(string title, string author, int year)    {        Title = title;        Author = author;        Year = year;    }    public void Print()    {        Console.WriteLine($"{Author}, \"{Title}\" ({Year})");    }}static void Main(string[] args){    Book first = new Book("Мастер и Маргарита", "Михаил Булгаков", 1967);    Book second = new Book("Преступление и наказание", "Фёдор Достоевский", 1866);    Book third = new Book("Война и мир", "Лев Толстой", 1869);    first.Print();    second.Print();    third.Print();}
Задача 4. Список книг

Создайте List<Book> с пятью книгами. Выведите их через foreach. Затем найдите самую старую книгу и выведите её отдельно.

Подсказка 1

Список создаётся как new List<Book>(). Добавляйте книги через .Add(...).

Подсказка 2

Поиск самой старой книги делается так же, как поиск максимума в уроке 14 - только теперь сравниваем не числа, а поля Year. Начинаем с первой книги и обновляем при нахождении меньшего года.

Решение учителя 
static void Main(string[] args){    var books = new List<Book>();    books.Add(new Book("Мастер и Маргарита", "Михаил Булгаков", 1967));    books.Add(new Book("Преступление и наказание", "Фёдор Достоевский", 1866));    books.Add(new Book("Война и мир", "Лев Толстой", 1869));    books.Add(new Book("Отцы и дети", "Иван Тургенев", 1862));    books.Add(new Book("Мёртвые души", "Николай Гоголь", 1842));    foreach (Book book in books)    {        book.Print();    }    Book oldest = books[0];    foreach (Book book in books)    {        if (book.Year < oldest.Year)        {            oldest = book;        }    }    Console.WriteLine();    Console.WriteLine("Самая старая книга:");    oldest.Print();}

Алгоритм поиска точно такой же, как в уроке про массивы - просто теперь мы сравниваем не числа, а одно из полей объекта.

Что мы узнали и что дальше

Сегодня мы сделали огромный шаг. Научились создавать собственные типы данных - классы. Разобрались, что класс - это чертёж, а объект - конкретная вещь, сделанная по этому чертежу. Научились объявлять поля, методы и конструкторы.

Теперь мы можем описывать в коде не только отдельные числа и строки, но целые сущности: студента, книгу, товар, персонажа игры. Каждая такая сущность хранит все свои данные в одном месте и умеет делать то, что ей положено. Это и есть настоящий объектно-ориентированный подход.

В следующем уроке мы разберём инкапсуляцию. Это способ защитить данные объекта от случайных изменений снаружи. Мы узнаем, зачем нужны свойства (get и set), и почему делать все поля публичными (public) - не самая лучшая идея.
