Проект: Крестики-нолики

~45 минут Средний уровень Проект

Вот и настал момент, когда мы соберём всё, чему научились за 10 уроков, в один полноценный проект. Мы напишем консольную игру «Крестики-нолики». Это классика, которая отлично тренирует логику, работу с массивами и написание чистого кода.

Правила игры

Думаю, все знают правила, но давайте зафиксируем их для программы:

  • Есть поле 3 на 3.
  • Игроки по очереди ставят свой знак (X или O).
  • Первый игрок всегда ходит крестиками (X).
  • Побеждает тот, кто первым соберёт три своих знака в ряд (по горизонтали, вертикали или диагонали).
  • Если поле заполнилось, а победителя нет - ничья.

Шаг 1: Игровое поле

Поле удобнее всего хранить в виде двумерного массива символов (char). Изначально все ячейки пустые. Чтобы игроку было проще ориентироваться, мы можем заполнить их номерами от 1 до 9. Тогда игрок сможет просто ввести цифру, чтобы поставить знак.

char[,] board = {    { '1', '2', '3' },    { '4', '5', '6' },    { '7', '8', '9' }};

Шаг 2: Рисуем поле

Чтобы игра выглядела красиво, напишем метод PrintBoard, который будет выводить сетку с разделителями.

static void PrintBoard(char[,] board){    Console.WriteLine();    for (int i = 0; i < 3; i++)    {        Console.WriteLine($" {board[i, 0]} | {board[i, 1]} | {board[i, 2]} ");        if (i < 2)        {            Console.WriteLine("---+---+---");        }    }    Console.WriteLine();}

На экране это будет выглядеть так:

 1 | 2 | 3 
---+---+---
 4 | 5 | 6 
---+---+---
 7 | 8 | 9

Шаг 3: Проверка победы

Самый важный метод в игре. Нам нужно проверить 3 строки, 3 столбца и 2 диагонали. Если где-то собрались три одинаковых символа (и это не пробел и не цифра, а именно знак игрока) - значит, победа.

static bool CheckWin(char[,] board, char player){    for (int i = 0; i < 3; i++)    {        if (board[i, 0] == player && board[i, 1] == player && board[i, 2] == player)            return true;                if (board[0, i] == player && board[1, i] == player && board[2, i] == player)            return true;    }    if (board[0, 0] == player && board[1, 1] == player && board[2, 2] == player)        return true;    if (board[0, 2] == player && board[1, 1] == player && board[2, 0] == player)        return true;    return false;}

Обратите внимание, как мы проверяем столбцы и строки в одном цикле. Нам не нужно писать 8 отдельных условий - мы используем цикл, чтобы пройтись по всем индексам.

Шаг 4: Обработка хода игрока

Игрок вводит число от 1 до 9. Нам нужно:

  1. Преобразовать это число в индексы строки и столбца.
  2. Проверить, что ячейка ещё не занята.
  3. Поставить туда знак игрока.
static bool MakeMove(char[,] board, int move, char player){    int row = (move - 1) / 3;    int col = (move - 1) % 3;    if (board[row, col] == 'X' || board[row, col] == 'O')    {        Console.WriteLine("Эта ячейка уже занята!");        return false;    }    board[row, col] = player;    return true;}

Здесь есть небольшая математическая хитрость. Если игрок ввёл 5 (центр), то:

  • (5 - 1) / 3 = 4 / 3 = 1 (это строка 1).
  • (5 - 1) % 3 = 4 % 3 = 1 (это столбец 1).

Индексы [1, 1] - это действительно центр.

Шаг 5: Главный цикл игры

Теперь собираем всё вместе в методе Main. У нас будет бесконечный цикл, внутри которого мы по очереди даём ход игрокам, пока кто-то не победит или не закончатся ходы.

static void Main(string[] args){    char[,] board = {        { '1', '2', '3' },        { '4', '5', '6' },        { '7', '8', '9' }    };    char currentPlayer = 'X';    int movesCount = 0;    while (true)    {        PrintBoard(board);        Console.WriteLine($"Ход игрока {currentPlayer}. Введите число от 1 до 9:");        try        {            int move = int.Parse(Console.ReadLine());                        if (move < 1 || move > 9)            {                Console.WriteLine("Нужно ввести число от 1 до 9!");                continue;            }            if (!MakeMove(board, move, currentPlayer))            {                continue;            }            movesCount++;            if (CheckWin(board, currentPlayer))            {                PrintBoard(board);                Console.WriteLine($"Победил игрок {currentPlayer}!");                break;            }            if (movesCount == 9)            {                PrintBoard(board);                Console.WriteLine("Ничья!");                break;            }            currentPlayer = currentPlayer == 'X' ? 'O' : 'X';        }        catch (FormatException)        {            Console.WriteLine("Ошибка: введите число!");        }    }    Console.WriteLine("Игра окончена.");}

Обратите внимание на строку currentPlayer = currentPlayer == 'X' ? 'O' : 'X';. Это тернарный оператор (урок 12). Он меняет игрока: если был X, станет O, и наоборот.

Собираем весь код вместе

Вот как выглядит полный код программы, если собрать все методы в один файл:

using System;namespace ConsoleApp1{    internal class Program    {        static void Main(string[] args)        {            char[,] board = {                { '1', '2', '3' },                { '4', '5', '6' },                { '7', '8', '9' }            };            char currentPlayer = 'X';            int movesCount = 0;            while (true)            {                PrintBoard(board);                Console.WriteLine($"Ход игрока {currentPlayer}. 'O' : 'X';                }                catch (FormatException)                {                    Console.WriteLine("Ошибка: введите число!");                }            }            Console.WriteLine("Игра окончена.");        }        static void PrintBoard(char[,] board)        {            Console.WriteLine();            for (int i = 0; i < 3; i++)            {                Console.WriteLine($" {board[i, 0]} | {board[i, 1]} | {board[i, 2]} ");                if (i < 2)                {                    Console.WriteLine("---+---+---");                }            }            Console.WriteLine();        }        static bool MakeMove(char[,] board, int move, char player)        {            int row = (move - 1) / 3;            int col = (move - 1) % 3;            if (board[row, col] == 'X' || board[row, col] == 'O')            {                Console.WriteLine("Эта ячейка уже занята!");                return false;            }            board[row, col] = player;            return true;        }        static bool CheckWin(char[,] board, char player)        {            for (int i = 0; i < 3; i++)            {                if (board[i, 0] == player && board[i, 1] == player && board[i, 2] == player)                    return true;                                if (board[0, i] == player && board[1, i] == player && board[2, i] == player)                    return true;            }            if (board[0, 0] == player && board[1, 1] == player && board[2, 2] == player)                return true;            if (board[0, 2] == player && board[1, 1] == player && board[2, 0] == player)                return true;            return false;        }    }}

Если что-то не работает

  • Программа падает с ошибкой IndexOutOfRangeException. Проверьте метод MakeMove. Если пользователь вводит 0 или число больше 9, формула будет считать неправильно. Убедитесь, что проверка move < 1 || move > 9 работает.
  • Победа не засчитывается. Проверьте метод CheckWin. В строках и столбцах должны быть индексы от 0 до 2. Убедитесь, что вы сравниваете именно player, а не строку "X" (в кавычках) с символом 'X' (в одинарных кавычках).
  • Игроки ходят бесконечно. Убедитесь, что после хода вызывается проверка на победу и на ничью, а затем игрок меняется.

Если что-то не получается - напишите в Telegram, разберёмся вместе.

Практика

Игра готова, но её можно сделать ещё круче. Вот идеи для самостоятельной доработки (решений нет, пробуйте сами):

Задача 1. Счётчик побед

Добавьте переменные scoreX и scoreO. После каждой игры спрашивайте, хотят ли игроки сыграть ещё раз. Если да - очищайте поле и продолжайте, сохраняя счёт.

Задача 2. Игра с ботом

Сделайте так, чтобы за 'O' играл компьютер. Используйте Random (урок 19). Компьютер должен случайно выбирать число от 1 до 9, пока не найдёт свободную ячейку (используйте цикл do while).

Задача 3. Очистка поля

Напишите метод ResetBoard, который возвращает полю первоначальный вид (с цифрами 1-9). Вызывайте его при старте новой игры.
