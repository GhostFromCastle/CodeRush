Math и Random

~20 минут Средний уровень Теория и Практика

В начале курса мы познакомились с базовой арифметикой: сложением, вычитанием, умножением и делением. Этого хватает для простых задач. Но что, если нужно посчитать квадратный корень, возвести число в степень или найти синус угла? Писать эти формулы вручную с нуля - долго и сложно.

К счастью, в C# есть специальный класс Math - это как большой ящик с готовыми математическими инструментами. Мы уже пользовались одним из них (Math.Abs) в уроке 8. Сегодня заглянем в этот ящик целиком.

А во второй половине урока мы узнаем, как генерировать случайные дробные числа и делать случайный выбор из списка.

Класс Math

Math - это статический класс. Это значит, что нам не нужно создавать объект (new Math()), а можно просто обращаться к его методам напрямую. Все инструменты уже лежат внутри.

Степень и корень

Самые частые операции - это возведение в степень и извлечение корня.

double square = Math.Pow(5, 2);double cube = Math.Pow(2, 3);double root = Math.Sqrt(16);

Разберём:

  • Math.Pow(число, степень) - возводит число в указанную степень. Math.Pow(5, 2) - это 5 в квадрате, результат 25. Math.Pow(2, 3) - это 2 в кубе, результат 8.
  • Math.Sqrt(число) - извлекает квадратный корень (square root). Math.Sqrt(16) вернёт 4.

Обратите внимание, что эти методы всегда возвращают тип double (дробное число), даже если результат целый. Это связано с тем, что корень или степень могут быть дробными.

Модуль числа (напоминание)

В уроке 8 мы использовали Math.Abs для подсказок «горячо-холодно». Он возвращает число без знака:

int diff = Math.Abs(10 - 25);

Результат будет 15. Минус отбрасывается.

Округление

Часто при работе с дробными числами нужно их округлить. В C# есть три способа это сделать, и они ведут себя по-разному:

double a = 4.3;double b = 4.5;double c = 4.7;double roundA = Math.Round(a);double floorA = Math.Floor(c);double ceilA = Math.Ceiling(a);
  • Math.Round() - математическое округление до ближайшего целого. 4.3 станет 4, 4.7 станет 5, а 4.5 по умолчанию округлится до 4 (правило «банковского округления»).
  • Math.Floor() - «пол» (floor). Округляет вниз до ближайшего целого. 4.7 станет 4, -4.3 станет -5.
  • Math.Ceiling() - «потолок» (ceiling). Округляет вверх. 4.1 станет 5, -4.9 станет -4.

Минимум, максимум и число Пи

Вместо того чтобы писать условия if (a > b), можно использовать готовые методы:

int min = Math.Min(10, 20);int max = Math.Max(10, 20);double circleArea = Math.PI * Math.Pow(5, 2);

Math.Min и Math.Max принимают два числа и возвращают меньшее или большее. А Math.PI - это встроенная константа, хранящая число Пи (3.14159...).

Продвинутый Random

В уроке 7 мы научились генерировать случайные целые числа: rnd.Next(1, 7) для кубика. Но что, если нужна случайная дробь? Например, случайное число от 0.0 до 1.0 или от 5.5 до 10.5.

NextDouble()

У генератора Random есть метод NextDouble(). Он всегда возвращает дробное число от 0.0 до 1.0 (не включая 1.0).

Random rnd = new Random();double x = rnd.NextDouble();

Результат будет что-то вроде 0.72345... или 0.15892....

Как получить случайное число в диапазоне

Допустим, нам нужно случайное дробное число от 5 до 10. Для этого используется формула:

double min = 5.0;double max = 10.0;double randomValue = min + rnd.NextDouble() * (max - min);

Давайте разберём логику. NextDouble() даёт нам число от 0 до 1. Мы умножаем его на разницу между максимумом и минимумом (в данном случае на 5). Получаем число от 0 до 5. А затем прибавляем минимум (5). В итоге получаем число от 5 до 10.

Случайный выбор из списка

Очень частая задача: выбрать случайный элемент из массива или списка. Для этого мы генерируем случайный индекс от 0 до длины коллекции - 1.

string[] names = { "Алексей", "Мария", "Иван", "Ольга" };int index = rnd.Next(0, names.Length);string randomName = names[index];Console.WriteLine($"Победитель: {randomName}");

Помните правило Next: верхняя граница не включается. Поэтому мы пишем names.Length, чтобы индекс мог быть от 0 до 3 (для массива из 4 элементов).

Шпаргалка

Самое важное в одном месте:

  • Math.Pow(x, y) x в степени y
  • Math.Sqrt(x) квадратный корень
  • Math.Abs(x) модуль числа
  • Math.Round(x) математическое округление
  • Math.Min / Max минимум и максимум из двух
  • rnd.NextDouble() случайное от 0.0 до 1.0
  • min + rnd.NextDouble() * (max - min) случайное в диапазоне

Если что-то не работает

Разберём типичные ошибки при работе с математикой и случайными числами.

  • «Cannot implicitly convert type 'double' to 'int'». Методы Math.Pow, Math.Sqrt, Math.Round и Math.Floor возвращают double. Если вам нужен int, используйте явное приведение: int result = (int)Math.Sqrt(16);.
  • Результат деления получается неточным. Помните урок 9? Если вы делите два int, дробная часть отбрасывается. Чтобы этого избежать, приводите одно из чисел к double.
  • Math.Round(2.5) возвращает 2, а не 3. Это не баг, а особенность «банковского округления» в C#. Если нужно классическое округление (0.5 вверх), используйте Math.Round(2.5, MidpointRounding.AwayFromZero).
  • Случайные числа всегда одинаковые при перезапуске. Если вы создаёте new Random() внутри быстрого цикла, он может выдавать одинаковые значения. Создавайте генератор один раз.
  • «IndexOutOfRangeException» при выборе из списка. Убедитесь, что верхняя граница в rnd.Next равна list.Count (или array.Length), а не Count - 1.

Если что-то не получается - напишите нам в Telegram, поможем разобраться.

Практика

Четыре задачи по возрастающей сложности. У каждой есть подсказка и решение учителя.

Задача 1. Гипотенуза

Попросите пользователя ввести длины двух катетов прямоугольного треугольника. Найдите и выведите длину гипотенузы.

Подсказка

Используйте теорему Пифагора: квадрат гипотенузы равен сумме квадратов катетов. Math.Sqrt(Math.Pow(a, 2) + Math.Pow(b, 2)).

Решение учителя 
Console.Write("Введите катет a: ");double a = double.Parse(Console.ReadLine());Console.Write("Введите катет b: ");double b = double.Parse(Console.ReadLine());double hypotenuse = Math.Sqrt(Math.Pow(a, 2) + Math.Pow(b, 2));Console.WriteLine($"Гипотенуза: {hypotenuse}");
Задача 2. Площадь круга

Попросите у пользователя радиус круга. Вычислите и выведите площадь. Используйте константу Math.PI.

Подсказка

Формула площади круга: π * r². То есть Math.PI * Math.Pow(r, 2).

Решение учителя 
Console.Write("Введите радиус: ");double r = double.Parse(Console.ReadLine());double area = Math.PI * Math.Pow(r, 2);Console.WriteLine($"Площадь круга: {area}");
Задача 3. Случайная температура

Сымитируйте случайное измерение температуры тела человека. Она должна быть в диапазоне от 36.0 до 37.5 градусов. Округлите результат до одного знака после запятой с помощью Math.Round и выведите.

Подсказка

Используйте формулу случайного числа в диапазоне: min + rnd.NextDouble() * (max - min). Для округления до одного знака используйте Math.Round(value, 1).

Решение учителя 
Random rnd = new Random();double min = 36.0;double max = 37.5;double temp = min + rnd.NextDouble() * (max - min);temp = Math.Round(temp, 1);Console.WriteLine($"Температура: {temp}°C");
Задача 4. Случайный выбор

Создайте массив из пяти любимых фильмов. Сымитируйте «рулетку»: выберите случайный фильм из этого массива и выведите его на экран с фразой «Сегодня смотрим: ...».

Подсказка

Сгенерируйте индекс через rnd.Next(0, movies.Length). Затем обратитесь к элементу массива по этому индексу.

Решение учителя 
Random rnd = new Random();string[] movies = { "Матрица", "Начало", "Интерстеллар", "Форрест Гамп", "Крестный отец" };int index = rnd.Next(0, movies.Length);Console.WriteLine($"Сегодня смотрим: {movies[index]}");

Обратите внимание, что movies.Length равно 5. rnd.Next(0, 5) выдаст индекс от 0 до 4, что идеально подходит для нашего массива.
