Псевдоклассы и псевдоэлементы

~30 минут Средний уровень Теория и Практика

Представьте, что вы навели курсор на кнопку, и она плавно изменила цвет. Или кликнули в поле ввода, и у него появилась синяя обводка. Или читаете статью, и первая буква в ней огромная и красивая, как в старинных книгах.

Всё это - работа псевдоклассов и псевдоэлементов. Это невидимые помощники, которые расширяют возможности CSS. С их помощью можно стилизовать состояния элементов и создавать декоративные штуки, не засоряя HTML лишними тегами.

Псевдоклассы: состояния элементов

Псевдокласс - это ключевое слово, которое начинается с одного двоеточия (:). Он позволяет применить стили к элементу только в определённом состоянии.

Интерактивные состояния

Это то, с чем пользователь взаимодействует напрямую. Самые популярные:

  • :hover - срабатывает, когда курсор мыши находится над элементом.
  • :focus - срабатывает, когда элемент получает фокус (например, при клике в поле ввода или при переходе по Tab).
  • :active - срабатывает в момент, когда пользователь нажимает на элемент (например, зажал кнопку мыши).

Обычно мы пишем стили для этих состояний отдельным блоком:

.btn {    background: #eee;    padding: 10px 20px;}.btn:hover {    background: #ff5a00;    color: white;}
Современный подход: CSS Nesting (Вложенность)

Раньше писать стили внутри класса было невозможно без препроцессоров (Sass/SCSS). Но сейчас современные браузеры поддерживают нативную вложенность.

Вы можете написать код более компактно, используя символ & (амперсанд). Он указывает на родительский селектор:

.btn {    background: #eee;    padding: 10px 20px;    &:hover {        background: #ff5a00;        color: white;    }}

Важно: hover - это псевдокласс, поэтому пишется с одним двоеточием (:hover). Два двоеточия (::) используются только для псевдоэлементов (например, ::before).

Структурные псевдоклассы

Они позволяют выбирать элементы на основе их положения в HTML-дереве, без использования классов.

  • :first-child - первый дочерний элемент.
  • :last-child - последний дочерний элемент.
  • :nth-child(n) - выбирает элементы по формуле. Например, :nth-child(2n) - это все чётные элементы, а :nth-child(odd) - нечётные.

Это очень удобно для стилизации списков или таблиц. Например, чтобы сделать «зебру» (чередование цветов строк):

tr:nth-child(even) {    background-color: #f2f2f2;}
Важно для доступности

Если вы делаете эффект при наведении (:hover), обязательно добавьте аналогичный эффект при фокусе (:focus-visible). Люди, которые пользуются клавиатурой, должны видеть, на каком элементе они находятся.

Псевдоэлементы: виртуальные элементы

Псевдоэлементы начинаются с двух двоеточий (::). Они создают элементы, которых физически нет в HTML. Это позволяет добавлять декоративный контент (иконки, кавычки, фоны) или стилизовать части текста.

::before и ::after

Самые мощные псевдоэлементы. Они создают «виртуальный» контейнер до и после содержимого элемента. Чтобы они появились, обязательно нужно свойство content (даже если оно пустое).

.quote::before {    content: "«";    color: #ff5a00;    font-size: 24px;}.quote::after {    content: "»";    color: #ff5a00;    font-size: 24px;}

Этот код возьмёт любой текст с классом .quote и автоматически добавит кавычки-ёлочки в начале и в конце, не засоряя HTML.

Другой пример: мы хотим поставить красивую точку перед пунктом меню.

.menu li::before {    content: "";    display: inline-block;    width: 6px;    height: 6px;    background: #ff5a00;    border-radius: 50%;    margin-right: 10px;}

Другие полезные псевдоэлементы

  • ::first-letter - стилизует первую букву текста (буквица).
  • ::first-line - стилизует первую строку текста.
  • ::selection - стилизует текст, который выделен пользователем (обычно синий фон).
  • ::placeholder - стилизует текст-подсказку в полях ввода.

Шпаргалка

Самое важное в одном месте:

  • :hover наведение курсора
  • :focus фокус на элементе
  • :active момент нажатия
  • :first-child первый дочерний элемент
  • :nth-child(odd) нечётные элементы
  • ::before / ::after виртуальные элементы до/после
  • content обязательное свойство для before/after
  • ::selection выделенный текст

Если что-то не работает

Разберём типичные проблемы при работе с этими инструментами.

  • «Мой ::before не появляется». Самая частая ошибка - забыли добавить свойство content. Даже если там пусто (content: "";), оно должно быть написано обязательно.
  • «Эффект :hover не работает на мобильных». На сенсорных экранах нет курсора мыши, поэтому :hover либо не срабатывает, либо срабатывает криво (остаётся после тапа). Не завязывайте важный функционал (например, раскрытие меню) только на :hover.
  • «Почему выделение текста ::selection работает не везде?» Это зависит от браузера. Некоторые свойства (например, text-shadow) внутри ::selection не поддерживаются. Но цвет фона и текста работают везде.
  • «Я задал :first-child, но стили применились не к тем элементам». :first-child срабатывает, только если элемент действительно является первым ребёнком своего родителя. Если перед ним стоит другой тег (даже пустой span), селектор не сработает.
  • «В чём разница между :nth-child и :nth-of-type?» :nth-child считает все элементы подряд. :nth-of-type считает только элементы конкретного тега (например, только параграфы, игнорируя заголовки).
  • «Почему вложенность `&:hover` не работает?» Убедитесь, что вы используете именно `&:hover`, а не `::hover`. И проверьте, что ваш браузер поддерживает нативный CSS Nesting (все современные браузеры поддерживают).

Если что-то не получается или есть вопрос - напишите в Telegram, разберёмся вместе.

Практика

Четыре задачи. Первые две - на понимание теории, вторые две - на практическое применение.

Задача 1. Выберите псевдокласс

Для каждой задачи выберите подходящий псевдокласс или псевдоэлемент.

  1. Изменить цвет кнопки, когда на неё навели мышь.
  2. Добавить декоративную иконку перед текстом ссылки.
  3. Сделать так, чтобы у каждой второй строки таблицы был серый фон.
  4. Убрать стандартную синюю обводку у поля ввода и сделать свою кастомную.
Подсказка

Вспомните: :hover для мыши, :focus для полей ввода, ::before для декора, :nth-child() для чередования.

Разбор
  1. :hover
  2. ::before (с обязательным content)
  3. :nth-child(even)
  4. :focus (или :focus-visible)
Задача 2. Что сделает код?

Объясните, как изменится внешний вид текста с этим CSS:

p::first-letter {    color: red;    font-size: 2em;    font-weight: bold;}
Подсказка

Каждый параграф на странице получит эффект, который часто используют в книгах и журналах. Как он называется?

Разбор

Все параграфы на странице получат «буквицу». Первая буква каждого параграфа станет красной, в два раза больше остального текста и жирной. Это классический типографский приём для привлечения внимания читателя.

Задача 3. Красивые ссылки

В вашем проекте создайте несколько ссылок (<a>) в виде списка. Сделайте так, чтобы:

  1. При наведении курсора ссылки меняли цвет на оранжевый (#ff5a00).
  2. При клике (в момент нажатия) они немного уменьшались (transform: scale(0.95)).
  3. У ссылок пропало стандартное подчёркивание, но оно появлялось при наведении.
Подсказка

Для управления подчёркиванием используйте text-decoration. Для состояний - псевдоклассы :hover и :active. Можете попробовать использовать синтаксис вложенности с &.

Разбор

CSS (с использованием вложенности):

a {    text-decoration: none;    color: #333;    transition: color 0.2s;    &:hover {        color: #ff5a00;        text-decoration: underline;    }    &:active {        transform: scale(0.95);    }}
Задача 4. Кастомный чекбокс с ::before

Создайте список задач (обычный <ul>). С помощью псевдоэлемента ::before сделайте так, чтобы перед каждым пунктом списка был не стандартный маркер, а кастомная галочка (можно использовать квадрат с закруглёнными углами или символ «✓», вставленный через content).

Подсказка

Сначала уберите стандартные маркеры у списка (list-style: none;). Затем добавьте ::before для тегов <li>.

Разбор

Пример с символом:

ul {    list-style: none;    padding-left: 0;}li::before {    content: "✓";    color: #10b981;    font-weight: bold;    margin-right: 10px;}

Или пример с кастомным квадратом:

li::before {    content: "";    display: inline-block;    width: 10px;    height: 10px;    background: #ff5a00;    border-radius: 3px;    margin-right: 10px;}

Что мы узнали и что дальше

Псевдоклассы и псевдоэлементы - это тот самый «слой лака», который отличает базовую вёрстку от профессиональной. Теперь вы умеете реагировать на действия пользователя и создавать элементы без лишнего HTML-кода.

Вы узнали:

  • Как стилизовать элементы при наведении (:hover) и фокусе (:focus).
  • Как использовать современную вложенность CSS с символом &.
  • Как выбирать чётные/нечётные элементы (:nth-child).
  • Как добавлять виртуальные элементы до и после контента (::before / ::after).
  • Как стилизовать первую букву (::first-letter).

В следующем уроке мы займёмся переходами и анимациями. Вы узнаете, как сделать так, чтобы изменения цветов и размеров происходили плавно, а не мгновенно. Это сделает ваш сайт невероятно приятным в использовании.
