Таблицы и медиа-элементы

~35 минут Средний уровень Теория и Практика

Мы завершаем средний уровень. Осталось разобрать два инструмента, которые часто используются в реальных проектах. Таблицы помогут нам аккуратно вывести данные (например, список сотрудников или сравнение тарифов), а медиа-элементы - сделать страницу живой и интерактивной.

Таблицы: только для данных

Первое и самое важное правило: никогда не используйте таблицы для вёрстки макета сайта. Для этого есть Flexbox и Grid. Таблицы нужны только для табличных данных (там, где есть строгая связь по строкам и столбцам).

Таблица состоит из нескольких обязательных частей:

  • <table> - сам контейнер таблицы.
  • <caption> - заголовок таблицы (очень важен для доступности).
  • <thead> - шапка таблицы (строка с заголовками столбцов).
  • <tbody> - основное тело таблицы (с данными).
  • <tr> - строка таблицы (table row).
  • <th> - ячейка заголовка (table header).
  • <td> - обычная ячейка с данными (table data).

Пример правильной таблицы:

<table>    <caption>Цены на подписки</caption>    <thead>        <tr>            <th>Тариф</th>            <th>Цена</th>        </tr>    </thead>    <tbody>        <tr>            <td>Базовый</td>            <td>500 ₽</td>        </tr>        <tr>            <td>Премиум</td>            <td>1500 ₽</td>        </tr>    </tbody></table>

Стилизация таблиц

По умолчанию у таблиц двойные рамки. Чтобы сделать их красивыми и аккуратными, используйте свойство border-collapse: collapse;. Оно объединяет соседние границы.

table {    width: 100%;    border-collapse: collapse;}th, td {    padding: 12px;    border-bottom: 1px solid #ddd;    text-align: left;}th {    background-color: #f4f4f4;}

Адаптивность таблиц

Если таблица широкая, на мобильном она вылезет за края экрана. Самый простой и рабочий способ это исправить - обернуть таблицу в контейнер с горизонтальной прокруткой.

<div class="table-wrapper">    <table>...</table></div>
.table-wrapper {    overflow-x: auto;}

Современные изображения: тег picture

Мы уже знаем тег <img>. Но если вы хотите показать разные картинки на мобильном и на десктопе (например, обрезанную и широкую версию), или хотите использовать современный формат (WebP/AVIF), но с фоллбэком (запасным вариантом) для старых браузеров, используется тег <picture>.

<picture>    <source srcset="photo.avif" type="image/avif">    <source srcset="photo.webp" type="image/webp">    <img src="photo.jpg" alt="Описание фото"></picture>

Браузер сам выберет первый поддерживаемый формат и загрузит его.

Видео и аудио

С появлением HTML5 нам больше не нужны сторонние плагины вроде Flash для видео. Тег <video> позволяет встраивать видео напрямую.

<video src="movie.mp4" controls width="600">    Ваш браузер не поддерживает видео.</video>
  • controls - показывает панель управления (плей, пауза, громкость).
  • autoplay - запускает видео автоматически. Важно: современные браузеры разрешают автозапуск только с атрибутом muted (без звука).
  • loop - зацикливает видео.
  • poster - картинка-заглушка до начала воспроизведения.

С аудио всё аналогично: тег <audio> с атрибутом controls.

Встраивание контента: iframe

Тег <iframe> позволяет встроить на страницу другой сайт. Чаще всего его используют для карт, видео с YouTube или виджетов соцсетей.

<iframe     src="https://www.youtube.com/embed/код_видео"     title="Описание видео"    width="560"     height="315"     loading="lazy"    allowfullscreen></iframe>

Обязательно добавляйте атрибут title (для доступности) и loading="lazy" (чтобы iframe загружался только тогда, когда пользователь до него доскроллит, экономя трафик).

Почему iframe встраивается со скриптом?

Если вы нажмете «Поделиться» -> «Встроить» на YouTube, вам дадут код с тегом <iframe>. Это сделано для удобства. Но современные блогеры часто используют так называемое «ленивое видео» (lite-youtube-embed), чтобы не нагружать страницу тяжелым плеером сразу. Но для базовой задачи <iframe> вполне подходит.

Шпаргалка

Самое важное в одном месте:

  • <table> контейнер таблицы (только для данных)
  • <caption> заголовок таблицы
  • border-collapse объединение рамок таблицы
  • overflow-x скролл для адаптивной таблицы
  • <picture> адаптивные изображения и WebP
  • <video> видео с controls и muted
  • <iframe> встраивание внешнего контента
  • loading="lazy" ленивая загрузка медиа

Если что-то не работает

Разберём типичные проблемы с таблицами и медиа.

  • «Таблица съехала и вылезает за края». Оберните её в div с overflow-x: auto;. Это самый простой и рабочий способ.
  • «Двойные рамки в таблице». По умолчанию браузер рисует рамку вокруг каждой ячейки. Добавьте border-collapse: collapse; для тега <table>.
  • «Видео не запускается автоматически». Браузеры блокируют автозапуск со звуком. Добавьте атрибут muted, тогда видео заиграет.
  • «Iframe не загружается». Некоторые сайты (например, банки или крупные соцсети) запрещают встраивание через заголовок X-Frame-Options. Их встроить не получится.
  • «Таблица не является адаптивной на мобильном». Помните, что table плохо сжимается. Если данных много, лучше рассмотреть вариант с карточками вместо таблицы на мобильных (через медиазапросы).

Если что-то не получается или есть вопрос - напишите в Telegram, разберёмся вместе.

Практика

Четыре задачи. Первые две - на понимание теории, вторые две - на практическое применение.

Задача 1. Теги таблицы

Какие теги используются для создания таблицы и что они означают?

  1. Основной контейнер.
  2. Строка таблицы.
  3. Ячейка с заголовком (жирный текст).
  4. Обычная ячейка с данными.
Подсказка

Все теги таблицы начинаются на букву T (table, tr, th, td).

Разбор
  1. <table>
  2. <tr>
  3. <th>
  4. <td>
Задача 2. Что сделает код?

Объясните, как будет вести себя видео с таким кодом:

<video src="video.mp4" autoplay muted loop></video>
Подсказка

Обратите внимание на атрибуты autoplay, muted и loop.

Разбор

Видео начнёт воспроизводиться автоматически, но без звука (так как есть muted). Когда оно закончится, оно начнётся заново (из-за loop). Панели управления не будет, так как нет атрибута controls.

Задача 3. Создайте таблицу

Создайте таблицу «Расписание уроков» на 3 дня (Понедельник, Вторник, Среда). В ней должно быть 3 столбца: День, Предмет, Время. Добавьте заголовок таблицы. Сделайте так, чтобы рамки не были двойными, а фон заголовков был светло-серым.

Подсказка

Не забудьте про <caption>, <thead> и <tbody>. Для рамок используйте border-collapse: collapse;.

Разбор

HTML:

<table>    <caption>Расписание</caption>    <thead>        <tr>            <th>День</th><th>Предмет</th><th>Время</th>        </tr>    </thead>    <tbody>        <tr>            <td>Пн</td><td>Математика</td><td>09:00</td>        </tr>        <tr>            <td>Вт</td><td>Физика</td><td>10:30</td>        </tr>    </tbody></table>

CSS:

table {    border-collapse: collapse;}th {    background: #eee;    padding: 8px;}td {    padding: 8px;    border-bottom: 1px solid #ccc;}
Задача 4. Встройте видео

Найдите на YouTube любое видео. Нажмите «Поделиться» -> «Встроить». Скопируйте код iframe и вставьте его на свою страницу. Добавьте к нему атрибут loading="lazy".

Подсказка

Код будет выглядеть как тег <iframe src="...">. Просто добавьте loading="lazy" внутрь тега.

Разбор

Пример:

<iframe width="560" height="315" src="https://www.youtube.com/embed/dQw4w9WgXcQ" title="YouTube video" loading="lazy" allowfullscreen></iframe>

Теперь видео на странице будет грузиться не сразу, а при прокрутке, что ускорит загрузку самой страницы.
