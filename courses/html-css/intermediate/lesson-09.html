Flexbox: современная раскладка

~35 минут Средний уровень Теория и Практика

Добро пожаловать на средний уровень! Вы уже умеете создавать красивые карточки и управлять блочной моделью. Но есть одна проблема: все элементы у нас идут строго сверху вниз. А что, если нам нужно поставить логотип и меню в одну строку? Или выровнять текст по центру кнопки? Или сделать так, чтобы карточки товаров стояли в ряд и переносились на новую строку, если не влезают?

Раньше для этого использовали сложные и хрупкие хаки с float и inline-block. Но в 2017 году все современные браузеры поддержали Flexbox - и вёрстка изменилась навсегда.

Что такое Flexbox

Flexbox (Flexible Box Layout Module) - это способ расположения элементов в одном измерении (либо по горизонтали, либо по вертикали). Он позволяет легко выравнивать элементы, распределять между ними свободное пространство и менять их порядок.

Представьте себе полку, на которой стоят книги. Вы можете прижать их к левому краю, к правому, поставить по центру или распределить равномерно по всей полке. Именно так работает Flexbox.

Контейнер и элементы

Чтобы использовать Flexbox, нужно разделить роли. Есть flex-контейнер (родитель) и flex-элементы (дети).

Всё начинается с одного свойства, которое задаётся родителю:

.container {    display: flex;}

Как только вы написали display: flex;, все прямые потомки этого элемента становятся flex-элементами. Они сразу же выстраиваются в один ряд (по умолчанию слева направо).

Главная и поперечная оси

Это самое важное для понимания Flexbox. У контейнера есть две оси:

  • Главная ось (Main Axis) - та, вдоль которой выстраиваются элементы. По умолчанию она горизонтальная (слева направо).
  • Поперечная ось (Cross Axis) - перпендикулярна главной. По умолчанию вертикальная (сверху вниз).

Запомните: все свойства Flexbox работают либо вдоль главной оси, либо вдоль поперечной. Если вы поменяете направление главной оси, свойства поменяют своё действие.

flex-direction: меняем направление

Свойство flex-direction задаёт направление главной оси.

  • row (по умолчанию) - слева направо.
  • column - сверху вниз.
  • row-reverse - справа налево.
  • column-reverse - снизу вверх.

Выравнивание элементов

Теперь разберём главные свойства для управления пространством.

justify-content: вдоль главной оси

Это свойство отвечает за распределение элементов вдоль главной оси (по умолчанию - по горизонтали).

  • flex-start (по умолчанию) - прижать к началу.
  • flex-end - прижать к концу.
  • center - выровнять по центру.
  • space-between - первый элемент в начале, последний в конце, остальные равномерно между ними.
  • space-around - равные отступы вокруг каждого элемента.
  • space-evenly - абсолютно равные отступы между всеми элементами и краями.

align-items: вдоль поперечной оси

А это свойство отвечает за выравнивание вдоль поперечной оси (по умолчанию - по вертикали).

  • stretch (по умолчанию) - элементы растягиваются на всю высоту контейнера.
  • flex-start - выровнять по верхнему краю.
  • flex-end - выровнять по нижнему краю.
  • center - выровнять по центру.
  • baseline - выровнять по базовой линии текста.
Как запомнить

justify - это всегда про главную ось. align - всегда про поперечную. Если вы поменяли flex-direction на column, то justify-content начнёт выравнивать по вертикали, а align-items - по горизонтали.

Отступы между элементами: gap

Раньше, чтобы сделать отступы между flex-элементами, приходилось использовать margin и потом бороться с лишними отступами по краям. Сейчас есть свойство gap, которое задаёт отступы только между элементами.

.container {    display: flex;    gap: 20px;}

Перенос элементов: flex-wrap

По умолчанию Flexbox пытается впихнуть все элементы в одну строку. Если места не хватает, элементы сжимаются. Чтобы они переносились на новую строку, используется свойство flex-wrap.

.container {    display: flex;    flex-wrap: wrap;}

Это очень полезно для создания галерей или списков карточек, которые должны адаптироваться под ширину экрана.

Шпаргалка

Самое важное в одном месте:

  • display: flex включает Flexbox для контейнера
  • flex-direction направление главной оси (row / column)
  • justify-content выравнивание по главной оси
  • align-items выравнивание по поперечной оси
  • gap отступы между элементами
  • flex-wrap: wrap разрешает перенос на новую строку
  • center идеальное центрирование (justify + align)

Если что-то не работает

Разберём типичные проблемы при работе с Flexbox.

  • «Я написал display: flex, но элементы всё равно стоят друг под другом». Проверьте, куда именно вы написали это свойство. Оно должно быть у родителя, а не у самих элементов. И проверьте, что элементы являются прямыми потомками.
  • «justify-content не выравнивает по вертикали». Потому что по умолчанию главная ось горизонтальная. Если вам нужно вертикальное выравнивание, либо используйте flex-direction: column, либо применяйте align-items.
  • «Элементы растягиваются на всю высоту, а я хочу, чтобы они были по размеру контента». Это поведение по умолчанию (align-items: stretch). Чтобы исправить, задайте align-items: center или flex-start.
  • «Мои элементы вылезают за пределы контейнера». Добавьте flex-wrap: wrap;, чтобы они переносились на новую строку, а не сжимались до нечитаемого состояния.
  • «Я использую gap, но в старом браузере он не работает». Свойство gap поддерживается всеми современными браузерами. Если вам нужно поддерживать очень старые версии, придётся использовать margin.

Если что-то не получается или есть вопрос - напишите в Telegram, разберёмся вместе.

Практика

Четыре задачи. Первые две - на понимание теории, вторые две - на практическое применение.

Задача 1. Какое свойство использовать

Для каждой задачи выберите подходящее свойство Flexbox.

  1. Нужно расставить элементы в колонку.
  2. Нужно, чтобы элементы были прижаты к правому краю.
  3. Нужно равномерно распределить элементы с одинаковыми отступами между ними.
  4. Нужно, чтобы элементы переносились на новую строку, если не хватает места.
Подсказка

Вспомните, какое свойство отвечает за направление, какое за выравнивание и какое за перенос.

Разбор
  1. flex-direction: column;
  2. justify-content: flex-end;
  3. justify-content: space-between; (или space-evenly в зависимости от задачи).
  4. flex-wrap: wrap;
Задача 2. Как это работает

Объясните, что сделает этот код:

.box {    display: flex;    justify-content: center;    align-items: center;    height: 300px;    background: #eee;}
Подсказка

Вспомните, где проходит главная ось, а где поперечная. И что делает center в каждом случае.

Разбор

Этот код создаёт контейнер высотой 300px и выравнивает всё его содержимое абсолютно по центру - и по горизонтали (justify-content: center), и по вертикали (align-items: center). Это классический способ центрировать элемент.

Задача 3. Сделайте меню

В вашем проекте создайте <header> с классом navbar. Внутри разместите логотип (например, <div class="logo">Logo</div>) и список ссылок (<ul class="menu"> с тремя <li>).

Используя Flexbox, расположите логотип слева, а меню - справа. Используйте justify-content: space-between.

Подсказка

Примените display: flex; и justify-content: space-between; к самому <header>. А для самого меню тоже можно применить flex, чтобы ссылки встали в ряд.

Разбор

Примерный код:

.navbar {    display: flex;    justify-content: space-between;    align-items: center;    padding: 20px;    background: #fff;}.menu {    display: flex;    gap: 20px;    list-style: none;    margin: 0;    padding: 0;}
Задача 4. Галерея карточек

Создайте контейнер .gallery и поместите в него три карточки (можно использовать код из урока 8). Сделайте так, чтобы карточки стояли в ряд, но если места не хватает - переносились на новую строку. Отступ между карточками должен быть 20px.

Подсказка

Используйте display: flex;, flex-wrap: wrap; и gap: 20px; для галереи.

Разбор

CSS:

.gallery {    display: flex;    flex-wrap: wrap;    gap: 20px;    justify-content: center;}

Если вы уменьшите окно браузера, карточки должны начать переноситься на новую строку. Это и есть магия flex-wrap.

Что мы узнали и что дальше

Flexbox - это, пожалуй, самый важный инструмент современного верстальщика. С его помощью можно решить 90% задач по расположению элементов. Теперь вы умеете:

  • Включать Flexbox через display: flex.
  • Понимать разницу между главной и поперечной осями.
  • Менять направление с помощью flex-direction.
  • Выравнивать элементы по горизонтали (justify-content) и вертикали (align-items).
  • Задавать отступы между элементами через gap.
  • Разрешать перенос элементов на новую строку через flex-wrap.

Но Flexbox идеален для одномерных раскладок (в строку или в колонку). А что, если нам нужна сложная сетка, как в шахматах или в журнале? Для этого существует CSS Grid - и ему будет посвящён наш следующий урок. Grid позволяет управлять и строками, и столбцами одновременно, создавая по-настоящему сложные макеты.
