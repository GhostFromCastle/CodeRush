Формы и элементы ввода

~35 минут Средний уровень Теория и Практика

До этого урока все наши страницы были «улицей с односторонним движением». Сайт рассказывал что-то пользователю, но не мог получить от него ответ. Формы меняют всё. Это тот мост, по которому информация от пользователя попадает на сервер.

Формы - это не только поля «Логин» и «Пароль». Это кнопки «Купить», слайдеры громкости, переключатели темы и даже поисковая строка. Сегодня мы разберём, как собрать форму, связать её элементы между собой и стилизовать так, чтобы она выглядела современно и была удобной для всех.

Тег form: контейнер для данных

Все элементы, которые должны быть отправлены на сервер, оборачиваются в тег <form>. У этого тега есть два важных атрибута:

  • action - адрес, куда уйдут данные (например, серверный скрипт).
  • method - метод отправки (чаще всего GET для поиска или POST для отправки чего-то важного).
<form action="/send" method="POST">    </form>

Пока мы не пишем серверную часть, поэтому можем использовать action="#" или вообще не указывать его. Но для реальной работы без него не обойтись.

Связка label и input

Поле ввода создаётся с помощью одиночного тега <input>. Главное - подписать его, чтобы пользователь понимал, что вводить. Для этого используется парный тег <label>.

Есть два способа связать подпись и поле ввода. Первый - обернуть их друг в друга:

<label>    Ваше имя    <input type="text" name="username"></label>

Второй способ (более популярный в сложных формах) - использовать атрибуты for у label и id у input. Они должны совпадать:

<label for="user-email">Email</label><input type="email" id="user-email" name="email">
Зачем это нужно?

Когда label связан с input, клик по тексту подписи автоматически ставит курсор в поле ввода. А для людей, использующих скринридеры, программа озвучит, что именно нужно ввести в это поле.

Атрибуты input: type, placeholder, required

У тега <input> есть множество настроек. Главная из них - это type (тип поля).

  • type="text" - обычный текст.
  • type="email" - поле для email (браузер сам проверит наличие собачки @).
  • type="password" - скрывает символы точками.
  • type="number" - разрешает вводить только цифры.
  • type="date" - откроет встроенный календарь.

Дополнительные атрибуты:

  • placeholder - серая подсказка внутри поля (например, «Введите ваш email»).
  • required - делает поле обязательным для заполнения (браузер не даст отправить форму, если оно пустое).
  • disabled - блокирует поле.

Чекбоксы и радиокнопки

Это элементы для выбора. Чекбокс (type="checkbox") позволяет выбрать несколько вариантов или подтвердить согласие.

Радиокнопка (type="radio") позволяет выбрать только один вариант из группы. Чтобы они работали как группа (и нельзя было выбрать два сразу), у них должен быть одинаковый атрибут name.

<!-- Чекбокс --><label>    <input type="checkbox" name="agree">    Я согласен с правилами</label><!-- Радиокнопки --><label>    <input type="radio" name="gender" value="male"> Мужской</label><label>    <input type="radio" name="gender" value="female"> Женский</label>

Кнопки отправки

Чтобы отправить форму, нужна кнопка с type="submit". Если не указать тип, браузер по умолчанию сделает её кнопкой отправки.

<button type="submit">Отправить</button>

Современная стилизация форм

Раньше стилизация форм была болью, потому что браузеры используют свои системные стили. Но сейчас появились отличные CSS-решения.

1. accent-color

Свойство accent-color - это магия. Оно позволяет перекрасить стандартные чекбоксы и радиокнопки в нужный цвет одной строчкой CSS.

input[type="checkbox"],input[type="radio"] {    accent-color: #ff5a00;    width: 20px;    height: 20px;}

2. Селектор :focus-visible

При клике на поле ввода браузер по умолчанию показывает синюю обводку. Иногда она портит дизайн. Мы можем убрать стандартную обводку (outline: none;) и добавить свою красивую рамку или тень.

input[type="text"] {    border: 2px solid #ccc;    padding: 10px;    border-radius: 8px;}input[type="text"]:focus {    outline: none;    border-color: #ff5a00;    box-shadow: 0 0 0 3px rgba(255, 90, 0, 0.2);}

3. Автозаполнение

Если в форме есть поля для логина, пароля, имени или телефона, обязательно используйте атрибут autocomplete. Это поможет браузеру подставить ранее сохранённые данные и сэкономит время пользователя.

<input type="email" name="email" autocomplete="email">

Шпаргалка

Самое важное в одном месте:

  • <form> контейнер для данных
  • <label> подпись, связанная с полем
  • <input> поле ввода
  • type тип поля (text, email, checkbox)
  • placeholder подсказка внутри поля
  • required обязательное поле
  • accent-color цвет для чекбоксов и радиокнопок
  • :focus стилизация активного поля

Если что-то не работает

Разберём частые проблемы при работе с формами.

  • «Клик по тексту не активирует поле». Проверьте связку. Либо оберните input в label, либо проверьте, что for у label и id у input совпадают (вплоть до регистра букв).
  • «Я не могу выбрать две радиокнопки одновременно». Так и задумано. Радиокнопки для того и нужны, чтобы выбрать один вариант. Если нужен множественный выбор - используйте type="checkbox".
  • «Браузер не отправляет форму». Проверьте, не забыли ли вы добавить required и не заполнили поле. Или, возможно, у вас нет кнопки с type="submit".
  • «placeholder пропадает, когда я начинаю печатать». Так и должно быть. Это подсказка, а не значение по умолчанию. Никогда не заменяйте placeholder на <label> - люди забывают, что было в поле, когда начинают печатать.
  • «Поле ввода выглядит по-разному в Chrome и Safari». Чтобы добиться единообразия, сбрасывайте стили (appearance: none;) и задавайте свои границы, отступы и шрифты.

Если что-то не получается или есть вопрос - напишите в Telegram, разберёмся вместе.

Практика

Четыре задачи. Первые две - на понимание HTML-структуры, вторые две - на практическую стилизацию.

Задача 1. Выберите правильный тип

Какой атрибут type использовать для каждого поля?

  1. Ввод пароля (чтобы символы скрывались точками).
  2. Ввод электронной почты (чтобы браузер проверил наличие @).
  3. Выбор даты рождения.
  4. Подтверждение согласия с правилами (да/нет).
Подсказка

Подумайте, какую клавиатуру или интерфейс должен показать браузер для этих данных.

Разбор
  1. type="password"
  2. type="email"
  3. type="date"
  4. type="checkbox"
Задача 2. Что не так с этим кодом?

Разработчик написал код, но клик по подписи не активирует поле. Почему?

<label for="name">Ваше имя:</label><input type="text" id="user-name" name="name">
Подсказка

Посмотрите внимательно на значения for и id. Они должны быть абсолютно одинаковыми.

Разбор

Ошибка в том, что for="name" не совпадает с id="user-name". Чтобы связь работала, они должны быть идентичны. Исправлено:

<label for="user-name">Ваше имя:</label><input type="text" id="user-name" name="name">
Задача 3. Форма подписки

Создайте форму подписки на новости. В ней должно быть:

  • Поле для ввода имени (обязательное).
  • Поле для ввода email (обязательное).
  • Чекбокс «Согласен на обработку данных» (обязательный).
  • Кнопка «Подписаться».

Стилизуйте форму: поля должны иметь рамку, скруглённые углы и отступы. Кнопка должна быть яркой. При фокусе на поле его рамка должна менять цвет.

Подсказка

Используйте display: flex; и flex-direction: column; для формы, чтобы элементы стояли друг под другом с отступами.

Разбор

HTML:

<form class="subscribe-form">    <label for="sub-name">Имя</label>    <input type="text" id="sub-name" required>    <label for="sub-email">Email</label>    <input type="email" id="sub-email" required>    <label>        <input type="checkbox" required> Согласен на обработку    </label>    <button type="submit">Подписаться</button></form>

CSS:

.subscribe-form {    display: flex;    flex-direction: column;    gap: 10px;    max-width: 300px;}.subscribe-form input[type="text"],.subscribe-form input[type="email"] {    padding: 10px;    border: 1px solid #ccc;    border-radius: 5px;}.subscribe-form input:focus {    outline: none;    border-color: #ff5a00;}.subscribe-form button {    padding: 10px;    background: #ff5a00;    color: white;    border: none;    border-radius: 5px;    cursor: pointer;}
Задача 4. Красивый чекбокс

Используя свойство accent-color, сделайте чекбокс из предыдущей задачи оранжевым. Увеличьте его размер до 20px. Сделайте так, чтобы при наведении на текст подписи курсор менялся на «руку».

Подсказка

Для курсора используйте cursor: pointer; у тега <label>.

Разбор 
input[type="checkbox"] {    accent-color: #ff5a00;    width: 20px;    height: 20px;}label {    cursor: pointer;    display: flex;    align-items: center;    gap: 8px;}
