Переходы и анимации

~35 минут Средний уровень Теория и Практика

До этого урока все изменения на наших страницах происходили мгновенно. Навели курсор - кнопка сразу стала оранжевой. Открыли меню - оно резко появилось. Это работает, но выглядит немного «деревянно».

Анимации добавляют интерфейсу плавности и «дороговизны». Они подсказывают пользователю, что происходит, и делают взаимодействие с сайтом приятным. Раньше для сложных эффектов приходилось подключать JavaScript-библиотеки, но в 2025-2026 годах CSS эволюционировал настолько, что многое можно делать нативно и с потрясающей производительностью.

Transition: плавные переходы

transition - это самый простой способ анимировать изменение свойства. Вместо того чтобы «прыгать», значение будет плавно меняться от старого к новому.

.btn {    background: #eee;    transition: background 0.3s ease;}.btn:hover {    background: #ff5a00;}

В свойстве transition мы указываем три вещи:

  • Что анимируем (например, background или all для всех свойств).
  • Как долго (например, 0.3s).
  • С какой скоростью (функция плавности: ease, linear, ease-in-out).

Современные функции плавности (Easing)

Долгое время у нас было всего несколько предустановок (ease, linear) и cubic-bezier(). Но в последнее время появилась функция linear(), которая позволяет создавать сложные кривые, включая эффекты пружины (spring) или отскока (bounce), без единой строчки JavaScript.

.bouncy-btn {    /* Пример сложной пружинной анимации */    transition: transform 0.8s linear(0, 0.5 20%, 1.25 40%, 1 60%, 0.95 80%, 1);}.bouncy-btn:hover {    transform: scale(1.1);}

Анимации по ключевым кадрам (@keyframes)

Если transition просто плавно переключает состояние «из точки А в точку Б», то @keyframes позволяет создать многошаговую анимацию: пройти через несколько состояний, зациклить её или запустить автоматически.

@keyframes pulse {    0% { transform: scale(1); opacity: 1; }    50% { transform: scale(1.1); opacity: 0.8; }    100% { transform: scale(1); opacity: 1; }}.heart-icon {    animation: pulse 2s infinite ease-in-out;}

Свойство animation принимает имя анимации, длительность, количество повторений и функцию плавности.

Анимация появления: @starting-style и allow-discrete

Исторически сложилось, что мы не могли анимировать появление элемента, если он менял свойство display с none на block. Браузер просто «включал» его. Но в 2025 году это изменилось.

С появлением свойств @starting-style и transition-behavior: allow-discrete мы можем анимировать появление модальных окон, всплывающих подсказок (popover) и просто блоков, которые были скрыты.

.popup {    display: none;    opacity: 0;    /* Разрешаем анимацию display */    transition: opacity 0.3s, display 0.3s allow-discrete;}.popup.active {    display: block;    opacity: 1;}/* Указываем, откуда начинать анимацию */@starting-style {    .popup.active {        opacity: 0;    }}

Scroll-driven анимации: будущее уже здесь

Это, пожалуй, самая захватывающая фича последних лет. Раньше, чтобы анимировать элемент при прокрутке страницы, нужно было писать JavaScript с обработчиком scroll. Это часто вызывало «тормоза».

Сейчас в CSS появилось свойство animation-timeline. Оно позволяет привязать прогресс анимации не ко времени, а к полосе прокрутки (scroll) или к положению самого элемента на экране (view).

@keyframes fadeIn {    from { opacity: 0; transform: translateY(50px); }    to { opacity: 1; transform: translateY(0); }}.card {    /* Привязываем анимацию к скроллу */    animation: fadeIn linear both;    animation-timeline: view();    /* Анимация начнется при входе элемента в экран */    animation-range: entry 0% cover 30%;}

На 2026 год эта технология уже поддерживается в Chrome, Edge, Firefox и Safari (начиная с версии 26).

View Transitions API: магия переходов

Еще одна современная фича - View Transitions API. Она позволяет делать плавные переходы между разными состояниями страницы (или даже между разными страницами сайта) с помощью простого CSS. Это тот эффект, когда вы нажимаете на фото, и оно плавно «перелетает» на новую страницу. Сейчас это поддерживается во всех основных браузерах (Baseline с конца 2025 года).

Доступность и производительность

Красивые анимации - это здорово, но не забывайте о людях. Некоторых пользователей (например, с вестибулярными расстройствами) быстрые анимации могут укачивать.

Всегда добавляйте медиазапрос prefers-reduced-motion, чтобы отключить анимации для тех, кто этого хочет:

@media (prefers-reduced-motion: reduce) {    * {        animation-duration: 0.01ms !important;        transition-duration: 0.01ms !important;    }}

Также для анимаций старайтесь использовать только свойства transform (изменение размера/поворота) и opacity (прозрачность). Они не заставляют браузер пересчитывать всю страницу заново, а работают на видеокарте.

Шпаргалка

Самое важное в одном месте:

  • transition плавный переход между состояниями
  • @keyframes многошаговая анимация
  • linear() сложные функции плавности (пружины)
  • @starting-style анимация появления элемента
  • allow-discrete разрешает анимацию display
  • animation-timeline анимация при скролле
  • prefers-reduced-motion отключение анимаций для доступности

Если что-то не работает

Разберём типичные проблемы, возникающие при работе с анимациями.

  • «Переход не работает при наведении». Проверьте, что transition задан в базовом состоянии элемента, а не только в :hover.
  • «Анимация при скролле не работает». Свойство animation-timeline: view() требует, чтобы у элемента была задана хотя бы одна анимация через animation. И проверьте поддержку браузера.
  • «Анимация лагает на старом телефоне». Скорее всего, вы анимируете свойства width, height, margin или top/left. Замените их на transform: translate() и opacity.
  • «Модальное окно появляется резко, без анимации». Убедитесь, что вы используете transition-behavior: allow-discrete; и @starting-style, иначе браузер не знает, с какого состояния начинать анимацию.

Если что-то не получается или есть вопрос - напишите в Telegram, разберёмся вместе.

Практика

Четыре задачи. Первые две - на понимание классических переходов, вторые две - на применение современных фич.

Задача 1. Плавная кнопка

Создайте кнопку. Сделайте так, чтобы при наведении она плавно меняла цвет фона за 0.3 секунды, а при клике — немного уменьшалась.

Подсказка

Используйте transition в базовом классе. Для уменьшения при клике используйте :active и transform: scale(0.95).

Разбор

CSS:

.btn {    background: #eee;    transition: background 0.3s, transform 0.1s;}.btn:hover {    background: #ff5a00;}.btn:active {    transform: scale(0.95);}
Задача 2. Пульсирующий индикатор

Создайте круглый индикатор (красный кружок). Напишите анимацию @keyframes, которая будет бесконечно плавно увеличивать и уменьшать его размер.

Подсказка

Используйте transform: scale() внутри ключевых кадров и свойство animation: имя 2s infinite alternate;.

Разбор

CSS:

@keyframes pulse {    from { transform: scale(1); }    to { transform: scale(1.2); }}.dot {    width: 20px;    height: 20px;    background: red;    border-radius: 50%;    animation: pulse 1s infinite alternate;}
Задача 3. Появление модального окна

У вас есть блок с классом .popup, который скрыт через display: none. Напишите CSS, чтобы при добавлении класса .active он плавно появлялся (проявлялся). Используйте современные свойства @starting-style и allow-discrete.

Подсказка

В базовом классе задайте transition для opacity и display (с allow-discrete). В .active задайте display: block; и opacity: 1;. А в @starting-style укажите opacity: 0 для активного состояния.

Разбор

CSS:

.popup {    display: none;    opacity: 0;    transition: opacity 0.4s, display 0.4s allow-discrete;}.popup.active {    display: block;    opacity: 1;}@starting-style {    .popup.active {        opacity: 0;    }}
Задача 4. Анимация при скролле

Создайте страницу с большим количеством контента (чтобы появился скролл). Разместите несколько карточек. Сделайте так, чтобы карточки плавно появлялись (сдвигались снизу вверх), когда пользователь доскролливает до них.

Подсказка

Используйте @keyframes для появления и свойства animation-timeline: view(); и animation-range: entry 0% cover 30%;.

Разбор

CSS:

@keyframes fadeInUp {    from { opacity: 0; transform: translateY(50px); }    to { opacity: 1; transform: translateY(0); }}.card {    animation: fadeInUp linear both;    animation-timeline: view();    animation-range: entry 0% cover 30%;}

Попробуйте проскроллить страницу и увидите, как карточки оживают по мере появления на экране.

Что мы узнали и что дальше

Анимации - это вишенка на торте вашего сайта. Теперь вы умеете делать плавные переходы, сложные многошаговые анимации и даже привязывать их к скроллу, как это делают в топовых проектах.

Вы узнали:

  • Как использовать transition для плавных изменений.
  • Как создавать анимации через @keyframes.
  • Как анимировать появление элементов с @starting-style.
  • Как создавать scroll-driven анимации с animation-timeline.
  • Почему важно соблюдать доступность и использовать prefers-reduced-motion.
