CSS Grid: двумерные сетки

~35 минут Средний уровень Теория и Практика

В прошлом уроке мы освоили Flexbox и научились выстраивать элементы в линию. Но что, если нам нужен сложный макет, где контент делится на колонки, а некоторые блоки занимают сразу несколько ячеек? Например, классическая страница сайта: шапка на всю ширину, слева меню, справа контент, а внизу подвал на всю ширину.

Flexbox тут придётся изворачиваться, создавая вложенные контейнеры. А вот CSS Grid (сетка) создан именно для таких задач. Если Flexbox - это умная полка, то Grid - это шахматная доска или таблица Excel, где мы управляем и строками, и столбцами одновременно.

Включаем Grid

Как и с Flexbox, всё начинается с родительского контейнера. Мы говорим ему: display: grid;. После этого все его прямые потомки становятся grid-элементами, но в отличие от Flexbox, они не выстраиваются в линию, а распределяются по ячейкам невидимой сетки. 

.container {    display: grid;}

Пока мы не задали количество строк и столбцов, контейнер будет вести себя как обычный блочный элемент, а все дети будут идти друг под другом. Чтобы создать сетку, нужно определить её структуру.

Столбцы и строки: template

Для создания сетки используются два свойства:

  • grid-template-columns - задаёт столбцы.
  • grid-template-rows - задаёт строки.

Значения перечисляются через пробел. Каждое значение - это ширина одного столбца. Например, если мы хотим создать сетку из трёх столбцов по 100 пикселей:

.container {    display: grid;    grid-template-columns: 100px 100px 100px;}

Волшебная единица fr

Задавать размеры в пикселях не всегда удобно. Что, если экран станет больше или меньше? В Grid есть специальная единица измерения - fr (от слова fraction - доля). Она делит свободное пространство контейнера на равные части.

Представьте, что у вас есть пицца, и вы хотите разделить её между друзьями. Если написать 1fr 1fr 1fr, это значит: «раздели всё доступное пространство на три равные части». 

.container {    display: grid;    grid-template-columns: 1fr 1fr 1fr;}

Можно комбинировать доли. Например, 1fr 2fr означает, что первый столбец займёт 1 часть, а второй - в два раза больше (2 части).

Функция repeat()

Если столбцов много, писать 1fr 1fr 1fr 1fr утомительно. На помощь приходит функция repeat(). Она принимает два аргумента: сколько раз повторить и что именно.

.container {    display: grid;    /* Создать 3 столбца по 1fr */    grid-template-columns: repeat(3, 1fr);}

Отступы между ячейками: gap

Как и в Flexbox, в Grid есть свойство gap, которое задаёт расстояние между строками и столбцами. Это очень удобно: не нужно возиться с margin у каждого элемента.

.container {    display: grid;    grid-template-columns: repeat(3, 1fr);    gap: 20px;}

Как растянуть элемент на несколько ячеек

Самое мощное в Grid - это возможность заставить один элемент занимать сразу несколько ячеек. Для этого используются свойства grid-column и grid-row. Они указывают, с какой линии сетки элемент начинается и на какой заканчивается.

Линии сетки нумеруются, начиная с 1. Если у нас 3 столбца, то линий будет 4 (перед первым, между первым и вторым, между вторым и третьим, и после третьего).

Синтаксис: grid-column: начальная_линия / конечная_линия;.

.item {    /* Элемент начнётся с 1-й линии и закончится на 3-й */    /* То есть займёт 2 столбца */    grid-column: 1 / 3;}

Если вам нужно, чтобы элемент занял все доступные столбцы (например, шапка сайта), можно использовать ключевое слово span или отрицательные числа. Но проще всего использовать конструкцию 1 / -1 - от первой линии до последней.

.header {    grid-column: 1 / -1;}

Выравнивание контента внутри ячеек

По умолчанию элементы внутри ячеек растягиваются на всю доступную ширину и высоту. Если нужно это изменить, используются свойства, похожие на Flexbox:

  • justify-items - выравнивает элементы по горизонтали внутри их ячеек (start, end, center, stretch).
  • align-items - выравнивает элементы по вертикали внутри их ячеек.
  • place-items - сокращённая запись для обоих свойств сразу (place-items: center;).

Шпаргалка

Самое важное в одном месте:

  • display: grid включает Grid-контейнер
  • grid-template-columns задаёт столбцы
  • grid-template-rows задаёт строки
  • fr доля свободного пространства
  • repeat(3, 1fr) повторение столбцов
  • gap отступы между ячейками
  • grid-column растягивание по столбцам
  • 1 / -1 растянуть от первой до последней линии

Если что-то не работает

Разберём типичные проблемы при переходе на Grid.

  • «Я написал display: grid, но элементы всё равно идут в столбик». Проверьте, задали ли вы grid-template-columns. Без этого свойства сетка состоит из одного столбца, и элементы просто выстраиваются друг под другом.
  • «Элементы вылезают за пределы контейнера». Если сумма фиксированных размеров (например, в пикселях) больше ширины контейнера, сетка переполнится. Используйте fr для гибкости или minmax() для ограничений.
  • «Не работает grid-column». Свойства позиционирования (grid-column, grid-row) применяются к дочерним элементам, а не к самому контейнеру. Убедитесь, что вы пишете их для правильного селектора.
  • «Я путаюсь в линиях сетки». Линии нумеруются от 1. Если 3 столбца, то линий 4. Если хотите растянуть элемент на все столбцы, проще использовать grid-column: 1 / -1;.
  • «Чем Grid лучше Flexbox?» Ничем. Это разные инструменты. Flexbox - для одномерных раскладок (меню, карточки в ряд), Grid - для двумерных (общий макет страницы, галереи со сложной структурой). Часто их используют вместе.

Если что-то не получается или есть вопрос - напишите в Telegram, разберёмся вместе.

Практика

Четыре задачи. Первые две - на понимание теории, вторые две - на практическое применение.

Задача 1. Расшифруйте код

Что сделает этот CSS-код?

.grid {    display: grid;    grid-template-columns: 200px 1fr;    gap: 20px;}.header {    grid-column: 1 / -1;}
Подсказка

Обратите внимание на ширину столбцов и на то, какую область занимает .header.

Разбор

Код создаёт сетку из двух столбцов: первый фиксированный (200px), второй занимает всё оставшееся место (1fr). Между ними отступ 20px. Элемент .header благодаря 1 / -1 растянется на оба столбца, заняв всю ширину контейнера. Это классический паттерн для шапки сайта.

Задача 2. Grid или Flexbox?

Для каждой задачи выберите, что лучше использовать: Flexbox или Grid.

  1. Выстроить логотип и меню навигации в одну строку.
  2. Создать общий макет страницы: шапка, две колонки (меню и контент), подвал.
  3. Галерея карточек товаров, которая автоматически переносит карточки на новую строку при сужении экрана.
  4. Расположить иконку и текст внутри кнопки строго по центру.
Подсказка

Если задача включает управление и строками, и столбцами одновременно (двумерность) - это Grid. Если элементы просто идут в ряд или в колонку - это Flexbox.

Разбор
  1. Flexbox. Одномерная раскладка в строку.
  2. Grid. Двумерная сетка с шапкой и подвалом на всю ширину.
  3. Grid. Свойство grid-template-columns: repeat(auto-fill, minmax(250px, 1fr)) (которое вы изучите чуть позже) идеально для таких галерей. Flexbox тоже справится, но с Grid будет аккуратнее.
  4. Flexbox. Идеальное центрирование содержимого через justify-content: center и align-items: center.
Задача 3. Создайте макет страницы

В вашем проекте создайте HTML-структуру:

<div class="layout">    <header class="header">Шапка</header>    <aside class="sidebar">Меню</aside>    <main class="main">Контент</main>    <footer class="footer">Подвал</footer></div>

Используя Grid, сделайте так, чтобы шапка и подвал занимали всю ширину, меню было слева (200px), а контент - справа (оставшееся место).

Подсказка

Используйте grid-template-columns: 200px 1fr; для родителя. А для шапки и подвала добавьте grid-column: 1 / -1;.

Разбор

CSS:

.layout {    display: grid;    grid-template-columns: 200px 1fr;    gap: 10px;}.header, .footer {    grid-column: 1 / -1;    background: #eee;    padding: 20px;}.sidebar {    background: #ddd;    padding: 20px;}.main {    background: #ccc;    padding: 20px;}
Задача 4. Сложная сетка

Создайте контейнер с 4 ячейками (две строки, два столбца). Сделайте так, чтобы первый элемент занимал всю верхнюю строку (оба столбца), а второй элемент занимал первый столбец, но растягивался на две строки вниз.

Подсказка

Для первого элемента используйте grid-column: 1 / -1;. Для второго - grid-row: span 2; (или укажите конкретные линии).

Разбор

HTML:

<div class="complex-grid">    <div class="box box1">1</div>    <div class="box box2">2</div>    <div class="box box3">3</div>    <div class="box box4">4</div></div>

CSS:

.complex-grid {    display: grid;    grid-template-columns: 1fr 1fr;    gap: 10px;}.box1 {    grid-column: 1 / -1;}.box2 {    grid-row: span 2;}

Обратите внимание: Grid автоматически размещает оставшиеся элементы (3 и 4) в свободных ячейках, заполняя сетку.

Что мы узнали и что дальше

Grid - это невероятно мощный инструмент, который изменил подход к вёрстке. Теперь вы умеете создавать двумерные сетки, управлять столбцами и строками, использовать единицы fr для гибкости и растягивать элементы на несколько ячеек.

Вы поняли главное отличие: Flexbox - для одномерных раскладок (в линию), Grid - для двумерных (сетки). И научились комбинировать их, что является признаком профессионала.

В следующем уроке мы займёмся позиционированием. Разберём, как вырвать элемент из общего потока и разместить его поверх других элементов (например, модальное окно или всплывающую подсказку). А также познакомимся с z-index - свойством, которое управляет слоями.
