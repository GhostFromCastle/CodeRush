Введение в CSS

~30 минут Начальный уровень Теория и Практика

До этого момента мы работали только с HTML. И если вы посмотрите на свою страницу сейчас, то увидите чёрный текст на белом фоне, стандартные шрифты и синие ссылки. Это выглядит как документ из прошлого века.

Пришло время это исправить. Сегодня мы познакомимся с CSS - языком, который отвечает за внешний вид. Если HTML - это скелет и внутренние органы, то CSS - это внешность, одежда и макияж. Именно CSS делает сайты красивыми и непохожими друг на друга.

Что такое CSS

CSS расшифровывается как Cascading Style Sheets - каскадные таблицы стилей. Это язык, который описывает, как должны выглядеть элементы на странице.

С помощью CSS мы можем:

  • Менять цвет текста и фона.
  • Задавать размеры шрифтов.
  • Добавлять отступы и рамки.
  • Располагать элементы в нужном порядке.
  • Добавлять анимации и переходы.

Три способа подключения CSS

Есть три способа сказать браузеру, как оформлять страницу. Мы разберём все, но использовать в реальной работе будем только один - самый правильный.

1. Встроенные стили (Inline)

Самый простой способ - написать CSS прямо в атрибуте style HTML-тега.

<p style="color: red; font-size: 18px;">Этот текст красный и крупный.</p>

Плюсы: быстро, видно сразу. Минусы: если у вас 100 параграфов, вы замучаетесь писать стили каждому. Смешивается код разметки и оформления. Использовать: почти никогда, кроме очень редких случаев.

2. Внутренние стили (Internal)

Стили пишутся внутри тега <style>, который находится в <head> документа.

<head>    <style>        p {            color: blue;        }    </style></head>

Плюсы: все стили в одном месте, в одном файле. Минусы: подходит только для одной страницы. Если у вас сайт из 10 страниц, придётся дублировать стили. Использовать: для маленьких тестовых страничек.

3. Внешние стили (External)

Самый правильный и профессиональный способ. Вы создаёте отдельный файл с расширением .css и подключаете его к HTML.

Как это делается:

  1. В папке с вашим проектом создайте файл styles.css.
  2. В HTML-файле, внутри тега <head>, добавьте тег <link>.
<link rel="stylesheet" href="styles.css">

В атрибуте href указывается путь к файлу. Если файлы в одной папке, достаточно написать просто название.

Главная мысль

Всегда используйте внешние стили. Это делает код чистым, позволяет переиспользовать стили на всех страницах сайта и упрощает поддержку.

Синтаксис CSS: анатомия правила

CSS состоит из набора правил. Каждое правило выглядит так:

селектор {    свойство: значение;}

Например:

h1 {    color: #ff5a00;    font-size: 32px;}

Что здесь что:

  • h1 - селектор. Он говорит: "примени стили ко всем тегам h1 на странице".
  • color и font-size - свойства. Это то, что мы хотим изменить.
  • #ff5a00 и 32px - значения. Это то, на что мы хотим изменить.

Обратите внимание: после свойства ставится двоеточие, после значения - точка с запятой. А всё правило заворачивается в фигурные скобки.

Селекторы: как выбрать элемент

Самый важный момент в CSS - это правильно выбрать элемент, к которому применить стили. Разберём три основных типа селекторов.

1. Селектор по тегу

Применяется ко всем тегам на странице с указанным именем.

p {    color: gray;}

Все параграфы станут серыми.

2. Селектор по классу

Самый популярный способ. Вы придумываете имя классу, ставите его через атрибут class в HTML, а в CSS обращаетесь к нему через точку.

<!-- В HTML --><p class="highlight">Этот текст будет выделен.</p>/* В CSS */.highlight {    background-color: yellow;}

Классы можно использовать многократно. Если вы добавите class="highlight" нескольким параграфам, все они получат жёлтый фон.

3. Селектор по id

Похож на класс, но используется для уникальных элементов. На странице может быть только один элемент с конкретным id. В CSS обращаемся через решётку #.

<!-- В HTML --><h1 id="main-title">Главный заголовок</h1>/* В CSS */#main-title {    text-transform: uppercase;}

Используйте id редко - в основном для якорей или для уникальных элементов, к которым нужен прямой доступ из JavaScript.

Цвета и шрифты

Разберём самые частые свойства, которые вы будете использовать.

Цвет текста и фона

  • color - цвет текста.
  • background-color - цвет фона.

Цвет можно задавать разными способами:

  • Словами: red, blue, black. Но названий всего около 140, и точные оттенки запомнить сложно.
  • HEX-кодом: #ff0000 (красный), #000000 (чёрный), #ffffff (белый). Это самый популярный способ. Код начинается с решётки, дальше 6 символов (0-9 и a-f).
  • RGB: rgb(255, 0, 0) - красный. Указывается количество красного, зелёного и синего от 0 до 255.

Размер и семейство шрифта

  • font-size - размер шрифта. Обычно в пикселях: 16px, 24px, 32px.
  • font-family - семейство шрифта. Например, Arial, Verdana, sans-serif.
  • font-weight - толщина шрифта: normal (обычный), bold (жирный) или цифры от 100 до 900.
  • line-height - межстрочный интервал. Отвечает за то, насколько свободно дышит текст. Обычно задают в процентах или безразмерным числом: 1.5.

Шпаргалка

Самое важное в одном месте:

  • CSS язык стилей
  • <link> подключение внешних стилей
  • Селектор выбор элемента (тег, класс, id)
  • .class селектор по классу
  • #id селектор по уникальному id
  • color цвет текста
  • background-color цвет фона
  • font-size размер шрифта

Если что-то не работает

Разберём типичные ошибки новичков при работе с CSS.

  • «Я написал стили, но ничего не изменилось». Проверьте три вещи: 1) Сохранили ли вы файл .css (Ctrl+S)? 2) Подключили ли вы его через <link>? 3) Правильно ли написан селектор (совпадает ли класс или тег)?
  • «Стили не применяются, хотя всё написано верно». Откройте инструменты разработчика в браузере (F12 или правая кнопка мыши -> «Посмотреть код»). Там видно, какие стили применены к элементу. Если ваш стиль зачёркнут - значит, его перебивает другой стиль (каскад).
  • «Я забыл точку перед классом». В CSS класс пишется с точкой: .my-class. Если написать my-class (без точки), браузер будет искать тег с таким названием, не найдёт и ничего не применит.
  • «Почему цвет не меняется?» Проверьте, не забыли ли вы точку с запятой после значения. Или не опечатались ли в названии свойства (например, colour вместо color).
  • «У меня не подключается файл styles.css». Проверьте путь в href. Если файл лежит в той же папке, что и HTML, просто href="styles.css". Если в папке css, то href="css/styles.css".

Если что-то не получается или есть вопрос - напишите в Telegram, разберёмся вместе.

Практика

Четыре задачи. Первые две - на понимание теории, вторые две - на практическое применение.

Задача 1. Подключите CSS

В папке вашего проекта создайте файл styles.css. В файле index.html внутри <head> добавьте тег <link>, чтобы подключить стили.

Подсказка

Тег <link> - одиночный. У него обязательно должны быть атрибуты rel="stylesheet" и href="styles.css".

Разбор

В <head> вашего HTML должно появиться:

<link rel="stylesheet" href="styles.css">

Чтобы проверить, что всё работает, добавьте в CSS любой стиль, например, body { background-color: #f0f0f0; } и сохраните оба файла. Если фон страницы изменился - вы всё сделали правильно.

Задача 2. Стилизуйте заголовок

Используя CSS, сделайте так, чтобы все теги <h1> на странице были тёмно-синего цвета (#1a365d) и имели размер 36px.

Подсказка

Используйте селектор по тегу h1 и свойства color и font-size.

Разбор

В файле styles.css:

h1 {    color: #1a365d;    font-size: 36px;}
Задача 3. Используйте класс

Создайте в HTML параграф с классом intro. В CSS задайте этому классу серый цвет текста (#666666) и размер шрифта 18px.

Подсказка

Класс в HTML задаётся атрибутом class="intro". В CSS обращаемся к нему через точку: .intro.

Разбор

HTML:

<p class="intro">Этот текст будет серым и крупным.</p>

CSS:

.intro {    color: #666666;    font-size: 18px;}
Задача 4. Найдите ошибки

Посмотрите на CSS-код. В нём есть три ошибки, из-за которых стили не применятся. Найдите и исправьте их.

h1 {    colour: red;    font-size 24px;}my-class {    background-color: blue;}
Подсказка

Проверьте: правильность написания свойства (английские слова), наличие двоеточия и точки перед классом.

Разбор

Ошибки:

  1. Опечатка в слове color. Правильно: color, а не colour.
  2. Пропущено двоеточие. После font-size должно быть двоеточие.
  3. Нет точки перед классом. Правильно: .my-class.

Исправленный код:

h1 {    color: red;    font-size: 24px;}.my-class {    background-color: blue;}

Что мы узнали и что дальше

Сегодня мы сделали огромный шаг вперёд! Мы перестали работать с голым HTML и добавили в нашу жизнь краски. Теперь вы знаете, что такое CSS, как его подключить и как применять стили к элементам.

Мы разобрали три способа подключения (и поняли, что внешний - самый правильный), познакомились с синтаксисом правил и научились менять цвет и размер шрифта.

Вы также узнали, что такое селекторы (по тегу, по классу и по id) и почему классы используются чаще всего. Это база, на которой строится вся дальнейшая работа.

Но пока элементы на странице стоят вплотную друг к другу. Мы не умеем управлять отступами - расстоянием между элементами и внутри них. В следующем уроке мы изучим блочную модель - главную концепцию CSS, без которой невозможно построить ни один красивый макет.
