Собираем первую страницу

~35 минут Начальный уровень Теория и Практика

Поздравляю! Вы дошли до финального урока начального уровня. Мы изучили много теории: теги, структуру, семантику, CSS-селекторы и блочную модель. Но, как говорится, теория без практики мертва.

Сегодня мы не будем учить новые теги или свойства. Вместо этого мы соберём настоящий проект - карточку товара. Это будет выглядеть как маленький кусочек интернет-магазина. Мы применим всё, что узнали, и вы увидите, как отдельные кирпичики складываются в красивую и аккуратную конструкцию.

Шаг 1. Продумываем структуру (HTML)

Прежде чем писать код, давайте представим, из чего состоит карточка товара. Нам понадобится:

  • Изображение товара (картинка).
  • Название товара (заголовок).
  • Краткое описание (параграф).
  • Характеристики в виде списка.
  • Кнопка "Купить" (ссылка).

Всю эту карточку логично обернуть в семантический тег <article>, ведь это независимая единица контента. Для стилизации мы дадим ей класс card.

Вот HTML-код. Скопируйте его в ваш файл index.html (внутри <body>):

<article class="card">    <img src="https://picsum.photos/400/300" alt="Кофе в зёрнах" class="card-image">    <div class="card-content">        <h2 class="card-title">Кофе в зёрнах "Арабика"</h2>        <p class="card-desc">Отборные зёрна из Колумбии. Средняя обжарка, идеально для турки или кофемашины.</p>        <ul class="card-features">            <li>Вес: 250 г</li>            <li>Степень обжарки: средняя</li>            <li>Страна: Колумбия</li>        </ul>        <a href="#" class="card-btn">Купить за 500 ₽</a>    </div></article>

Обратите внимание: мы обернули текст и кнопку в отдельный <div> с классом card-content. Зачем? Чтобы потом мы могли задать отступы содержимому, не затрагивая картинку. Картинка будет растянута на всю ширину карточки, а текст будет с отступами внутри.

Шаг 2. Стилизуем карточку (CSS)

Теперь переходим к магии. Откройте ваш файл styles.css. Сначала обязательно добавьте правило для всех элементов, чтобы блочная модель считалась правильно:

* {    box-sizing: border-box;}

Теперь стилизуем саму карточку. Мы зададим ей фон, рамку, скругления, отступы и тень. Кстати, свойство border-radius скругляет углы, а box-shadow добавляет тень. Это то, что делает дизайн современным.

body {    font-family: sans-serif;    background-color: #f0f2f5;    padding: 40px;}.card {    width: 350px;    background-color: #ffffff;    border-radius: 16px;    overflow: hidden;    box-shadow: 0 4px 20px rgba(0, 0, 0, 0.1);    margin: 0 auto;}

Разберём эти свойства:

  • width: 350px; - фиксированная ширина карточки.
  • background-color: #ffffff; - белый фон.
  • border-radius: 16px; - скруглённые углы.
  • overflow: hidden; - это важно! Если картинка будет прямоугольной, а углы карточки скруглёнными, картинка вылезет за них. overflow: hidden обрезает всё, что выходит за границы.
  • box-shadow: 0 4px 20px rgba(0, 0, 0, 0.1); - лёгкая тень для объёма.
  • margin: 0 auto; - это волшебный способ отцентрировать блок по горизонтали.

Теперь стилизуем картинку. Она должна занимать всю ширину карточки.

.card-image {    width: 100%;    height: 200px;    object-fit: cover;}

Свойство object-fit: cover; - это секретное оружие. Оно заставляет картинку заполнить всё пространство, сохраняя пропорции. Без него картинка могла бы сплющиться или растянуться.

Теперь добавим отступы тексту и стилизуем элементы внутри:

.card-content {    padding: 24px;}.card-title {    margin-top: 0;    margin-bottom: 12px;    font-size: 22px;    color: #111111;}.card-desc {    color: #666666;    line-height: 1.5;    margin-bottom: 16px;}.card-features {    padding-left: 20px;    margin-bottom: 24px;    color: #444444;}.card-features li {    margin-bottom: 8px;}

И последний штрих - кнопка. Она должна выглядеть как настоящая кнопка, хотя технически это ссылка <a>.

.card-btn {    display: block;    width: 100%;    padding: 14px;    background-color: #ff5a00;    color: #ffffff;    text-align: center;    text-decoration: none;    border-radius: 8px;    font-weight: bold;}

Свойство display: block; превращает строчную ссылку в блочный элемент, чтобы она заняла всю ширину. text-decoration: none; убирает стандартное подчёркивание у ссылок.

Что у нас получилось

Сохраните оба файла и посмотрите на результат. У вас должна получиться аккуратная белая карточка с тенью, скруглёнными углами, картинкой сверху, текстом, списком и яркой оранжевой кнопкой.

Это уже не просто текст на странице. Это настоящий UI-компонент, который можно использовать в реальном проекте. Похвалите себя - вы проделали большую работу!

Шпаргалка

Самое важное в одном месте:

  • border-radius скругление углов
  • box-shadow тень элемента
  • overflow: hidden обрезает всё, что выходит за границы
  • object-fit: cover картинка заполняет блок без искажений
  • margin: 0 auto центрирование блока по горизонтали
  • display: block делает строчный элемент блочным
  • text-decoration: none убирает подчёркивание у ссылок

Если что-то не работает

Разберём типичные проблемы, которые могут возникнуть при сборке карточки.

  • «Картинка вылезает за скруглённые углы». Забыли добавить overflow: hidden; для класса .card.
  • «Кнопка не растягивается на всю ширину». Ссылки по умолчанию строчные. Добавьте display: block; или display: flex; для класса кнопки.
  • «Кнопка синяя и подчёркнутая». Это стандартные стили ссылки. Сбросьте их через text-decoration: none; и color: #ffffff;.
  • «Картинка искажена (сплющена)». Добавьте object-fit: cover;. Без этого свойства браузер будет растягивать картинку под заданные размеры, игнорируя пропорции.
  • «Текст прилипает к краям». Проверьте, есть ли у .card-content свойство padding. И убедитесь, что этот класс действительно есть в HTML.

Если что-то не получается или есть вопрос - напишите в Telegram, разберёмся вместе.

Практика

Четыре задачи. Первые две - на понимание теории, вторые две - на практическое применение.

Задача 1. Разберитесь в свойствах

Для каждого свойства выберите, за что оно отвечает в карточке товара.

  1. border-radius: 16px;
  2. object-fit: cover;
  3. box-shadow
  4. overflow: hidden;
Подсказка

Вспомните визуальный эффект от каждого свойства: что происходит с углами, картинкой и содержимым, которое выходит за границы.

Разбор
  1. Скругление углов.
  2. Заполнение блока картинкой без искажений.
  3. Добавление тени для объёма.
  4. Обрезка картинки по скруглённым углам.
Задача 2. Как отцентрировать карточку?

В коде урока мы использовали margin: 0 auto; для класса .card. Как вы думаете, почему это работает и что делает каждое из значений?

Подсказка

Свойство margin может принимать четыре значения: сверху, справа, снизу, слева. Что значит auto в контексте отступов?

Разбор

margin: 0 auto; означает: сверху и снизу отступ 0, а слева и справа - автоматический. Браузер берёт оставшееся свободное место и делит его поровну между левым и правым отступами. Так блок встаёт ровно по центру. Это работает только для блочных элементов с заданной шириной.

Задача 3. Измените дизайн

Поиграйте с дизайном вашей карточки:

  1. Измените цвет кнопки с оранжевого на любой другой (например, синий или зелёный).
  2. Сделайте так, чтобы при наведении на кнопку курсор менялся на "руку" (это уже есть по умолчанию для ссылок, но проверьте).
  3. Увеличьте скругление углов у карточки до 24px.
  4. Сделайте описание товара темнее (например, #333333).
Подсказка

Все изменения делаются в CSS-файле. Найдите нужные классы и поменяйте значения свойств background-color, border-radius и color.

Разбор

Пример изменений:

.card {    border-radius: 24px;}.card-btn {    background-color: #2563eb;}.card-desc {    color: #333333;}
Задача 4. Соберите свою карточку

Придумайте свой товар (например, книгу, наушники, кроссовки или курс). Создайте для него карточку по образцу из урока. Измените картинку, название, описание и характеристики.

Подсказка

Можете использовать заглушку для картинки: https://picsum.photos/400/300. Или найдите любую картинку в интернете и скопируйте её адрес.

Разбор

Здесь нет единственно правильного ответа. Главное - чтобы структура осталась правильной (article, заголовок, описание, список, кнопка), а стили применились. Если ваша карточка выглядит аккуратно и соответствует теме товара - вы отлично справились!
