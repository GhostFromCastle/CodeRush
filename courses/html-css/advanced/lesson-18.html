CSS-переменные: управление дизайном

~35 минут Продвинутый уровень Теория и Практика

Представьте, что вы сверстали огромный сайт. У вас 20 страниц, и на всех используется один и тот же оранжевый цвет кнопок (например, #ff5a00). Вы проделали отличную работу.

Но вот заказчик приходит и говорит: «А давайте сделаем кнопки зелёными. И не просто зелёными, а чуть темнее». В этот момент у любого верстальщика начинается паника. Ведь #ff5a00 разбросан по сотням мест в CSS-файлах. Искать и заменять вручную? А вдруг где-то есть похожий цвет, который менять нельзя? Это ад.

Именно для решения этой проблемы придумали **CSS-переменные** (официальное название - кастомные свойства). Это способ хранить значения в одном месте и переиспользовать их по всему проекту.

Как объявить переменную

В CSS переменная создаётся так же, как обычное свойство, но её имя обязательно должно начинаться с двух дефисов --. Значение задаётся через двоеточие.

.card {    --main-color: #ff5a00;    --padding-size: 20px;}

В этом примере мы создали две переменные внутри блока .card. Но сейчас они работают только внутри этого блока. Чтобы они были доступны всему сайту, их нужно объявить в специальном селекторе :root.

Глобальные переменные и :root

:root - это псевдокласс, который указывает на самый главный элемент документа (тег <html>). Переменные, объявленные в :root, наследуются всеми элементами на странице.

:root {    --accent-orange: #ff5a00;    --bg-dark: #0a0a0a;    --text-main: #ffffff;    --radius-md: 16px;}

Чаще всего в переменные выносят:

  • Цвета бренда (основной, акцентный, фоны, текст).
  • Размеры шрифтов (для заголовков, основного текста).
  • Скругления углов (радиусы).
  • Отступы (padding/margin).

Как использовать переменную

Чтобы применить переменную, используется функция var(). Внутри скобок указывается имя переменной.

.btn {    background-color: var(--accent-orange);    color: var(--text-main);    border-radius: var(--radius-md);}

Теперь, если заказчик попросит поменять оранжевый на зелёный, вам достаточно будет изменить одну строчку в :root. Все кнопки на сайте мгновенно перекрасятся!

Запасные значения (Fallback)

Иногда переменная может не сработать (например, вы забыли её объявить или браузер старый). Чтобы сайт не «сломался», можно указать запасное значение через запятую внутри var().

.card {    /* Если переменной нет, будет использован красный цвет */    background-color: var(--card-bg, #ff0000);}

Локальные переменные и переопределение

Самое мощное в CSS-переменных - это каскад. Вы можете переопределить глобальную переменную внутри конкретного блока, и это изменит только этот блок.

:root {    --btn-color: blue;}.btn {    background: var(--btn-color);}.btn-danger {    /* Переопределяем только для этой кнопки */    --btn-color: red;}

Кнопка с классом .btn-danger будет красной, а все остальные кнопки .btn останутся синими.

Практический пример: Тёмная тема

Благодаря переменным, сделать тёмную тему стало невероятно просто. Мы просто меняем значения цветов в зависимости от класса на body (или медиазапроса).

:root {    --bg-main: #ffffff;    --text-main: #000000;}body.dark-theme {    --bg-main: #111111;    --text-main: #ffffff;}body {    background: var(--bg-main);    color: var(--text-main);    transition: background 0.3s, color 0.3s;}

Весь CSS для компонентов (карточек, кнопок, текста) пишется один раз и просто ссылается на эти переменные.

Переменные и JavaScript

CSS-переменные - это часть DOM. Вы можете читать и изменять их через JavaScript. Это позволяет создавать динамические интерфейсы (например, слайдер, который меняет цвет всего сайта).

const root = document.documentElement;root.style.setProperty('--accent-orange', '#10b981');

Этот скрипт мгновенно поменяет акцентный цвет на зелёный во всём документе.

Шпаргалка

Самое важное в одном месте:

  • --имя объявление переменной
  • :root глобальная область видимости
  • var(--имя) использование переменной
  • var(--имя, fallback) запасное значение
  • Каскад переменные можно переопределять
  • Темная тема меняем значения переменных

Если что-то не работает

Разберём типичные проблемы при работе с переменными.

  • «Переменная не работает». Проверьте, что при объявлении вы написали два дефиса (--my-color), а при использовании не забыли функцию var().
  • «В консоли ошибка Invalid property value». Скорее всего, в переменной лежит некорректное значение. Например, вы забыли единицы измерения (20 вместо 20px).
  • «Регистр имеет значение». CSS-переменные чувствительны к регистру. --Main-Color и --main-color - это две разные переменные.
  • «Не срабатывает fallback». Функция var(--var, fallback) использует запасное значение, только если переменная вообще не объявлена. Если она объявлена, но содержит ошибку, fallback не сработает.
  • «Не могу использовать переменную в медиазапросе». В старых браузерах переменные не работали внутри @media. Сейчас это поддерживается, но если вы задаёте переменную для медиазапроса, она должна быть объявлена внутри него: @media (min-width: 768px) { :root { --padding: 40px; } }.

Если что-то не получается или есть вопрос - напишите в Telegram, разберёмся вместе.

Практика

Четыре задачи. Первые две - на понимание теории, вторые две - на создание реальных компонентов.

Задача 1. Найдите ошибку

Разработчик написал такой код, но кнопка не стала красной. Почему?

:root {    main-color: #ff0000;}.btn {    background: var(main-color);}
Подсказка

Посмотрите внимательно на имя переменной в двух местах.

Разбор

Ошибка в том, что при объявлении переменной забыли два дефиса. Должно быть --main-color: #ff0000;.

Задача 2. Где сработает переменная?

Будет ли текст внутри карточки красным?

.card {    --text-color: red;}.title {    color: var(--text-color);}

И изменится ли ситуация, если тег .title находится вне карточки?

Подсказка

Вспомните, что переменные работают по правилам каскада и наследуются потомками.

Разбор

Если .title находится внутри .card, то текст будет красным, так как переменная наследуется.

Если .title находится вне карточки, текст останется стандартным (чёрным), потому что переменная --text-color существует только в области видимости карточки и не видна снаружи.

Задача 3. Создайте систему цветов

Создайте в :root три переменные: --brand-color (оранжевый #ff5a00), --text-main (тёмно-серый #333333), --bg-light (светло-серый #f4f4f4).

Создайте карточку .card, задайте ей фон из --bg-light и цвет текста --text-main. Создайте внутри кнопку .btn, задайте ей фон --brand-color и белый текст.

Подсказка

Не забудьте использовать функцию var() при применении переменных к свойствам.

Разбор 
:root {    --brand-color: #ff5a00;    --text-main: #333333;    --bg-light: #f4f4f4;}.card {    background: var(--bg-light);    color: var(--text-main);    padding: 20px;}.btn {    background: var(--brand-color);    color: white;    padding: 10px 20px;}
Задача 4. Тёмная тема

Используя код из предыдущей задачи, создайте класс .dark. Если добавить этот класс к тегу <body>, фон карточки должен стать тёмным (#222), а текст — белым. Переменные должны меняться, а сами компоненты (карточка и кнопка) переписывать не нужно.

Подсказка

Создайте класс body.dark и переопределите в нём значения переменных --bg-light и --text-main.

Разбор 
body.dark {    --bg-light: #222222;    --text-main: #ffffff;}

Поскольку .card использует var(--bg-light), она автоматически подхватит новое значение, так как класс .dark находится выше по дереву DOM. Это и есть магия каскада переменных.

Что мы узнали и что дальше

CSS-переменные - это фундамент современной, поддерживаемой вёрстки. Теперь вы умеете создавать глобальные и локальные переменные, использовать запасные значения и легко переключать темы оформления.

Вы узнали:

  • Как объявлять переменные через --.
  • Как использовать их через var().
  • Зачем нужен :root.
  • Как работает наследование переменных в DOM.
  • Как сделать простую тёмную тему.

В следующем уроке мы заглянем в **современный CSS**. Вы узнаете про функции clamp(), min() и max() для адаптивной типографики, а также про вложенность (CSS Nesting), которая позволяет писать код в стиле SCSS прямо в обычном CSS.
