Финальный проект: Собираем лендинг

~60 минут Продвинутый уровень Практика

Поздравляю! Вы дошли до финала. За 23 урока мы прошли огромный путь от тега <p> до сложных сеток, анимаций и архитектуры CSS. Но, как говорил один мудрый человек: «Знания без применения — это просто багаж, который тянет вниз».

Шпаргалка

Что мы использовали в этом проекте:

  • Семантика header, main, section, footer
  • БЭМ header__container, btn--primary
  • :root глобальные переменные
  • clamp() адаптивный заголовок
  • Grid auto-fit сетка карточек без медиазапросов
  • background-clip текст с градиентом
  • box-shadow объемные кнопки и карточки

Если что-то не работает

Разберём моменты, которые могут вызвать вопросы при сборке проекта.

  • «Шрифт какой-то скучный». В этом проекте мы не подключали Google Fonts, чтобы код был компактным. В реальной жизни вы бы добавили @import или <link> на красивый шрифт (например, Manrope или Inter) в тег <head>.
  • «Карточки не выстраиваются в один ряд». Проверьте, что у .features__grid задано display: grid. Свойство auto-fit автоматически перенесет карточки, если они не влезают по ширине.
  • «Текст с градиентом не виден». Убедитесь, что вы добавили color: transparent. Без него текст перекроет градиент.
  • «Кнопка не нажимается». Если кнопка сделана через <a> (ссылку), у неё должен быть атрибут href, даже если это пустая ссылка href="#".

Если что-то не получается или есть вопрос - напишите в Telegram, разберёмся вместе.

Практика

Четыре задачи. Это ваши дополнительные шаги к идеальному проекту.

Задача 1. Адаптивность навигации

В нашем коде меню на мобильных устройствах съедет. Напишите медиазапрос для экранов до 768px, который спрячет навигацию (или сделает её столбиком).

Подсказка

Используйте @media (max-width: 768px) и измените flex-direction у списка на column.

Разбор 
@media (max-width: 768px) {    .header__container {        flex-direction: column;        gap: 15px;    }    .nav__list {        flex-direction: column;        text-align: center;    }}
Задача 2. Добавьте секцию тарифов

Добавьте в HTML новую секцию <section id="pricing"> перед подвалом. Создайте внутри две карточки с ценами (например, «Базовый» и «Про»). Стилизуйте их, используя уже созданные классы feature-card.

Подсказка

Вы можете использовать ту же сетку .features__grid, чтобы не писать новые стили для сетки.

Разбор

Структура:

<section class="features" id="pricing">    <div class="container">        <h2 class="section-title">Тарифы</h2>        <div class="features__grid">            <div class="feature-card">                <h3 class="feature-card__title">Базовый</h3>                <p class="feature-card__text">Бесплатно</p>            </div>        </div>    </div></section>
Задача 3. Плавный скролл

Сделайте так, чтобы при клике на ссылки в меню («Возможности», «Тарифы»), страница прокручивалась к нужной секции плавно, а не мгновенно.

Подсказка

Это можно сделать одной строчкой CSS для тега html.

Разбор 
html {    scroll-behavior: smooth;}
Задача 4. Сделайте свой лендинг

Возьмите этот шаблон и переделайте его под свой проект. Например, сделайте страницу для кофейни, фитнес-клуба или онлайн-курса. Поменяйте цвета в :root, заголовки, текст и добавьте свои картинки.
