Препроцессоры: Sass и SCSS

~40 минут Продвинутый уровень Теория и Практика

За время обучения мы написали немало CSS-кода. И вы наверняка заметили: в CSS есть переменные (мы проходили их в 18 уроке), есть нативная вложенность (19 урок). Но исторически так сложилось, что разработчики начали использовать препроцессоры задолго до того, как эти фичи появились в самом CSS.

Препроцессор - это надстройка над CSS, которая добавляет ему возможности языка программирования: миксины (функции), математические операции, циклы и многое другое. Самый популярный препроцессор сегодня - это Sass (а его синтаксис называется SCSS).

Главное правило: браузеры не понимают SCSS. Вы пишете код в файле .scss, а затем специальная программа (компилятор) превращает его в обычный .css, который уже подключается к HTML.

Переменные в SCSS

В CSS переменные объявляются через два дефиса (--main-color). В SCSS для этого используется знак доллара ($).

Разница в том, когда они работают. CSS-переменные живут в браузере (их можно менять через JavaScript). SCSS-переменные работают только на этапе компиляции. Они нужны, чтобы вам было удобно писать код, но в итоговом CSS их не будет (компилятор просто подставит нужные значения).

$brand-color: #ff5a00;$text-dark: #333333;.btn {    background-color: $brand-color;    color: $text-dark;}

Вложенность (Nesting)

Мы уже знаем, что нативный CSS теперь поддерживает вложенность. В SCSS она работает точно так же, но появилась намного раньше. Символ & ссылается на родителя.

.card {    padding: 20px;    .title {        font-size: 24px;    }    &:hover {        background: #eee;    }}

Миксины (Mixins)

Это, пожалуй, самая мощная фича SCSS. Миксин - это блок стилей, который можно переиспользовать. Представьте, что у вас есть код для центрирования элемента (Flexbox). Вы можете создать миксин и вызывать его одной строчкой.

Создаётся миксин через @mixin, а вызывается через @include.

@mixin flex-center {    display: flex;    justify-content: center;    align-items: center;}.header {    @include flex-center;    height: 80px;}.modal {    @include flex-center;    height: 100vh;}

Миксины могут принимать аргументы. Это делает их похожими на настоящие функции.

@mixin button($bg-color) {    background-color: $bg-color;    padding: 10px 20px;    border-radius: 5px;    color: white;}.btn-primary {    @include button(#ff5a00);}.btn-secondary {    @include button(#2563eb);}

Функции для работы с цветом

В SCSS встроены полезные функции. Например, чтобы сделать цвет темнее или светлее, не нужно искать HEX-код в фотошопе.

.btn {    background-color: $brand-color;    &:hover {        background-color: darken($brand-color, 10%);    }}

Как это использовать?

Поскольку браузер не понимает SCSS, вам нужен компилятор. Если вы работаете в VS Code, проще всего установить расширение Live Sass Compiler.

После установки внизу появится кнопка Watch Sass. Вы нажимаете на нее, и расширение автоматически компилирует ваш style.scss в style.css каждый раз, когда вы сохраняете файл. В HTML вы подключаете уже скомпилированный style.css.

Шпаргалка

Самое важное в одном месте:

  • SCSS синтаксис препроцессора Sass
  • $var переменная в SCSS
  • @mixin создание функции со стилями
  • @include вызов миксина
  • darken() затемнение цвета
  • Live Sass Compiler компилятор для VS Code

Если что-то не работает

Разберём типичные проблемы новичков при работе с препроцессорами.

  • «Я написал код, но браузер его не видит». Вы подключили к HTML файл .scss. Браузеры не умеют их читать. В HTML нужно подключать скомпилированный файл .css.
  • «Компилятор выдает ошибку». Проверьте синтаксис. В SCSS обязательно ставить точку с запятой после свойств и закрывать фигурные скобки. Если вы забыли импортировать миксин или переменную, компилятор сообщит, что они не найдены.
  • «Миксин не применяется». Убедитесь, что вы написали @include перед именем миксина. Просто написать имя (flex-center;) не сработает.
  • «Зачем мне SCSS, если в CSS уже есть переменные и вложенность?» Это отличный вопрос. Если вы делаете небольшой проект, вам может хватить и чистого CSS. SCSS нужен в крупных проектах, где важны миксины, математические вычисления, циклы и разбиение стилей на десятки маленьких файлов (partials).

Если что-то не получается или есть вопрос - напишите в Telegram, разберёмся вместе.

Практика

Четыре задачи. Первые две - на понимание теории, вторые две - на написание SCSS-кода.

Задача 1. Что выведет компилятор?

Какой CSS-код получится после компиляции этого SCSS?

$color: red;.box {    color: $color;        &:hover {        color: blue;    }}
Подсказка

Вспомните, как работает символ & и что происходит с переменными при компиляции.

Разбор 
.box {    color: red;}.box:hover {    color: blue;}

Переменная $color заменилась на red, а &:hover превратилось в .box:hover.

Задача 2. Создайте миксин

Напишите миксин с именем text-style, который принимает два аргумента: размер шрифта и цвет. Примените этот миксин к классу .title с размером 24px и красным цветом.

Подсказка

Используйте @mixin text-style($size, $color).

Разбор 
@mixin text-style($size, $color) {    font-size: $size;    color: $color;}.title {    @include text-style(24px, red);}
Задача 3. Вложенность и миксины

Создайте SCSS-код для карточки .card. Внутри неё должен быть заголовок h2 синего цвета. При наведении на карточку её фон должен меняться на светло-серый. Используйте вложенность.

Подсказка

Вложите h2 и &:hover внутрь .card.

Разбор 
.card {    padding: 20px;    border: 1px solid #ccc;    h2 {        color: blue;    }    &:hover {        background: #eee;    }}
Задача 4. Попробуйте скомпилировать

Если у вас установлен VS Code, установите расширение Live Sass Compiler. Создайте файл style.scss, напишите там любой код с переменными, нажмите кнопку "Watch Sass" внизу редактора и посмотрите, как рядом автоматически появится файл style.css. Подключите его к HTML и проверьте результат.

Подсказка

Компилятор обычно создает файлы в той же папке или в папке dist. Проверьте настройки расширения, если файл не появляется.

Разбор

Препроцессоры - это мощный инструмент, который делает написание CSS быстрее и приятнее. Теперь вы знаете, что такое переменные, вложенность и миксины в SCSS, и как компилировать их в обычный CSS.

Вы узнали:

  • Чем SCSS отличается от чистого CSS.
  • Как создавать и использовать переменные через $.
  • Как работают миксины (@mixin и @include).
  • Как использовать функции вроде darken().
  • Как компилировать SCSS с помощью Live Sass Compiler.
