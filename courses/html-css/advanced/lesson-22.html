Оптимизация: скорость и производительность

~40 минут Продвинутый уровень Теория и Практика

Скорость загрузки сайта - это не просто техническая метрика. Это то, что напрямую влияет на конверсию и удобство. По статистике, если сайт грузится дольше 3 секунд, половина пользователей просто закроет вкладку. Поисковые системы (Google, Яндекс) тоже понижают рейтинг медленных сайтов.

Главная проблема медленных сайтов - это картинки и шрифты. Сегодня мы разберём, как «сжать» наш чемодан, чтобы он летел со скоростью света.

1. Оптимизация изображений

Картинки - это 80% веса большинства страниц. Если вы загрузите фото с телефона (5 МБ) на сайт, пользователь будет ждать его вечность.

Современные форматы: WebP и AVIF

Старый добрый JPEG хорош, но у него есть более современные конкуренты. WebP и AVIF сжимают картинку в 2-3 раза сильнее при том же качестве. Они поддерживаются всеми современными браузерами.

Чтобы показать картинку в новом формате, но оставить запасной вариант для старых браузеров, используется тег <picture>, который мы проходили ранее:

<picture>    <source srcset="image.avif" type="image/avif">    <source srcset="image.webp" type="image/webp">    <img src="image.jpg" alt="Описание"></picture>

Ленивая загрузка (Lazy Loading)

Зачем грузить картинку, которая находится в самом низу страницы, если пользователь до нее еще не доскроллил? Атрибут loading="lazy" решает эту проблему. Браузер загрузит картинку только тогда, когда она появится в поле зрения.

<img src="photo.jpg" alt="Фото" loading="lazy">
Важно

Никогда не ставьте loading="lazy" на главную картинку в самом верху страницы (например, на логотип или баннер). Она должна загружаться сразу, иначе это замедлит отображение главного экрана.

2. Оптимизация шрифтов

Когда вы подключаете Google Fonts или локальные шрифты, браузеру нужно время, чтобы их скачать. Пока он это делает, текст может быть невидимым (эффект FOIT - Flash of Invisible Text).

Решается это свойством font-display. Самое популярное значение - swap. Оно говорит браузеру: «Сначала покажи системный шрифт, а когда скачается наш красивый, плавно замени его».

@font-face {    font-family: 'MyFont';    src: url('my-font.woff2') format('woff2');    font-display: swap;}

Кстати, формат WOFF2 - это самый современный и сжатый формат шрифтов для веба. Всегда используйте его.

3. Критический CSS (Critical CSS)

Браузер не может отрисовать страницу, пока не скачает весь CSS. Если ваш файл стилей весит 500 КБ, пользователь увидит белый экран на несколько секунд.

Смысл Critical CSS в том, чтобы вынести стили для «первого экрана» (то, что видно сразу) в тег <style> прямо в HTML, а остальные стили подключить асинхронно внизу страницы.

<head>    <!-- Стили для шапки и первого экрана -->    <style>        .header { background: #fff; }    </style>        <!-- Остальной CSS грузится в фоне -->    <link rel="stylesheet" href="style.css" media="print" onload="this.media='all'"></head>

4. Кэширование (Caching)

Когда пользователь заходит на сайт во второй раз, он не должен скачивать картинки и CSS заново. Браузер должен взять их из своего кэша.

Для этого на сервере настраиваются заголовки Cache-Control. Если вы используете GitHub Pages, за вас это делает сервер. Но есть важный лайфхак: в имя файла добавляют хеш (уникальный набор символов).

Пример: style.a1b2c3d4.css. Если вы обновите файл, изменится хеш: style.e5f6g7h8.css. Браузер увидит новое имя и скачает свежую версию, а старые файлы пользователи будут брать из кэша мгновенно.

Шпаргалка

Самое важное в одном месте:

  • WebP / AVIF современные форматы картинок
  • loading="lazy" отложенная загрузка
  • font-display: swap показ текста до загрузки шрифта
  • Critical CSS быстрая отрисовка первого экрана
  • Cache-Control управление кэшем браузера
  • Minification удаление пробелов из кода

Если что-то не работает

Разберём типичные проблемы оптимизации.

  • «Картинка загружается слишком долго». Проверьте её вес. Если она весит больше 200-300 КБ, её нужно сжать. Можно использовать сервисы вроде TinyPNG, Squoosh или конвертировать в WebP.
  • «loading="lazy" сломал скролл». Такое бывает, если у картинки не заданы размеры (width и height). Браузер не знает, сколько места она займет, и страница «прыгает». Всегда задавайте размеры или aspect-ratio.
  • «Текст прыгает при загрузке шрифта». Это эффект FOUT (Flash of Unstyled Text). Уменьшить его поможет настройка size-adjust в @font-face, чтобы системный шрифт по размерам совпадал с кастомным.
  • «Стили не применились после Critical CSS». Убедитесь, что ссылка на основной файл стилей стоит после тега <style> и что скрипт onload сработал корректно.

Если что-то не получается или есть вопрос - напишите в Telegram, разберёмся вместе.

Практика

Четыре задачи. Первые две - на понимание теории, вторые две - на практическое применение.

Задача 1. Выберите формат

Для каждой ситуации выберите лучший формат изображения.

  1. Фотография товара для интернет-магазина (нужна максимальная скорость).
  2. Логотип компании (нужна прозрачность и чёткость).
  3. Простая иконка в меню.
Подсказка

Для фото и прозрачности нужны разные форматы.

Разбор
  1. AVIF или WebP (идеально для фото, отличное сжатие).
  2. SVG (векторный формат, не теряет качество при масштабировании) или WebP.
  3. SVG (идеально для иконок).
Задача 2. Что не так с кодом?

Разработчик оптимизировал страницу, но скорость загрузки главного экрана упала. Найдите ошибку.

<img src="logo.png" alt="Логотип" loading="lazy"><h1>Добро пожаловать</h1>
Подсказка

Вспомните, какие изображения должны загружаться в первую очередь.

Разбор

Ошибка в том, что к логотипу применили loading="lazy". Логотип находится на первом экране, он должен загружаться моментально. Из-за ленивой загрузки браузер отложит его скачивание, и пользователь увидит пустое место вместо логотипа.

Задача 3. Внедрите lazy loading

Возьмите страницу с длинным контентом (например, список из 20 картинок). Добавьте всем картинкам, кроме первой, атрибут loading="lazy". Убедитесь, что у них заданы width и height (или CSS aspect-ratio), чтобы страница не «прыгала».

Подсказка

Откройте вкладку Network в инструментах разработчика (F12). При прокрутке страницы вы увидите, как новые картинки начинают загружаться только тогда, когда до них доходит экран.

Разбор

Это отличный способ сэкономить трафик пользователя (особенно на мобильном интернете). Главное - не забыть про размеры.

Задача 4. Настройте шрифты

Представьте, что вы подключаете локальный шрифт через @font-face. Напишите код, который будет использовать современный формат woff2 и предотвратит исчезновение текста во время загрузки шрифта.

Подсказка

Используйте свойство font-display: swap.

Разбор 
@font-face {    font-family: 'MyFont';    src: url('fonts/myfont.woff2') format('woff2');    font-weight: 400;    font-style: normal;    font-display: swap;}
