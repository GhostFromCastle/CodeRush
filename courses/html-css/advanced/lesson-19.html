Современный CSS: функции и селекторы

~40 минут Продвинутый уровень Теория и Практика

Если вы посмотрите на код сайтов пятилетней давности, вы увидите горы медиазапросов и сложные хаки. Современный CSS позволяет делать то же самое, но в разы элегантнее и короче.

В этом уроке мы разберём функции для математических вычислений, селектор родителя (который все ждали 20 лет) и нативную вложенность. Эти знания позволят вам писать код, который выглядит как профессиональный SCSS, но работает в обычном браузере.

Псевдокласс :root и специфичность

Прежде чем нырять в современные функции, давайте уточним один важный момент про :root, который мы использовали в прошлом уроке. Многие путают его с обычным тегом html.

:root - это псевдокласс, который указывает на корневой элемент документа (в HTML это всегда <html>). Так зачем использовать его, если можно просто написать html { ... }?

Всё дело в специфичности. Специфичность - это «вес» селектора. Чем он выше, тем сложнее перебить стиль.

  • Селектор по тегу html имеет специфичность (0, 0, 1).
  • Псевдокласс :root имеет специфичность (0, 1, 0).

То есть :root «сильнее» обычного тега. Если в вашем проекте кто-то (или вы сами) напишет html { --main-color: red; }, а в другой библиотеке есть :root { --main-color: blue; }, то победит синий цвет.

Поэтому в современной разработке принято объявлять глобальные переменные именно в :root, чтобы их случайно не перебил какой-нибудь менее специфичный селектор.

:root {    /* Эта переменная будет защищена от случайного перезаписывания */    --accent-orange: #ff5a00;}

Математика в CSS: clamp, min, max

Раньше, чтобы шрифт плавно уменьшался на мобильных, нам приходилось писать несколько медиазапросов. Теперь для этого есть функция clamp().

clamp(минимум, предпочтительно, максимум) - это функция, которая ограничивает значение в заданных пределах.

h1 {    /* Минимум 24px, максимум 56px, а между ними - 5% от ширины экрана */    font-size: clamp(24px, 5vw, 56px);}

Это магия: на маленьком экране шрифт будет ровно 24px, на огромном - 56px, а при изменении окна он будет плавно масштабироваться.

Похожие функции - min() и max():

  • width: min(100%, 800px); - блок будет не шире 800px, но на мобильном сожмётся до 100%.
  • width: max(50%, 300px); - блок будет не уже 300px, даже если 50% экрана меньше.

Свойство aspect-ratio

Раньше, чтобы сделать контейнер с фиксированными пропорциями (например, для ютуб-видео), использовали трюк с padding-top: 56.25%. Сейчас достаточно одного свойства:

.video-wrapper {    width: 100%;    aspect-ratio: 16 / 9;    background: #000;}

Блок будет всегда сохранять пропорции 16:9, независимо от ширины экрана.

Селектор родителя :has()

Долгое время в CSS нельзя было стилизовать родителя в зависимости от его детей. Это приходилось делать через JavaScript. Теперь есть псевдокласс :has().

Синтаксис: родитель:has(дочерний_элемент).

/* Карточка, внутри которой есть картинка */.card:has(img) {    display: flex;    flex-direction: row;}/* Форма, в которой хотя бы одно поле в фокусе */.form:has(input:focus) {    border-color: #ff5a00;}

Это открывает невероятные возможности для создания интерактивных интерфейсов без единой строчки JS.

Нативная вложенность (CSS Nesting)

В уроке 13 мы уже упоминали, что CSS теперь поддерживает вложенность. Символ & (амперсанд) ссылается на родительский селектор.

.card {    padding: 20px;    background: white;    /* Наведение на карточку */    &:hover {        box-shadow: 0 10px 20px rgba(0,0,0,0.1);    }    /* Заголовок внутри карточки */    h2 {        color: var(--text-main);    }}

Код стал намного читабельнее. Больше не нужно дублировать имя класса .card на каждой строчке.

Логические свойства (Logical Properties)

Раньше мы использовали margin-left (слева) и margin-right (справа). Но что, если пользователь переключит язык сайта на арабский или иврит, где текст пишется справа налево? Сайт сломается.

Современный подход - использовать логические свойства:

  • margin-inline-start - отступ в начале строки (слева для нас, справа для арабов).
  • margin-inline-end - отступ в конце строки.
  • padding-block - отступы сверху и снизу (по вертикали).
.btn {    padding-inline: 20px; /* Аналог padding-left и padding-right */    padding-block: 10px; /* Аналог padding-top и padding-bottom */}

Шпаргалка

Самое важное в одном месте:

  • :root корневой элемент с высокой специфичностью
  • clamp() адаптивный размер в пределах
  • min() / max() выбор наименьшего/наибольшего
  • aspect-ratio сохранение пропорций блока
  • :has() селектор родителя
  • & нативная вложенность
  • padding-inline логический отступ по горизонтали
  • padding-block логический отступ по вертикали

Если что-то не работает

Разберём типичные проблемы с современным CSS.

  • «clamp() не работает, шрифт слишком большой». Проверьте порядок аргументов: сначала минимум, потом предпочтительное, потом максимум. Если минимум больше максимума, функция может выдать непредсказуемый результат.
  • «:has() не работает в старом браузере». Это правда. :has() появился в браузерах только в 2023 году. Если нужна поддержка очень старых устройств, придётся использовать JS или менее элегантные CSS-хаки.
  • «Вложенность не применяется». Если вы пишете :hover без амперсанда внутри класса, браузер может подумать, что вы ищете элемент :hover внутри него. Всегда используйте &:hover.
  • «Я использую 5vw для отступов, и на широком экране они становятся огромными». Всегда оборачивайте vw в clamp() или max().
  • «Logical properties ломают вёрстку». Если вы используете абсолютное позиционирование с left/right, логические свойства не сработают. Они работают только с margin, padding, border.

Если что-то не получается или есть вопрос - напишите в Telegram, разберёмся вместе.

Практика

Четыре задачи. Первые две - на понимание функций, вторые две - на создание компонентов с :has() и вложенностью.

Задача 1. Разберите clamp()

Какой размер шрифта будет у заголовка на экране шириной 1200px?

h2 {    font-size: clamp(20px, 4vw, 40px);}
Подсказка

Посчитайте, сколько будет 4% от 1200px, и сравните с минимумом и максимумом.

Разбор

4vw от 1200px - это 48px. Но наша функция ограничена максимумом в 40px. Значит, шрифт будет ровно 40px.

Задача 2. Специфичность :root

Какой цвет будет у текста в этом коде и почему?

html {    --main-color: red;}:root {    --main-color: blue;}p {    color: var(--main-color);}
Подсказка

Вспомните про вес селекторов (специфичность).

Разбор

Текст будет синим. Несмотря на то, что html написан первым, псевдокласс :root имеет более высокую специфичность (0,1,0), чем тег html (0,0,1). Поэтому его значение перебивает красный цвет.

Задача 3. Интерактивная форма

Создайте форму с классом .login-form, внутри которой есть поле ввода input. С помощью селектора :has() сделайте так, чтобы при фокусе на поле ввода (когда пользователь кликнул и печатает) вся форма получала синюю рамку (border: 2px solid #2563eb).

Подсказка

Селектор должен выглядеть так: .login-form:has(input:focus).

Разбор 
.login-form {    border: 2px solid #ccc;    transition: border-color 0.3s;}.login-form:has(input:focus) {    border-color: #2563eb;}
Задача 4. Вложенность и пропорции

Создайте блок .video-card. Используя нативную вложенность, сделайте внутри него заголовок h3 (красного цвета) и блок .video-box с соотношением сторон 16 / 9 и серым фоном. При наведении на .video-card заголовок должен становиться синим.

Подсказка

Используйте &:hover и вложите в него h3.

Разбор 
.video-card {    padding: 20px;    h3 {        color: red;    }    .video-box {        aspect-ratio: 16 / 9;        background: #eee;    }    &:hover {        h3 {            color: blue;        }    }}
